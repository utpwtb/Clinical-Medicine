# 临床医学考研 306 笔记 · 真题导向版

> **定位**：二轮刷题配套的**考点精讲 + 避坑手册**。以【考点】为组织单位，五段式：常考题型与命题角度 → 核心结论（加粗锚点）→ 陷阱与干扰项 → 一句话辨析 → 模拟示例题。
> **诚信声明**：本版所有示例题均为**自编模拟题（非真题）**，只描述"常考法"与"常见陷阱"，不声称引用任何年份真题原文。
> **306 题型速览**：满分 300 分、180 分钟、165 题。A 型题 1–40（每题 1.5 分）+ 41–115（每题 2 分，含病例题）；B 型题 116–135（每题 1.5 分）；X 型题 136–165（每题 2 分，多选/少选均不得分）。

## 三套版本怎么配合用

| 阶段 | 用哪套 | 怎么用 |
|---|---|---|
| 一轮 | 讲义精讲版 + 教材 | 建立框架 |
| **二轮** | **真题导向版（本版）** + 成套真题 | 先做题→对答案→只回看做错考点对应条目→重点读"陷阱与干扰项" |
| 冲刺 | 背诵手册版 | 过速记总表 |
| 考前 | 本版各文件末尾【陷阱清单】 | 快速过一遍命题坑位 |
