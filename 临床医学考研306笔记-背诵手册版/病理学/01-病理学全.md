# 病理学 · 背诵手册版——全考点表解

> 定位：306统考冲刺背诵手册，覆盖总论（适应损伤、修复、血循障碍、炎症、肿瘤）与各论（各系统疾病+传染病寄生虫）。
> 用法：按章背四列表格；考前过【速记总表】"病变-疾病"配对；用【易混对照】【记忆口诀】收尾。

## 总论

### 1. 细胞和组织的适应

| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
|---|---|---|---|
| 萎缩 | 发育正常的细胞体积缩小（可伴数目减少） | 营养不良性、压迫性、废用性、去神经性、内分泌性、老化和损伤性 | 萎缩属可逆性改变 |
| 肥大 | 细胞体积增大、功能增强 | 高血压左心室向心性肥大 | 肥大常与增生并存 |
| 增生 | 细胞数目增多 | 子宫内膜增生、甲状腺增生 | — |
| 化生 | 一种成熟细胞/组织被另一种成熟细胞/组织取代 | 慢支鳞状上皮化生；慢性胃炎肠上皮化生 | 只发生于同源细胞间、可逆、有癌变倾向 |
| 适应的意义 | 均为可逆性改变 | 去除病因多可恢复 | — |
| 假性肥大 | 实质萎缩+间质脂肪结缔组织增生致器官体积增大 | — | 与真性肥大机制不同 |

### 2. 可逆性损伤（变性）

| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
|---|---|---|---|
| 细胞水肿 | 线粒体肿胀、内质网扩张 | 病毒性肝炎气球样变 | 最常见的轻度变性 |

| 玻璃样变 | 均质红染的玻璃样蛋白蓄积 | 三处：细动脉壁（高血压）、结缔组织（瘢痕）、细胞内 | 细胞内者：Mallory小体（酒精性肝病）、Russell小体（浆细胞） |
| 淀粉样变 | 淀粉样蛋白（β-折叠）沉积 | 刚果红染色阳性 | — |
| 黏液样变 | 黏多糖与蛋白质蓄积 | 间叶组织肿瘤间质 | — |
| 含铁血黄素 | 巨噬细胞内含铁血黄素沉积 | 左心衰肺淤血=心衰细胞 | 心衰细胞吞噬的是红细胞 |
| 脂褐素 | 自噬溶酶体内不溶性色素 | 老年与萎缩细胞（心脏褐色萎缩） | — |
| 黑色素 | 黑色素细胞合成 | 黑色素瘤、色素痣 | — |
| 营养不良性钙化 | 钙盐沉积于变性坏死组织或异物 | 全身钙磷代谢正常 | 见于结核干酪坏死、粥瘤 |
| 转移性钙化 | 高血钙致正常组织钙盐沉积 | 甲状旁腺功能亢进 | — |
| 病理性色素总结 | 含铁血黄素、脂褐素、黑色素、胆红素 | 胆红素沉积=黄疸 | — |
| 虎斑心vs脂肪浸润 | 虎斑心=心肌脂肪变呈条纹；脂肪浸润=心外膜脂肪长入心肌间 | — | 两者是不同概念 |

## 【易混对照】

| 组别 | 一句话辨析 |
|---|---|
| 肥大vs增生 | 肥大=细胞体积增大；增生=细胞数目增多，两者常并存 |
| 凝固性vs干酪样vs液化性坏死 | 凝固性轮廓保留（心肝肾）；干酪样最彻底（结核）；液化性变液（脑、脓肿） |
| 干性vs湿性vs气性坏疽 | 干性=四肢、分界清、中毒轻；湿性=肠肺子宫、中毒重；气性=产气荚膜梭菌、捻发音 |
| 贫血性vs出血性梗死 | 贫血性=终末动脉+致密器官（心脾肾脑）；出血性=双血供/疏松+淤血（肺肠） |
| 蜂窝织炎vs脓肿 | 蜂窝织炎=链球菌、弥漫；脓肿=金葡菌、局限 |
| 癌vs肉瘤 | 癌=上皮、常见、淋巴道转移、巢状；肉瘤=间叶、少见、血道转移、弥漫 |
| 葡萄胎vs侵蚀性葡萄胎vs绒癌 | 葡萄胎限于宫腔；侵蚀性葡萄胎侵肌层且有绒毛；绒癌无绒毛无间质、血道转移 |
| 流脑vs乙脑 | 流脑=细菌、蛛网膜下腔脓性炎；乙脑=病毒、脑实质灰质炎（蚊传播） |
| 肠道溃疡四联 | 肠结核环形垂直、伤寒平行椭圆、菌痢地图浅、阿米巴烧瓶状 |
| A型vs B型胃炎 | A型=自身免疫、胃体、恶性贫血；B型=HP、胃窦、肠化与胃癌相关 |
| 桥本vs亚急性甲状腺炎 | 桥本=淋巴+生发中心、无痛；亚甲炎=肉芽肿+巨细胞、疼痛 |
| 乳头状vs髓样甲状腺癌 | 乳头状=砂粒体毛玻璃核、淋巴转移、预后最好；髓样=C细胞降钙素、MEN2 |
| 肉芽组织vs肉芽肿 | 肉芽组织=毛细血管+成纤维细胞（修复）；肉芽肿=巨噬细胞结节（慢性炎症） |
| 心衰细胞vs尘细胞 | 心衰细胞=肺淤血时吞噬含铁血黄素的巨噬细胞；尘细胞=吞噬炭末的巨噬细胞 |
| 原位癌vs浸润癌 | 原位癌未突破基底膜、不转移；浸润癌已突破基底膜、可转移 |
