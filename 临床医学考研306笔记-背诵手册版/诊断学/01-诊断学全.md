## 模块一 症状学

### 1.1 发热分度
| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
| --- | --- | --- | --- |
| 低热 | 口温轻度升高 | 37.3-38℃ | ≥37.3℃才算发热 |
| 中度发热 | 中等程度升高 | 38.1-39℃ | 与低热分界为38℃ |
| 高热 | 高温持续 | 39.1-41℃ | |
| 超高热 | 极度升高 | >41℃ | |

### 1.2 热型六种-疾病配对
| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
| --- | --- | --- | --- |
| 稽留热 | 高热恒定，24h波动<1℃ | 伤寒、大叶性肺炎 | 波动<1℃是判定关键 |
| 弛张热 | ≥39℃，24h波动>2℃，最低点仍高于正常 | 败血症、风湿热、重症肺结核 | 又称败血症热型 |
| 间歇热 | 骤升骤降，高热期与无热期交替 | 疟疾、急性肾盂肾炎 | 与回归热区别：升降更急骤 |
| 波状热 | 体温渐升渐降、反复多次 | 布鲁氏菌病 | 无骤升骤降过程 |
| 回归热 | 高热与无热各持续数日规律交替 | 霍奇金淋巴瘤（周期热） | 霍奇金=Pel-Ebstein热 |
| 不规则热 | 发热无规律可循 | 结核病、风湿热、支气管肺炎、渗出性胸膜炎 | 风湿热两型热均可见 |

### 1.3 发热与昏迷先后

| 昏迷后发热 | 体温调节中枢受损 | 脑出血 | 先昏后热≠感染 |

### 1.12 意识障碍分级
| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
| --- | --- | --- | --- |
| 嗜睡 | 最轻的意识障碍 | 可唤醒、能正确回答，刺激去除后迅速再睡 | 病理性倦睡 |
| 意识模糊 | 定向力障碍 | 思维语言不连贯，可有错觉幻觉躁动 | 嗜睡基础上＋定向障碍 |
| 昏睡 | 近乎不省人事 | 强刺激可唤醒、答非所问，停止刺激即睡 | 需强痛刺激方能唤醒 |
| 浅昏迷 | 意识大部分丧失 | 声光刺激无反应、痛刺激有防御反应、生理反射存在 | 角膜反射与对光反射仍在 |
| 中度昏迷 | 介于浅深之间 | 强痛刺激防御反射减弱、对光反射迟钝 | |
| 深昏迷 | 最重的意识障碍 | 全身肌肉松弛、一切刺激无反应、深浅反射均消失 | 仅存自主呼吸心跳 |
| 谵妄 | 以兴奋性增高为主 | 意识模糊＋定向力丧失＋幻觉躁动 | 急性脑病综合征表现 |

## 模块二 体格检查

### 2.1 叩诊五音
| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
| --- | --- | --- | --- |
| 清音 | 含气量正常 | 正常肺部叩诊音 | |
| 鼓音 | 含大量气体 | 气胸、靠近胸壁的肺大空洞、胃泡区 | 气胸叩鼓音 |
| 过清音 | 含气增多弹性下降 | 肺气肿、哮喘发作 | 正常成人工叩不出 |

| 实音 | 完全不含气 | 大量胸腔积液、肺实变 | 绝对浊音 |

## 【易混对照】
| 组 | 两者区别要点 |
| --- | --- |
| 心源性vs肾源性水肿 | 心源性自下垂部位起、伴颈静脉怒张；肾源性晨起眼睑颜面起、伴尿改变 |
| 压迫性vs阻塞性肺不张 | 压迫性（胸腔积液上方）语颤增强＋异常支气管呼吸音；阻塞性语颤减弱、无支气管呼吸音 |
| 胸膜vs心包摩擦音 | 胸膜摩擦音屏气消失；心包摩擦音屏气不消失、与心搏一致 |
| 左室大vs右室大 | 左室大心尖冲动向左下；右室大仅向左、可略向上 |
| Austin-Flint vs Graham-Steell | A-F=主闭致心尖相对性二狭；G-S=肺高压致肺动脉瓣区相对性肺闭 |
| 二度Ⅰ型vsⅡ型AVB | Ⅰ型PR渐长后脱落、多功能性；Ⅱ型PR恒定突然脱落、需起搏 |
| 血管内vs血管外溶血 | 血管内游离Hb↑结合珠蛋白↓含铁血黄素尿；血管外间接胆红素↑尿胆原↑ |
| 洋地黄效应vs中毒 | 效应=鱼钩样ST、治疗剂量表现；中毒=室早二联律等心律失常、须停药 |
| Ⅰ型vsⅡ型呼衰 | Ⅰ型仅PaO2<60；Ⅱ型PaO2<60＋PaCO2>50 |
| 结核性vs恶性胸水 | 结核性ADA>45、淋巴细胞为主；恶性血性、CEA↑、pH>7.4 |
