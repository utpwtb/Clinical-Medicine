# 外科学·背诵手册版——04 胸部外科

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：肋骨骨折/连枷胸、气胸三型、血胸、创伤性窒息、脓胸、肺癌与食管癌外科。

## 一、肋骨骨折与连枷胸

| 项目 | 要点 |
|---|---|
| 好发 | 第 4~7 肋骨（长而固定） |
| 单处骨折处理 | 止痛＋胸带固定，鼓励咳痰 |
| 连枷胸定义 | 多根多处肋骨骨折→局部胸壁软化 |
| 反常呼吸 | 吸气时软化区胸壁内陷、呼气时外突；纵隔摆动→循环紊乱 |
| 处理 | 止痛＋固定软化胸壁（牵引/内固定）＋保持气道通畅；呼吸衰竭者机械通气 |

## 二、气胸三型（必背）

| 项目 | 闭合性（单纯性） | 交通性（开放性） | 张力性（高压性） |
|---|---|---|---|
| 胸膜腔与外界 | 通道闭合 | 持续相通 | 单向活瓣，气体只进不出 |
| 症状 | 相对轻 | 持续漏气 | 进行性加重、严重呼吸困难、皮下气肿 |
| 体征 | 患侧呼吸音↓ | 胸壁伤口"嘶嘶"漏气 | 患侧饱满、气管向健侧移、呼吸音消失 |
| 现场处理 | 观察/穿刺抽气 | 封闭伤口变开放为闭合 | ⚠ 立即用粗针于患侧锁骨中线第 2 肋间穿刺排气救命 |
| 后续 | 肺压缩大者闭式引流 | 清创缝合＋闭式引流 | 闭式引流 |
| ⚠ | 张力性气胸必须先排气再拍片 | | |

| 胸腔闭式引流 | 要点 |
|---|---|
| 排气位置 | 患侧锁骨中线第 2 肋间 |
| 排液位置 | 腋中线与腋后线之间第 6~8 肋间 |
| 水封瓶 | 长管入水 3~4 cm；引流瓶低于胸腔引流口 60 cm 以上 |
| 观察 | 水柱随呼吸波动；持续大量气体逸出→警惕支气管/肺裂伤 |
| 拔管 | 引流停止后 24 h，夹管观察无呼吸困难 |

## 三、血胸（必背）

| 项目 | 要点 |
|---|---|
| 分级（成人） | 小量<500 ml；中量 500~1000 ml；大量>1000 ml |
| 特征 | 胸腔积液体征＋失血表现；胸穿抽出血液可确诊 |
| 胸腔积血 | 因心肺运动去纤维蛋白而不凝固；⚠ 迅速凝固提示活动性出血 |
| 进行性血胸指征① | 持续脉搏加快、血压下降，或补充血容量后血压仍不稳定 |
| 进行性血胸指征② | 闭式引流量>200 ml/h，持续 3 h |
| 进行性血胸指征③ | Hb、红细胞计数、血细胞比容进行性降低；引流液 Hb 接近外周血且迅速凝固 |
| 进行性血胸处理 | 及时剖胸探查止血 |
| 感染性血胸 | 发热等感染征象＋引流液涂片/培养发现细菌 |
| 凝固性血胸 | 血块机化前尽早清除（伤后早期手术） |
| 慢性/机化 | 胸膜纤维板剥脱 |

## 四、创伤性窒息与肺爆震伤

| 项目 | 要点 |
|---|---|
| 机制 | 胸腹部猛烈挤压瞬间声门紧闭→胸内压骤升→上腔静脉血逆流→头颈上胸毛细血管破裂 |
| 表现 | 面颈部、上胸部瘀点瘀斑＋结膜下出血 |
| 预后 | 多数对症处理可恢复；⚠ 重点排查合并胸部其他损伤 |

## 五、脓胸

| 项目 | 要点 |
|---|---|
| 病程 | 渗出期→纤维素期→机化期 |
| 确诊 | 胸腔穿刺（脓液＋培养） |
| 急性治疗 | 抗生素＋彻底引流（量大/脓液稠→闭式引流） |
| 慢性治疗 | 胸膜纤维板剥脱术；ⓘ 全身营养支持 |

## 六、肺癌外科要点

| 病理类型 | 特点 | 治疗 |
|---|---|---|
| 鳞癌 | 多为中央型，与吸烟相关，生长较慢、转移较晚 | 以手术为主的综合治疗 |
| 腺癌 | 多为周围型，女性不吸烟者也常见 | 早期手术；晚期靶向/免疫 |
| 小细胞癌 | 恶性度高、转移早 | ⚠ 以化疗+放疗为主，手术价值有限 |
| 大细胞癌 | 少见、恶性度高 | 综合治疗 |

| 手术要点 | 内容 |
|---|---|
| 标准术式 | 肺叶切除＋系统性淋巴结清扫 |
| 中央型贴近大血管 | 袖式肺叶切除 |
| 全肺切除 | 慎重；对肺功能要求高 |
| 手术适应 | 以非小细胞肺癌 Ⅰ~Ⅱ 期为主；小细胞肺癌首选化疗放疗 |
| ⚠ | 术前评估心肺功能；纵隔淋巴结转移影响术式选择 |

## 七、食管癌

| 项目 | 要点 |
|---|---|
| 好发部位 | 食管中段（我国以鳞癌为主） |
| 早期症状 | 咽下哽噎感、胸骨后烧灼/针刺样痛、异物感 |
| 中晚期标志 | ⚠ 进行性吞咽困难（先固体后流质）＋消瘦 |
| 晚期表现 | 压迫喉返神经→声嘶；侵犯气管→食管气管瘘（饮水呛咳）；左锁骨上淋巴结 |
| 确诊 | 食管镜（胃镜）+活检——金标准 |
| 钡餐表现 | 黏膜皱襞中断破坏、充盈缺损、管壁僵硬狭窄、龛影 |
| 早期筛查 | 高发区食管脱落细胞（拉网）检查 |
| 手术 | 食管癌切除＋胃代食管（多行颈部吻合） |
| 放疗地位 | 颈段、上段食管癌以放疗为主（手术损伤大） |
| 术前放化疗 | 局部进展期可降期后再手术 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 三型气胸 | 闭合：通道已闭 | 交通：持续相通；张力：单向活瓣最危 | 张力性先救命后检查 |
| 排气 vs 排液引流 | 锁骨中线第 2 肋间 | 腋中线~腋后线第 6~8 肋间 | "气上二、液下六八" |
| 闭合 vs 进行性血胸 | 抽出后稳定 | >200 ml/h×3 h、Hb 持续降 | 看引流量动态 |
| 鳞癌 vs 小细胞 | 中央型、转移晚、可手术 | 恶性度高、化疗敏感、手术少 | 治疗路线完全不同 |
| 食管癌 vs 食管静脉曲张 | 进行性吞咽困难、黏膜中断 | 肝病史、串珠样、无僵硬 | 钡餐形态与病史 |

## 【记忆口诀】

- 气胸三型："闭合能关、交通直通、张力只进不出"——张力性先穿刺救命。
- 引流位置："气走二肋锁中线，液到六八腋中线"。
- 进行性血胸三联看："血不稳、量不止、Hb 不升"——>200 ml/h 持续 3 h 剖胸。
- 连枷胸："吸陷呼突，纵隔乱摆；止痛固定保气道"。
- 食管癌："早期哽噎火烧胸，晚期咽难一线通；胃镜活检定乾坤"。
