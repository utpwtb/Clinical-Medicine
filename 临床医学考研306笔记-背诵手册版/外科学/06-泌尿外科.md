# 外科学·背诵手册版——06 泌尿外科

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：泌尿系损伤、结石、结核、泌尿男生殖系肿瘤、BPH、鞘膜积液与精索静脉曲张。

## 一、泌尿系损伤

| 项目 | 肾损伤 | 膀胱损伤 | 尿道损伤 |
|---|---|---|---|
| 常见原因 | 腰腹部钝性伤 | 充盈时受暴力、骨盆骨折 | 骑跨伤/骨盆骨折 |
| 核心表现 | 腰痛+血尿 | 排尿困难、尿外渗 | 排尿困难+尿道口滴血 |
| ⚠ 关键 | 血尿程度不与伤情平行（肾蒂伤可无血尿） | 腹膜内型=尿性腹膜炎 | 见下表 |
| 首选检查 | 增强 CT（分型首选） | 膀胱造影（确诊）；注水试验 | 逆行尿道造影 |
| 保守治疗 | 大多数可保守：绝对卧床 2~4 周 | 小裂口留置导尿持续引流 | 前尿道试插导尿管（成功留置） |
| 手术指征 | 休克难纠正、贯通伤、合并腹腔脏器伤、严重尿外渗 | 保守失败/腹膜内型 | 造瘘/会师/吻合 |

| 项目 | 前尿道损伤 | 后尿道损伤 |
|---|---|---|
| 部位 | 球部多见 | ⚠ 膜部 |
| 机制 | 骑跨伤 | 骨盆骨折最常见合并伤 |
| 尿道口 | 滴血明显 | 少量流血 |
| 尿外渗 | 会阴浅筋膜下（会阴、阴囊、阴茎、下腹壁） | 耻骨后间隙/盆腔（腹膜外） |
| 伴随 | 会阴部肿痛 | 骨盆骨折+休克、膀胱充盈 |
| 处理 | 试插软质导尿管；失败→耻骨上膀胱造瘘 | ⚠ 不宜反复试插：耻骨上造瘘或尿道会师；后期尿道修复 |

| 膀胱损伤分型 | 特点 |
|---|---|
| 腹膜内型 | 膀胱顶部破裂→尿液入腹腔→尿性腹膜炎 |
| 腹膜外型 | 膀胱前壁破裂→耻骨后尿外渗+盆腔血肿 |
| 注水试验 | 导尿注入定量盐水，出入量不符提示破裂 |

## 二、泌尿系结石（必背）

| 部位表现 | 要点 |
|---|---|
| 肾/输尿管结石 | 肾绞痛（阵发性、向下腹/会阴放射）+血尿（肉眼少、镜下多） |
| 输尿管膀胱壁段结石 | 膀胱刺激征 |
| 膀胱结石 | ⚠ 排尿突然中断（典型）+疼痛放射至阴茎头 |
| 尿道结石 | 排尿困难/尿潴留 |

| 检查 | 要点 |
|---|---|
| 超声 | 首选筛查 |
| CT 平扫 | 确诊金标准（含透 X 线结石） |
| KUB+IVP | 尿酸结石为阴性结石（不显影） |

| 治疗阶梯 | 适应证 |
|---|---|
| ①保守排石 | 结石<6 mm：大量饮水（>2000 ml/d）+坦索罗辛（α 阻滞剂）+NSAIDs（肾绞痛首选，如双氯芬酸） |
| ②ESWL | 肾结石<2 cm、输尿管上段结石——首选体外冲击波碎石 |
| ESWL 禁忌 | 妊娠、凝血功能障碍、泌尿系感染急性期、结石远端尿路梗阻、严重心脑血管疾病 |
| ③URS | 输尿管中下段结石首选；软镜（RIRS）处理肾内结石 |
| ④PCNL | ⚠ 肾结石>2 cm、鹿角形/复杂性肾结石首选 |
| ⚠ 石街 | ESWL 后大量碎屑堆积输尿管所致 |

| 结石成分 | 要点 |
|---|---|
| 草酸钙 | 最常见；不透 X 线 |
| 磷酸镁铵（鸟粪石） | ⚠ 感染性结石——变形杆菌尿素酶分解尿素；碱性尿 |
| 尿酸 | 透 X 线（阴性结石）；碱性尿中溶解——枸橼酸钾碱化+低嘌呤 |
| 胱氨酸 | 碱化尿液；家族性 |
| 预防 | 大量饮水；草酸钙限草酸限钠；噻嗪类利尿剂降低尿钙 |

## 三、泌尿系结核

| 项目 | 要点 |
|---|---|
| 感染途径 | 血行感染，继发于肺结核 |
| 核心规律 | 病变在肾脏、症状在膀胱 |
| 最早症状 | ⚠ 尿频（进行性加重）→尿急尿痛 |
| 血尿 | 终末血尿 |
| 脓尿 | 米汤样（无菌性脓尿——普通培养阴性） |
| 影像 | IVP：肾盏虫蚀样破坏→空洞→肾自截（全肾钙化、无功能） |
| 确诊 | 尿找抗酸杆菌/结核培养 |
| 治疗 | 抗结核药物（短程方案约 6 个月）为基础；肾切除：广泛破坏/无功能肾 |
| ⚠ 晚期 | 膀胱挛缩（尿频极重）→抗痨后行膀胱扩大术 |

## 四、泌尿男生殖系肿瘤（必背）

| 项目 | 肾癌（肾细胞癌） | 肾盂/输尿管癌 | 膀胱癌 |
|---|---|---|---|
| 病理 | 透明细胞癌为主（VHL 基因相关） | 移行（尿路上皮）癌 | ⚠ 移行（尿路上皮）癌占 90% 以上 |
| 典型表现 | 血尿+腰痛+肿块（三联征，现已少见） | 无痛性肉眼血尿 | ⚠ 间歇性无痛性全程肉眼血尿（最常见/最早） |
| 特殊 | 副瘤综合征：红细胞增多（EPO）、高钙、高血压、肝功异常 | 术后易膀胱内复发 | 吸烟是最明确危险因素；膀胱刺激征提示弥漫病变 |
| 诊断 | 增强 CT 首选 | 输尿管镜+活检 | 膀胱镜+活检（金标准）；尿细胞学 |
| 手术 | 根治性肾切除（±腔静脉癌栓取栓）；⚠ 保肾手术（NSS）：T1a≤4 cm 或双侧肿瘤 | 肾+输尿管全长+膀胱袖状切除 | NMIBC：TURBT+膀胱灌注（中高危 BCG）；MIBC：根治性膀胱切除+尿流改道 |
| 晚期 | ⚠ 对放化疗不敏感→靶向（舒尼替尼等）/免疫 | 化疗 | GC 方案化疗/免疫 |
| ⚠ | 肾癌可靶向；膀胱癌复发率高需定期膀胱镜随访 | | |

| 项目 | 前列腺癌 | 睾丸肿瘤 |
|---|---|---|
| 好发 | 老年男性；腺癌、位于外周带 | 青年（20~35 岁）；隐睾为危险因素 |
| 表现 | 常无症状；DRE 可及质硬结节；⚠ 骨转移为成骨性（腰椎骨盆） | 无痛性睾丸肿大、质硬 |
| 标志物 | PSA>4 ng/ml 需进一步检查（4~10 为灰区）；Gleason 评分（2~10，越高越差） | AFP、HCG 升高（非精原细胞瘤常见） |
| 确诊 | 超声引导穿刺活检 | 高危：AFP/HCG/LDH 检查 |
| 治疗 | 低危：主动监测；局限：根治性切除/放疗；进展：⚠ 内分泌治疗（去势+抗雄激素）；CRPC：新型内分泌药/化疗 | 根治性睾丸切除经腹股沟切口（⚠ 不经阴囊）；精原细胞瘤放疗敏感；非精原细胞瘤 BEP 方案化疗 |

## 五、良性前列腺增生（BPH）

| 项目 | 要点 |
|---|---|
| 部位 | ⚠ 移行带（前列腺增生）/外周带（前列腺癌） |
| 最早症状 | 尿频（夜尿增多） |
| 主症 | ⚠ 进行性排尿困难（排尿费力、尿线细、滴沥） |
| 并发 | 急性尿潴留、血尿、膀胱结石、肾积水、肾功能不全 |
| 直肠指检 | 腺体增大、表面光滑、质韧、中央沟变浅/消失 |
| 超声 | 测体积+残余尿（残余尿>50 ml 提示治疗考虑手术的参考） |
| 尿流率 | Qmax<15 ml/s 提示梗阻 |
| PSA | BPH 可轻度升高；用于排除前列腺癌 |

| BPH 药物对比 | 机制/用途 | 注意 |
|---|---|---|
| α₁ 受体阻滞剂（坦索罗辛、多沙唑嗪） | 松弛前列腺与膀胱颈平滑肌——起效快、改善症状 | ⚠ 体位性低血压 |
| 5α 还原酶抑制剂（非那雄胺、度他雄胺） | 抑制睾酮转双氢睾酮——缩小前列腺体积（大腺体者） | 起效慢（需数月）；⚠ 使 PSA 下降约 50%（影响筛查判读） |
| 手术 | TURP——金标准（中小体积腺体）；巨大腺体/合并膀胱憩室结石→开放手术 | 激光剜除（HoLEP）等渐多 |

| TUR 综合征 | 要点 |
|---|---|
| 机制 | 冲洗液（不含电解质）经创面大量吸收→稀释性低钠血症+水中毒 |
| 表现 | 烦躁、恶心、意识障碍、血压升高后下降 |
| 处理 | 停止手术、限水、利尿、补充高渗盐水 |
| ⚠ 急性尿潴留导尿 | 缓慢放尿（先放约 500 ml，之后间断放完），防膀胱出血/虚脱 |

## 六、鞘膜积液与精索静脉曲张

| 项目 | 鞘膜积液 | 精索静脉曲张 |
|---|---|---|
| 本质 | 鞘膜腔内液体积聚 | 精索内静脉蔓状丛迂曲扩张 |
| 分型 | 睾丸型、精索型、睾丸精索型（婴儿型）、⚠ 交通性（与腹腔相通） | 分度：Ⅰ 触诊需 Valsalva；Ⅱ 触诊可及；Ⅲ 视诊可见 |
| 体征 | 阴囊肿块、透光试验阳性 | 站立时阴囊蚯蚓状团块+坠胀，平卧减轻/消失 |
| ⚠ 鉴别 | 交通性：站立出现、卧位缩小消失；斜疝不透光 | 左侧约 90%（左精索内静脉垂直汇入左肾静脉）；⚠ 继发性（肾肿瘤压迫）平卧不消失 |
| 相关 | 与腹股沟斜疝鉴别 | 可致不育 |
| 治疗 | 交通性：鞘状突高位结扎+鞘膜翻转；非交通性：鞘膜翻转/切除 | 症状明显、Ⅲ 度、合并不育→高位结扎（腹腔镜） |

## 【速记总表】

| 考点 | 必背内容 |
|---|---|
| 肾损伤 | 血尿≠伤情；增强 CT；绝对卧床 2~4 周 |
| 膀胱破裂 | 膀胱造影确诊；腹膜内=尿性腹膜炎 |
| 前尿道损伤 | 球部+骑跨伤+会阴浅袋尿外渗 |
| 后尿道损伤 | 膜部+骨盆骨折；不宜反复插管→造瘘/会师 |
| 肾绞痛首选药 | NSAIDs（双氯芬酸） |
| 保守排石 | <6 mm、多饮水+坦索罗辛 |
| ESWL | <2 cm 肾结石/输尿管上段首选；孕妇禁 |
| URS | 输尿管中下段首选 |
| PCNL | >2 cm、鹿角形肾结石首选 |
| 排尿中断 | 膀胱结石典型症状 |
| 尿酸结石 | 阴性结石；碱化尿液可溶 |
| 感染性结石 | 磷酸镁铵（变形杆菌尿素酶） |
| 肾结核 | 病变在肾、症状在膀胱；尿频最早；米汤样脓尿 |
| 肾自截 | 全肾钙化无功能 |
| 肾癌 | 三联征少见；副瘤综合征；对放化疗不敏感 |
| 保肾手术 | ≤4 cm（T1a）/双侧肿瘤 |
| 肾盂输尿管癌 | 肾+输尿管全长+膀胱袖状切除 |
| 膀胱癌 | 间歇无痛全程肉眼血尿；膀胱镜活检金标准 |
| NMIBC | TURBT+灌注（中高危 BCG） |
| 前列腺癌 | 外周带、PSA、Gleason、成骨性骨转移 |
| 前列腺癌晚期 | 内分泌治疗（去势+抗雄） |
| 睾丸肿瘤 | 腹股沟切口切除；精原细胞瘤放疗敏感；AFP/HCG |
| BPH | 尿频最早、进行性排尿困难主症、移行带 |
| α 阻滞剂 | 起效快；体位性低血压 |
| 5ARI | 缩小体积；PSA 减半 |
| TURP | 金标准；TUR 综合征=稀释性低钠 |
| 残余尿 | >50 ml 提示考虑手术 |
| 鞘膜积液 | 透光试验阳性；交通性平卧消失 |
| 精索静脉曲张 | 左侧 90%；合并不育→高位结扎 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 前尿道 vs 后尿道 | 球部、骑跨伤、会阴部尿外渗 | 膜部、骨盆骨折、盆腔尿外渗 | 部位+暴力方向 |
| 肾癌 vs 肾盂癌 | 透明细胞、增强 CT、靶向 | 尿路上皮、血尿早、袖状切除 | 病理决定术式 |
| 肾癌 vs 前列腺癌骨转移 | 溶骨为主 | ⚠ 成骨性 | 成骨想前列腺 |
| BPH vs 前列腺癌 | 移行带、光滑质韧、中央沟浅 | 外周带、质硬结节、PSA 升高明显 | 指检手感是第一关 |
| 交通性 vs 非交通性鞘膜积液 | 与腹腔相通、卧位消失 | 不相通、卧位不消失 | 体位变化试验 |
| 精索静脉曲张 vs 继发性曲张 | 平卧消失（原发） | 平卧不消失（肾肿瘤压迫） | ⚠ 左侧突发曲张查肾 |

## 【记忆口诀】

- 尿道损伤："前球骑跨会阴渗，后膜骨盆盆腔渗；后尿道伤莫乱插，造瘘会师保平安"。
- 结石阶梯："六毫米下保守喝，两厘米内冲击波；中下输尿管镜走，鹿角大于二用皮肾戳"。
- 肾结核："病变在肾症在膀，尿频最早米汤样；虫蚀空洞终自截，抗痨六月记心上"。
- BPH 与药："α 快来 5α 慢，一个降压一个 PSA 减半"。
- 前列腺癌 vs BPH："移行增生外周癌，光滑是增生、硬节怕癌来"。
- 交通性鞘膜积液："站起出现卧下藏，透光阳性关门窗"。
