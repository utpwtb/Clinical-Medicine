# 外科学·背诵手册版——01 外科总论

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：无菌术、水电酸碱、输血、休克、围术期、营养、外科感染、创伤烧伤、肿瘤总论。

## 一、无菌术

| 项目 | 参数/要点 |
|---|---|
| 灭菌 | 杀灭一切微生物（含芽孢） |
| 消毒 | 杀灭病原微生物，芽孢不一定杀灭 |
| 压力蒸汽灭菌（下排气） | 121 ℃、102.9 kPa、20~30 min（耐湿耐热物品首选） |
| 压力蒸汽灭菌（预真空） | 132~134 ℃、4~6 min |
| 煮沸法 | 100 ℃、15~20 min；芽孢需 60 min |
| 干热灭菌 | 160 ℃、2 h |
| 药液浸泡 | 2% 中性戊二醛：30 min 达消毒、10 h 达灭菌 |
| 常用消毒剂 | 碘伏、酒精、氯己定（属消毒剂，不杀芽孢） |
| 手术区消毒范围 | ≥15 cm；由手术区中心向四周；⚠ 感染伤口/肛门区由四周向中心 |
| 戴手套顺序 | 干手套：先穿手术衣后戴手套；湿手套：先戴手套后穿手术衣 |
| 无菌规则 | 背部、腰部以下、肩部以上视为有菌区；术中污染即重新消毒 |

## 二、体液分布与三型脱水

| 项目 | 数值 |
|---|---|
| 体液占体重 | 男 60%、女 55% |
| 细胞内液 | 40% |
| 细胞外液 | 20%（血浆 5%＋组织间液 15%） |
| 血钠正常 | 135~150 mmol/L |

| 项目 | 等渗性缺水 | 低渗性缺水 | 高渗性缺水 |
|---|---|---|---|
| 又名 | 急性/混合性 | 慢性/继发性 | 原发性 |
| 血钠 | 正常 | <135 mmol/L | >150 mmol/L |
| 丢失特点 | 细胞外液急性丢失 | 失钠>失水 | 失水>失钠 |
| 常见病因 | 呕吐、肠瘘、肠梗阻、烧伤早期 | 反复呕吐、胃肠减压、利尿剂；只补水不补钠 | 高热、大汗、气管切开、尿崩 |
| 口渴 | 不口渴 | 不口渴 | 口渴最早最突出 |
| 特征表现 | 尿少、比重↑、血压下降 | 早期尿量不减少（比重↓）；重者低钠性休克 | 尿比重↑、烦躁谵妄 |
| 治疗原则 | 平衡盐液/等渗盐水 | 补钠：等渗或高渗盐水 | 5% 葡萄糖或 0.45% 盐水 |
| ⚠ | 大量补等渗盐水→高氯性酸中毒，宜用平衡盐 | 补钠公式（142−Na）×体重×0.6（男）/0.5（女），首日补 1/2 | 补水同时适当补钠 |
| 水中毒 | 稀释性低钠：脑水肿（头痛、抽搐）——限水＋袢利尿剂 | | |
| 补液效果判断 | 最可靠指标为尿量（30~40 ml/h）＋CVP＋血压 | | |

## 三、钾异常（必背）

| 项目 | 低钾血症 | 高钾血症 |
|---|---|---|
| 标准 | <3.5 mmol/L | >5.5 mmol/L |
| 病因 | 摄入不足、呕吐腹泻/利尿剂、碱中毒、胰岛素+葡萄糖使 K⁺入胞 | 摄入/输入过多、肾衰排钾↓、酸中毒、溶血、挤压综合征 |
| 肌肉 | 肌无力→软瘫（四肢→躯干→呼吸肌）、肠麻痹 | 神志淡漠、肢体软弱 |
| ECG | T 波低平倒置、U 波增高、ST 压低 | T 波高尖（最早）→QRS 增宽→正弦波→室颤 |
| 尿液特点 | 碱中毒＋反常性酸性尿 | 酸中毒 |
| 心脏风险 | 对洋地黄敏感性↑ | 心搏骤停 |
| 处理原则 | 补钾四原则 | ①停钾→②钙剂→③促转移→④促排出 |

| 补钾四原则 | 具体数值 |
|---|---|
| 不宜过早 | 见尿补钾（尿量>30~40 ml/h） |
| 不宜过浓 | 浓度<0.3%（40 mmol/L） |
| 不宜过快 | 速度<20 mmol/h；严禁静脉推注 |
| 不宜过多 | 每日 3~5 g（40~80 mmol）；能口服尽量口服 |
| ⚠ | 补钾 3~5 天细胞内才平衡；血钾正常≠缺钾纠正 |

| 高钾处理顺序 | 内容 |
|---|---|
| ①停 | 停用一切含钾药物/库血 |
| ②钙 | 10% 葡萄糖酸钙 10~20 ml 静推——拮抗心肌毒性，不降血钾 |
| ③转 | 葡萄糖+胰岛素（1 U 胰岛素 : 3~4 g 糖）；5% NaHCO₃（酸中毒伴高钾） |
| ④排 | 阳离子交换树脂；⚠ 透析最有效（血钾>6.5 mmol/L 指征） |

| 钙镁 | 要点 |
|---|---|
| 低钙 | <2.0 mmol/L（正常 2.25~2.75）；手足搐搦；Chvostek 征（叩面神经口角抽动）；Trousseau 征（袖带加压腕痉挛）；10% 葡萄糖酸钙 |
| 低镁 | 与低钙表现相似；缺镁时低钙难纠正、常伴低钾；硫酸镁 |

## 四、四种酸碱失衡

| 类型 | 病因 | 特征 | 治疗要点 |
|---|---|---|---|
| 代酸 | AG 增高型：乳酸、酮症、尿毒症；AG 正常型（高氯）：腹泻、肾小管酸中毒 | HCO₃⁻<22 mmol/L；呼吸深快（Kussmaul）、酮味 | 治病因；pH<7.15~7.2 或 HCO₃⁻<10 补 NaHCO₃；⚠ 忌过快过量 |
| 代碱 | 呕吐/胃减压失 H⁺失 Cl⁻、低钾、利尿剂 | 低氯低钾＋反常性酸性尿 | 补氯补钾（生理盐水/氯化钾）；重症用稀盐酸/精氨酸 |
| 呼酸 | 通气不足（COPD） | CO₂ 潴留 | 改善通气；慎用 NaHCO₃ |
| 呼碱 | 过度通气（癔症、发热、机械通气过度） | CO₂ 过低 | 镇静、治疗原发病、减少通气 |
| ⚠ 混合 | 呼酸+代碱（COPD+利尿）pH 可正常 | | |

## 五、输血

| 项目 | 要点 |
|---|---|
| 红细胞输注 | 围术期 Hb<70 g/L 考虑输注；Hb>100 g/L 不需；70~100 视情况 |
| 血小板 | <20×10⁹/L 预防性输注；手术/有创操作 <50×10⁹/L |
| 悬浮红细胞 | 最常用；洗涤红细胞——过敏史/IgA 缺乏/PNH；少白红细胞——反复输血发热反应 |
| 新鲜冰冻血浆 | 补充凝血因子 |
| 冷沉淀 | Ⅷ因子＋vWF＋纤维蛋白原；用于血友病 A、血管性血友病、低纤维蛋白原 |
| 配血 | ABO+RhD 血型鉴定＋交叉配血；同型输血；⚠ O 型非"万能供血者" |

| 输血反应 | 特点 | 处理 |
|---|---|---|
| 溶血性（最严重） | ABO 不合即发型：腰背痛、血红蛋白尿、休克、DIC | 立即停止输血＋核对＋抗休克＋水化碱化尿液＋防 DIC，重者透析 |
| 非溶血性发热（最常见） | 白细胞抗体 | 减慢/停止；解热；用少白细胞成分血 |
| 过敏 | IgA 缺乏者多见 | 抗过敏；洗涤红细胞 |
| 细菌污染 | G⁻杆菌、迅速休克 | 立即停止＋抗感染＋抗休克 |
| TRALI | 抗白细胞抗体→ARDS 样肺水肿 | 停止输血、呼吸支持 |
| TA-GVHD | 免疫低下、直系亲属输血 | 预防：辐照血 |
| 循环超负荷 | 老年心衰者快速大量 | 减慢速度 |
| 自体输血 | 预存、血液稀释、回收式 | 回收禁忌：恶性肿瘤、空腔脏器破裂污染 |

## 六、休克

| 项目 | 要点 |
|---|---|
| 本质 | 有效循环血量↓＋组织灌注不足＋细胞代谢紊乱和器官功能障碍 |
| 微循环三期 | 缺血缺氧期（代偿）→淤血缺氧期（失代偿）→DIC 期 |
| 休克指数 | 脉率/收缩压：≈0.5 正常；1.0~1.5 提示休克；>2.0 严重休克 |
| CVP 正常值 | 5~12 cmH₂O |
| 尿量 | <25 ml/h 提示血容量不足；≥30 ml/h 提示休克纠正（最简单可靠监测之一） |
| 乳酸 | 组织缺氧与预后指标；脓毒性休克标准之一为乳酸>2 mmol/L |

| CVP | BP | 判断 | 处理 |
|---|---|---|---|
| ↓ | ↓ | 血容量严重不足 | 充分补液 |
| ↓ | 正常 | 血容量不足 | 适当补液 |
| ↑ | ↓ | 心功能不全/血容量相对过多 | 强心＋扩血管、减慢输液 |
| ↑ | 正常 | 容量血管过度收缩 | 扩血管 |
| 正常 | ↓ | 心功能不全或血容量不足 | 补液试验 |

| 低血容量休克 | 要点 |
|---|---|
| 扩容 | 晶体液（平衡盐）首先→胶体/血制品；Hb<70 g/L 输血 |
| 病因治疗 | 止血为根本；未有效止血前血压不宜升得过高过快——"允许性低血压"（收缩压 80~90 mmHg；⚠ 颅脑损伤除外） |
| 体位 | 头胸 20°＋下肢 15°（V 形体位）；保暖吸氧 |
| 大量输血（24 h≥自身血容量） | 低体温、稀释性凝血病（FFP:RBC:PLT≈1:1:1，损伤控制复苏）、枸橼酸中毒→低钙（补钙）、高钾 |

| 项目 | 暖休克（高动力型） | 冷休克（低动力型） |
|---|---|---|
| 机制 | 血管扩张 | 血管收缩 |
| 皮肤 | 温暖干燥、潮红 | 湿冷、花斑 |
| 脉搏 | 有力（洪） | 细速 |
| 尿量 | 正常偏多 | 少 |
| 常见菌 | G⁺菌感染早期多见 | G⁻菌感染多见、更常见更危险 |

| 感染性休克治疗（1 小时 bundle） | 内容 |
|---|---|
| 抗生素 | 1 h 内留取培养后经验性广谱抗生素 |
| 液体复苏 | 晶体液 30 ml/kg（3 h 内） |
| 升压首选 | ⚠ 去甲肾上腺素（维持 MAP≥65 mmHg）；多巴胺仅用于心动过缓风险低者；心功能不全加多巴酚丁胺 |
| 激素 | 血管活性药依赖时氢化可的松 200 mg/d |
| 监测 | 乳酸清除率、尿量、MAP |

## 七、围手术期处理

| 项目 | 要点 |
|---|---|
| 胃肠道准备 | 术前 12 h 禁食、4 h 禁饮；胃肠道手术术前 1~2 日流质；结直肠术前肠道准备 |
| 特殊准备 | 幽门梗阻者术前洗胃；高血压控制后手术；糖尿病血糖适当控制 |
| 切口分类 | Ⅰ类清洁（甲状腺、疝）；Ⅱ类可能污染（胃肠道、胆道、阴道）；Ⅲ类污染（下消化道穿孔、脓肿、开放伤口） |
| 愈合分级 | 甲：优良；乙：炎症但未化脓；丙：化脓 |
| 拆线时间 | 头面颈 4~5 d；下腹会阴 6~7 d；胸上腹背臀 7~9 d；四肢 10~12 d；减张缝线 14 d |
| 术后体位 | 全麻未醒平卧头偏一侧；颅脑术后头高 15°~30°；颈胸术后高半坐位；腹部术后低半坐位；腰麻后去枕平卧 |
| 尿潴留 | 术后 6~8 h 未排尿应处理：热敷/诱导，无效导尿 |
| 术后发热 | 术后 1~3 天 38 ℃ 左右多为吸收热；3 天后>38.5 ℃ 查感染源（肺不张、切口、导管、DVT） |
| 肺不张 | 鼓励深呼吸、翻身咳痰、雾化 |
| 切口裂开 | 多在术后 1 周左右、咳嗽用力后；预防：腹带、减张缝合；处理：无菌敷料覆盖立即手术缝合 |
| DVT | 预防：早期活动＋气压泵＋弹力袜±低分子肝素 |
| 应激性溃疡 | 重症预防用 PPI |

## 八、外科营养

| 项目 | 要点 |
|---|---|
| 营养不良指标 | BMI<18.5；近 3 个月体重下降>5%；白蛋白<30 g/L |
| 应激代谢 | 高分解、负氮平衡、胰岛素抵抗——不宜过度喂养 |
| EN 优先原则 | 有肠道功能（或部分功能）者优先肠内营养 |
| EN 途径 | 短期：鼻胃管；误吸高风险/需越过幽门：鼻空肠管；长期：造瘘 |
| EN 并发症 | 误吸（防：半卧 30°）、腹泻（防：控制速度浓度温度）、再喂养综合征（低磷低钾低镁——缓慢起始） |
| PN 指征 | 肠道无功能或不能用：肠梗阻、短肠、高流量肠瘘、重症胰腺炎早期 |
| PN 途径 | 短期低渗：周围静脉；>2 周或高渗：中心静脉（CVC/PICC） |
| PN 并发症 | 导管相关感染（导管败血症：拔管＋培养＋抗生素）、高血糖、淤胆/胆囊结石、气栓 |
| 需要量 | 热量 25~30 kcal/kg/d；氮 0.15~0.2 g/kg/d（应激加量）；糖脂双能源 |
| 特殊营养素 | 谷氨酰胺——肠黏膜/免疫；支链氨基酸——肝病；必需脂肪酸 |

## 九、外科感染

| 病名 | 病原 | 部位/特点 | 处理要点 |
|---|---|---|---|
| 疖 | 金葡 | 单个毛囊及其皮脂腺 | ⚠ 面部"危险三角区"疖忌挤压→海绵窦血栓性静脉炎 |
| 痈 | 金葡 | 多个相邻毛囊；糖尿病好发 | "+"/"++"字切口引流 |
| 皮下急性蜂窝织炎 | 溶血性链球菌为主 | 弥漫、边界不清 | 口底/颌下者警惕喉头水肿窒息→早切开 |
| 丹毒 | 乙型溶血性链球菌 | 网状淋巴管炎；边界清楚的片状红疹 | 易复发（下肢，足癣为诱因） |
| 淋巴管炎 | 链球菌/金葡 | 体表"红线" | 治原发感染灶 |
| 脓毒症 | G⁻杆菌、金葡、真菌 | 感染＋器官功能障碍；可寒战高热、瘀斑、转移性脓肿 | 感染源控制＋抗生素（降阶梯）＋液体复苏 |

| 破伤风 | 要点 |
|---|---|
| 病原 | 破伤风梭菌（厌氧芽孢杆菌）——深部窄小伤口 |
| 毒素 | 痉挛毒素→肌张力增高＋阵发性痉挛 |
| 潜伏期 | 通常 6~12 天；⚠ 潜伏期越短预后越差 |
| 最早表现 | 牙关紧闭；随后苦笑面容、角弓反张 |
| ⚠ 关键特征 | 神志始终清楚；轻微刺激可诱发抽搐 |
| 主要死因 | 窒息（喉痉挛）、肺部感染 |
| 治疗 | 清创开放伤口＋3% 过氧化氢；TAT/人破伤风免疫球蛋白中和游离毒素（必须早期）；镇静解痉（地西泮）；抽搐频繁/呼吸不畅尽早气管切开；青霉素/甲硝唑 |
| 预防 | 主动免疫（类毒素）最可靠；被动：TAT（皮试，过敏脱敏）/免疫球蛋白 |

| 气性坏疽 | 要点 |
|---|---|
| 病原 | 产气荚膜梭菌——深部肌肉广泛开放伤 |
| 典型表现 | 胀裂样剧痛、捻发音（皮下气肿）、恶臭血性分泌物 |
| X 线 | 肌群间气体影 |
| 治疗 | 紧急手术清创（广泛切开引流，重者截肢）＋大剂量青霉素＋高压氧 |
| ⚠ | 严格接触隔离 |

| 抗菌药原则 | 内容 |
|---|---|
| 定位 | 不替代清创/引流；能单一不联合 |
| 围术期预防 | 切开前 0.5~2 h 给药（清洁手术常用头孢唑林）；手术>3 h 或出血>1500 ml 追加 |

## 十、创伤要点

| 项目 | 要点 |
|---|---|
| 损伤控制外科（DCS） | 复杂伤：简化手术控制出血污染→ICU 复苏→二期确定性手术 |
| 挤压综合征 | 肌红蛋白尿（酱油色）＋高钾＋急性肾衰；补液＋碱化尿液＋透析；⚠ 解压后防猝死（高钾） |
| 脂肪栓塞综合征 | 长骨骨折后 1~3 天；呼吸窘迫＋神志改变＋前胸颈肩皮肤瘀点；氧疗＋激素＋支持 |

## 十一、烧伤

| 九分法部位 | 占比 |
|---|---|
| 头颈 | 9%（发部 3＋面部 3＋颈部 3） |
| 双上肢 | 18%（双手 5＋双前臂 6＋双上臂 7） |
| 躯干 | 27%（前 13＋后 13＋会阴 1） |
| 双下肢 | 46%（双臀 5＋双大腿 21＋双小腿 13＋双足 7） |
| ⚠ 女性 | 双臀 6%、双足 6%（各+1，相应部位-1） |
| 儿童 | 头颈=9＋(12−年龄)；双下肢=46−(12−年龄) |
| 手掌法 | 患者五指并拢单掌≈体表 1% |

| 深度 | 损伤层次 | 表现 | 愈合 |
|---|---|---|---|
| Ⅰ° | 表皮浅层 | 红斑、干燥、灼痛、无水疱 | 3~7 天脱屑痊愈，无瘢痕 |
| 浅Ⅱ° | 表皮+真皮浅层 | 大水疱、剧痛、基底潮红 | 1~2 周愈合，可有色素沉着无瘢痕 |
| 深Ⅱ° | 真皮深层 | 小水疱、痛觉迟钝、基底红白相间 | 3~4 周愈合，遗留瘢痕 |
| Ⅲ° | 全层及附件 | 蜡白/焦黄炭化、无痛、干燥如皮革、树枝状血管栓塞 | 不能自愈，需植皮 |

| 严重程度 | 标准 |
|---|---|
| 轻度 | Ⅱ°面积<10% |
| 中度 | Ⅱ°面积 11%~30% 或 Ⅲ°<10% |
| 重度 | Ⅱ°面积 31%~50% 或 Ⅲ°10%~20%；或虽不足上述面积但休克/合并伤/中重度吸入性损伤 |
| 特重 | 总面积>50% 或 Ⅲ°>20% |

| 烧伤补液（第一个 24 h） | 公式 |
|---|---|
| 晶体+胶体 | （Ⅱ°+Ⅲ°面积 %）×体重 kg×1.5 ml（成人；儿童 1.8、婴儿 2.0） |
| 基础水分 | 另加 2000 ml（成人） |
| 晶:胶 | 2:1（广泛深度烧伤 1:1） |
| 输入节奏 | 前 8 h 输总量一半，后 16 h 输另一半 |
| 第二个 24 h | 晶胶量为第一天的半量＋基础水分 2000 ml |
| 调节指标 | 成人尿量 30~50 ml/h、神志、心率、Hct |
| 吸入性损伤 | 密闭空间受伤＋面颈部烧伤＋声嘶＋碳末痰/呼吸困难；⚠ 警惕喉头水肿，必要时尽早气管切开 |
| 创面处理 | 浅Ⅱ°小水疱保留疱皮；深Ⅱ°/Ⅲ°削痂切痂＋自体皮移植；大面积微粒皮+异体皮覆盖 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 低钾 vs 高钾 | T 低平+U 波、软瘫肠麻痹 | T 高尖、心搏骤停风险 | 高钾先给钙保心，再降钾 |
| 等渗 vs 高渗脱水 | 不口渴、血压下降为主 | 口渴最早、谵妄 | 血钠 135~150 / >150 |
| 冷休克 vs 暖休克 | 湿冷花斑、脉细速、G⁻多见 | 温暖干燥潮红、脉洪、G⁺早期 | 冷休克更常见更危险 |
| 破伤风 vs 气性坏疽 | 肌痉挛、神志清、无气体 | 胀裂痛、捻发音、肌间隙气体 | 都厌氧：都需清创+抗生素 |
| 灭菌 vs 消毒 | 杀灭一切含芽孢（蒸汽、干热） | 杀病原菌不一定杀芽孢（碘伏、酒精） | 消毒剂不能替代灭菌 |
| EN vs PN | 有肠道功能首选；并发症误吸 | 肠道无功能；并发症导管感染 | 记"能经肠不经肠外" |

## 【记忆口诀】

- 补钾四不宜："早、浓、快、多"都不宜——见尿补钾、<0.3%、<20 mmol/h、每日 3~5 g。
- 高钾四步："停钙转排"——停钾、钙剂护心、转移入胞、树脂透析排出。
- 三型脱水："等渗不渴低渗渴，高渗渴得最早"——低渗重者才见真性缺钠表现，靠血钠定类型。
- CVP 判读："低低快补、高高强心、正常低压做试验"。
- 烧伤九分法："三三三、五六七、躯干会阴二十七，双臀五、腿二十一，小腿十三足七会阴一"。
- 破伤风："苦笑角弓牙关紧，神志清醒是特征，抗毒清创镇静齐"。
- 癌痛："口服按时按阶梯，能口不注能少不多"。
