# 外科学·背诵手册版——03 颈部与乳腺外科

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：甲状腺结节、甲亢外科、甲状腺癌四型、乳腺良性疾病、乳腺癌。

## 一、甲状腺基础与结节评估

| 项目 | 要点 |
|---|---|
| 单纯性甲状腺肿 | 缺碘为主；青春期/妊娠期多见；T3T4 正常；胸骨后/明显压迫→手术 |
| 结节首选检查 | 超声（TI-RADS 分类） |
| 确诊手段 | 细针穿刺细胞学（FNA） |
| 恶性超声提示 | 实性低回声、微钙化、边界不清、纵横比>1、短期增大 |
| 高危人群 | 童年颈部放射史、男性单发结节、家族史 |
| 基础代谢率（BMR） | =脉率＋脉压−111 |
| BMR 分度 | 正常 ±10%；+20%~30% 轻度；+30%~60% 中度；>+60% 重度 |

## 二、甲亢外科（必背）

| 手术指征 | 内容 |
|---|---|
| ① | 中度以上原发甲亢 |
| ② | 腺体明显肿大伴压迫症状、胸骨后甲状腺肿 |
| ③ | 抗甲状腺药物无效、复发或不能耐受 |
| ④ | 疑有恶变 |
| ⑤ | 妊娠 4~6 个月（中期）且症状较重 |

| 术前准备 | 内容 |
|---|---|
| 一般准备 | 镇静、休息；心率快用普萘洛尔 |
| 碘剂 | 复方碘化钾（卢戈液）2~3 周——抑制蛋白水解酶、减少甲状腺激素释放 |
| ⚠ 碘剂 | 只用于术前准备/危象抢救，单独应用不能治疗甲亢；突然停药可加重 |
| 达标标准 | 情绪稳定、睡眠好、体重增加；脉率<90 次/分；BMR<+20%；T3/T4 正常 |
| 术后体位等 | 床旁备气管切开包与无菌手套（防术后窒息） |

| 术后并发症 | 时间/表现 | 处理 |
|---|---|---|
| ①呼吸困难和窒息 | 术后 48 h 内，最危急 | 四因：切口出血血肿压迫／喉头水肿／气管塌陷／双侧喉返神经损伤；出血→床旁拆线清除血肿，气管受压→气管插管/切开 |
| ②喉上神经损伤 | 内支（感觉）：饮水呛咳；外支（环甲肌）：声调降低 | 多可恢复，对症 |
| ③喉返神经损伤 | 一侧：声嘶（可代偿）；双侧：失声、窒息 | 双侧→气管切开 |
| ④手足抽搐 | 术后 1~3 天；甲状旁腺误切/血供受损致低钙 | 10% 葡萄糖酸钙静推±维生素 D |
| ⑤甲亢危象 | 多在术后 12~36 h：高热>39 ℃＋脉>120＋烦躁大汗＋呕吐腹泻 | 碘剂（口服/静脉）＋丙硫氧嘧啶＋氢化可的松＋降温＋镇静＋普萘洛尔 |
| ⚠ 顺序记忆 | 窒息最早最危（48 h 内）→神经损伤→低钙→危象（12~36 h） | |

| 甲状腺炎 | 要点 |
|---|---|
| 亚急性甲状腺炎 | 上感后甲状腺疼痛肿大、血沉快；激素治疗有效 |
| 慢性淋巴细胞性（桥本） | 自身免疫；TPOAb/TGAb 阳性；趋向甲减；甲状腺素替代 |

## 三、甲状腺癌四型对比（必背）

| 项目 | 乳头状癌 | 滤泡状癌 | 髓样癌 | 未分化癌 |
|---|---|---|---|---|
| 占比 | 最多（约 80%） | 次之 | 较少 | 少 |
| 好发 | 年轻女性 | 中年 | 中年 | 老年 |
| 生物学 | 生长慢、颈淋巴结转移早 | 易血行转移（肺/骨） | 滤泡旁 C 细胞来源 | 生长迅速、早期浸润压迫 |
| 标志 | — | 摄碘 | 降钙素↑、MEN2 相关 | — |
| 预后 | 最好 | 较好 | 中等 | 最差 |
| 131I | 可摄取 | 可摄取 | ⚠ 不吸碘（无效） | 不敏感 |
| 治疗 | 腺叶+峡部切除起步±颈清；术后 TSH 抑制 | 手术+131I | 全甲状腺切除+中央区清扫 | 手术难切净，外照射放疗为主 |

## 四、乳腺解剖与淋巴引流

| 项目 | 要点 |
|---|---|
| 第一站 | 腋窝淋巴结（最主要引流途径） |
| 第二站 | 锁骨下淋巴结→锁骨上淋巴结 |
| 内乳途径 | 胸骨旁淋巴结（内乳区） |
| ⚠ | 腋窝淋巴结状态是分期与手术方案核心依据 |

## 五、乳腺良性疾病

| 病名 | 好发 | 特征 | 处理 |
|---|---|---|---|
| 急性乳腺炎 | 初产妇、产后 3~4 周 | 乳汁淤积＋金葡入乳头破损；红肿热痛+发热 | 排空乳汁为主（一般不停止哺乳）；抗生素选青霉素/头孢类；⚠ 哺乳期避免四环素、磺胺、甲硝唑、喹诺酮 |
| 急性乳腺炎脓肿 | 脓肿形成后 | 波动感 | 切开引流：表浅轮辐状（放射状）；乳晕下弧形；深部/乳房后——乳房下缘弧形；脓肿形成期暂停患侧哺乳 |
| 乳腺囊性增生病 | 中年 | 双侧多发结节＋周期性胀痛（经前加重） | 对症＋随访；⚠ 不典型增生属癌前病变 |
| 乳腺纤维腺瘤 | 20~25 岁 | 单发、无痛、光滑、活动好 | 手术切除（唯一有效） |
| 导管内乳头状瘤 | 40~50 岁 | 乳头单孔血性溢液、乳晕区小结节 | 病变乳管切除；有恶变倾向 |

## 六、乳腺癌（必背）

| 项目 | 要点 |
|---|---|
| 高危因素 | 初潮早/绝经晚；未育/晚育/未哺乳；肥胖；BRCA1/2 家族史；胸部放射史 |
| 好发部位 | 外上象限 |
| 早期表现 | 无痛、单发、质硬、边界不清、活动度差的肿块 |
| 酒窝征 | 肿瘤累及 Cooper 韧带→韧带缩短→皮肤凹陷 |
| 橘皮征 | 癌细胞堵塞皮下淋巴管→真皮水肿→毛囊凹陷呈橘皮样 |
| 乳头凹陷 | 肿瘤侵犯牵拉乳管 |
| 炎性乳癌 | 局部红肿热痛似急性炎症；恶性度高、转移早；不宜手术，以化疗为主 |
| Paget 病 | 乳头乳晕湿疹样改变（瘙痒、糜烂）；恶性程度相对低 |
| 淋巴转移 | 腋窝（第一站）→锁骨下→锁骨上；胸骨旁 |
| 血行转移 | 骨（椎体、骨盆）、肺、肝 |
| 诊断 | 钼靶：簇状细小钙化（40 岁以上首选）；超声：年轻/致密型；确诊：空芯针穿刺活检 |
| 分子分型 | ER/PR、HER2、Ki-67——决定内分泌/靶向方案 |

| 治疗 | 适应证/方案 |
|---|---|
| 改良根治术 | 经典术式（保留胸大肌） |
| 保乳手术 | 早期（T1~T2）、切缘阴性＋术后放疗（必做） |
| 前哨淋巴结活检 | 示踪剂定位；阴性→不行腋窝清扫，避免上肢淋巴水肿 |
| 新辅助化疗 | 局部晚期降期、争取保乳 |
| 术后化疗 | 中高危：蒽环类±紫杉类方案 |
| 内分泌治疗 | 仅 ER/PR 阳性；绝经前：他莫昔芬 5~10 年（⚠ 子宫内膜增生/血栓风险）；绝经后：芳香化酶抑制剂（来曲唑等） |
| 靶向治疗 | HER2 阳性→曲妥珠单抗 |
| 放疗 | 保乳术后必做；T3~4 或腋淋巴结阳性者术后胸壁/区域放疗 |

## 【速记总表】

| 考点 | 必背内容 |
|---|---|
| BMR | =脉率+脉压−111；>+60% 重度 |
| 甲亢手术达标 | 脉率<90、BMR<+20%、T3T4 正常 |
| 碘剂定位 | 只用于术前准备与危象，单用不治甲亢 |
| 术后窒息 | 48 h 内；血肿/喉头水肿/气管塌陷/双侧喉返损伤 |
| 喉上神经 | 内支呛咳、外支声调低 |
| 喉返神经 | 一侧声嘶、双侧失声窒息 |
| 术后低钙 | 术后 1~3 天手足搐搦→葡萄糖酸钙 |
| 甲亢危象 | 术后 12~36 h、高热脉快；碘+PTU+氢化可的松 |
| 甲癌最多/预后最好 | 乳头状癌 |
| 不吸碘 | 髓样癌（降钙素↑、MEN2） |
| 预后最差 | 未分化癌（外照射为主） |
| 产后 3~4 周乳腺炎 | 淤积+金葡；排空乳汁；脓肿放射状切开 |
| 哺乳期禁用 | 四环素、磺胺、甲硝唑、喹诺酮 |
| 乳腺周期性胀痛 | 囊性增生病；不典型增生=癌前病变 |
| 单孔血性溢液 | 导管内乳头状瘤 |

| 钼靶特征 | 簇状细小钙化 |

| 内分泌 | 绝经前 TAM／绝经后 AI |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 甲状腺炎 | 亚急性：疼痛、血沉快、激素有效 | 桥本：无痛、抗体+、趋向甲减替代治疗 | 有无疼痛是第一线索 |
| 乳头状 vs 滤泡状 | 颈淋巴结转移早、预后最好 | 血行转移早、131I 治疗突出 | 转移路径不同 |
| 髓样 vs 未分化 | 降钙素、不吸碘、全切 | 老年进展快、放疗为主 | 一者查降钙素，一者靠外照射 |
| 酒窝 vs 橘皮 | Cooper 韧带缩短（皮肤凹陷） | 淋巴管堵塞水肿（毛囊下陷） | 一个"牵拉"，一个"水肿" |
| 纤维腺瘤 vs 囊性增生病 | 青年、单发、无痛、活动好 | 中年、双侧多发、周期性胀痛 | 周期性是增生关键词 |
| 乳腺炎 vs 炎性乳癌 | 产后哺乳期、发热、按压痛、可出脓 | 非哺乳期也见、红肿无发热、抗炎无效 | 炎性乳癌抗炎治疗不消退 |

## 【记忆口诀】

- 甲亢术后并发症顺序："先窒息、后声哑，低钙抽搐危象后"——48 h 窒息、声嘶呛咳、1~3 天低钙、12~36 h 危象。
- 喉上/喉返："内呛外低，返损声嘶；双侧失声要切开"。
- 甲状腺癌四型："乳头最多预后好，滤泡跑血 131I 烧，髓样降钙不吸碘，未分化最凶放疗保"。
- 乳腺癌皮肤征："酒窝韧带来，橘皮淋巴塞，乳头凹陷管牵拉"。
- 乳腺脓肿切口："表浅轮辐乳晕弧，深部后方下缘弧"。
- 内分泌用药："经前他莫昔芬，绝后芳香化酶"。
