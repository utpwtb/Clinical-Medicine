# 外科学·背诵手册版——02 神经外科

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：颅高压、脑疝、颅脑损伤、颅内血肿、GCS 评分。

## 一、颅内压增高

| 要点 | 内容 |
|---|---|
| 正常 ICP | 成人 0.7~2.0 kPa（70~200 mmH₂O）；儿童 0.5~1.0 kPa |
| 增高判定 | 成人 ICP>200 mmH₂O |
| 三主征 | 头痛（晨起重、用力加重）｜呕吐（喷射性、与进食无关）｜视盘水肿（最客观体征） |
| Cushing 反应 | 颅压急骤升高→血压↑＋心率↓＋呼吸慢（"两慢一高"，濒临脑疝信号） |
| 常见原因 | 颅内占位、脑水肿、脑脊液循环受阻、颅腔容积缩小（凹陷骨折、狭颅症） |
| 降颅压药物 | 20% 甘露醇 0.25~1 g/kg 快速滴注；甘油果糖；高渗盐水；利尿剂（呋塞米） |
| 临时手段 | 过度通气（PCO₂ 30~35 mmHg）、脑室外引流、去骨瓣减压、抬高床头 15°~30° |
| ⚠ 禁忌 | 枕骨大孔疝禁腰穿；禁低渗液；疑颅高压者腰穿应极谨慎 |

## 二、两类脑疝对比（必背）

| 项目 | 小脑幕切迹疝（颞叶钩回疝） | 枕骨大孔疝（小脑扁桃体疝） |
|---|---|---|
| 疝出结构 | 颞叶钩回疝入小脑幕裂孔 | 小脑扁桃体疝入枕骨大孔 |
| 受压组织 | 中脑＋动眼神经 | 延髓 |
| 瞳孔 | 患侧瞳孔先缩小后散大（动眼神经受激惹→麻痹） | 瞳孔改变出现晚 |
| 意识 | 进行性加深，较早 | 意识障碍出现较晚 |
| 呼吸/生命体征 | 晚期紊乱 | 呼吸骤停可先于意识障碍（最凶险） |
| 其他体征 | 对侧肢体偏瘫（锥体束征） | 颈项强直、生命体征紊乱早 |
| ⚠ 一句话 | 同侧瞳孔散大＋对侧偏瘫 | 呼吸先停；禁腰穿 |

## 三、头皮血肿与颅骨骨折

| 项目 | 特点/处理 |
|---|---|
| 皮下血肿 | 小而硬、局限、疼痛明显，多自行吸收 |
| 帽状腱膜下血肿 | 大而软、波动感，可蔓延全头 |
| 骨膜下血肿 | 局限于两颅缝之间（多见于产伤/新生儿） |
| 线性骨折 | 多不需特殊处理；⚠ 跨脑膜血管沟/静脉窦者警惕血肿 |
| 凹陷性骨折手术指征 | 深度>1 cm；脑受压/神经功能障碍/癫痫；大面积凹陷致颅高压 |
| 颅前窝骨折 | 熊猫眼征（眶周瘀斑）＋脑脊液鼻漏＋嗅/视神经损伤 |
| 颅中窝骨折 | Battle 征（乳突瘀斑）＋脑脊液耳漏/鼻漏＋面/听神经损伤 |
| 颅后窝骨折 | 枕下乳突区瘀斑＋后组脑神经损伤 |
| ⚠ 颅底骨折 | 属内开放性骨折（与颅腔相通），本身不需复位，防感染是核心 |

## 四、脑脊液漏处理（必背）

| 原则 | 内容 |
|---|---|
| 体位 | 头高位卧床，避免用力咳嗽、擤鼻、打喷嚏 |
| 四禁 | 禁填塞、禁冲洗、禁滴药、禁腰穿 |
| 转归 | 多数 2 周内自停；>1 个月不愈→手术修补漏口 |
| ⚠ 目标 | 防逆行颅内感染，严禁堵塞 |
| 抗生素 | 预防性应用；同时预防破伤风（开放伤） |

## 五、脑震荡 vs 脑挫裂伤

| 项目 | 脑震荡 | 脑挫裂伤 |
|---|---|---|
| 意识障碍 | 一过性，<30 min | >30 min，持续较久 |
| 遗忘 | 逆行性遗忘（标志性） | 可有，非标志 |
| 神经体征 | 阴性 | 阳性（局灶体征） |
| CT | 阴性 | 挫伤灶、蛛网膜下腔出血 |
| 处理 | 观察为主 | 降颅压、防治脑水肿，必要时手术 |

## 六、颅内血肿（必背）

| 项目 | 硬脑膜外血肿 | 硬脑膜下血肿 |
|---|---|---|
| 出血源 | 脑膜中动脉（颞部） | 桥静脉/挫裂伤血管（额颞部） |
| 意识特点 | 昏迷→中间清醒期→再昏迷（特征性） | 持续昏迷，无中间清醒期 |
| CT 形态 | 梭形（双凸透镜）高密度 | 新月形高密度 |
| 跨颅缝 | 不跨颅缝 | 可跨颅缝 |
| 慢性型 | — | >3 周；老年人＋脑萎缩＋轻微外伤；钻孔引流 |
| 治疗 | 出血量大→钻孔引流/开颅清除 | 急性→开颅清除 |
| 时间分型 | 急性<3 天；亚急性 3 天~3 周；慢性>3 周（同用于硬膜下） | |
| 脑内血肿 | 挫裂伤深部出血，CT 圆形高密度，与挫裂伤并存 | |

## 七、GCS 评分（必背）

| 项目 | 6 分 | 5 分 | 4 分 | 3 分 | 2 分 | 1 分 |
|---|---|---|---|---|---|---|
| 睁眼 | — | — | 自动睁眼 | 呼唤睁眼 | 刺痛睁眼 | 不能睁眼 |
| 语言 | — | 回答正确 | 回答错乱 | 用词不当 | 只能发声 | 无反应 |
| 运动 | 遵嘱活动 | 刺痛定位 | 刺痛躲避 | 刺痛屈曲（去皮层） | 刺痛过伸（去大脑） | 无反应 |

| 项目 | 内容 |
|---|---|
| 计算 | GCS=睁眼＋语言＋运动，满分 15 分，最低 3 分 |
| 分级 | 13~15 轻型；9~12 中型；3~8 重型 |
| ⚠ | GCS≤8 为昏迷，需尽早保护气道（气管插管） |

## 【速记总表】

| 考点 | 必背内容 |
|---|---|
| 正常 ICP | 成人 70~200 mmH₂O，>200 为增高 |
| 颅高压三主征 | 头痛、喷射性呕吐、视盘水肿 |
| Cushing 反应 | 血压↑＋心率↓＋呼吸慢（两慢一高） |
| 小脑幕切迹疝 | 同侧瞳孔先小后大＋对侧偏瘫 |
| 枕骨大孔疝 | 呼吸骤停先于意识障碍；禁腰穿 |
| 降颅压首选 | 20% 甘露醇快速滴注 |
| 熊猫眼征 | 颅前窝骨折＋脑脊液鼻漏 |
| Battle 征 | 颅中窝骨折＋脑脊液耳漏 |
| 脑脊液漏 | 头高位、四禁（填塞/冲洗/滴药/腰穿）、1 月不愈手术 |
| 脑震荡 | 意识障碍<30 min＋逆行性遗忘＋CT（−） |
| 硬膜外血肿 | 中间清醒期、梭形、不跨颅缝 |
| 硬膜下血肿 | 持续昏迷、新月形、可跨颅缝 |
| 慢性硬膜下 | 老年＋轻微外伤→钻孔引流 |
| GCS | 睁 4＋语 5＋动 6；≤8 重型昏迷 |
| 凹陷骨折手术 | 深度>1 cm、脑受压、颅高压 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 硬膜外 vs 硬膜下 | 脑膜中动脉、梭形、不跨缝、中间清醒期 | 桥静脉、新月形、跨缝、持续昏迷 | 先定血肿类型再看意识曲线 |
| 切迹疝 vs 枕大孔疝 | 瞳孔改变早、偏瘫 | 呼吸骤停早、瞳孔改变晚 | 颅高压者腰穿前先想枕大孔疝 |
| 脑震荡 vs 脑挫裂伤 | <30 min＋逆行遗忘＋CT（−） | >30 min＋局灶体征＋CT（+） | CT 是分水岭 |
| 三种头皮血肿 | 皮下：小硬 | 帽状腱膜下：大软可蔓延 | 骨膜下：限于颅缝 |
| 颅底骨折三窝 | 前：鼻漏＋熊猫眼 | 中：耳漏＋Battle | 后：后组脑神经 |

## 【记忆口诀】

- 颅高压三主征："痛、吐、视"——晨起头痛喷射吐，视盘水肿最客观。
- Cushing 反应："两慢一高"——心率慢、呼吸慢、血压高。
- 脑脊液漏四禁："填冲滴腰全不许"——禁填塞、冲洗、滴药、腰穿。
- 硬膜外血肿："中间醒，梭形影"——中间清醒期＋梭形 CT。
- GCS 运动分："遵定避屈伸无"——遵嘱 6、定位 5、躲避 4、屈曲 3、过伸 2、无 1。
