# 外科学·背诵手册版——05 腹部外科

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：疝、腹部损伤、腹膜炎、胃大部切除、肠梗阻、阑尾炎、结直肠肛管、肝胆胰、周围血管。

## 一、腹外疝

| 项目 | 要点 |
|---|---|
| 斜疝机制 | 腹膜鞘突未闭＋腹股沟管薄弱 |
| 直疝机制 | 海氏三角（直疝三角）薄弱 |
| 海氏三角边界 | 腹直肌外缘＋腹股沟韧带＋腹壁下动脉 |
| 股疝 | 经股环→卵圆窝突出 |
| 婴儿斜疝 | 1 岁内可随发育自愈，观察；之后手术 |

| 项目 | 腹股沟斜疝 | 腹股沟直疝 | 股疝 |
|---|---|---|---|
| 好发年龄 | 儿童/青壮年 | 老年人 | 中年经产妇女 |
| 突出途径 | 经内环→腹股沟管→外环，可入阴囊 | 经海氏三角，不入阴囊 | 经股环至卵圆窝 |
| 形态 | 梨形/椭圆 | 半球形 | 球形 |
| 回纳后压内环 | 不再突出 | 仍可突出 | 压内环无效 |
| 嵌顿机会 | 较多 | 极少 | ⚠ 最易嵌顿 |
| 与腹壁下动脉关系 | 突出于其外侧 | 突出于其内侧 | 位于其下方（股环） |
| 术式注意 | 常规修补 | 常规修补 | McVay 修补（缝至耻骨梳韧带） |

| 嵌顿 vs 绞窄 | 要点 |
|---|---|
| 嵌顿 | 内容物卡压→静脉回流受阻→淤血水肿 |
| 绞窄 | ⚠ 动脉血供受阻→肠管坏死；嵌顿未解除必然发展为绞窄 |
| 手法复位指征 | 嵌顿 3~4 h 内、局部压痛不明显、无腹膜刺激征；年老体弱伴重病者；复位后仍需观察 |
| 手法复位方法 | 镇静＋头低脚高＋轻柔推按 |
| 原则 | 成人嵌顿/绞窄→急诊手术；⚠ 绞窄疝肠管坏死者禁忌疝修补（防感染） |

| 特殊疝 | 内容 |
|---|---|
| Richter 疝 | 部分肠壁嵌顿（肠管壁疝） |
| Littre 疝 | 小肠憩室（多为 Meckel 憩室）嵌顿 |
| 滑动疝 | 膀胱/乙状结肠构成疝囊壁一部分；属难复性 |
| 切口疝 | 术后切口感染是主因 |

## 二、腹部损伤

| 项目 | 实质性脏器破裂（脾/肝） | 空腔脏器破裂（胃肠） |
|---|---|---|
| 核心表现 | 内出血→休克（面色苍白、脉快） | 腹膜炎（板状腹、压痛反跳痛） |
| 腹膜刺激征 | 较轻 | 明显 |
| 膈下游离气体 | 无 | ⚠ 约 80% 可见（立位 X 线） |
| 腹腔穿刺 | 不凝固血液 | 消化液、胆汁、食物残渣 |
| 优先问题 | 补充血容量抗休克 | 抗感染＋手术修补 |

| 项目 | 要点 |
|---|---|
| 脾破裂 | 最常见受损实质脏器；左上腹痛＋左肩放射（Kehr 征） |
| 被膜下脾破裂 | ⚠ 延迟性真性破裂，多在伤后 1~2 周内发生 |
| 脾处理 | 切除/修补/部分切除；儿童尽量保脾（防 OPSI 脾切除后凶险性感染） |
| 肝破裂 | 腹膜刺激征比脾重（胆汁刺激）；清创缝合/填塞止血 |
| 十二指肠损伤 | 第 2 段腹膜后伤：上腹痛+腰背痛，早期隐匿易漏诊 |
| 诊断性穿刺 | 脐与髂前上棘连线中外 1/3 交点；⚠ 穿刺阴性不能排除损伤（可 CT/灌洗/观察） |
| 观察原则 | 诊断未明：禁食、不随意搬动、不用强效镇痛剂；反复评估生命体征+腹部体征+血象 |
| 手术探查指征 | 休克难纠正（边抗边探）、腹膜刺激征加重、膈下游离气体、红细胞进行性下降、穿刺阳性 |

## 三、急性腹膜炎

| 项目 | 要点 |
|---|---|
| 继发性（最常见） | 阑尾炎穿孔、溃疡穿孔等原发灶扩散 |
| 原发性 | 血行/淋巴/女性生殖道感染；儿童、肝硬化腹水多见 |
| 核心体征 | 腹膜刺激征：压痛＋反跳痛＋肌紧张（板状腹） |
| 肠鸣音 | 减弱→消失（麻痹性肠梗阻） |
| 辅助 | 白细胞↑；空腔脏器穿孔见膈下游离气体 |
| 非手术 | 半卧位（利于渗液流向盆腔、减少吸收）＋禁食胃肠减压＋抗生素＋补液 |
| 半卧位意义 | 盆腔腹膜吸收力弱、中毒轻；一旦形成脓肿便于引流 |
| 手术指征 | 非手术 6~8 h 无效或加重；原发病重（穿孔、绞窄）；伴休克；腹腔积液多 |
| 手术内容 | 处理原发灶＋彻底冲洗＋充分引流 |

## 四、胃十二指肠溃疡外科与胃大部切除术

| 手术适应证 | 内容 |
|---|---|
| 大出血 | 短期内休克；经 6~8 h 输血 600~900 ml 仍不稳定；复发出血；60 岁以上伴动脉硬化 |
| 急性穿孔 | 穿孔时间长/腹腔污染重/伴出血或幽门梗阻→手术；空腹小穿孔症状轻可先非手术（6~8 h 无效→手术） |
| 瘢痕性幽门梗阻 | 大量呕吐宿食（隔夜）、低氯低钾碱中毒；术前温盐水洗胃+纠正水电 |
| 癌变/可疑恶变 | 胃溃疡为主 |
| 内科治疗无效 | 严格掌握 |

| 项目 | 毕Ⅰ式 | 毕Ⅱ式 |
|---|---|---|
| 吻合方式 | 胃-十二指肠吻合 | 胃-空肠吻合 |
| 适用 | 胃溃疡 | 十二指肠溃疡（也可用于胃溃疡） |
| 生理性 | 接近正常、并发症少 | 改变通道、并发症多 |
| ⚠ | 毕Ⅱ式特有：十二指肠残端破裂、输入袢梗阻、碱性反流性胃炎 | |

| 术后早期并发症 | 时间/表现 | 处理 |
|---|---|---|
| 术后胃出血 | 24 h 内胃管引出鲜血 | 保守；无效手术 |
| 十二指肠残端破裂 | 毕Ⅱ式特有，术后 3~6 天：右上腹剧痛+发热+腹膜炎 | 手术引流+残端造瘘，积极抗感染 |
| 吻合口瘘 | 术后早期腹膜炎 | 引流+抗感染 |
| 急性完全性输入袢梗阻 | 突发上腹剧痛、频繁呕吐、⚠ 呕吐物量少且不含胆汁 | 手术解除 |
| 慢性不全性输入袢梗阻 | 餐后上腹胀痛→呕吐大量胆汁（不含食物）→吐后缓解 | 少量多餐，重者手术 |
| 输出袢梗阻 | 呕吐物含食物与胆汁 | 保守/手术 |
| 吻合口梗阻 | 呕吐食物、不含胆汁（吻合口水肿多见） | 胃肠减压、营养支持 |

| 术后远期并发症 | 要点 |
|---|---|
| 早期倾倒综合征 | 餐后 30 min 内：高渗食糜入肠→细胞外液入肠腔＋肠道血管活性物质→心悸、出汗、面色苍白、腹泻 |
| 早期倾倒处理 | 少量多餐、避免过甜过浓食、进餐后平卧 20~30 min |
| 晚期倾倒（低血糖综合征） | 餐后 2~4 h：高糖刺激胰岛素分泌→反应性低血糖（心慌、出汗、乏力）；进糖可缓解 |
| 碱性反流性胃炎 | 毕Ⅱ式后数月~数年；三联：上腹/胸骨后烧灼痛＋呕吐胆汁（制酸剂无效）＋体重下降/贫血；Roux-en-Y 手术 |
| 吻合口溃疡 | 多在毕Ⅱ式空肠侧；症状类似溃疡 |
| 营养性并发症 | 毕Ⅱ式 bypass 十二指肠→铁、钙吸收差（缺铁性贫血）；维生素 B12 缺乏 |
| 残胃癌 | 良性病变胃切除术后 ≥5 年发生的残胃原发癌；定期胃镜随访 |
| ⚠ 区分 | 早期倾倒=高渗；晚期倾倒=低血糖；呕吐胆汁不含食物=输入袢（慢性）；呕吐食物不含胆汁=吻合口 |

## 五、胃癌

| 项目 | 要点 |
|---|---|
| 好发部位 | 胃窦部 |
| 转移途径 | 淋巴转移为主；左锁骨上淋巴结（Virchow） |
| 种植转移 | 女性卵巢（Krukenberg 瘤） |
| 血行 | 肝最常见 |
| 诊断 | 胃镜+活检（金标准）；增强 CT 分期；HER2 检测 |
| 手术 | 远端胃癌 D2 根治术（清扫第 2 站淋巴结）；贲门/胃体部可行全胃切除 |
| 化疗 | 新辅助（局部进展期降期）＋术后辅助化疗 |
| ⚠ | D2=第二站淋巴结清扫范围，是标准根治术式 |

## 六、肠梗阻

| 分类 | 要点 |
|---|---|
| 机械性 | 粘连性（最常见，术后）、肿瘤、嵌顿疝、扭转 |
| 动力性 | 麻痹性（术后、腹膜炎、低钾）——肠鸣音消失 |
| 血运性 | 肠系膜血管阻塞 |
| 单纯 vs 绞窄 | 有无血运障碍 |

| 四大症状 | 表现 |
|---|---|
| 痛 | 阵发性绞痛（机械性）；持续性胀痛（麻痹性） |
| 吐 | 高位早而频；低位晚，可粪样 |
| 胀 | 低位明显；闭袢性不对称 |
| 闭 | 停止排气排便 |
| 体征 | 机械性肠鸣音亢进（气过水声/金属音）；麻痹性肠鸣音消失 |

| 绞窄性肠梗阻征象（必背，手术指征） | 内容 |
|---|---|
| ① | 腹痛由阵发性转为持续性剧痛 |
| ② | 呕吐物、胃肠减压物、肛门排出物为血性 |
| ③ | 出现腹膜刺激征 |
| ④ | 腹胀不对称、可触及压痛性包块（孤立胀大肠袢） |
| ⑤ | 体温↑、脉速、白细胞↑、早期休克表现 |
| ⑥ | X 线示孤立、固定、胀大的肠袢 |
| ⚠ | 绞窄性梗阻一经诊断→急诊手术 |

| 治疗 | 要点 |
|---|---|
| 基础治疗 | 禁食胃肠减压＋补液纠正水电酸碱＋抗生素 |
| 非手术适应 | 单纯性粘连性、麻痹性、蛔虫性等 |
| 手术适应 | 绞窄性、肿瘤性、先天性、保守无效者 |
| ⚠ 麻痹性肠梗阻 | 禁手术解除"梗阻"，治原发病（腹膜炎、低钾） |

| 特殊肠梗阻 | 要点 |
|---|---|
| 肠套叠 | 2 岁以下多见；阵发性哭闹＋果酱样便＋腹部腊肠样包块；病程<48 h、全身好→空气灌肠复位；失败/坏死→手术 |
| 肠扭转 | 饱食后剧烈活动；腹痛剧烈、呕吐频繁；⚠ 易绞窄，急诊手术 |
| 肠系膜血管缺血 | 老年、房颤；⚠ 剧烈腹痛与腹部体征不符（早期"重痛轻征"）→肠坏死风险 |

## 七、阑尾炎（必背）

| 项目 | 要点 |
|---|---|
| 病因 | 阑尾腔梗阻（粪石最常见）＋细菌感染 |
| 典型症状 | ⚠ 转移性右下腹痛（脐周→右下腹麦氏点） |
| 最重要的体征 | 麦氏点压痛（脐与右髂前上棘连线中外 1/3） |
| Rovsing 征 | 按压左下腹引起右下腹痛（结肠充气试验） |
| 腰大肌试验 | 阳性提示盲肠后位阑尾 |
| 闭孔内肌试验 | 阳性提示盆位阑尾 |
| 直肠指检 | 盆位阑尾炎直肠右前方触痛 |
| 并发症①腹腔脓肿 | 阑尾周围脓肿：右下腹包块；病情稳定先抗生素/引流，⚠ 3 个月后再行阑尾切除 |
| 并发症②门静脉炎 | 寒战高热＋黄疸＋肝大（细菌性肝脓肿前奏） |
| 并发症③ | 内外瘘、切口感染 |
| 小儿 | 大网膜短、壁薄→穿孔早、腹膜炎重，宜早期手术 |
| 老人 | 体征轻、实际重（症状体征分离），穿孔率高 |
| 妊娠 | 压痛点上移；大网膜被推开→炎症难局限；⚠ 宜积极手术 |
| 治疗 | 首选阑尾切除术（腹腔镜）；术前抗生素 |

## 八、结直肠癌（必背）

| 项目 | 右半结肠癌 | 左半结肠癌 |
|---|---|---|
| 大体类型 | 肿块型为主 | 浸润型（缩窄）为主 |
| 肠腔 | 宽→梗阻晚 | 窄→⚠ 梗阻早 |
| 典型表现 | 全身症状：贫血、乏力、腹部包块 | 便血、黏液便、肠梗阻 |
| 一句话 | 右半"全身型"，左半"梗阻型" | |

| 项目 | 要点 |
|---|---|
| 结肠癌诊断 | 结肠镜+活检（金标准）；CEA 用于监测复发而非确诊 |
| 直肠癌诊断 | ⚠ 直肠指检最简单重要（多数中低位直肠癌可触及） |
| Dixon 手术 | 经腹直肠癌切除+吻合（保肛）；适用于肿瘤下缘距齿状线较远（约 2 cm 以上）、括约肌功能良好 |
| Miles 手术 | 腹会阴联合切除+永久性乙状结肠造口；适用于肿瘤距齿状线近（约 2 cm 以内）/侵犯括约肌 |
| Hartmann 手术 | 切除肿瘤+乙状结肠造口、远端封闭；适用于急性梗阻、全身情况差、吻合风险高者 |
| TME | 全直肠系膜切除——中低位直肠癌手术原则 |
| 新辅助放化疗 | 中低位局部进展期直肠癌降期后手术 |
| 化疗 | FOLFOX/XELOX 类方案为辅助治疗常用选择 |

## 九、直肠肛管疾病（必背）

| 病名 | 核心机制 | 诊断关键 | 治疗要点 |
|---|---|---|---|
| 肛裂 | 排便损伤＋内括约肌痉挛 | 后正中线（截石位 6 点）；周期性疼痛（排便痛→缓解→痉挛剧痛）；三联征：肛裂＋前哨痔＋肛乳头肥大 | 保守：坐浴+润便；慢性/顽固：肛裂切除＋内括约肌侧方切开 |
| 直肠肛管周围脓肿 | 肛腺感染 | 肛周皮下（最常见）；坐骨肛管间隙（全身症状重）；骨盆直肠间隙（位置深、易漏诊——穿刺/超声） | 切开引流是关键；⚠ 处理不当形成肛瘘 |
| 肛瘘 | 脓肿后遗 | 内口（肛窦）+瘘管+外口；反复流脓 | 手术：挂线疗法（缓慢切割、保护括约肌）等；⚠ 手术成败在于正确处理内口 |
| 内痔 | 齿状线以上、无痛性 | 间歇性无痛性便后鲜血；分度见下 | Ⅰ~Ⅱ 保守（饮食+坐浴+药物）；Ⅲ~Ⅳ 手术（PPH/外剥内扎等） |
| 外痔 | 齿状线以下、躯体神经 | ⚠ 血栓性外痔：剧痛紫蓝色硬结 | 保守；剧痛者切开取栓 |
| ⚠ 便血鉴别 | 任何便血先做直肠指检排除直肠癌 | | |

| 内痔分度 | 内容 |
|---|---|
| Ⅰ度 | 便时出血，无脱出 |
| Ⅱ度 | 脱出，便后可自行回纳 |
| Ⅲ度 | 脱出需手助回纳 |
| Ⅳ度 | 脱出不能回纳 |

## 十、肝脓肿

| 项目 | 细菌性肝脓肿 | 阿米巴肝脓肿 |
|---|---|---|
| 病原 | 大肠杆菌、金葡、厌氧菌 | 溶组织阿米巴 |
| 入侵途径 | 胆道逆行（最常见）、肝动脉、门静脉 | 门静脉（肠阿米巴病） |
| 数量 | 多发多见 | 单发多见（右叶） |
| 脓液 | 黄白色、可培养出菌 | 巧克力（果酱）样、可找到滋养体 |
| 全身症状 | 寒战高热明显 | 相对缓和 |
| 治疗 | 抗生素＋经皮穿刺置管引流 | 甲硝唑＋必要时反复穿刺抽脓 |

## 十一、原发性肝癌

| 项目 | 要点 |
|---|---|
| 病因 | 乙肝/丙肝、肝硬化、黄曲霉毒素、酒精 |
| 首发症状 | 肝区疼痛（持续性钝痛） |
| 诊断核心 | AFP≥400 μg/L 持续 4 周（或≥200 μg/L 持续 8 周），排除妊娠、活动性肝病、生殖腺胚胎瘤 |
| 影像 | 增强 CT/MRI："快进快出"；超声用于筛查 |
| 高危筛查 | 乙肝/肝硬化人群：超声＋AFP 每 6 个月 |
| 转移 | 肝内经门静脉最早播散；血行→肺 |
| 手术切除 | 首选（可切除＋肝功能储备良好者） |
| 射频/微波消融 | 小肝癌（≤3 cm）疗效与切除相当 |
| TACE | 不能切除的中晚期肝癌首选姑息手段 |
| 肝移植 | Milan 标准：单个肿瘤≤5 cm；或多发≤3 个且每个≤3 cm；无大血管侵犯/淋巴结转移/肝外转移 |
| 晚期 | 靶向（索拉非尼、仑伐替尼）＋免疫治疗 |
| ⚠ 并发症 | 自发性破裂出血：突发右上腹剧痛+腹膜炎+休克 |

## 十二、门静脉高压症

| 项目 | 要点 |
|---|---|
| 病因 | 肝硬化（我国以肝炎后为主） |
| 正常门静脉压 | 13~24 cmH₂O（平均 18）；>25 cmH₂O 提示高压 |
| 最重要侧支 | ⚠ 食管胃底曲张静脉（破裂出血是主要死因） |
| 其他侧支 | 脐周（海神头）、直肠上静脉（痔）、腹膜后 |
| 脾功能亢进 | 脾大＋白细胞/血小板减少 |
| 出血表现 | 呕大量鲜血＋黑便，可迅速休克 |

| 术式对比 | 断流术 | 分流术 |
|---|---|---|
| 代表 | 贲门周围血管离断术 | 脾肾分流、肠腔分流等 |
| 机制 | 离断出血侧支，保留入肝血流 | 门体分流直接降压 |
| 肝性脑病 | 少 | ⚠ 多（入肝血流↓） |
| 再出血 | 相对多 | 少 |
| 急诊止血 | ⚠ 首选 | 择期为主 |
| TIPS | 肝内门体分流：难治性出血/顽固性腹水 | |
| 预防再出血 | 非选择性 β 受体阻滞剂＋内镜套扎 | |

## 十三、胆道疾病

| 项目 | 要点 |
|---|---|
| 胆囊结石 | 危险因素"4F"：Female、Fat、Forty、Fecundity |
| 无症状胆囊结石 | 随访观察；有症状/并发症（急性胆囊炎、继发胆管结石、胆囊癌变风险）→胆囊切除 |
| 胆囊切除术 | 腹腔镜胆囊切除（LC）——金标准 |
| 肝外胆管结石 | ERCP 取石（EST）或腹腔镜胆总管探查 |

| 急性胆囊炎 | 要点 |
|---|---|
| 病因 | 结石嵌顿（90% 以上为结石性） |
| 诱因/症状 | 进食油腻后右上腹痛→右肩背放射；发热、恶心 |
| 关键体征 | Murphy 征阳性 |
| B 超 | 胆囊增大、壁增厚>3 mm（双边征）、结石影 |
| 治疗 | 早期腹腔镜胆囊切除（发病 72 h 内为佳）或保守后择期；坏疽穿孔→急诊手术 |

| AOSC（急性梗阻性化脓性胆管炎） | 要点 |
|---|---|
| 病因 | 胆管梗阻＋化脓性感染（胆管结石最常见） |
| Charcot 三联征 | 腹痛＋寒战高热＋黄疸 |
| Reynolds 五联征 | Charcot 三联＋休克＋神经中枢症状（意识障碍） |
| 治疗核心 | ⚠ 胆道减压引流是关键（解除梗阻、通畅引流） |
| 减压途径 | ERCP+ENBD／PTCD／手术胆总管切开+T 管引流 |
| 原则 | 短时间抗休克抗感染无效→立即减压；引流前慎用强效镇痛（掩盖病情） |
| T 管 | 术后约 2 周，造影证实胆道通畅后拔除 |

| 项目 | 要点 |
|---|---|
| 胆道蛔虫症 | 剑突下"钻顶样绞痛"+体征轻（症征不符）；B 超见条状虫影；解痉+缓解后驱虫 |
| 胆管癌 | 好发上段（肝门部 Klatskin 瘤最多见）；进行性无痛性黄疸＋瘙痒＋陶土便；手术是唯一可能根治手段 |
| Courvoisier 征 | 胆总管下段/壶腹周围梗阻→无痛性胆囊肿大（见于胆管下段癌、胰头癌） |

## 十四、急性胰腺炎（外科视角）

| 项目 | 要点 |
|---|---|
| 常见病因 | 胆道疾病（胆源性）、酗酒、高脂血症 |
| 首发症状 | 持续性上腹痛向腰背放射 |
| 酶学 | 血淀粉酶 6~12 h 升高、3~5 天恢复；尿淀粉酶升高更晚持续更久；⚠ 酶高低与病情不平行 |
| 更特异 | 血脂肪酶 |
| 重症提示 | ⚠ 血钙<1.87 mmol/L 预后不良；血糖>11.1 mmol/L 提示预后不良 |
| 治疗核心 | 非手术为主：液体复苏＋禁食胃肠减压＋镇痛（哌替啶；慎用吗啡——Oddi 括约肌痉挛之说） |
| 营养 | 早期肠内营养（空肠喂养）优先 |
| 抗生素 | 胆源性/感染性坏死者使用 |
| 手术指征 | 感染性胰腺坏死（穿刺证实）、胰腺脓肿、胆道梗阻持续（ERCP 减压）、暴发性胰腺炎 |
| 胰腺假性囊肿 | 多在 4~6 周形成；小而无症状观察；大/有症状/持续→内引流（囊肠吻合） |

## 十五、胰腺癌

| 项目 | 要点 |
|---|---|
| 好发 | 胰头部（约 70%） |
| 症状 | 上腹隐痛向腰背放射（夜间平卧加重）＋无痛性进行性黄疸＋消瘦 |
| Courvoisier 征 | 无痛性胆囊肿大（胰头/壶腹周围癌致下段梗阻） |
| 肿瘤标志 | CA19-9（常用监测指标） |
| 首选检查 | 增强薄层 CT（双管征：胰管+胆管扩张） |
| 手术 | 胰头癌：Whipple（胰十二指肠切除：胰头+远端胃+十二指肠+胆总管下段；胰肠+胆肠+胃肠吻合） |
| 体尾部 | 联合脾脏切除 |
| 化疗 | 吉西他滨类方案 |
| ⚠ | 40 岁以上黄疸+无痛性胆囊肿大先想胰腺癌/壶腹周围癌 |

## 十六、周围血管疾病（必背）

| 病名 | 核心机制 | 诊断关键 | 治疗要点 |
|---|---|---|---|
| 原发性下肢静脉曲张 | 浅静脉瓣膜功能不全 | 迂曲团块+色素沉着+内踝溃疡；试验见下 | 深静脉通畅→手术（高位结扎+剥脱/激光）；弹力袜保守 |
| DVT | Virchow 三要素 | 下肢肿痛+Homans 征；加压超声首选；D-二聚体筛查 | 抗凝（低分子肝素过渡华法林/DOAC，3~6 个月）；⚠ 急性期禁按摩挤压；最严重并发症=肺栓塞 |
| ASO | 动脉粥样硬化闭塞 | 老年+间歇性跛行→静息痛→坏疽；ABI<0.9 | 戒烟+运动+他汀+抗血小板；腔内介入/旁路搭桥 |
| 急性动脉栓塞 | 心源性栓子（房颤最常见） | ⚠ 5P 征：疼痛、苍白、无脉、感觉异常、麻痹 | 急诊取栓（发病 6~8 h 内为最佳时机） |
| 血栓闭塞性脉管炎 | 青壮年男性吸烟者，中小动静脉 | 游走性浅静脉炎+缺血表现；Buerger 试验阳性 | ⚠ 戒烟是根本；不支持动脉重建（流出道差） |

| 静脉功能试验 | 意义 |
|---|---|
| Trendelenburg 试验 | 大隐静脉瓣膜功能（松解后自下而上充盈=瓣膜关闭不全） |
| Perthes 试验 | 深静脉通畅试验；阳性（深静脉阻塞）→⚠ 禁忌浅静脉手术 |
| Pratt 试验 | 交通支瓣膜功能 |

| DVT 分型 | 要点 |
|---|---|
| 中央型 | 髂股静脉（左侧多见——髂静脉受压） |
| 周围型 | 小腿肌肉静脉丛/股-腘 |
| 混合型 | 全下肢 |
| 特殊处理 | 髂股型可导管溶栓/取栓；抗凝禁忌或肺栓塞再发→下腔静脉滤器 |

| ASO Fontaine 分期 | 内容 |
|---|---|
| Ⅰ | 无症状 |
| Ⅱ | 间歇性跛行 |
| Ⅲ | 静息痛 |
| Ⅳ | 溃疡/坏疽 |

## 【速记总表】

| 考点 | 必背内容 |
|---|---|
| 斜疝 vs 直疝 | 压内环：斜疝不再突出、直疝仍突出 |
| 海氏三角 | 腹直肌外缘+腹股沟韧带+腹壁下动脉 |
| 股疝 | 中年女性、最易嵌顿、McVay 修补 |
| 绞窄疝 | 动脉血供断→坏死；急诊手术、坏死者不做修补 |
| 腹穿点 | 脐与髂前上棘连线中外 1/3 |
| 实质 vs 空腔 | 内出血休克 vs 腹膜炎+膈下游离气体 |
| 脾破裂 | Kehr 征；被膜下延迟破裂 1~2 周 |
| 腹膜炎体位 | 半卧位（渗液入盆腔、减少吸收） |
| 幽门梗阻 | 呕吐宿食+低氯低钾碱中毒 |
| 十二指肠残端破裂 | 毕Ⅱ式特有、术后 3~6 天、右上腹剧痛 |
| 早期倾倒 | 餐后 30 min 内、高渗；少食多餐+餐后平卧 |
| 晚期倾倒 | 餐后 2~4 h 反应性低血糖 |
| 慢性输入袢梗阻 | 呕大量胆汁不含食物、吐后缓解 |
| 胃癌 D2 | 第二站淋巴结清扫标准根治 |
| 绞窄性肠梗阻 | 持续痛+血性呕吐物+腹膜刺激征→急诊 |
| 肠套叠 | 2 岁内+果酱样便+腊肠包块→空气灌肠复位 |
| 阑尾炎体征 | 麦氏点压痛最重要；腰大肌=盲肠后位；闭孔=盆位 |
| 阑尾周围脓肿 | 先保守/引流，3 个月后切阑尾 |
| 右半 vs 左半结肠癌 | 右半全身型（贫血包块）；左半梗阻型（便血梗阻早） |
| 直肠指检 | 中低位直肠癌多数可触及 |
| Dixon/Miles/Hartmann | 保肛吻合／永久造口／梗阻高危单口 |
| 肛裂三联征 | 肛裂+前哨痔+肛乳头肥大；后正中 |
| 肛瘘 | 挂线保护括约肌；处理内口是关键 |
| 内痔分度 | Ⅰ出血Ⅱ自纳Ⅲ手助Ⅳ不能 |
| 细菌 vs 阿米巴肝脓肿 | 多发黄白脓 vs 单发果酱样；引流 vs 甲硝唑 |
| 肝癌 AFP | ≥400 μg/L 持续 4 周（排除妊娠等） |
| 肝癌筛查 | 高危人群每 6 个月超声+AFP |
| Milan 标准 | 单发≤5 cm 或 ≤3 个各≤3 cm，无血管侵犯 |
| TACE | 不可切除中晚期首选姑息 |
| 门静脉压 | 正常 13~24 cmH₂O；>25 为高压 |
| 断流 vs 分流 | 断流保肝流、脑病少、急诊首选；分流降压好、脑病多 |
| AOSC | Reynolds 五联征→胆道减压引流（ERCP/PTCD/T 管） |
| 胆管癌 | 上段 Klatskin 最多；进行性无痛性黄疸 |
| 胰腺炎重症 | 血钙<1.87 预后不良；酶高低≠病情 |
| Whipple | 胰十二指肠切除（胰头癌） |
| CA19-9 | 胰腺癌监测 |
| 静脉曲张试验 | Trendelenburg 瓣膜；Perthes 深静脉通畅（阳性禁手术）；Pratt 交通支 |
| DVT | 抗凝 3~6 月；急性期禁按摩；警惕肺栓塞 |
| Fontaine | Ⅰ无症状 Ⅱ跛行 Ⅲ静息痛 Ⅳ坏疽 |
| 5P 征 | 疼痛、苍白、无脉、感觉异常、麻痹——急性动脉栓塞 |
| 脉管炎 | 青壮年吸烟；戒烟是根本 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 斜疝 vs 直疝 vs 股疝 | 青壮年、入阴囊、压内环不再出 | 老年、海氏三角、压内环仍出 | 股疝：女性、卵圆窝、最易嵌顿 |
| 嵌顿 vs 绞窄 | 静脉受阻、淤血水肿 | ⚠ 动脉受阻、肠坏死 | 一旦怀疑绞窄立即手术 |
| 早期 vs 晚期倾倒 | 30 min 内、高渗性、腹泻 | 2~4 h、低血糖、进糖缓解 | 时间点定类型 |
| 输入袢 vs 吻合口梗阻 | 慢性：呕大量胆汁不含食物 | 吻合口：呕食物不含胆汁 | 看"有胆无胆" |
| 右半 vs 左半结肠癌 | 贫血+包块+全身症状 | 便血+梗阻早 | 管腔宽窄决定梗阻早晚 |
| 断流 vs 分流 | 脑病少、再出血多、急诊首选 | 脑病多、降压好、择期 | 保肝血流 vs 牺牲肝血流 |
| 细菌 vs 阿米巴肝脓肿 | 多发、寒战高热、黄白脓 | 单发、果酱样、甲硝唑有效 | 脓液颜色与性状 |
| ASO vs 脉管炎 | 老年、大中动脉、可介入 | 青壮年吸烟、中小血管、戒烟为主 | 年龄+血管口径 |
