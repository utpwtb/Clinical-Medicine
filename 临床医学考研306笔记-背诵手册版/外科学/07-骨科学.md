# 外科学·背诵手册版——07 骨科学

> 冲刺背诵版：全表格、短句，一行一考点；⚠=高频易错。
> 覆盖：骨折总论、四肢脊柱骨盆、脱位、周围神经、慢性损伤、腰腿痛颈椎病、感染结核、骨肿瘤。

## 一、骨折总论（必背）

| 项目 | 要点 |
|---|---|
| 专有体征（三大） | ⚠ 畸形、异常活动、骨擦音/骨擦感——有其一即可确诊；禁止故意诱发 |
| 其他表现 | 疼痛、肿胀、功能障碍 |
| 疲劳骨折 | 长距离行军/跑跳——第二跖骨、胫骨 |
| 按骨折端稳定 | 稳定性（横形、嵌插）vs 不稳定性（斜形、螺旋、粉碎） |

| 愈合三期 | 时间 | 特征 |
|---|---|---|
| 血肿炎症机化期 | 约伤后 2 周 | 血肿机化、肉芽组织 |
| 原始骨痂形成期 | 约伤后 4~8 周 | 内外骨痂会师，临床愈合 |
| 骨痂改造塑形期 | 8~12 周起，历时更长 | 骨痂改造为成熟板层骨 |

| 影响愈合因素 | 要点 |
|---|---|
| 最关键 | 局部血供（⚠ 股骨颈头下型、腕舟骨腰部、距骨易缺血坏死） |
| 治疗因素 | 反复复位、固定不牢、过度牵引、过早负重 |
| 其他 | 感染、软组织嵌入、年龄营养 |

| 早期并发症 | 要点 |
|---|---|
| 休克 | 股骨干、骨盆骨折大出血 |
| 脂肪栓塞综合征 | 长骨骨折后 1~3 天：呼吸窘迫＋神志改变＋颈胸前瘀点 |
| 骨筋膜室综合征 | 见下表 |
| 血管神经损伤 | 肱骨髁上→肱动脉；肱骨干→桡神经 |

| 骨筋膜室综合征 | 要点 |
|---|---|
| 机制 | 骨筋膜室内压力增高→肌肉神经缺血 |
| 最早最可靠 | ⚠ 被动牵拉痛（被动牵拉受累肌肉剧痛） |
| 5P | 疼痛→感觉异常→麻痹→苍白→无脉（无脉为晚期表现） |
| 危险时限 | ⚠ 缺血>8 h 肌肉坏死→Volkmann 挛缩（爪形手） |
| 处理 | 立即筋膜室切开减压，禁抬高患肢、禁热敷 |

| 晚期并发症 | 要点 |
|---|---|
| 坠积性肺炎、压疮、DVT | 长期卧床三大并发症 |
| 损伤性骨化（骨化性肌炎） | ⚠ 肘部多见；过早粗暴活动/复位所致 |
| 创伤性关节炎 | 关节内骨折复位不良 |
| 缺血性骨坏死 | 股骨头、舟骨、距骨 |
| 缺血性肌挛缩 | 骨筋膜室综合征晚期=Volkmann 挛缩 |
| 愈合异常 | 延迟愈合、不愈合（假关节）、畸形愈合 |

| 功能复位标准（必背） | 内容 |
|---|---|
| 必须完全纠正 | 旋转移位、分离移位 |
| 短缩移位 | 成人下肢<1 cm；儿童<2 cm（可自行矫正） |
| 成角移位 | 与关节活动方向一致的轻微前/后成角可接受；侧方成角必须纠正 |
| 对位 | 长骨干横形骨折对位≥1/3；干骺端骨折≥3/4 |
| ⚠ 特殊 | 前臂双骨折要求对位对线均好（旋转功能） |
| 治疗三原则 | 复位、固定、功能锻炼 |
| 固定方式 | 石膏（超关节、可塑形）；小夹板（不超关节）；牵引；内固定（髓内钉/钢板）；外固定架（开放骨折） |

## 二、上肢骨折（必背）

| 骨折 | 好发/机制 | 特征表现 | 神经血管 | 治疗 |
|---|---|---|---|---|
| 锁骨骨折 | 中外 1/3 最常见 | 近端上移（胸锁乳突肌）、远端下移 | — | 8 字绷带；移位明显/开放→钢板 |
| 肱骨外科颈骨折 | 老年人 | 外展/内收型分类 | 腋神经偶伤 | 保守为主 |
| 肱骨干骨折 | 中下 1/3 | — | ⚠ 桡神经→垂腕+虎口区麻木 | 保守（夹板/悬吊石膏）或手术 |
| 肱骨髁上骨折（伸直型 90%） | 儿童、手掌撑地 | 远折端向后上移位 | ⚠ 肱动脉→Volkmann 挛缩；正中/桡神经 | 闭合复位石膏；肿胀重→尺骨鹰嘴牵引 |
| 肱骨髁上骨折晚期 | — | ⚠ 肘内翻（最常见晚期并发症） | — | 影响功能者截骨矫形 |
| 尺桡骨干双骨折 | 直接/间接暴力 | 前臂旋转受限 | — | ⚠ 要求解剖复位，多手术内固定 |
| Colles 骨折（伸直型） | 老年骨质疏松、手掌撑地 | ⚠ 银叉样+枪刺样畸形；远折端向背侧、桡侧移位 | — | 手法复位+石膏（掌屈尺偏位） |
| Smith 骨折（屈曲型） | 腕背着地 | 远折端向掌侧移位（反 Colles） | — | 复位+石膏 |
| ⚠ 髁上骨折 vs 肘脱位 | 髁上骨折肘后三角关系正常 | 肘关节脱位肘后三角改变 | | 靠肘后三角区分 |

| 儿童骨骺损伤 Salter-Harris 分型 | 内容 |
|---|---|
| Ⅰ 型 | 经骺板骨骺分离 |
| Ⅱ 型 | 骨骺分离＋干骺端骨折（最常见） |
| Ⅲ 型 | 经骨骺骨折（关节内） |
| Ⅳ 型 | 骨骺＋干骺端骨折（关节内） |
| Ⅴ 型 | 骺板挤压伤——⚠ 预后最差，易生长障碍 |

## 三、下肢骨折（必背）

| 骨折 | 要点 |
|---|---|
| 股骨颈骨折 | 老年骨质疏松、轻微外伤；患肢短缩、屈曲、⚠ 外旋 45°~60° |
| 股骨颈血供 | 旋股内侧动脉分支（骺外侧动脉）为主——⚠ 头下型易缺血坏死+不愈合 |
| Garden 分型 | Ⅰ 不完全；Ⅱ 完全无移位；Ⅲ 部分移位；Ⅳ 完全移位 |
| Pauwels 角 | <30°（外展型）稳定；>50°（内收型）不稳定 |
| 股骨颈治疗 | 无移位/年轻：闭合复位空心螺钉；老年移位型/头下型：人工髋关节置换 |
| 股骨转子间骨折 | 更高龄；⚠ 患肢外旋可达 90°（与股骨颈鉴别关键）；极少缺血坏死；髓内钉/DHS 内固定 |
| 股骨干骨折 | 高能损伤；闭合性内出血可达 500~1000 ml→休克 |
| 股骨干移位 | 近段屈曲外展外旋（髂腰肌）；远段向后（腓肠肌）——警惕腘血管 |
| 股骨干治疗 | 成人首选闭合复位交锁髓内钉；儿童可牵引 |
| 髌骨骨折 | 股四头肌牵拉横断；移位大/伸膝装置破坏→张力带钢丝内固定 |
| 胫腓骨骨折 | 全身长骨骨折最常见；胫前内紧贴皮下→开放性多见 |
| 胫腓骨并发症 | ⚠ 骨筋膜室综合征（4 室）；中下 1/3 血供差→延迟/不愈合 |
| 胫腓骨治疗 | 交锁髓内钉；开放伤外固定架 |

## 四、脊柱与骨盆骨折

| 项目 | 要点 |
|---|---|
| 好发部位 | 胸腰段（T10~L2） |
| Denis 三柱 | 前柱+中柱+后柱；⚠ 中柱破坏=不稳定 |
| 压缩骨折 | 前柱压缩；爆裂骨折——中柱破坏、骨块入椎管 |
| Chance 骨折 | 屈曲牵张损伤（安全带型） |
| 骨折脱位 | 三柱均损——最不稳定 |
| 寰椎 Jefferson 骨折 | 寰椎前后弓爆裂；开口位片侧块外移 |
| 枢椎 Hangman 骨折 | 过伸损伤（绞刑骨折） |
| 脊髓损伤 Frankel 分级 | A 完全性；B 无运动仅有感觉；C 无益运动；D 有益运动；E 正常 |
| 脊髓半切（Brown-Séquard） | ⚠ 同侧运动+本体感觉障碍，对侧痛温觉障碍 |
| 中央管综合征 | 上肢重于下肢（颈髓过伸伤） |
| 骨盆骨折 | 高能量伤；⚠ 腹膜后大出血（失血性休克首因） |
| 骨盆骨折合并伤 | ⚠ 后尿道损伤最常见；膀胱、直肠、坐骨神经、女性生殖道 |
| 骨盆急救 | 骨盆带固定；持续出血→DSA 动脉栓塞 |
| 治疗 | 不稳定/神经损害→手术减压内固定；甲泼尼龙冲击仅伤后 8 h 内考虑（存在争议） |

| 脊柱脊髓伤搬运原则 | 内容 |
|---|---|
| 原则 | 保持脊柱轴线位，避免扭转、屈伸 |
| 方法 | 整体滚动/多人平托，木板或硬担架搬运 |
| 颈髓伤 | 专人固定头颈部，沿纵轴牵引 |
| ⚠ 禁忌 | 一人抬肩一人抬腿、软担架、随意背抱 |

## 五、关节脱位（必背）

| 脱位 | 机制 | 特征体征 | 处理 |
|---|---|---|---|
| 肩关节前脱位（最常见） | 外展外旋传导暴力 | 方肩畸形+Dugas 征阳性（患手搭对侧肩、肘不能贴胸）+弹性固定 | Hippocrates 足蹬法复位；三角巾固定 3 周；⚠ 易成习惯性脱位（Bankart 损伤） |
| 肘关节后脱位（第二常见） | 跌倒手掌撑地 | ⚠ 肘后三角关系改变（与髁上骨折鉴别）；弹性固定 | 复位后固定 2~3 周；⚠ 防骨化性肌炎（忌粗暴过早活动） |
| 桡骨头半脱位 | <5 岁、前臂牵拉 | 患肢拒动、不肯持物；X 线阴性 | 手法复位：旋后+屈肘，复位后不需固定 |
| 髋关节后脱位（最常见） | 屈膝屈髋位膝部撞击（仪表盘伤） | ⚠ 患肢屈曲、内收、内旋、短缩畸形；大转子上移 | Allis 提拉法复位（越早越好，防股骨头坏死）；⚠ 合并坐骨神经损伤；复位后牵引 3~4 周 |
| 髋关节前脱位 | — | 患肢外展、外旋、屈曲畸形 | — |
| ⚠ 畸形速记 | 肩前脱=方肩+Dugas；髋后脱=屈内收内旋短缩；股骨颈=外旋 45°~60° | | |

## 六、周围神经损伤（五对大表）

| 神经 | 常见损伤 | 运动障碍 | 感觉障碍 | 特征手/足畸形 |
|---|---|---|---|---|
| 桡神经 | ⚠ 肱骨干中下 1/3 骨折 | 伸腕、伸拇、伸指不能 | 虎口区（手背桡侧）麻木 | 垂腕 |
| 桡神经深支 | 桡骨小头附近 | 伸指不能但伸腕保留（不垂腕） | 无明显感觉区 | 垂指不垂腕 |
| 正中神经 | 腕部（腕管）、肘部 | 拇对掌不能、大鱼际萎缩 | 桡侧三个半指掌面感觉障碍 | 猿手 |
| 尺神经 | 肘部（肘管）、腕部 | 骨间肌/蚓状肌麻痹：掌指关节过伸+指间关节屈曲 | 小指+环指尺侧感觉障碍 | 爪形手+Froment 征阳性 |
| 腓总神经 | ⚠ 腓骨颈（石膏/体位压迫） | 足背伸、外翻不能 | 小腿前外侧+足背感觉障碍 | 马蹄内翻足（足下垂） |
| 坐骨神经 | 髋后脱位、臀部注射不当 | 膝以下运动障碍 | 足部感觉障碍 | 足下垂 |
| 治疗要点 | 一期缝合（锐器清洁伤）；神经再生判断：Tinel 征（叩击向远端放射处=再生前沿） | | | |

## 七、运动系统慢性损伤

| 疾病 | 要点 |
|---|---|
| 肩周炎（冻结肩） | 50 岁前后（五十肩）；各方向主动+被动均受限（外旋最早受限）；夜间痛；三角肌萎缩；自限（1~2 年） |
| 肩周炎治疗 | ⚠ 功能锻炼（爬墙、钟摆）是关键＋NSAIDs＋封闭 |
| 网球肘（肱骨外上髁炎） | 伸腕肌起点劳损；肘外侧痛；Mill 征阳性（握拳屈腕、前臂旋前、伸肘时痛） |
| 网球肘治疗 | 制动+封闭（⚠ 不宜反复多次注射） |
| 桡骨茎突狭窄性腱鞘炎 | Finkelstein 征阳性（拇指内收握拳尺偏时痛） |
| 弹响指（手指屈肌腱鞘炎） | 掌指关节掌侧压痛+弹响交锁 |
| 腕管综合征 | 正中神经卡压；中年女性；⚠ 夜间麻醒、甩手缓解（特征性）；大鱼际萎缩、对掌障碍 |
| 腕管检查 | Phalen 征（屈腕 1 min 诱发）阳性；Tinel 征；肌电图确诊 |
| 腕管治疗 | 制动+封闭；无效→屈肌支持带切开（内镜） |
| 股骨头缺血性坏死 | 病因：⚠ 大量长期激素（最常见）、酒精、股骨颈头下型骨折、减压病 |
| 股骨头坏死表现 | 腹股沟区痛+跛行；4 字试验阳性 |
| 股骨头坏死影像 | ⚠ MRI 最敏感最早（双线征）；X 线：新月征→塌陷 |
| 股骨头坏死治疗 | 塌陷前保头（髓芯减压+植骨等）；塌陷后期→人工髋关节置换 |

## 八、腰腿痛与颈肩痛（必背）

| 腰椎间盘突出定位 | 受累神经根 | 感觉异常 | 肌力异常 | 反射 |
|---|---|---|---|---|
| L4~5 椎间盘 | L5 神经根 | 小腿外侧+足背 | 踇趾背伸无力 | 多无明显改变 |
| L5~S1 椎间盘 | S1 神经根 | 小腿后外侧+足外侧 | 足跖屈/踇屈无力 | ⚠ 跟腱反射减弱 |
| ⚠ 占比 | 约 90% 位于 L4~5 与 L5~S1 | | | |

| 腰椎间盘突出症 | 要点 |
|---|---|
| 症状 | 腰痛+坐骨神经痛（沿大腿后→小腿→足放射；咳嗽喷嚏加重） |
| 直腿抬高试验 | <60° 出现放射痛为阳性；加强试验阳性→真性神经根受压 |
| ⚠ 马尾综合征 | 中央型巨大突出：鞍区麻木+大小便功能障碍+性功能障碍——⚠ 急诊手术指征 |
| 非手术 | 绝对卧床（硬板床）+牵引+NSAIDs+神经营养；多数可缓解 |
| 手术指征 | ①马尾综合征（急诊）；②进行性肌力下降/足下垂；③规范保守 3 个月无效且影响生活；④反复发作 |
| 术式 | 椎板开窗髓核摘除为基础；不稳定者行融合内固定 |

| 项目 | 腰椎间盘突出症 | 腰椎管狭窄症 |
|---|---|---|
| 典型 | 坐骨神经放射痛、直腿抬高阳性 | ⚠ 间歇性跛行（行走加重、蹲坐/前屈缓解、骑车可） |
| 体征 | 明显 | ⚠ 症状重而体征轻、直腿抬高常阴性 |
| 影像 | 突出压迫神经根 | 椎管矢状径减小（三叶草形椎管） |

| 颈椎病四型 | 要点 |
|---|---|
| 神经根型（最常见） | 颈肩痛+上肢放射痛麻木；Spurling 压头试验+臂丛牵拉试验阳性 |
| 脊髓型（最严重） | 四肢无力、精细动作障碍（扣扣子、持筷）+踩棉花感+束带感；⚠ 腱反射亢进+Hoffmann 征/Babinski 征阳性 |
| 脊髓型治疗 | ⚠ 诊断明确宜尽早手术（前路 ACDF/后路单开门）；⚠ 严禁推拿按摩牵引粗暴治疗（可致瘫痪） |
| 交感型 | 头晕、眼花、心悸等交感症状 |
| 椎动脉型 | 转头时眩晕、猝倒 |
| 检查 | MRI 首选 |

## 九、化脓性骨髓炎与化脓性关节炎

| 急性血源性骨髓炎 | 要点 |
|---|---|
| 好发 | 儿童长骨干骺端（血流丰富缓慢）；金葡最常见 |
| 表现 | 寒战高热+干骺端深压痛+患肢拒动 |
| ⚠ X 线 | 起病 14 天内多无异常（骨质破坏与骨膜反应出现晚）——勿等 X 线延误 |
| 早期影像 | MRI 最敏感（骨髓水肿/脓肿）；核素骨扫描早期阳性 |
| 确诊 | ⚠ 分层穿刺抽脓+培养 |
| 治疗 | 大剂量敏感抗生素（足程）＋保守 48~72 h 无效→钻孔开窗引流＋患肢制动（石膏） |
| 慢性骨髓炎 | 死骨+死腔+窦道（包壳形成）；手术：病灶清除+肌瓣填充等 |

| 化脓性关节炎 | 要点 |
|---|---|
| 病原/关节 | 金葡；膝关节最常见 |
| 表现 | 关节红肿热痛、屈曲位强直 |
| 确诊 | ⚠ 关节穿刺：脓性/浑浊液，白细胞显著增高、中性为主，涂片培养阳性 |
| ⚠ 时间窗 | 软骨破坏可在起病 48~72 h 内开始——尽早处理 |
| 治疗 | 全身抗生素+关节穿刺冲洗／关节镜灌洗清创（首选）／切开引流；功能位制动+适当活动防强直 |

## 十、骨与关节结核

| 脊柱结核 | 要点 |
|---|---|
| 地位 | 骨关节结核最常见部位（椎体为主，胸腰段多） |
| 病理 | 边缘型侵蚀椎间盘→⚠ 椎间隙变窄（与肿瘤椎间隙正常鉴别） |
| 表现 | 腰背痛+后凸畸形+⚠ 寒性脓肿（不红不热）+截瘫（最严重并发症） |
| 脓肿流向 | 椎旁→腰大肌→髂窝/大腿 |
| 影像 | MRI 早期敏感；X 线：椎体破坏楔变+椎间隙狭窄+椎旁脓肿 |
| 治疗 | 抗结核药物（异烟肼+利福平+吡嗪酰胺+乙胺丁醇等，长程）＋支具；手术：病灶清除+植骨融合+内固定（神经受压/脓肿/死骨/不稳者） |

| 关节结核 | 要点 |
|---|---|
| 髋关节结核 | 儿童；跛行；⚠ 可仅表现为膝痛（闭孔神经牵涉——髋病膝痛）；Thomas 征阳性 |
| 膝关节结核 | 梭形肿胀、浮髌试验阳性 |
| 治疗原则 | 抗痨+牵引/制动；病灶清除；晚期功能位融合 |

## 十一、骨关节炎（OA）

| 项目 | 要点 |
|---|---|
| 本质 | 关节软骨退变+骨赘形成（负重关节） |
| 好发 | 膝、髋；手远端指间（Heberden 结节）、近端指间（Bouchard 结节） |
| 疼痛特点 | 活动后加重、休息缓解；晨僵<30 min |
| ⚠ X 线 | ①关节间隙不对称变窄（最早）；②骨赘；③软骨下骨硬化+囊性变；④关节内游离体 |
| 膝 OA | 内翻畸形（O 形腿） |
| 治疗 | 教育+减重+股四头肌锻炼→NSAIDs/对乙酰氨基酚→透明质酸关节腔注射（激素注射不宜频繁）→截骨矫形（年轻早中期）→人工关节置换（终末期金标准） |

## 十二、骨肿瘤（必背）

| 良恶性鉴别 | 良性 | 恶性 |
|---|---|---|
| 生长速度 | 慢 | 快 |
| 疼痛 | 无痛/轻痛 | ⚠ 进行性加重、夜间痛 |
| 局部 | 界清、无压痛、皮温正常 | 界不清、皮温高、静脉怒张、压痛 |
| 转移 | 无 | 有（骨肉瘤→肺） |
| X 线 | 界限清、膨胀性、硬化边、无骨膜反应 | 虫蚀样破坏、⚠ 骨膜反应（Codman 三角/日光射线/葱皮样）、软组织肿块 |

| 肿瘤 | 年龄 | 部位 | X 线特征 | 治疗 |
|---|---|---|---|---|
| 骨软骨瘤 | 青少年 | 长骨干骺端（股骨下端、胫骨上端） | 骨性突起+软骨帽 | 无症状观察；压迫/恶变倾向→切除 |
| 骨巨细胞瘤 | 20~40 岁 | 长骨骨端（股骨下端、胫骨上端、桡骨远端） | ⚠ 偏心性溶骨、肥皂泡样、无骨膜反应 | 交界性（潜在恶性）；扩大刮除+灭活+骨水泥/植骨 |
| 骨肉瘤（最常见原发恶性） | 10~20 岁 | 长骨干骺端（膝周） | ⚠ 成骨/溶骨混合+Codman 三角+日光射线 | 新辅助化疗→广泛切除（保肢）→术后化疗；易肺转移 |
| 尤因肉瘤 | 5~15 岁儿童 | 长骨骨干/扁骨 | ⚠ 葱皮样骨膜反应+虫蚀样破坏 | ⚠ 对放化疗敏感；CD99 阳性 |
| 软骨肉瘤 | 成人 | 骨盆、股骨 | 点状/环状钙化 | 手术为主（放化疗不敏感） |
| 骨囊肿 | 儿童 | 干骺端中心性 | 椭圆透亮区 | 病理性骨折常为首发；刮除+植骨 |
| 骨纤维异常增殖症 | — | — | 磨玻璃样改变 | — |
| 转移性骨肿瘤 | 中老年 | 脊柱（胸腰段）最常见 | 成骨/溶骨 | 姑息：放疗止痛+双膦酸盐/地诺单抗+内固定/椎体成形 |

| 转移癌来源配对（必背） | 要点 |
|---|---|
| 成骨性转移 | ⚠ 前列腺癌最典型；部分乳腺癌 |
| 溶骨性转移 | 肺癌、肾癌、甲状腺癌、多数乳腺癌 |
| ⚠ 筛查注意 | 纯成骨转移骨扫描可"假阴性"显像减低灶需结合影像 |

## 【易混对照】

| 组别 | A | B | 鉴别要点 |
|---|---|---|---|
| 股骨颈 vs 转子间 | 外旋 45°~60°、易坏死不愈合 | 外旋 90°、极少坏死 | 外旋程度是第一线索 |
| 肱骨髁上骨折 vs 肘脱位 | 儿童伸直型、肘后三角正常 | 弹性固定、肘后三角改变 | 肘后三角定乾坤 |
| 骨巨 vs 骨肉瘤 | 20~40、骨端、肥皂泡、刮除 | 10~20、干骺端、日光射线、化疗+切除 | 部位（骨端/干骺端）+影像 |
| 骨肉瘤 vs 尤因 | 干骺端、Codman+日光 | 骨干、葱皮样、CD99、放化疗敏感 | 部位+骨膜反应形态 |
| LDH vs 椎管狭窄 | 直腿抬高（+）、放射痛 | 间歇跛行、前屈缓解、体征轻 | 骑车不受限=狭窄 |
| 神经根型 vs 脊髓型颈椎病 | 上肢放射麻、压头试验（+） | 四肢无力+病理征+踩棉花感 | 有无下肢上运动元征 |
| 骨髓炎 vs 化脓性关节炎 | 干骺端深压痛、关节活动可部分保留 | 关节内剧痛、各向活动全受限、穿刺定诊 | 部位+穿刺 |
| 脊柱结核 vs 转移瘤 | 椎间隙变窄、寒性脓肿 | ⚠ 椎间隙正常、年龄大、原发瘤史 | 椎间隙是分水岭 |
| OA vs RA | 负重大关节、晨僵<30 min、骨赘 | 对称小关节、晨僵>1 h、骨侵蚀 | 晨僵时长+关节分布 |

## 【记忆口诀】

- 骨折专有体征："畸动擦"——畸形、异常活动、骨擦音。
- 骨筋膜室 5P："痛感麻白无"——疼痛、感觉异常、麻痹、苍白、无脉；牵拉痛最早。
- 神经配对："肱干桡垂腕，髁上动脉险；尺爪正中猿，腓总马蹄翻"。
- Colles："银叉枪刺背桡偏，掌屈尺偏来复原"。
- 股骨颈与转子间："颈旋四五转子九，头下缺血置换走"。
- 腰椎定位："四五背伸无反射，五一跟腱往外偏"（L4-5 踇背伸弱、反射正常；L5-S1 跟腱反射减弱）。
- 骨肿瘤记忆："巨瘤端上泡，肉瘤骺上烧，尤因葱皮骨干绕，成骨前列腺跑"。
- OA 的 X 线："窄、赘、硬、囊、游离体"——间隙窄、骨赘、硬化、囊变、游离体。
- 骨髓炎："十四天上骨，穿刺定乾坤；钻孔加开窗，抗生要足程"。
- 脊髓半切："同动同本，对侧痛温"。
