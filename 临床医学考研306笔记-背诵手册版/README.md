# 临床医学考研 306 笔记 · 背诵手册版

> **定位**：冲刺阶段**背诵与快速翻查手册**。全表格化、短句、每行一个信息点，信息密度最大化；每系统末尾附【速记总表】＋【易混对照】＋【记忆口诀】。
> **编写基准**：人卫第 10 版教材体系与现行主流指南共识；宁缺毋滥——不确定的数据不收录，背诵内容以稳定口径为准。
> **标记约定**：★ 必背 ｜ ⚠ 易错 ｜ 表格优先，无长段落。

## 三套版本怎么配合用

| 阶段 | 用哪套 | 怎么用 |
|---|---|---|
| 一轮 | 讲义精讲版 + 教材 | 逐病精读建立框架 |
| 二轮 | 真题导向版 + 真题 | 考点回看、避开陷阱 |
| **冲刺** | **背诵手册版（本版）** | 每天按系统过【速记总表】；易混对照反复看；口诀辅助记忆 |
| 考前 | 背诵手册版【速记总表】+ 第一版速记 | 只过数值、标准、首选药 |

## 背诵建议
1. 数值类（分级、阈值、剂量界限）每天过一遍【速记总表】，用手指遮住右列自测。
2. 易混对照按"配对"记：斜疝-直疝、文氏-MobitzⅡ、缺铁-海洋性、骨巨-骨肉瘤……
3. 口诀只作检索线索，记不准时回到对应表格核对完整内容。
