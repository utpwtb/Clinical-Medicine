## 第二章 细胞的基本功能

### 2.1 细胞膜物质转运

| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
|---|---|---|---|
| 单纯扩散 | 脂溶性小分子顺浓度梯度，不耗能 | O2、CO2、N2、乙醇、尿素 | 无需膜蛋白、无饱和现象 |
| 通道易化扩散 | 离子经门控通道顺电化学梯度 | Na+、K+、Ca2+、Cl-；水经AQP | 门控分电压/化学/机械门控 |
| 载体易化扩散 | 载体构象改变转运底物，不耗能 | 葡萄糖入一般细胞(GLUT)、氨基酸 | 有饱和现象；肠黏膜/肾小管管腔侧为继发主动 |
| 原发主动转运 | 直接分解ATP逆梯度转运 | Na-K泵：3Na+出、2K+入，耗1ATP | 哇巴因(洋地黄)抑制Na-K泵 |
| Na-K泵意义 | 维持Na/K梯度、静息电位、细胞容积、继发转运能量 | 具生电效应 | Na-K泵被抑→继发主动转运随之减弱 |
| 继发主动转运 | 间接利用Na+浓度势能 | SGLT(Na-葡萄糖同向)、Na-Ca交换(反向)、Na-K-2Cl同向 | 同向=共转运，反向=反交换 |
| 出胞/入胞 | 大分子经膜泡转运 | 递质释放需Ca2+；入胞分吞噬与吞饮 | 出胞属主动过程 |
| G蛋白耦联受体 | 经G蛋白-第二信使(如cAMP)转导 | 7次跨膜受体 | 作用慢而持久 |
| 离子通道型受体 | 配体门控，直接改变离子流 | N2型ACh受体 | 作用快 |
| 酶联型受体 | 胞内段具酶活性或偶联酶 | 酪氨酸激酶受体(胰岛素受体) | — |

### 2.2 细胞电生理

| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
|---|---|---|---|
| 静息电位 | K+外流达到平衡，接近K+平衡电位 | 内负外正 | 细胞外K+升高→RP绝对值减小 |
| RP形成条件 | 膜对K+选择性通透+膜内外K+浓度差 | K+梯度由Na-K泵维持 | RP略小于EK（少量Na+内漏） |
| AP上升支 | Na+经电压门控通道爆发性内流 | 去极化达阈电位触发、可超射 | 上升支绝不是K+外流 |
| AP下降支 | K+外流复极化 | Na+通道失活后需复活 | — |
| 全或无 | AP幅度不随刺激强度增大 | 强度以频率编码 | AP传导不衰减 |
| 兴奋性周期 | 绝对不应期→相对不应期→超常期→低常期 | 绝对不应期=Na+通道失活 | 超常期兴奋性最高 |
| 局部电位 | 阈下刺激产生的等级性电位 | ①等级性②衰减传导③可总和④无不应期 | 终板电位、EPSP/IPSP皆属之 |

### 2.3 神经-骨骼肌接头与收缩

| 条目 | 一句话要点/机制 | 必背数值或关键词 | 一句易错点 |
|---|---|---|---|
| 接头传递 | AP→Ca2+内流→ACh量子式释放→N2受体→终板电位→肌膜AP | 前膜释放ACh依赖Ca2+ | 终板电位是局部电位，总和达阈电位才触发AP |
| 量子释放 | 每个囊泡为一个"量子" | 囊泡释放 | 肉毒毒素抑制ACh释放、肌无力与接头传递障碍相关 |

| 三联管 | T管+两侧终池 | 骨骼肌耦联结构 | 心肌以二联管为主 |
| 前负荷 | 初长度决定收缩张力 | 肌节2.0-2.2μm最适 | 过长过短张力均下降 |

## 第三章 血液

|---|---|---|---|
| 血量 | 占体重比例恒定 | 7%-8%（约70-80ml/kg） | 少量失血(<10%)可代偿 |
| 血细胞比容 | 红细胞占全血容积百分比 | 男40%-50%、女37%-48% | — |

| 血沉ESR | 红细胞第一小时末下沉距离 | 加快：纤维蛋白原↑、球蛋白↑；白蛋白↓ | ESR取决于血浆成分，非红细胞本身 |

| 白细胞分类 | 中性粒50%-70%、淋巴20%-40%、单核3%-8%、嗜酸0.5%-5%、嗜碱0%-1% | 总数(4-10)×10⁹/L | 儿童淋巴细胞比例较高 |
| 血小板 | 生理特性：黏附、释放、聚集、收缩、吸附 | (100-300)×10⁹/L | 聚集依赖纤维蛋白原与GPⅡb/Ⅲa |
| 生理性止血 | 血管收缩→血小板血栓→血液凝固 | 出血时间与血小板相关 | 出血时间≠凝血时间 |
| 内源性凝血 | Ⅻ启动，速度慢 | 因子全在血浆中 | 由血管内膜损伤激活 |
| 外源性凝血 | 组织因子(FⅢ/TF)启动，速度快 | TF是生理性凝血启动子 | — |

| 依赖VitK因子 | 肝合成需VitK参与羧化 | Ⅱ、Ⅶ、Ⅸ、Ⅹ | Ⅳ=Ca2+；Ⅴ、Ⅷ最不稳定 |
| 抗凝系统 | 抗凝血酶Ⅲ+肝素协同灭活凝血酶等 | 肝素增强抗凝血酶Ⅲ活性 | 体外抗凝用枸橼酸盐螯合Ca2+ |

## 【易混对照】

| 组别 | 一句话辨析 |
|---|---|
| 正反馈vs前馈 | 正反馈是输出加强输入"滚雪球"；前馈是干扰信号提前的"预防性"调节 |
| 绝对不应期vs有效不应期 | 绝对不应期Na+通道完全失活；心肌有效不应期还包括Na+通道少量复活的局部反应期 |
| 异长vs等长自身调节 | 异长=前负荷(初长度)改变；等长=心肌收缩力改变 |
| 波尔效应vs何尔登效应 | 波尔=pH/PCO2影响Hb与O2结合；何尔登=氧合状态影响Hb与CO2结合 |
| 胃泌素vs促胰液素vsCCK | 胃泌素促胃酸；促胰液素促胰液水碱并抑酸；CCK促胰酶并缩胆囊 |
| 应激vs应急 | 应激=ACTH-糖皮质激素轴；应急=交感-肾上腺髓质系统 |
| 腱反射vs肌紧张 | 腱反射单突触快速位相性；肌紧张多突触持续紧张性、维持姿势 |
| 慢波睡眠vsREM睡眠 | 慢波睡眠生长激素↑促生长恢复；REM梦境、肌张力最低、脑电似清醒 |
| 帕金森病vs亨廷顿病 | 帕金森=黑质DA↓、肌张力↑运动减少；亨廷顿=纹状体GABA↓、舞蹈样动作肌张力↓ |
| 呆小症vs黏液性水肿 | 呆小症=胚胎或新生儿甲低；黏液性水肿=成人甲低 |
| 水利尿vs渗透性利尿 | 水利尿=大量清水后ADH↓；渗透性利尿=小管液溶质浓度↑（糖尿病、甘露醇） |
| 心迷走vs心交感 | 迷走递质ACh(M)抑制心脏；交感递质NE(β1)兴奋心脏 |
| 突触后vs突触前抑制 | 后抑制经IPSP超极化实现；前抑制减少前膜Ca2+内流使EPSP幅度↓ |
| ERP vs RRP | ERP任何强刺激均无AP；RRP阈上刺激可产生AP |
