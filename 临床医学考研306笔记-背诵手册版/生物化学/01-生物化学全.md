## 【易混对照】

| 组别 | 一句话辨析 |
|---|---|
| 竞争性vs非竞争性抑制 | 竞争性Km↑Vmax不变（可加大底物解除）；非竞争性Km不变Vmax↓ |
| 辅酶vs辅基 | 辅酶松散结合易透析分离；辅基共价紧密结合 |

| 肝糖原vs肌糖原 | 肝有G6P酶可直接升血糖；肌无G6P酶、只能自用 |
| 酮体生成vs利用 | 生成限速HMG-CoA合酶在肝；利用限SCOT在肝外，肝不能利用酮体 |
| 嘌呤vs嘧啶分解 | 嘌呤→尿酸(痛风)；嘧啶→NH3、CO2、β-氨基酸，不产尿酸 |
| 模板链vs编码链 | 模板链被转录读取(反义)；编码链序列与mRNA相同仅T/U之差(有义) |
| 外显子vs内含子 | 外显子保留于成熟mRNA；内含子被剪接去除 |
| 原癌激活vs抑癌失活 | 原癌激活为显性(一次即效)；抑癌失活为隐性(两次打击) |
| 变构调节vs化学修饰 | 变构=S形曲线+效应剂结合；修饰=磷酸化等共价可逆+级联放大 |
