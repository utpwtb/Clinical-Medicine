# 内科学·背诵手册版——04 泌尿系统

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：肾病综合征、各型肾小球病、狼疮肾炎、糖尿病肾病、尿路感染、肾小管酸中毒、AKI、CKD。

---

## 一、肾小球病总论与肾病综合征

| 维度 | 必背要点 |
|---|---|
| 发病机制 | 免疫介导（循环/原位免疫复合物）＋非免疫（高血压、高血脂） |
| 诊断模式 | 临床分型＋病理分型结合（肾活检为金标准） |
| NS 标准① | 大量蛋白尿 >3.5 g/24 h（必备） |
| NS 标准② | 低白蛋白血症 <30 g/L（必备） |
| NS 标准③④ | 水肿、高脂血症 |
| NS 并发症 | 感染（最常见）、血栓栓塞、脂代谢紊乱、急性肾损伤、营养不良 |
| 肾静脉血栓 | 腰痛＋血尿＋蛋白尿加重；膜性肾病最高危 |
| 易错点 | ①②必备③④辅助；膜性肾病最先想到肾静脉血栓 |

## 二、各型肾小球病一表通（光镜/电镜/荧光/临床/治疗）

| 疾病 | 临床特点 | 电镜/荧光标志 | 治疗要点 |
|---|---|---|---|
| 急性肾小球肾炎 | 前驱感染 1-3 周后肾炎综合征（血尿蛋白尿水肿高血压） | 驼峰样电子致密物；C3 颗粒沉积 | 自限性：对症休息限盐；不用激素；青霉素清除残存链球菌 |
| 急进性肾炎（RPGN） | 数周-数月进至少尿无尿肾衰；病理新月体 | I 型抗 GBM（+）；III 型 ANCA（+） | I 型血浆置换；大剂量激素冲击＋环磷酰胺 |
| 微小病变 | 儿童 NS 最常见；选择性蛋白尿 | 足突融合；荧光阴性 | 激素敏感（约 90%）；复发加环磷酰胺/CNI |
| 膜性肾病（IMN） | 成人特发 NS 最常见 | 抗 PLA2R 抗体（+）；上皮下致密物 | 低危观察；中高危激素＋环磷酰胺或 CNI/利妥昔单抗；抗凝 |
| FSGS | 激素抵抗倾向，进展至肾衰 | 局灶节段硬化 | 激素＋CNI |
| 膜增生性肾炎 | NS＋肾炎综合征混合表现 | 系膜插入（双轨征）；C3 持续降低 | 难治，疗效差 |
| IgA 肾病 | 我国最常见肾小球病；上感/运动后 1-2 天内血尿（同步） | 系膜区 IgA 沉积为主 | ACEI/ARB 降蛋白为基础；进展型激素＋免疫抑制 |
| 慢性肾小球肾炎 | 病程 >3 月、缓慢进展、不同程度肾功能减退 | 多样 | 延缓进展：ACEI/ARB＋限蛋白＋控压 |
| 隐匿性肾炎 | 无症状血尿/蛋白尿，无水肿高血压 | — | 观察＋ACEI/ARB，定期随访 |

### 两对经典鉴别

| 组 | 一句话辨析 |
|---|---|
| 急性肾炎 vs IgA 肾病 | 感染后 1-3 周发病（不同步）为急性肾炎；1-2 天内血尿（同步）为 IgA |
| 微小病变 vs 膜性 | 儿童激素敏感看微小；成人 PLA2R 与血栓看膜性 |

## 三、狼疮肾炎（LN）

| 维度 | 必背要点 |
|---|---|
| 定位 | SLE 最常见脏器损害与主要死因之一 |
| 分型 | ISN/RPS I-VI 型；III 局灶、IV 弥漫增殖、V 膜性 |
| 最重类型 | IV 型（弥漫增殖） |
| 诊断依据 | 尿检异常＋肾活检分型（金标准） |
| 诱导治疗 | 激素＋环磷酰胺或吗替麦考酚酯 |
| 维持治疗 | 吗替麦考酚酯/硫唑嘌呤＋小剂量激素 |
| 易错点 | 分型不同治疗强度不同，先活检后用药 |

## 四、糖尿病肾病（DKD）

| 维度 | 必背要点 |
|---|---|
| 早期标志 | UACR（尿白蛋白/肌酐比）≥30 mg/g 为微量白蛋白尿 |
| 大量白蛋白尿 | UACR ≥300 mg/g→GFR 逐渐下降 |
| 诊断复核 | UACR 于 6 个月内 3 次检测中 ≥2 次阳性 |
| 治疗核心 | ACEI/ARB 降尿蛋白（即使血压不高） |
| 新进展 | SGLT2 抑制剂延缓肾脏进展 |
| 筛查 | T1DM 确诊 5 年后起；T2DM 确诊时即查 |
| 易错点 | 微量 30、大量 300，单位是 mg/g 不是 mg/24h |

## 五、尿路感染（UTI）

| 维度 | 必背要点 |
|---|---|
| 最常见病原 | 大肠埃希菌（>80%） |
| 最常见途径 | 上行感染 |
| 真性菌尿 | 清洁中段尿 ≥10^5/ml（杆菌）；有膀胱刺激征者 ≥10^3/ml 即有意义 |
| 尿检辅助 | 白细胞尿 ≥5/HP、亚硝酸盐（+） |
| 下尿路（膀胱炎） | 膀胱刺激征＋无发热或低热＋无白细胞管型 |
| 上尿路（肾盂肾炎） | 刺激征＋发热腰痛＋肾区叩痛＋白细胞管型（特异） |
| 慢性肾盂肾炎 | 影像学肾盂肾盏变形缩窄为确诊条件 |
| 无症状菌尿 | 孕妇需治疗；一般成人不治疗 |
| 急性膀胱炎治疗 | 短程 3 天（氟喹诺酮/呋喃妥因） |
| 肾盂肾炎治疗 | 14 天（氟喹诺酮/三代头孢）；复杂性按药敏 |
| 反复发作 | ≥2 次/6 个月——低剂量长程抑菌 |
| 易错点 | 白细胞管型＝上尿路的特异证据；孕妇菌尿要治 |

## 六、肾小管酸中毒（RTA）四型

| 项目 | I 型（远端） | II 型（近端） | IV 型（高钾型） |
|---|---|---|---|
| 缺陷 | 远端泌氢障碍 | 近端 HCO3- 重吸收障碍 | 醛固酮减少/抵抗 |
| 尿 pH | 持续 >5.5（即使酸中毒） | 可 <5.5（血 HCO3 降到阈值后） | 多 <5.5 |
| 血钾 | 低钾 | 低钾 | 高钾（特征） |
| 结石钙化 | 常见（高钙尿、磷酸盐结石） | 少见 | 无 |
| 病因举例 | 干燥综合征、两性霉素 B | 范科尼综合征、多发性骨髓瘤 | 糖尿病肾病、Addison 病 |
| 治疗 | 枸橼酸盐/碳酸氢盐补碱补钾 | 补碱量大＋补钾 | 补碱＋处理高钾（氟氢可的松部分适用） |
| 易错点 | I 型结石、IV 型高钾；III 型为混合型罕见 | — | — |

## 七、急性肾损伤（AKI）

| 维度 | 必背要点 |
|---|---|
| KDIGO 定义 | 48 h 内 Scr 升高 ≥26.5 μmol/L，或 7 天内升至基线 ≥1.5 倍，或尿量 <0.5 ml/kg/h 持续 ≥6 h |
| 分期 | 1、2、3 期（按 Scr 与尿量） |

### 肾前性 vs 肾性（ATN）vs 肾后性鉴别

| 项目 | 肾前性 | 肾性（ATN） | 肾后性 |
|---|---|---|---|
| 病因 | 低灌注（失血失液、心衰） | 缺血、肾毒性（造影剂、氨基糖苷、肌红蛋白） | 梗阻（结石、前列腺、肿瘤） |
| BUN/Cr | >20:1 | 10-15:1 | 可变 |
| FENa | <1% | >1%（常 >2%） | <1% |
| 尿比重 | >1.020（浓缩） | 等比重约 1.010 | 变化 |
| 尿沉渣 | 正常/透明管型 | 棕褐色颗粒管型（泥棕色） | 正常或血尿 |
| 补液试验 | 尿量增加 | 尿量不增 | 无效 |

### 处理

| 项目 | 要点 |
|---|---|
| 容量管理 | 维持液体平衡，防肺水肿 |
| 高钾血症顺序 | 葡萄糖酸钙→胰岛素＋葡萄糖→碳酸氢钠→排钾树脂→透析 |
| 透析指征① | 难治性容量超负荷 |
| 透析指征② | 高钾血症（≥6.5 mmol/L） |
| 透析指征③ | 严重代谢性酸中毒（pH <7.15） |
| 透析指征④ | 尿毒症症状（脑病、心包炎） |
| 透析指征⑤ | 少尿/无尿持续（无尿 2 天、少尿 4 天） |
| 造影剂肾病预防 | 水化（等渗盐水）；停肾毒性药 |
| 易错点 | 补液试验尿量增=肾前性；透析是最后兜底不是首选 |

## 八、慢性肾脏病（CKD）

| 维度 | 必背要点 |
|---|---|
| 定义 | 肾结构/功能异常 >3 个月（GFR <60 或标志物异常） |
| G1 | GFR ≥90 |
| G2 | 60-89 |
| G3a | 45-59 |
| G3b | 30-44 |
| G4 | 15-29 |
| G5 | <15（尿毒症期，需肾脏替代治疗） |
| 延缓进展 | ACEI/ARB 降蛋白＋血压 <130/80＋控糖＋他汀 |
| 肾性贫血 | ESA（EPO）＋铁剂；Hb 目标 110-130 g/L（不宜 >130） |
| CKD-MBD | 磷结合剂＋活性维生素 D；防血管钙化 |
| 代谢性酸中毒 | 碳酸氢盐 |
| 尿毒症最早表现 | 消化道（食欲不振、晨起恶心） |
| 尿毒症死因第一 | 心血管（心衰、心包炎） |
| 尿毒症心包炎 | 摩擦音——透析指征 |
| 肾性骨病 | 继发甲旁亢（PTH 升高）→纤维囊性骨炎 |

### 替代治疗三方式对比

| 项目 | 血液透析 | 腹膜透析 | 肾移植 |
|---|---|---|---|
| 通路/条件 | 自体动静脉内瘘首选（成熟 6-8 周） | 腹膜（CAPD） | 供肾 |
| 节奏 | 每周 3 次、每次 4-5 h | 每日持续 | — |
| 优点 | 高效清除 | 居家、血流动力学稳定 | 最佳生存质量 |
| 主要风险 | 透析失衡（首次）、血管通路并发症 | 腹膜炎（金葡/真菌重者拔管） | 排斥反应 |
| 易错点 | 内瘘先于插管；腹膜炎是腹透最大障碍 | — | G5 最佳选择 |

## 【速记总表】泌尿系统必背数值与首选

| 项目 | 数值/答案 |
|---|---|
| NS 诊断 | 蛋白尿 >3.5 g/24h＋白蛋白 <30 g/L |
| 儿童 NS 最常见 | 微小病变（激素敏感） |
| 成人特发 NS 最常见 | 膜性肾病（PLA2R、肾静脉血栓） |
| 急性肾炎 | C3 8 周内恢复；自限不用激素 |
| RPGN I 型 | 抗 GBM（+）→血浆置换 |
| RPGN III 型 | ANCA（+）→激素冲击＋环磷酰胺 |
| IgA 肾病 | 上感后 1-2 天同步血尿；我国最常见 |
| 双轨征 | 膜增生性肾炎；C3 持续降低 |
| LN 最重 | IV 型弥漫增殖；CTX/MMF＋激素 |
| DKD 早期 | UACR ≥30 mg/g |
| DKD 大量 | UACR ≥300 mg/g |
| UTI 病原 | 大肠埃希菌 |
| 菌落计数 | 无症状 ≥10^5/ml；有症状 ≥10^3/ml |
| 上尿路证据 | 白细胞管型；肾盂肾盏变形（慢性） |
| 膀胱炎疗程 | 3 天；肾盂肾炎 14 天 |
| RTA I 型 | 尿 pH >5.5＋低钾＋结石 |
| RTA IV 型 | 高钾＋醛固酮减少 |
| AKI 定义 | 48 h Scr↑≥26.5 μmol/L 或 1.5 倍或尿量 <0.5 ml/kg/h×6 h |
| 肾前性 | FENa <1%、比重 >1.020、BUN/Cr >20 |
| ATN | FENa >1%、等比重、泥棕色颗粒管型 |
| 透析指征 | 容量超负荷、钾 ≥6.5、pH <7.15、尿毒症症状 |
| CKD 分期 | 90/60/45/30/15 五个界值 |
| CKD 贫血目标 | Hb 110-130 g/L |
| 透析通路 | 自体动静脉内瘘，成熟 6-8 周 |
| 腹透最大风险 | 腹膜炎 |
| 尿毒症最早症状 | 消化道；死亡首因为心血管 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| 微小 vs 膜性 | 儿童+激素敏感=微小；成人+PLA2R+血栓=膜性 |
| 急性肾炎 vs IgA 肾病 | 感染后 1-3 周发病是急性肾炎，1-2 天内血尿是 IgA |
| 肾前性 vs ATN | 补液后尿增/ FENa<1 是肾前性；泥棕管型/ FENa>1 是 ATN |
| 膀胱炎 vs 肾盂肾炎 | 有发热腰痛白细胞管型是上尿路 |
| RTA I vs II | I 型尿 pH 始终 >5.5 且结石；II 型尿 pH 可 <5.5 |
| 血透 vs 腹透 | 血透怕失衡与通路问题；腹透怕腹膜炎 |
| 肾性骨病 vs 骨质疏松 | CKD 继发甲旁亢 PTH 升高为纤维囊性骨炎 |
