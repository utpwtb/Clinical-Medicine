# 内科学·背诵手册版——07 风湿性疾病与中毒

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：RA、SLE、干燥、AS、血管炎、肌炎、SSc；中毒总论、有机磷、CO、镇静催眠药、酒精、热射病。

---

## 一、类风湿关节炎（RA）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 滑膜慢性炎症→血管翳→骨侵蚀（自身免疫） |
| 关节分布 | 对称性、多关节、小关节（腕、掌指、近端指间） |
| 不受累 | 远端指间关节（区别于 OA） |
| 晨僵 | >1 h |
| 晚期畸形 | 尺侧偏斜、天鹅颈、纽扣花 |
| 关节外 | 类风湿结节（伸侧受压部位，特征性）、肺间质病 |
| 血清学 | RF（+）但不特异；抗 CCP 抗体特异性最高 |
| X 线 | 关节间隙窄＋骨侵蚀（OA 是骨赘） |
| 治疗核心 | 达标治疗；NSAIDs 只止痛不改变病程 |
| 首选 DMARD | 甲氨蝶呤（MTX）——锚定药，叶酸对抗副作用 |
| 其他 DMARD | 羟氯喹、来氟米特、柳氮磺吡啶 |
| 生物制剂/JAKi | TNF-α 抑制剂、IL-6 抑制剂、托法替布 |
| 激素 | 小剂量桥接，尽快撤减 |
| 易错点 | 抗 CCP 特异性＞RF；RA 不累远端指间 |

## 二、系统性红斑狼疮（SLE）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 自身抗体＋免疫复合物多系统沉积 |
| 好发 | 育龄女性 |
| 皮肤 | 蝶形红斑（颧部）、光过敏、口腔溃疡 |
| 血液 | 溶血性贫血、白细胞↓、血小板↓ |
| 抗体入组 | ANA（+）为诊断入组条件 |
| 特异性抗体 | 抗 Sm（最特异）、抗 dsDNA（与活动度/肾炎相关） |
| 诊断标准 | 2019 EULAR/ACR：ANA 阳性入组＋加权积分 ≥10 分 |
| 狼疮肾炎 | 最常见脏器损害；ISN/RPS IV 型弥漫增殖最重；肾活检定分型 |
| LN 诱导治疗 | 激素＋环磷酰胺或吗替麦考酚酯 |
| LN 维持 | 吗替麦考酚酯/硫唑嘌呤＋小剂量激素 |
| 基础用药 | 羟氯喹——所有患者（防视网膜病变监测） |
| 抗磷脂综合征 | 血栓＋习惯性流产＋APL 抗体 |
| 死因 | 感染、狼疮肾炎（肾衰） |
| 妊娠用药 | 羟氯喹＋小剂量激素/硫唑嘌呤；CTX、MMF 妊娠禁忌 |
| 易错点 | Sm 最特异、dsDNA 看活动；羟氯喹全员基础 |

## 三、干燥综合征（SS）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 外分泌腺淋巴细胞浸润 |
| 表现 | 口干、眼干、猖獗龋齿 |
| 抗体 | 抗 SSA、抗 SSB |
| 客观检查 | Schirmer 试验（泪液分泌↓）、角膜染色 |
| 肾损害 | 远端肾小管酸中毒（I 型、低钾周期性瘫痪） |
| 肿瘤风险 | 淋巴瘤（警惕持续腮腺肿大、单克隆丙球） |
| 易错点 | 干燥＋低钾瘫=远端 RTA；淋巴瘤风险要随访 |

## 四、强直性脊柱炎（AS）与脊柱关节炎

| 维度 | 必背要点 |
|---|---|
| 好发 | 青年男性 |
| 炎性腰背痛 | 晨僵 >30 min、活动缓解、休息加重、夜间痛 |
| 附着点炎 | 跟腱附着点疼痛 |
| 关节炎特点 | 下肢非对称大关节炎 |
| 关联疾病 | 葡萄膜炎、银屑病、炎症性肠病 |
| 遗传标志 | HLA-B27（+） |
| 影像 | X 线骶髂关节炎（晚期竹节样脊柱）；MRI 早期骶髂关节炎 |
| 首选治疗 | NSAIDs＋功能锻炼 |
| 重要区别 | MTX 对中轴病变无效（与 RA 相反）；外周型可用柳氮磺吡啶 |
| 生物制剂 | TNF-α 抑制剂（中轴症状重者） |
| 易错点 | NSAIDs 是 AS 首选不是 MTX；骶髂关节是主战场 |

## 五、血管炎

| 疾病 | 核心特征 | 关键检查/治疗 |
|---|---|---|
| GPA（肉芽肿性多血管炎） | 上/下呼吸道肉芽肿＋肾受累；c-ANCA/PR3（+） | 激素＋环磷酰胺 |
| MPA（显微镜下多血管炎） | 坏死性血管炎＋肾肺受累；p-ANCA/MPO（+） | 激素＋环磷酰胺 |
| EGPA（嗜酸性肉芽肿性多血管炎） | 哮喘＋嗜酸性粒细胞升高＋血管炎 | ANCA 可（+）；激素 |
| 大动脉炎 | 年轻女性、无脉、双侧血压不对称 | 激素±免疫抑制剂 |
| 巨细胞动脉炎 | 老年、颞部头痛、下颌跛行、合并风湿性多肌痛 | 颞动脉活检（巨细胞肉芽肿）；大剂量激素 |
| 白塞病 | 口腔＋外阴溃疡＋眼炎＋针刺反应（+） | 对症＋免疫抑制 |
| 易错点 | c-ANCA 配 GPA、p-ANCA 配 MPA；针刺反应=白塞 | — |

## 六、特发性炎性肌病

| 维度 | 必背要点 |
|---|---|
| 皮肌炎特征皮疹 | Gottron 丘疹（指关节背侧）、向阳性紫红斑（眶周） |
| 肌肉表现 | 近端肌无力、CK 显著升高 |
| 肌电图 | 肌源性损害 |
| 特异性抗体 | 抗 Jo-1（伴间质性肺病）、抗 Mi-2 |
| 成人皮肌炎必查 | 肿瘤筛查（伴发肿瘤风险高） |
| 治疗 | 激素＋免疫抑制剂 |
| 易错点 | 成人皮肌炎≠单纯风湿病，先查肿瘤 |

## 七、系统性硬化症（SSc）

| 维度 | 必背要点 |
|---|---|
| 首发症状 | 雷诺现象 |
| 分型 | 局限型与弥漫型（皮肤受累范围） |
| 内脏受累 | 肺间质纤维化、肺动脉高压、食管运动障碍、肾危象 |
| 局限型抗体 | 抗着丝点抗体（ACA）——CREST 综合征 |
| CREST | 钙化、雷诺、食管运动障碍、指（趾）硬化、毛细血管扩张 |
| 弥漫型抗体 | 抗 Scl-70（抗拓扑异构酶 I） |
| 治疗 | 对症（雷诺用 CCB）、肺纤维化免疫抑制、肺高压靶向药 |
| 易错点 | Scl-70 配弥漫、着丝点配局限；雷诺常首发多年 |

## 八、中毒总论

### 处理流程

| 步骤 | 要点 |
|---|---|
| ①终止接触 | 脱离毒物、脱去污染衣物、清洗皮肤 |
| ②催吐洗胃 | 服毒 6 h 内最佳（超时仍有指征者不放弃） |
| 洗胃禁忌 | 强腐蚀性毒物（穿孔风险）、惊厥未控制、近期上消化道大出血、休克未纠正 |
| ③吸附导泻 | 活性炭吸附、导泻 |
| ④促排泄 | 强利尿；血液净化 |
| ⑤特效解毒 | 按解毒剂配对表 |
| ⑥对症支持 | 保护脏器功能 |

### 血液净化选择

| 方式 | 适用毒物 |
|---|---|
| 血液透析 | 水溶性小分子：甲醇、乙二醇、锂、水杨酸 |
| 血液灌流 | 脂溶性/中大分子：有机磷、镇静催眠药 |
| 血浆置换 | 蛋白结合率高者 |
| 易错点 | 甲醇锂水杨酸走透析；有机磷安眠药走灌流 |

### 解毒剂配对表

| 毒物 | 特效解毒剂 |
|---|---|
| 有机磷 | 阿托品＋胆碱酯酶复能剂（氯解磷定） |
| 氰化物 | 亚硝酸钠＋硫代硫酸钠 |
| 亚硝酸盐（高铁血红蛋白血症） | 亚甲蓝 |
| 甲醇/乙二醇 | 乙醇或甲吡唑＋透析 |
| 华法林 | 维生素 K1 |
| 肝素 | 鱼精蛋白 |
| 苯二氮䓬类 | 氟马西尼（慢性依赖者慎禁） |
| 阿片类 | 纳洛酮 |
| 铁剂 | 去铁胺 |
| 地高辛 | 地高辛抗体片段（Fab） |
| 铅 | 依地酸钙钠（EDTA） |
| 砷/汞 | 二巯基丙醇、二巯丙磺钠 |
| 易错点 | 氟马西尼对慢性苯二氮䓬依赖者可诱发戒断癫痫 |

## 九、有机磷杀虫药中毒

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 胆碱酯酶失活→乙酰胆碱蓄积 |
| M 样症状 | 瞳孔针尖样缩小、流涎多汗、支气管分泌物多、腹痛腹泻、心率减慢、肺水肿 |
| N 样症状 | 肌束颤动、肌无力 |
| 中枢症状 | 头晕、昏迷、抽搐 |
| 诊断与分级 | 全血胆碱酯酶活力：轻度 50%-70%、中度 30%-50%、重度 <30% |
| 阿托品化指征 | 瞳孔较前扩大、口干、皮肤干燥、颜面潮红、肺部啰音消失、心率增快 |
| 阿托品中毒 | 瞳孔散大固定、谵妄、高热 |
| 复能剂 | 氯解磷定——早期足量（恢复酶活性） |
| 中间综合征 | 中毒后 24-96 h，颈屈肌/呼吸肌麻痹 |
| 迟发性多发性神经病 | 中毒后 2-4 周，肢体远端瘫痪 |
| 净化治疗 | 血液灌流 |
| 禁用药物 | 新斯的明、吗啡 |
| 易错点 | 中间综合征在中毒后 2-4 天，迟发神经病在 2-4 周；别混 |

## 十、急性一氧化碳中毒

| 维度 | 必背要点 |
|---|---|
| 核心机制 | CO 与 Hb 亲和力高→碳氧血红蛋白→组织缺氧 |
| 特征体征 | 口唇樱桃红色 |
| 轻度 | COHb 10%-20%：头痛头晕 |
| 中度 | COHb 30%-40%：昏迷、对刺激有反应 |
| 重度 | COHb >40%：深昏迷、脑水肿、肺水肿、休克 |
| 关键治疗 | 氧疗；重度/昏迷者高压氧 |
| 防脑水肿 | 甘露醇脱水 |
| 迟发性脑病 | 假愈期 2-60 天后出现痴呆精神症状 |
| 易错点 | COHb 测定数值才分级；高压氧防迟发脑病 |

## 十一、镇静催眠药中毒

| 项目 | 苯二氮䓬类 | 巴比妥类 |
|---|---|---|
| 毒性 | 相对小 | 呼吸循环抑制重 |
| 表现 | 嗜睡共济失调，深昏迷少见 | 昏迷＋呼吸抑制＋低血压 |
| 特效解毒 | 氟马西尼 | 无（对症） |
| 净化 | — | 血液灌流；碱化尿液促排 |
| 易错 | 氟马西尼只解 BZ，别忘依赖者诱发癫痫 | — |

## 十二、急性酒精中毒

| 维度 | 必背要点 |
|---|---|
| 分期 | 兴奋期→共济失调期→昏迷期 |
| 处理 | 防误吸、补液、纳洛酮辅助促醒 |
| 镇静禁忌 | 慎用/禁用吗啡及强镇静剂 |
| 双硫仑样反应 | 头孢类等＋饮酒→面红心悸低血压；用药期间及停药后禁酒 |
| 易错 | 昏迷者先保气道；双硫仑反应重在预防宣教 |

## 十三、中暑与热射病

| 维度 | 必背要点 |
|---|---|
| 谱系 | 先兆中暑→轻症中暑→热射病 |
| 热射病定义 | 核心体温 >40℃＋意识障碍 |
| 分型 | 经典型（长期暴露）与劳力型（年轻高强度运动） |
| 致命并发症 | DIC、横纹肌溶解、多器官衰竭 |
| 降温目标 | 快速降温，30 min 内核心温度降至 39℃ 以下 |
| 降温方法 | 冰水浸浴/蒸发降温＋冰袋大血管处 |
| 注意 | 昏迷者气道保护；降温至 38.5℃ 左右即放缓防低体温 |
| 易错 | 先降温后转运，降温是第一救命措施 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| RA vs OA | RA 对称近端小关节晨僵 1 h 以上；OA 负重大关节晨僵短、远端指间骨赘 |
| RA vs AS | RA 用 MTX 首选；AS 用 NSAIDs 首选且 MTX 对中轴无效 |
| SLE vs 皮肌炎 | 都有面部皮疹；SLE 蝶形红斑不累眶周，皮肌炎向阳性紫红斑在眶周 |
| GPA vs MPA | c-ANCA/PR3 上呼吸道肉芽肿=GPA；p-ANCA/MPO=MPA |
| 阿托品化 vs 阿托品中毒 | 阿托品化口干心率快；中毒是瞳孔散大固定＋谵妄高热 |
| 中间综合征 vs 迟发神经病 | 2-4 天呼吸肌无力 vs 2-4 周远端瘫痪 |
| 经典型 vs 劳力型热射病 | 老弱被动暴露 vs 年轻人剧烈运动产热过多 |
| 亚甲蓝 vs 亚硝酸钠 | 亚硝酸盐中毒用亚甲蓝；氰化物先用亚硝酸钠再用硫代硫酸钠 |
