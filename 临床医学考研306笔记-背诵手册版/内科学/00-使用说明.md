# 内科学·背诵手册版——使用说明

> 定位：冲刺阶段背诵与快速翻查手册，信息密度最大化，零废话，只收稳定成熟公认内容。
> 依据：人卫第 10 版《内科学》知识体系；面向 2028 届临床医学专硕 306 全国统考。

## 一、本版与另两版的配合

| 版本 | 用途 | 用法 |
|---|---|---|
| 讲义版 | 系统理解、建立框架 | 一轮打底，先读它 |
| 背诵手册版（本版） | 冲刺记忆、考前速查 | 二三轮每天翻、按系统滚动背 |
| 真题版 | 检验与纠偏 | 背完一系统立刻做题反馈 |

## 二、目录与建议背诵节奏

| 文件 | 内容 | 建议遍数 |
|---|---|---|
| 01-呼吸系统 | COPD、哮喘、肺炎、结核、栓塞、呼衰等 | 3 遍 |
| 02-循环系统 | 心衰、心律失常、高血压、冠心病、瓣膜病等 | 3 遍 |
| 03-消化系统 | 溃疡、IBD、肝硬化、胰腺炎、出血等 | 3 遍 |
| 04-泌尿系统 | 肾小球病、UTI、AKI、CKD 等 | 3 遍 |
| 05-血液系统 | 贫血、白血病、淋巴瘤、出凝血等 | 3 遍 |
| 06-内分泌与代谢 | 甲亢、糖尿病、痛风等 | 3 遍 |
| 07-风湿性疾病与中毒 | RA、SLE、AS、中毒总论等 | 2-3 遍 |

## 三、每个疾病的固定字段

| 字段 | 说明 |
|---|---|
| 核心机制 | 一句话记住病理生理 |
| 诊断金标准/关键检查 | 含必背数值 |
| 首选治疗 | 考题常问"首选" |
| 必背数值/标准 | 数字化条目 |
| 易错点 | 高频陷阱一句话 |

## 四、建议背诵节奏（共 8 周）

| 周次 | 任务 |
|---|---|
| 第 1-2 周 | 呼吸＋循环，每天 1 个小时读表＋遮盖右栏自测 |
| 第 3-4 周 | 消化＋泌尿，同法 |
| 第 5 周 | 血液＋内分泌 |
| 第 6 周 | 风湿＋中毒；同时复盘前四周错题 |
| 第 7 周 | 只背每个文件的【速记总表】＋【易混对照】＋【口诀】 |
| 第 8 周 | 全套翻查＋真题查漏，只看存疑条目 |

## 五、使用规范

| 规则 | 说明 |
|---|---|
| 只背右栏 | 左栏为提示词，遮盖自测 |
| 数值即考点 | 表中数字均按教材口径，宁缺毋滥 |
| 存疑即查 | 本手册不收录有争议数据；做题冲突以最新教材为准 |
| 禁止当真题 | 本手册不声称任何条目出自真题 |
