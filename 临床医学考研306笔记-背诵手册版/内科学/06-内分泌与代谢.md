# 内科学·背诵手册版——06 内分泌与代谢

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：甲状腺、肾上腺、垂体、尿崩症、糖尿病、痛风、骨质疏松。

---

## 一、甲状腺功能亢进症（Graves 病为主）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 自身免疫（TRAb 刺激 TSH 受体）→甲状腺激素过多 |
| 高代谢表现 | 怕热多汗、消瘦、心悸、脉压增大、手颤 |
| 特征体征 | 甲状腺肿大伴血管杂音、浸润性突眼、胫前黏液性水肿 |
| 心脏表现 | 窦速、房颤（老年甲亢性心脏病） |
| 化验 | TSH↓、FT3/FT4↑、TRAb（+） |
| 摄碘率 | 升高且高峰前移（诊断与鉴别用） |
| 危象诱因 | 感染、手术、骤停碘剂、创伤 |

### 三种疗法对比

| 项目 | 抗甲状腺药物 | 放射性 131I | 手术 |
|---|---|---|---|
| 代表 | 甲巯咪唑（MMI）首选口服；PTU | 131I | 甲状腺次全切除 |
| 首选人群 | 轻中度、儿童孕早期用 PTU | 成人中等大小、复发者 | 中重度肿大、压迫、怀疑恶变、胸骨后 |
| 禁忌/慎用 | 粒缺、肝损害 | 妊娠哺乳绝对禁忌；重度突眼慎用 | 术前准备不全者 |
| 术前准备 | ATD＋复方碘溶液（2-3 周）＋普萘洛尔 | — | 同左 |
| 主要并发症 | 粒细胞缺乏（发热咽痛立即查血常规）、皮疹、肝损 | 甲减为最常见远期并发症 | 喉返神经损伤、甲状旁腺损伤 |
| 特殊说明 | PTU 用于妊娠 T1 期与甲亢危象 | 131I 不用于术前准备 | — |
| 易错点 | 碘剂只用于术前准备和危象，不单独长期用 | — | — |

### 甲亢危象处理

| 步骤 | 要点 |
|---|---|
| ①抑合成 | 大剂量 PTU（首选，妊娠可用） |
| ②阻释放 | PTU 后 1 h 用复方碘溶液 |
| ③拮外周 | 普萘洛尔（β 阻滞剂） |
| ④补激素 | 氢化可的松 |
| ⑤降温支持 | 物理降温（慎用阿司匹林）；抗感染 |

## 二、甲状腺功能减退症

| 维度 | 必背要点 |
|---|---|
| 化验（原发性） | TSH↑、FT4↓ |
| 特征体征 | 黏液性水肿（非凹陷性）、面色蜡黄 |
| 代谢改变 | 胆固醇升高、心率慢 |
| 最危重状态 | 黏液性水肿昏迷（低体温、意识障碍） |
| 治疗 | 左甲状腺素（LT4）替代；昏迷者静脉 LT4/LT3 紧急替代 |
| 亚临床甲减 | TSH >10 或有症状——替代治疗 |
| 易错点 | 原发性 TSH 升高是关键；LT4 从小量起（老年人） |

## 三、亚急性甲状腺炎 vs 桥本甲状腺炎

| 项目 | 亚急性甲状腺炎 | 桥本甲状腺炎 |
|---|---|---|
| 病因 | 病毒感染 | 自身免疫 |
| 主症 | 颈前疼痛＋发热、甲状腺触痛 | 无痛、质韧弥漫肿大 |
| ESR | 显著升高 | 可正常 |
| 抗体 | 不特异 | TPOAb、TGAb 高滴度（+） |
| 摄碘率 | 降低与 FT4 升高"分离"——诊断特征 | 视甲功状态 |
| 转归 | 自限性 | 倾向永久甲减 |
| 治疗 | NSAIDs；重症短期激素 | 甲减时 LT4 替代 |
| 易错点 | 分离现象=亚甲炎；高抗体=桥本 | — |

## 四、库欣综合征（三级诊断法）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 皮质醇分泌过多（垂体 ACTH 瘤最常见——库欣病） |
| 典型表现 | 向心性肥胖、满月脸、水牛背、紫纹、高血压、糖尿、骨质疏松 |
| 异位 ACTH 特点 | 明显低钾碱中毒、色素沉着 |
| 第一步（定性） | 午夜 1 mg 地塞米松抑制试验不受抑（或 24h 尿游离皮质醇↑、午夜皮质醇↑） |
| 第二步（定部位） | 血 ACTH：依赖型不低（垂体/异位）；非依赖型降低（肾上腺腺瘤） |
| 第三步（垂体 vs 异位） | 大剂量地塞米松抑制试验：垂体受抑 >50%、异位不受抑；岩下窦采血 |
| 定位影像 | 垂体 MRI / 肾上腺 CT |
| 治疗 | 库欣病——经蝶窦垂体瘤切除；腺瘤——腹腔镜切除 |
| 易错点 | 1 mg 过夜法不受抑=库欣状态；大剂量受抑=垂体来源 |

## 五、原发性醛固酮增多症

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 醛固酮自主分泌过多→钠潴留排钾 |
| 三联表现 | 高血压＋低血钾（肌无力、周期性瘫痪）＋碱血症 |
| 筛查 | 血浆醛固酮/肾素比值（ARR）升高 |
| 确诊试验 | 盐水输注试验、卡托普利试验 |
| 分型 | 腺瘤（APA）vs 特发性增生（IHA） |
| 治疗 | 腺瘤——手术切除；增生——螺内酯 |
| 易错点 | 高血压低钾先想原醛；肾素是被抑制的 |

## 六、嗜铬细胞瘤/副神经节瘤

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 嗜铬细胞分泌儿茶酚胺过多 |
| 典型三联 | 头痛＋心悸＋多汗（阵发性高血压） |
| 定性 | 血/尿甲氧基肾上腺素类（MNs）升高——首选 |
| 定位 | CT/MRI；异位/转移用 131I-MIBG |
| 发作期降压 | 酚妥拉明（α 阻滞剂） |
| 术前准备 | α 阻滞剂（酚苄明）≥2 周，扩容后再手术 |
| 用药铁律 | 先 α 后 β；严禁单用 β 阻滞剂（致高血压危象） |
| 相关遗传综合征 | MEN2、VHL、NF1 |
| 易错点 | β 阻滞剂必须在 α 阻断之后上 |

## 七、肾上腺皮质功能减退（Addison 病）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 原发性肾上腺皮质破坏→皮质醇+醛固酮↓ |
| 特征表现 | 皮肤黏膜色素沉着（ACTH↑）、低血压、低钠高钾、低血糖 |
| 化验 | 皮质醇↓＋ACTH↑；ACTH 兴奋试验无反应 |
| 治疗 | 氢化可的松替代＋氟氢可的松（补盐皮质激素） |
| 应激原则 | 感染、手术时激素加量 |
| 危象 | 突停激素/应激→休克呕吐低血糖——氢化可的松静推＋大量盐水 |
| 易错点 | 原发性色素沉着；继发性（垂体）无色素沉着 |

## 八、垂体瘤与尿崩症

| 项目 | 要点 |
|---|---|
| 最常见功能性垂体瘤 | 泌乳素瘤（PRL↑，闭经溢乳） |
| 泌乳素瘤首选 | 多巴胺激动剂（溴隐亭/卡麦角林）——药物优于手术 |
| GH 瘤 | 肢端肥大症（成人）/巨人症（青少年）；手术＋奥曲肽 |
| 经蝶窦手术 | 多数垂体瘤首选治疗方式 |
| 尿崩症核心 | ADH 缺乏（中枢）或抵抗（肾性）→多尿低比重 |
| 诊断试验 | 禁水加压试验（注射加压素后尿比重升=中枢性） |
| 中枢性治疗 | 去氨加压素（DDAVP） |
| 肾性治疗 | 噻嗪类利尿剂（反常有效）＋低盐饮食 |
| 易错点 | 泌乳素瘤先药物不先手术；肾性尿崩用噻嗪类 |

## 九、糖尿病

### 诊断与分型

| 项目 | 内容 |
|---|---|
| 诊断① | 空腹血糖 ≥7.0 mmol/L |
| 诊断② | OGTT 2 h 血糖 ≥11.1 mmol/L |
| 诊断③ | 随机血糖 ≥11.1 mmol/L＋典型症状 |
| 诊断④ | HbA1c ≥6.5%（需复查确认） |
| 糖尿病前期 | FPG 6.1-7.0（IFG）；2 h 7.8-11.1（IGT） |
| 1 型特征 | 年轻、酮症倾向、C 肽低、自身抗体（+）——必须胰岛素 |
| 2 型特征 | 成人、肥胖、家族史、胰岛素抵抗＋分泌不足 |
| 易错点 | 无症状者两条异常需复查；随机血糖诊断要带症状 |

### 急性并发症：DKA 与 HHS

| 项目 | DKA（酮症酸中毒） | HHS（高渗高血糖状态） |
|---|---|---|
| 好发 | 1 型；诱因感染、停胰岛素 | 老年 2 型 |
| 三联 | 高血糖＋酮症＋代谢性酸中毒 | 血糖 >33.3＋有效渗透压 >320＋无明显酮症 |
| 呼吸气味 | 烂苹果味（丙酮） | 无特殊 |
| 意识 | 淡漠嗜睡 | 意识障碍突出 |
| 治疗第一 | 补液（生理盐水起步） | 补液更慢更谨慎 |
| 胰岛素 | 0.1 U/kg/h 持续静滴（小剂量） | 小剂量持续 |
| 血糖转折点 | <13.9 mmol/L 时改 5% 葡萄糖＋胰岛素 | — |
| 降糖速度 | 每小时降 3.9-6.1 mmol/L（过快防脑水肿） | 更缓 |
| 补钾 | 血钾 <5.5 有尿即补；<3.3 先补钾暂缓胰岛素 | 同原则 |
| 补碱 | 仅 pH <7.1（或 HCO3 <5）才补 | 一般不补 |
| 易错点 | 补液第一、补碱从严、血糖降太快会脑水肿 | — |

### 慢性并发症与筛查

| 并发症 | 要点 |
|---|---|
| 微血管三联 | 肾病、视网膜病变、神经病变 |
| 糖尿病肾病 | UACR ≥30 mg/g 起病；ACEI/ARB＋SGLT2i |
| 视网膜病变 | 非增殖期→增殖期（新生血管）；激光/抗 VEGF |
| 眼底筛查 | T2DM 确诊时即查；T1DM 确诊 5 年后起 |
| 神经病变 | 远端对称性多神经病变最常见（袜套样） |
| 糖尿病足 | 神经＋血管＋感染；10 g 尼龙丝＋ABI 筛查 |
| 大血管 | 冠心病、卒中、外周动脉病 |

### 口服降糖药机制表

| 药物 | 机制 | 关键注意 |
|---|---|---|
| 二甲双胍 | 抑制肝糖输出＋增敏 | 2 型一线首选；eGFR <30 禁用（乳酸酸中毒） |
| SGLT2i（达格列净） | 尿糖排泄 | 减重降压、心肾获益；血糖不高型 DKA、泌尿生殖感染 |
| GLP-1RA（司美格鲁肽） | 促泌＋抑食欲＋延缓胃排空 | 减重、心血管获益；甲状腺髓样癌/MEN2 禁用 |
| α-糖苷酶抑制剂（阿卡波糖） | 延缓肠道糖吸收 | 降餐后血糖；低血糖必须口服葡萄糖 |
| 磺脲类（格列美脲） | 促胰岛素分泌 | 低血糖风险；老年慎用格列本脲 |
| 格列奈类 | 短效促泌 | 控制餐后血糖 |
| TZD（吡格列酮） | PPARγ 增敏 | 水肿、心衰慎用；骨折风险 |
| DPP-4i（西格列汀） | 延长内源性 GLP-1 | 中性体重、耐受好 |

### 胰岛素与低血糖

| 项目 | 要点 |
|---|---|
| 胰岛素绝对指征 | 1 型糖尿病、急性并发症、手术妊娠 |
| 2 型起始 | 口服药控制不佳或 HbA1c 显著升高 |
| 方案 | 基础＋餐时（甘精＋门冬）或预混 |
| 黎明现象 | 夜间血糖好、晨起高——加基础量 |
| Somogyi 效应 | 夜间低血糖后反跳晨高——测夜间血糖减量 |
| 低血糖界值 | 血糖 <3.9 mmol/L |
| Whipple 三联 | 症状＋低血糖＋进食缓解 |
| 意识清楚 | 口服糖 15 g，15 min 复测（15-15 原则） |
| 意识不清 | 50% 葡萄糖 20-40 ml 静推 |
| 易错点 | 阿卡波糖的低血糖只能用葡萄糖解 |

## 十、痛风与高尿酸血症

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 尿酸盐结晶沉积（嘌呤代谢异常） |
| 典型首发 | 第一跖趾关节午夜红肿热痛 |
| 慢性表现 | 痛风石（耳廓）、关节畸形、尿酸性肾石 |
| 金标准 | 关节液/痛风石双折光针状尿酸盐结晶 |
| 急性期用药 | 秋水仙碱（发作 24-36 h 内最有效）、NSAIDs、糖皮质激素 |
| 急性期禁忌 | 不起始降尿酸药（已服者不停药） |
| 间歇期降尿酸 | 别嘌醇/非布司他（抑制生成）；苯溴马隆（促排，尿石症禁用） |
| 别嘌醇前提 | HLA-B*5801 基因筛查（阳性禁用） |
| 达标值 | 血尿酸 <360 μmol/L；有痛风石/频发者 <300 |
| 辅助 | 碱化尿液（枸橼酸盐）；忌酒（啤酒）、内脏、高果糖 |
| 易错点 | 急性期停降酸药也不加；苯溴马隆怕结石 |

## 十一、骨质疏松症

| 维度 | 必背要点 |
|---|---|
| 诊断标准 | DXA 骨密度 T 值 ≤-2.5（绝经后女性、50 岁以上男性） |
| 危险因素 | 绝经、糖皮质激素、吸烟、低钙低维生素 D |
| 严重状态 | 脆性骨折（髋部、椎体） |
| 基础治疗 | 钙＋维生素 D |
| 一线药物 | 双膦酸盐（阿仑膦酸钠：晨起空腹大量水、直立 30 min） |
| 其他 | 地舒单抗、特立帕肽（严重者） |
| 易错点 | 双膦酸盐服用姿势错会致食管炎 |

## 【速记总表】内分泌必背数值与首选

| 项目 | 数值/答案 |
|---|---|
| 甲亢化验 | TSH↓＋FT3/FT4↑＋TRAb（+） |
| ATD 首选 | MMI 口服首选；PTU 用于妊娠 T1 与危象 |
| ATD 最重副作用 | 粒细胞缺乏（发热咽痛查血常规） |
| 131I 绝对禁忌 | 妊娠、哺乳 |
| 危象流程 | PTU→1 h 后碘剂→普萘洛尔→氢化可的松 |
| 甲减化验 | TSH↑＋FT4↓；LT4 替代 |
| 亚甲炎 | ESR↑＋摄碘率与 FT4 分离；自限 |
| 桥本 | TPOAb/TGAb 高滴度；甲减倾向 |
| 库欣筛查 | 午夜 1 mg 地塞米松不受抑 |
| 大剂量抑制试验 | 垂体受抑、异位不受抑 |
| 原醛 | ARR 升高；低钾碱中毒；腺瘤手术/增生螺内酯 |
| 嗜铬 | MNs 定性；先 α 后 β；术前 α 阻滞 2 周 |
| Addison | 色素沉着＋皮质醇↓ACTH↑；氢化可的松＋氟氢可的松 |
| 泌乳素瘤 | 溴隐亭首选 |
| 尿崩症 | 禁水加压试验；中枢用 DDAVP、肾性用噻嗪类 |
| DM 诊断 | ≥7.0 / ≥11.1 / 随机 ≥11.1＋症状 / HbA1c ≥6.5% |
| DKA 三联 | 高血糖＋酮症＋代酸 |
| DKA 胰岛素 | 0.1 U/kg/h；每小时降 3.9-6.1 mmol/L |
| DKA 补碱线 | pH <7.1 |
| HHS | 血糖 >33.3＋渗透压 >320＋无酮症 |
| 低血糖 | <3.9 mmol/L；意识不清 50%GS 20-40 ml |
| 二甲双胍 | eGFR <30 禁用 |
| DKD 界值 | UACR 30（微量）/300（大量）mg/g |
| 眼底筛查 | T2DM 确诊时、T1DM 5 年后 |
| 痛风金标准 | 双折光针状尿酸盐结晶 |
| 秋水仙碱 | 24-36 h 内最有效 |
| 降尿酸达标 | <360 μmol/L（重者 <300） |
| 别嘌醇 | 先查 HLA-B*5801 |
| 骨质疏松 | T 值 ≤-2.5；钙＋维 D＋双膦酸盐 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| Graves vs 亚甲炎 | 摄碘率升高前移=Graves；摄碘率降低与 FT4 升高分离=亚甲炎 |
| 库欣病 vs 肾上腺腺瘤 | ACTH 不低且大剂量受抑=垂体库欣病；ACTH 低=腺瘤 |
| 原醛 vs Liddle | 都低钾高血压；原醛醛固酮高，Liddle（假性醛固酮增多）醛固酮低 |
| DKA vs HHS | 酮症酸中毒在 1 型；高渗无酮症在老年 2 型 |
| 黎明现象 vs Somogyi | 都晨起高；测夜间血糖，低后反跳是 Somogyi |
| 中枢性 vs 肾性尿崩 | 加压素后尿比重升=中枢性；不升=肾性 |
| 别嘌醇 vs 苯溴马隆 | 一个抑生成（怕药疹查基因）、一个促排泄（怕结石） |
