# 内科学·背诵手册版——01 呼吸系统

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：COPD、哮喘、支扩、肺炎、肺结核、PTE、肺心病、间质病、胸膜病、ARDS、呼衰。

---

## 一、慢性阻塞性肺疾病（COPD）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 持续气流受限（不完全可逆）＋气道与肺实质慢性炎症 |
| 确诊标准 | 吸入支气管舒张剂后 FEV1/FVC <70% |
| 危险因素 | 吸烟（最重要）、职业粉尘、生物燃料、α1-抗胰蛋白酶缺乏 |
| GOLD 1 级 | FEV1 占预计值 ≥80% |
| GOLD 2 级 | 50%-79% |
| GOLD 3 级 | 30%-49% |
| GOLD 4 级 | <30% |
| 肺气肿型（A 型） | 瘦、桶状胸、缺氧轻、呼衰晚（红喘型） |
| 支气管炎型（B 型） | 胖、发绀水肿、呼衰早（紫肿型） |
| 稳定期核心治疗 | 支气管舒张剂（LAMA/LABA）；必要时联用 |
| ICS 使用原则 | 仅频繁急性加重者用 LABA+ICS；不单用 ICS |
| 急性加重治疗 | 雾化 SABA+SAMA＋全身激素＋控制性氧疗＋抗感染 |
| 抗感染指征 | 呼吸困难加重＋痰量增加或脓性痰 |
| 氧疗目标 | SpO2 88%-92%（防 CO2 潴留加重） |
| 家庭氧疗指征 | PaO2≤55 mmHg 或 SaO2≤88%；伴肺心病/红细胞增多者 PaO2≤60 |
| 家庭氧疗时长 | >15 h/d |
| 易错点 | 判断呼衰首选动脉血气，不是肺功能 |

## 二、支气管哮喘

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 气道慢性炎症＋气道高反应性＋可逆性气流受限 |
| 本质区别 | 可逆（COPD 不可逆） |
| 舒张试验阳性 | FEV1 较用药前增加 ≥12% 且绝对值 ≥200 ml |
| 激发试验阳性 | FEV1 下降 ≥20% |
| PEF 变异率 | 昼夜（或日）变异率 ≥20% 提示可逆 |
| CVA（咳嗽变异型） | 唯一症状慢性咳嗽，夜间明显，激发试验（+） |
| 缓解药（急救） | SABA 首选、SAMA、全身激素、茶碱 |
| 控制药（长期） | ICS 一线基础；ICS+LABA 中重度首选；白三烯调节剂 |
| 阶梯治疗 | 按控制水平升降级，长期管理 |
| 茶碱注意 | 治疗窗窄（血药浓度 5-15 mg/L）；大环内酯/喹诺酮升高其浓度 |
| 重度发作处理 | 持续雾化 SABA+SAMA＋全身激素＋吸氧，必要时机械通气 |
| 重度发作禁忌 | 慎用/禁用镇静剂（抑制呼吸） |
| 哮喘持续状态 | 常规治疗无效持续 >24 h |
| 易错点 | 哮喘可逆、COPD 不可逆；重度发作别给镇静药 |

## 三、支气管扩张症

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 感染＋阻塞反复破坏支气管壁 |
| 典型三联 | 慢性咳嗽、大量脓痰（静置分层）、反复咯血 |
| 干性支扩 | 反复咯血为唯一症状，多在上叶（引流好） |
| 体征 | 背部固定持久湿啰音、杵状指 |
| 确诊首选 | HRCT：印戒征、轨道征、囊状扩张 |
| 感染病原 | 铜绿假单胞菌常见——喹诺酮或 β 内酰胺类 |
| 引流与祛痰 | 体位引流＋祛痰；慎用强力镇咳药 |
| 大咯血 | 首选支气管动脉栓塞；垂体后叶素止血 |
| 垂体后叶素禁忌 | 高血压、冠心病、妊娠 |
| 易错点 | 干性支扩在上叶；强镇咳药会憋痰 |

## 四、肺炎总论与五大病原鉴别

| 维度 | 必背要点 |
|---|---|
| CAP 最常见病原 | 肺炎链球菌 |
| HAP 定义 | 住院 ≥48 h 后发生 |
| HAP 常见病原 | 铜绿假单胞菌、金葡菌（MRSA）、G- 杆菌、不动杆菌 |
| 重症 CAP 警惕 | 军团菌、金葡菌、G- 杆菌 |

| 五大病原 | 痰/特征 | 病原 | 首选药 |
|---|---|---|---|
| 肺炎链球菌肺炎 | 铁锈色痰、口周疱疹、肺实变、青壮年 | G+ 球菌 | 青霉素 G（耐药用氟喹诺酮） |
| 葡萄球菌肺炎 | 脓血痰、中毒重、易肺脓肿脓胸 | 金葡菌 | 万古霉素（MRSA） |
| 克雷伯菌肺炎 | 砖红色胶冻样痰、叶间裂下坠、老年 | G- 杆菌 | 三代头孢（β 内酰胺类）±氨基糖苷 |
| 肺炎支原体肺炎 | 阵发性刺激性呛咳、症状重体征少、冷凝集（+） | 支原体 | 大环内酯类（阿奇霉素） |
| 军团菌肺炎 | 高热＋相对缓脉＋肌痛、低钠血症、腹泻 | 军团菌 | 大环内酯或氟喹诺酮 |

## 五、肺脓肿

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 吸入性多见（口咽部厌氧菌）；血源性多金葡菌 |
| 好发部位 | 仰卧吸入——右上叶后段、下叶背段 |
| 典型表现 | 急起高热＋大量脓臭痰（分层） |
| 治疗首选 | 抗生素覆盖厌氧菌（青霉素＋甲硝唑/克林霉素）＋体位引流 |
| 手术指征 | 内科治疗 >3 个月不愈、大咯血内科无效 |
| 易错点 | 脓痰分层提示厌氧菌；疗程要足防慢性化 |

## 六、肺结核

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 结核分枝杆菌感染；飞沫传播；迟发型变态反应 |
| 分类 | 原发型（儿童）、血行播散型、继发型（成人最常见）、结核性胸膜炎、肺外 |
| 筛查指征 | 咳嗽咳痰 ≥2 周应查痰 |
| 确诊金标准 | 痰培养（涂片抗酸染色筛查）；Xpert MTB/RIF 快速并测耐药 |
| PPD 判读 | 硬结 ≥5 mm 阳性；≥20 mm 或有水疱为强阳性 |
| PPD 假阳性 | 卡介苗接种、非结核分枝杆菌 |
| PPD 假阴性 | 免疫抑制、重症结核、HIV |
| T-SPOT | γ 干扰素释放试验；不受卡介苗影响 |
| 影像特征 | 上叶尖后段、下叶背段；多形态病灶共存 |
| 治疗原则 | 早期、联合、适量、规律、全程 |
| 初治方案 | 2HRZE/4HR（强化 2 月 4 联＋巩固 4 月 HR） |
| 异烟肼（H） | 周围神经炎（预防用维生素 B6）、肝损害 |
| 利福平（R） | 肝损害、体液橙红色 |
| 吡嗪酰胺（Z） | 高尿酸血症、肝损害 |
| 乙胺丁醇（E） | 球后视神经炎（视力减退、红绿色盲） |
| 链霉素（S） | 耳毒性、肾毒性 |
| 咯血处理 | 患侧卧位、镇咳慎用强镇咳药、垂体后叶素 |
| 大咯血窒息抢救 | 头低足高 45°、拍背、清理气道；反复咯血可支气管动脉栓塞 |
| 易错点 | 培养是金标准；E 管眼睛 S 管耳朵 |

## 七、肺血栓栓塞症（PTE）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 深静脉血栓脱落堵塞肺动脉（Virchow 三要素） |
| 危险因素 | 淤滞（卧床术后）、内膜损伤、高凝（肿瘤妊娠避孕药） |
| 常见表现 | 呼吸困难最常见；三联征（呼吸困难、胸痛、咯血）少见 |
| 大面积提示 | 晕厥、低血压休克 |
| 心电图线索 | S1Q3T3、窦速、V1-V4 T 波倒置 |
| 排除检查 | D-二聚体 <500 μg/L（低中度验前概率）排除价值高 |
| 确诊首选 | CTPA（CT 肺动脉造影） |
| 金标准 | 肺动脉造影（有创，少用）；V/Q 扫描备选 |
| 高危（大面积） | 溶栓＋抗凝；rt-PA 50-100 mg/2h，症状 14 天内 |
| 中低危 | 抗凝为主 |
| 抗凝监测 | 普通肝素监测 APTT 至 1.5-2.5 倍 |
| 华法林 | INR 2-3；与肝素重叠 ≥5 天后单用 |
| 抗凝疗程 | 可逆诱因 3 个月；不明原因首次 6 个月；复发或危险因素持续则长期 |
| 溶栓禁忌 | 活动性内出血、近期手术创伤、出血性脑卒中 |
| 易错点 | D-二聚体用于排除不能确诊；溶栓后序贯抗凝 |

## 八、肺动脉高压与肺源性心脏病

| 维度 | 必背要点 |
|---|---|
| 肺动脉高压标准 | 静息 mPAP >20 mmHg（新标准，旧标准 ≥25） |
| 五大类 | 动脉性、左心疾病、肺病/低氧、CTEPH、混合性 |
| PAH 靶向药 | 前列环素类、内皮素受体拮抗剂、5 型 PDE 抑制剂（西地那非） |
| 肺心病病因 | COPD 最多（80%-90%） |
| 核心机制 | 缺氧致肺动脉高压→右室肥大→右心衰 |
| 诊断要点 | 肺动脉高压＋右心室肥大/右心衰（颈静脉怒张、肝大、肝颈征＋、下肢水肿） |
| 心电图 | 肺型 P 波（P≥0.25 mV）、电轴右偏、RV1+SV5≥1.05 mV |
| X 线 | 右下肺动脉干增宽、肺动脉段凸出 |
| 急性加重诱因 | 呼吸道感染 |
| 治疗首要 | 控制感染＋通畅气道＋纠正缺氧和 CO2 潴留（低流量持续给氧） |
| 利尿原则 | 慎用、小量缓用（防血液浓缩、痰黏稠） |
| 强心原则 | 慎用洋地黄（缺氧易中毒） |
| 肺性脑病 | 慎用脱水剂、禁用镇静安眠药 |
| 最常见酸碱失衡 | 呼吸性酸中毒 |
| 易错点 | 肺心病心衰先抗感染控氧，不急着强心利尿 |

## 九、间质性肺疾病与肺癌要点

| 疾病 | 核心要点 |
|---|---|
| IPF | 隐匿进行性呼吸困难＋干咳；Velcro 啰音、杵状指 |
| IPF 影像 | HRCT：网状影＋蜂窝肺＋牵拉性支扩，胸膜下、基底部 |
| IPF 治疗 | 吡非尼酮/尼达尼布抗纤维化；不长期用激素 |
| 结节病 | 非干酪性肉芽肿；双侧肺门淋巴结肿大；ACE 升高、高钙血症 |
| 小细胞肺癌（SCLC） | 恶性度最高、早期转移；全身化疗为主；副肿瘤综合征最多 |
| NSCLC 早中期 | I-II 期首选手术（肺叶切除＋淋巴清扫） |
| NSCLC 晚期 | 基因检测：EGFR 突变用 EGFR-TKI；无靶点免疫＋化疗 |
| 副肿瘤综合征 | Cushing、SIADH、Lambert-Eaton——小细胞；肥大性骨关节病——腺癌/鳞癌 |

## 十、胸腔积液

| 维度 | 必背要点 |
|---|---|
| 漏出液病因 | 心衰、肝硬化、肾病综合征（不符合 Light 标准） |
| 渗出液病因 | 结核（我国最常见）、肺炎旁、恶性、结缔组织病 |
| Light 标准① | 胸液蛋白/血清蛋白 >0.5 |
| Light 标准② | 胸液 LDH/血清 LDH >0.6 |
| Light 标准③ | 胸液 LDH >正常血浆 LDH 上限的 2/3 |
| 判定 | 符合任一条即渗出液 |
| 结核性胸膜炎 | ADA >45 U/L、淋巴细胞为主、草黄色 |
| 恶性胸腔积液 | 血性、CEA 升高、脱落细胞学（+）；胸膜固定术 |
| 脓胸引流指征 | pH <7.2、糖 <2.2 mmol/L——胸腔置管引流 |
| 结核性抽液 | 首次 <700 ml，之后每次 <1000 ml，每周 2-3 次 |
| 抽液过量风险 | 复张性肺水肿、胸膜反应 |
| 治疗 | 抗结核＋中毒症状重/大量积液时加糖皮质激素 |
| 易错点 | Light 标准只分渗漏出，不定病因；ADA 高才想结核 |

## 十一、气胸

| 维度 | 必背要点 |
|---|---|
| 三型 | 闭合性（单纯性）、交通性（开放性）、张力性（高压性） |
| 张力性机制 | 裂口单向活瓣→胸内压持续升高→纵隔移位、循环衰竭 |
| 张力性处理 | 立即排气：患侧锁骨中线第 2 肋间粗针穿刺后闭式引流 |
| 体征 | 气管向健侧移位、患侧鼓音、呼吸音消失 |
| 小量气胸 | 肺压缩 <20% 且症状轻——观察 |
| 引流位置（气） | 锁骨中线第 2 肋间或腋前线 4-5 肋间 |
| 引流位置（液） | 腋中线与腋后线之间 6-8 肋间 |
| 复发性 | 胸膜固定术或手术 |
| 易错点 | 张力性先救命排气，别等 X 线 |

## 十二、急性呼吸窘迫综合征（ARDS）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 肺泡-毛细血管膜损伤→非心源性肺水肿 |
| 柏林定义 | 起病 1 周内；双肺浸润影；除外心源性 |
| 氧合指数分级 | PaO2/FiO2 ≤300（轻 200-300、中 100-200、重 <100） |
| 核心—肺保护通气 | 小潮气量 6 ml/kg、平台压 <30 cmH2O |
| 辅助策略 | 足量 PEEP、俯卧位通气；难治性用 ECMO |
| 易错点 | 氧合指数看 PaO2/FiO2（吸氧状态下的 PaO2） |

## 十三、呼吸衰竭

| 维度 | 必背要点 |
|---|---|
| I 型呼衰 | PaO2 <60 mmHg，PaCO2 正常或降低——换气障碍（ARDS、肺纤维化、肺水肿、肺栓塞） |
| II 型呼衰 | PaO2 <60 mmHg 伴 PaCO2 >50 mmHg——通气障碍（COPD、呼吸肌麻痹） |
| 氧疗目标 | PaO2 ≥60 mmHg 即可 |
| I 型氧疗 | 可较高浓度（≥50%） |
| II 型氧疗 | 持续低流量低浓度：1-2 L/min，目标 SpO2 88%-92% |
| II 型低氧机制 | COPD 呼吸中枢对 CO2 敏感性下降，靠低氧刺激驱动呼吸 |
| 高浓度氧危险 | 解除低氧驱动→呼吸抑制→CO2 麻醉（肺性脑病） |
| 机械通气指征 | 意识障碍、PaO2 吸氧不升、PaCO2 进行性升高、pH<7.25 等 |
| 无创通气首选 | COPD 急性加重伴呼吸性酸中毒 |
| 肺性脑病 | 禁镇静安眠药、慎碱性药脱水剂 |
| 易错点 | II 型呼衰给的氧气越浓越危险 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| 哮喘 vs COPD | 哮喘可逆（舒张试验＋），COPD 持续受限不可逆 |
| 肺气肿型 vs 支气管炎型 | 红喘瘦而缺氧轻，紫肿胖而呼衰早 |
| 支原体 vs 军团菌 | 都用大环内酯；支原体呛咳体征少，军团菌低钠缓脉 |
| 浸润性 vs 血行播散型结核 | 继发型成人最常见；血行播散双肺均匀粟粒影 |
| I 型 vs II 型呼衰 | 换气障碍单纯低氧；通气障碍低氧＋CO2 潴留 |
| 结核性 vs 恶性胸水 | ADA 高、淋巴为主是结核；血性、CEA 高是恶性 |
| 张力性 vs 交通性气胸 | 张力性有单向活瓣进行性加重，需立即粗针排气 |
