# 内科学·背诵手册版——05 血液系统

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：贫血、再障、溶血、白血病、淋巴瘤、MM、ITP、TTP、血友病、DIC、输血。

---

## 一、贫血总论与 MCV 分类

| 维度 | 必背要点 |
|---|---|
| 贫血标准（海平面） | 男 Hb <120 g/L；女 <110 g/L；孕妇 <100 g/L |
| 小细胞（MCV <80） | 缺铁性、海洋性、铁粒幼细胞性 |
| 正常细胞（80-100） | 再障、急性失血、溶血性 |
| 大细胞（MCV >100） | 巨幼细胞性贫血、MDS |
| 易错点 | 先分大小再定病；MDS 常被误归正常细胞 |

## 二、缺铁性贫血（IDA）

| 维度 | 必背要点 |
|---|---|
| 地位 | 最常见贫血 |
| 病因 | 摄入不足、吸收障碍（胃切除）、丢失过多（慢性失血——月经、消化道） |
| 查因原则 | 男性和绝经后女性缺铁必查胃肠道 |
| 指标变化 | 血清铁↓、铁蛋白↓（最早最敏感）、转铁蛋白饱和度↓、总铁结合力（TIBC）↑ |
| 最可靠指标 | 骨髓铁染色（细胞外铁阴性、铁粒幼细胞减少） |
| 血象 | MCV↓、MCHC↓（小细胞低色素） |
| 治疗首选 | 口服铁剂（＋维生素 C 促吸收） |
| 最早疗效指标 | 网织红细胞 5-10 天达高峰 |
| 停药标准 | Hb 正常后再服 3-6 个月（补足储存铁） |
| 注射铁指征 | 口服不耐受、吸收障碍、需快速纠正 |
| 易错点 | 铁蛋白最早降、骨髓铁最可靠；见好别停药 |

## 三、巨幼细胞贫血

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 维生素 B12 或叶酸缺乏→DNA 合成障碍（核幼浆老） |
| 血象 | MCV >100、大卵圆红细胞、中性粒分叶过多 |
| 特征表现 | 牛肉舌、食欲差；B12 缺乏伴感觉异常 |
| B12 缺乏神经损害 | 亚急性脊髓联合变性 |
| 治疗原则 | 补叶酸前必须排除 B12 缺乏（防神经症状加重） |
| 易错点 | 单补叶酸会掩盖并加重 B12 神经损害 |

## 四、再生障碍性贫血（AA）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 骨髓造血功能衰竭（T 细胞免疫介导） |
| 三系表现 | 贫血＋感染＋出血；网织红细胞绝对值↓ |
| 骨髓象 | 增生减低、非造血细胞比例↑、无原始细胞增多 |
| 常见诱因 | 氯霉素、保泰松、苯、放射线、肝炎病毒 |
| 重型（SAA）标准 | 中性粒 <0.5×10^9/L、PLT <20×10^9/L、网织红 <15×10^9/L（符合两条以上＋骨髓符合） |
| SAA 治疗 | 年轻有供者首选异基因造血干细胞移植；否则 ATG/ALG＋环孢素 |
| 非重型治疗 | 环孢素±雄激素（司坦唑醇） |
| 支持 | 输血、抗感染；造血因子只是过渡 |
| 易错点 | 全血细胞减少＋网织红低＋骨髓减低三联；别误诊为 MDS |

## 五、溶血性贫血

| 维度 | 必背要点 |
|---|---|
| 总机制 | 红细胞破坏加速；黄疸、脾大、网织红↑、间接胆红素↑ |
| 血管内溶血 | 游离血红蛋白↑、血红蛋白尿（酱油色）、含铁血黄素尿 |
| 血管外溶血 | 脾脏破坏、脾大为主 |
| 确诊线索 | 红细胞寿命缩短＋骨髓红系代偿增生 |

### 常见溶血病鉴别

| 疾病 | 标志检查 | 治疗要点 |
|---|---|---|
| 自身免疫性溶血（AIHA） | Coombs 试验（+） | 温抗体 IgG 型——糖皮质激素首选；冷抗体型注意保温 |
| PNH | Ham 试验（+）；流式 CD55/CD59 缺失 | 补体异常；对症与补体抑制剂 |
| G6PD 缺乏（蚕豆病） | G6PD 活性↓；蚕豆/氧化药诱发急性血管内溶血 | 去除诱因为主 |
| 遗传性球形红细胞增多症 | 渗透脆性↑ | 脾切除有效 |
| 海洋性贫血 | Hb 电泳异常 | 轻型观察；重型输血＋祛铁 |
| Evans 综合征 | AIHA＋ITP 同存 | 激素 |
| 易错点 | Coombs 对 AIHA、Ham 对 PNH、脆性对球红、电泳对地贫 |

## 六、白血病

### 急性白血病总则

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 造血干/祖细胞克隆性恶性增殖（原始细胞蓄积） |
| 表现 | 贫血、出血、感染发热＋浸润（肝脾淋巴结、骨痛） |
| 诊断金标准 | 骨髓象（原始细胞 ≥20%） |
| MICM | 形态＋免疫＋细胞遗传＋分子 |
| 免疫标记（ALL） | CD10、CD19、CD20、TdT |
| 免疫标记（AML） | MPO、CD13、CD33 |
| 诱导目标 | 完全缓解：原始细胞 <5%＋三系恢复 |
| 移植指征 | 高危、难治复发——异基因造血干细胞移植 |
| 肿瘤溶解综合征 | 高尿酸高钾高磷低钙——别嘌醇＋水化碱化 |

### AML-M3（APL）专条

| 维度 | 必背要点 |
|---|---|
| 遗传标志 | t(15;17)、PML-RARα 融合基因 |
| 突出危险 | DIC 最严重（早幼粒细胞颗粒释放促凝） |
| 首选治疗 | 全反式维 A 酸（ATRA）＋砷剂，治愈率高 |
| 易错点 | M3 出血重是 DIC；化疗不当反而促发 DIC |

### CML 与 CNSL

| 项目 | 内容 |
|---|---|
| CML 标志 | Ph 染色体 t(9;22)、BCR-ABL 融合基因 |
| CML 血象 | 白细胞极高、嗜碱性粒细胞↑、NAP 积分↓、巨脾 |
| CML 首选 | 伊马替尼（酪氨酸激酶抑制剂 TKI） |
| CML 转归 | 急变（急粒/急淋变）预后差 |
| CNSL 好发 | ALL 最常见（尤其高危） |
| CNSL 表现 | 颅压高＋脑神经麻痹；脑脊液找到白血病细胞确诊 |
| CNSL 预防治疗 | 鞘内注射 MTX（±Ara-C、地塞米松） |
| 易错点 | NAP 积分：CML 低、类白血病反应高 |

## 七、淋巴瘤

| 项目 | 霍奇金淋巴瘤（HL） | 非霍奇金淋巴瘤（NHL） |
|---|---|---|
| 特征细胞 | R-S 细胞 | 多样（免疫表型分类） |
| 播散方式 | 连续性、向心性 | 跳跃性、结外多见 |
| 人群 | 青年与老年双峰 | 中老年为主 |
| 早期治疗 | I-II 期放疗（受累野）±化疗 | 依病理类型个体化 |
| 经典方案 | III-IV 期 ABVD | DLBCL——R-CHOP；Burkitt 高剂量短程 |
| 预后 | 相对较好 | 差异大 |
| 易错点 | 见 R-S 先想 HL；DLBCL 最常见 NHL 用 R-CHOP |

### Ann Arbor 分期与 B 症状

| 项目 | 内容 |
|---|---|
| I 期 | 单一淋巴结区 |
| II 期 | 横膈同侧两组及以上 |
| III 期 | 横膈两侧 |
| IV 期 | 结外器官弥漫受累（肝、骨髓） |
| B 症状 | 发热 >38℃ 连续 3 天、盗汗、6 个月内体重下降 >10% |
| 易错点 | 有 B 症状加" B "，分期数字不变 |

## 八、多发性骨髓瘤（MM）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 单克隆浆细胞恶性增殖＋M 蛋白 |
| CRAB | 高钙血症（C）、肾损害（R）、贫血（A）、骨病（B） |
| 首发症状 | 骨痛（腰背痛）；X线穿凿样溶骨破坏 |
| M 蛋白 | 血清/尿单克隆免疫球蛋白；IgG 型最常见；本周蛋白尿=轻链 |
| 诊断核心 | 骨髓浆细胞 ≥10%＋M 蛋白＋CRAB 器官损害 |
| 首选方案 | 硼替佐米＋来那度胺±激素±自体移植 |
| 辅助 | 双膦酸盐防骨事件；高钙危象水化＋降钙素/双膦酸盐 |
| 易错点 | 穿凿样骨破坏、本周蛋白是 MM 的招牌词 |

## 九、ITP 与 TTP

| 项目 | ITP（原发免疫性血小板减少症） | TTP（血栓性血小板减少性紫癜） |
|---|---|---|
| 核心机制 | 自身抗体破坏血小板 | ADAMTS13 活性↓→vWF 巨多聚体→微血栓 |
| 骨髓象 | 巨核细胞数量↑但成熟障碍（产板型↓） | 无特异（微血管病性溶血） |
| 标志表现 | 只有出血、无贫血脾大 | 五联征：微血管病性溶血＋血小板减少＋神经精神＋肾损害＋发热 |
| 溶血标志 | 无 | 破碎红细胞 >1% |
| 首选治疗 | 糖皮质激素；IVIG 快速升板 | 血浆置换（救命治疗） |
| 二线 | 利妥昔单抗、TPO 受体激动剂、脾切除 | 免疫抑制 |
| 大忌 | — | 禁输血小板（加重微血栓） |
| 处理阈值 | PLT >30×10^9/L 无出血可不治疗 | 急症立刻置换 |
| 易错点 | TTP 输血小板等于火上浇油 | — |

## 十、血友病与 DIC

### 血友病

| 维度 | 必背要点 |
|---|---|
| 遗传方式 | X 连锁隐性（男性发病） |
| 血友病 A/B | 分别缺凝血因子 VIII/IX |
| 筛查 | APTT 延长、PT 正常、PLT 正常 |
| 确诊 | 因子活性测定（纠正试验分型） |
| 出血特点 | 深部血肿、关节积血、术后延迟出血 |
| 治疗 | 替代治疗：因子 VIII 浓缩物；轻型 A 可用 DDAVP |
| 禁忌 | 禁阿司匹林等抗血小板药；禁肌内注射 |
| 易错点 | APTT 长 PT 正常=内源性途径问题 |

### DIC

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 广泛微血栓＋凝血因子消耗＋继发纤溶出血 |
| 常见病因 | 感染（最常见）、肿瘤（APL）、产科意外、创伤 |
| 实验室 | PLT↓、纤维蛋白原↓、PT/APTT 延长、D-二聚体/FDP↑↑ |
| 治疗顺序 | ①去除病因（根本）②替代（PLT/FFP/纤维蛋白原）③肝素（高凝期或栓塞为主）④抗纤溶（纤溶亢进为主） |
| 肝素使用前提 | 纤维蛋白原过低（<1 g/L）先补充再抗凝 |
| 易错点 | 先补后抗凝；病因不除一切白搭 |

## 十一、输血反应

| 类型 | 特点与处理 |
|---|---|
| 非溶血性发热 | 最常见；对症退热 |
| 急性溶血（ABO 不合） | 最严重；立即停输＋水化碱化＋抗休克 |
| 过敏反应 | 抗组胺；严重者肾上腺素 |
| TA-GVHD | 免疫功能低下者；预防用辐照血 |
| 细菌污染 | 高热休克；停输＋抗感染 |
| TRALI | 输血相关急性肺损伤；停输＋呼吸支持 |
| Rh 系统 | Rh 阴性育龄女性输 RhD 阴性血 |
| 易错点 | 发热最常见、溶血最凶险；预防 TA-GVHD 靠辐照 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| IDA vs 慢病贫血 | 都小细胞；IDA 铁蛋白低 TIBC 高，慢性病铁蛋白不低 |
| 血管内 vs 血管外溶血 | 酱油色尿、含铁血黄素尿=血管内；脾大为主=血管外 |
| 再障 vs MDS | 再障增生减低无病态造血；MDS 病态造血+原始细胞增多 |
| CML vs 类白血病反应 | CML 有 Ph 染色体、NAP 低；类白 NAP 高无 Ph |
| ITP vs TTP | ITP 单纯出血性紫癜；TTP 微血栓五联、要血浆置换 |
| 血友病 vs ITP | 凝血障碍深部血肿（APTT 异常）；血小板减少皮肤瘀点（PLT 低） |
| HL vs NHL | HL 连续播散见 R-S；NHL 跳跃播散结外多 |
| DIC vs TTP | 都有微血栓；DIC 消耗凝血（FIB↓），TTP 是 vWF 巨多聚体 |
