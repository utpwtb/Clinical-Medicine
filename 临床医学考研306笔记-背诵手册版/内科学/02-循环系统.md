# 内科学·背诵手册版——02 循环系统

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：心衰、心律失常、高血压、冠心病、瓣膜病、IE、心肌病、心包疾病。

---

## 一、心力衰竭

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 心输出量下降＋神经体液（RAAS、交感）长期激活有害 |
| EF 分类 | HFrEF ≤40%；HFmrEF 41%-49%；HFpEF ≥50% |
| 最常见诱因 | 呼吸道感染；心律失常中房颤最常见 |
| NYHA I 级 | 体力活动不受限 |
| NYHA II 级 | 日常活动即气促（轻受限） |
| NYHA III 级 | 轻于日常活动即气促（明显受限） |
| NYHA IV 级 | 休息时也有症状 |
| Killip I 级 | 无心衰 |
| Killip II 级 | 湿啰音 <50% 肺野 |
| Killip III 级 | 全肺湿啰音＋奔马律（肺水肿） |
| Killip IV 级 | 心源性休克（SBP <90） |
| Killip 用于 | 急性心梗合并心衰（NYHA 不用于 AMI 早期） |
| 左心衰 | 肺淤血：劳力性→端坐→夜间阵发性→急性肺水肿、奔马律 |
| 右心衰 | 体循环淤血：颈静脉怒张、肝大、肝颈回流征＋、下垂性水肿 |
| 排除指标 | BNP/NT-proBNP 排除价值大；超声心动图评估 EF |
| 新四联（GDMT） | ARNI/ACEI＋β 阻滞剂＋MRA＋SGLT2 抑制剂 |
| 利尿剂定位 | 控制液体潴留必需，但不改善预后、不属于新四联 |
| 地高辛定位 | 改善症状、减少住院，不降低病死率 |
| 伊伐布雷定 | 窦性心律、HR≥70、EF≤35% 且 β 阻滞剂已足量 |
| CRT 指征 | QRS≥150 ms＋LBBB＋EF≤35% |
| ICD 指征 | 猝死一级/二级预防 |
| 心衰避免用药 | 非二氢吡啶 CCB、I 类抗心律失常药、NSAIDs |
| 易错点 | NYHA 反映症状、Killip 用于心梗；新四联才降死亡率 |

### 急性左心衰（急性肺水肿）流程

| 步骤 | 要点 |
|---|---|
| 体位 | 端坐位、双腿下垂 |
| 吸氧 | 高流量 6-8 L/min，酒精湿化抗泡沫 |
| 镇静 | 吗啡 3-5 mg 静注（慢阻肺、低血压、颅脑损伤禁用） |
| 利尿 | 呋塞米 20-40 mg 静注 |
| 扩血管 | 硝普钠（动静脉均扩）、硝酸甘油（扩静脉为主） |
| 强心 | 西地兰（房颤快室率者佳）、多巴酚丁胺、米力农 |
| 通气 | 必要时无创/有创机械通气 |

### 洋地黄要点

| 项目 | 内容 |
|---|---|
| 最佳适应证 | 心衰合并快速房颤 |
| 禁忌 | 肥厚梗阻型心肌病、预激合并房颤、II/III 度 AVB；低钾慎用 |
| 中毒表现 | 室早二联律最常见（室速）、黄视绿视、胃肠道、神经系统 |
| 中毒处理 | 停药＋补钾＋苯妥英钠/利多卡因；禁电复律 |
| 易错点 | 中毒所致心律失常别电击 |

## 二、心律失常

### 抗心律失常药（Vaughan Williams 分类）

| 类别 | 代表药 | 用途 |
|---|---|---|
| Ia | 奎尼丁、普鲁卡因胺 | 广谱 |
| Ib | 利多卡因、苯妥英、美西律 | 窄谱——室性 |
| Ic | 普罗帕酮、氟卡尼 | 广谱 |
| II | β 阻滞剂 | 交感相关、心梗后防猝死 |
| III | 胺碘酮、索他洛尔 | 广谱；胺碘酮注意肺纤维化、甲功 |
| IV | 维拉帕米、地尔硫䓬 | 室上速 |
| 其他 | 腺苷 | 终止室上速首选之一 |

### 房颤

| 维度 | 必背要点 |
|---|---|
| 处理三原则 | 室率控制、节律控制、抗凝防栓塞 |
| 室率控制药 | β 阻滞剂、非二氢吡啶 CCB、地高辛 |
| 宽松室率目标 | 静息 <110 次/分 |
| 药物复律 | 胺碘酮、普罗帕酮 |
| 电复律 | 血流动力学不稳定——同步电复律 |
| 复律前抗凝 | 房颤 >48 h 或时间不明——复律前 3 周、复律后 4 周 |
| CHA2DS2-VASc | 心衰 1、高血压 1、年龄≥75 得 2、糖尿病 1、卒中史 2、血管病 1、年龄 65-74 得 1、女性 1 |
| 抗凝阈值 | 男性 ≥2 分、女性 ≥3 分需抗凝（1 分考虑） |
| 抗凝药 | 华法林（INR 2-3）或 NOAC（达比加群、利伐沙班）多数患者首选 |
| 出血评估 | HAS-BLED 评分 |
| 消融 | 药物无效症状明显——肺静脉隔离 |
| 易错点 | 复律不抗凝最易出栓塞题 |

### 预激合并房颤与其他

| 项目 | 内容 |
|---|---|
| 预激＋房颤禁用 | 洋地黄、维拉帕米、地尔硫䓬（阻断房室结→经旁路下传→室颤） |
| 预激＋房颤可用 | 普罗帕酮、胺碘酮；不稳定同步电复律 |
| 根治手段 | 射频消融（旁路） |
| 室速稳定 | 胺碘酮/利多卡因/普罗帕酮 |
| 室速不稳定 | 同步电复律 |
| 无脉室速/室颤 | 非同步电除颤 |
| 一度 AVB | 不需治疗 |
| 二度 II 型/三度 AVB | 有症状——起搏器 |
| 病窦综合征 | 慢-快综合征；症状性心动过缓——双腔起搏器 |
| 下壁心梗 AVB | 多为房室结缺血所致，常可逆 |
| 易错点 | 预激房颤三禁药；无脉即非同步 |

## 三、高血压

| 维度 | 必背要点 |
|---|---|
| 诊断标准（诊室） | ≥140/90 mmHg |
| 家庭自测 | ≥135/85 mmHg |
| 动态血压 | 24 h 平均 ≥130/80 mmHg |
| 1 级 | 140-159 和/或 90-99 |
| 2 级 | 160-179 和/或 100-109 |
| 3 级 | ≥180 和/或 ≥110 |
| 单纯收缩期高血压 | SBP≥140 且 DBP<90（老年人多见） |
| 危险因素 | 年龄（男>55、女>65）、吸烟、血脂异常、糖耐量异常、肥胖、早发家族史 |
| 生活方式 | 限盐 <5 g/d、减重、运动、限酒戒烟 |

### 五大类一线药

| 药物 | 适应证亮点 | 禁忌/注意 |
|---|---|---|
| ACEI（普利） | 心衰、心梗后、糖尿病肾病蛋白尿 | 干咳、高钾；妊娠禁用；双侧肾动脉狭窄禁用 |
| ARB（沙坦） | 同 ACEI，不咳嗽 | 妊娠禁用、高钾 |
| CCB（地平） | 老年单纯收缩期高血压、稳定心绞痛 | 踝部水肿；非二氢吡啶类禁用于心衰 |
| 噻嗪类利尿剂 | 老年、盐敏感、心衰 | 痛风慎用禁用、低钾、影响糖脂代谢 |
| β 阻滞剂 | 心率快、冠心病、心衰、甲亢 | 哮喘禁用（非选择性）、AVB、运动员慎用 |
| 联合原则 | ACEI/ARB＋CCB 或＋利尿剂 | 不联 ACEI＋ARB（副作用叠加） |

### 继发性高血压五线索

| 病因 | 线索 |
|---|---|
| 肾动脉狭窄 | 上腹部血管杂音、双侧血压差 >20 mmHg、ACEI 后 Cr 明显升高 |
| 原发性醛固酮增多症 | 高血压＋低血钾＋碱血症；醛固酮升高、肾素降低 |
| 嗜铬细胞瘤 | 阵发性高血压＋头痛心悸出汗三联 |
| 库欣综合征 | 向心性肥胖、紫纹、皮质醇节律消失 |
| 主动脉缩窄 | 上肢血压高于下肢、背部杂音 |

### 高血压急症

| 项目 | 内容 |
|---|---|
| 定义 | 血压显著升高＋靶器官急性损害 |
| 用药 | 静脉降压：硝普钠、硝酸甘油、拉贝洛尔、乌拉地尔 |
| 降幅 | 1 h 内 MAP 下降 ≤25% |
| 后续 | 2-6 h 降至 160/100 左右；24-48 h 逐渐正常 |
| 亚急症 | 口服药 24-48 h 内逐步降压 |
| 主动脉夹层 | 目标 SBP 100-120、心率 <60；β 阻滞剂先于血管扩张剂 |
| 易错点 | 降压不能一步到位；夹层先控心率 |

## 四、冠心病

### 稳定型心绞痛

| 维度 | 必背要点 |
|---|---|
| 典型部位 | 胸骨体中上段后，放射左肩左臂内侧/颈咽下颌 |
| 典型性质 | 压榨、闷胀、紧缩（非针刺样锐痛） |
| 持续时间 | 3-5 min，一般 <15 min |
| 缓解方式 | 休息或含服硝酸甘油 3-5 min 内缓解 |
| 发作时 ECG | ST 水平/下斜型压低 ≥0.1 mV，缓解后恢复 |
| 运动试验阳性 | ST 压低 ≥0.1 mV 持续 >2 min |
| 运动试验禁忌 | 不稳定心绞痛、MI 急性期、严重心律失常、梗阻性肥厚型心肌病 |
| 诊断金标准 | 冠脉造影（狭窄 ≥50% 诊断冠心病） |
| 无创筛查 | 冠脉 CTA 阴性预测值高 |
| 发作时用药 | 硝酸甘油 0.5 mg 舌下含服 |
| 缓解期 ABCDE | 抗血小板＋ACEI、β 阻滞剂＋血压、他汀＋戒烟、饮食＋控糖、运动教育 |
| 变异型心绞痛 | 冠脉痉挛——CCB 首选；单用 β 阻滞剂禁忌 |
| 血运重建 | 左主干/三支病变倾向 CABG |
| 易错点 | 硝酸甘油含服无效警惕心梗；变异型用 CCB 别用 β 阻滞剂 |

### UA/NSTEMI 与 STEMI

| 维度 | 必背要点 |
|---|---|
| UA vs NSTEMI | cTn（-）为 UA；（+）为 NSTEMI |
| UA/NSTEMI 禁忌 | 不主张溶栓 |
| UA/NSTEMI 治疗 | DAPT（阿司匹林＋替格瑞洛/氯吡格雷）＋抗凝＋他汀＋β 阻滞剂；高危 24 h 内介入 |
| STEMI 诊断 | 胸痛 >30 min＋硝酸甘油不缓解＋相邻两导联 ST 弓背抬高＋动态演变＋cTn 升高 |
| 再灌注时间窗 | 直接 PCI：首诊至导丝通过 ≤120 min |
| 溶栓条件 | 无 PCI 条件、发病 ≤12 h（尿激酶、rt-PA） |
| 再通判断① | 2 h 内胸痛缓解 |
| 再通判断② | ST 回落 ≥50% |
| 再通判断③ | 再灌注心律失常出现 |
| 再通判断④ | CK-MB 峰值提前至 14 h 内 |
| 抗栓 | 阿司匹林嚼服＋P2Y12 抑制剂＋肝素 |
| 早期口服 | β 阻滞剂（24 h 内无禁忌）、ACEI（24-48 h 内）、他汀、DAPT |
| 硝酸酯注意 | 下壁＋右室梗死慎用 |
| 吗啡注意 | 下壁/右室心梗慎用 |
| 右室梗死 | 下壁＋V4R ST 抬高＋低血压＋肺野清晰——补液扩容，禁硝酸酯和利尿剂 |
| 易错点 | 下壁心梗先想右冠、右室、AVB |

### STEMI 定位（ECG）

| 导联 | 部位 |
|---|---|
| V1-V3 | 前间壁 |
| V3-V5 | 前壁 |
| V1-V5 | 广泛前壁 |
| I、aVL、V5-V6 | 侧壁/高侧壁 |
| II、III、aVF | 下壁（右冠多见） |
| V7-V9 | 正后壁 |
| V3R-V4R | 右心室 |

### 心梗并发症

| 并发症 | 要点 |
|---|---|
| 心律失常 | 24 h 内最多；室颤为主要死因；下壁易 AVB/心动过缓，前壁易室性 |
| 乳头肌功能失调/断裂 | 二尖瓣关闭不全杂音（心尖收缩期） |
| 室间隔穿孔 | 胸骨左缘 3-4 肋间粗糙收缩期杂音 |
| 心室游离壁破裂 | 起病 1 周内多见，心包填塞猝死 |
| 室壁瘤 | ST 段持续抬高、附壁血栓 |
| 栓塞 | 附壁血栓脱落——抗凝 |
| 梗死后综合征（Dressler） | 1-4 周，心包炎胸膜炎表现 |

## 五、心脏瓣膜病四病对比

| 项目 | 二尖瓣狭窄 | 二尖瓣关闭不全 | 主动脉瓣狭窄 | 主动脉瓣关闭不全 |
|---|---|---|---|---|
| 常见病因 | 风湿热最常见 | 风湿、二尖瓣脱垂 | 老年钙化、先天二叶瓣 | 风湿、IE、夹层 |
| 杂音 | 心尖舒张中晚期隆隆样 | 心尖全收缩期吹风样向腋下传导 | 主动脉瓣区收缩期喷射性向颈部传导 | 胸骨左缘 3 肋间舒张期叹息样，前倾坐位呼气末最响 |
| 特征体征 | S1 亢进、开瓣音、P2 亢进 | S1 减弱 | S2 反常分裂、脉搏细迟 | 脉压增大：水冲脉、枪击音、毛细血管搏动征 |
| 周围血管征 | 无 | 无 | 无 | 有（＋Austin-Flint 杂音） |
| 心影 | 梨形心（左房大＋肺动脉段凸） | 球形心（左房左室大） | 左室大、心腰凹陷 | 靴形心 |
| 首选治疗 | 经皮球囊二尖瓣成形（无血栓/中重度反流时） | 症状性重度——二尖瓣修复首选 | 出现症状即换瓣（高危者 TAVR） | 血管扩张剂减反流；症状性换瓣 |
| 关键禁忌 | 房颤需抗凝 | — | 血管扩张剂禁用/慎用；药物无效 | — |
| 易错点 | 梨形心=二狭；靴形心=主闭/主狭 | 心尖收缩期先想二闭 | 症状即手术指征 | 舒张期杂音坐位前倾听 |

## 六、风湿热（Jones 标准）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | A 组链球菌感染后免疫反应 |
| 主要表现 | 心脏炎、多关节炎、舞蹈病、环形红斑、皮下结节 |
| 诊断组合 | 2 主要，或 1 主要＋2 次要，＋前驱链球菌感染证据 |
| 治疗 | 青霉素清除链球菌＋阿司匹林抗炎；心脏炎用糖皮质激素 |
| 继发预防 | 长效青霉素定期肌注 |
| 易错点 | 关节炎不留后遗症，心脏炎才致瓣膜病 |

## 七、感染性心内膜炎（IE）

| 维度 | 必背要点 |
|---|---|
| 亚急性病原 | 草绿色链球菌（口腔操作） |
| 急性病原 | 金黄色葡萄球菌 |
| 静脉药瘾者 | 金葡菌、三尖瓣 |
| 人工瓣膜 | 凝固酶阴性葡萄球菌、肠球菌 |
| 诊断标准 | Duke 标准 |
| 血培养 | 用药前采；多次（≥3 次）间隔 ≥1 h |
| 影像金标准 | 超声心动图见赘生物＋新反流性杂音 |
| 血管现象 | 瘀点、Janeway 损害（无痛） |
| 免疫现象 | Osler 结节（痛性）、Roth 斑、肾小球肾炎 |
| 治疗原则 | 先采血后用药；大剂量长程（4-6 周）静脉杀菌剂 |
| 用药 | 草绿链——青霉素±庆大霉素；金葡——（去甲）万古霉素 |
| 手术指征① | 瓣膜功能不全致心衰 |
| 手术指征② | 难控感染（脓肿、持续菌血症、真菌） |
| 手术指征③ | 大赘生物（>10 mm）反复栓塞 |
| 易错点 | Osler 痛、Janeway 不痛 |

## 八、心肌病与心肌炎

| 项目 | 扩张型（DCM） | 肥厚型（HCM） | 限制型（RCM） |
|---|---|---|---|
| 核心机制 | 全心扩大＋收缩功能下降 | 室间隔不对称肥厚＋流出道梗阻 | 心内膜纤维化＋舒张受限 |
| 遗传 | 家族性常见 | 常染色体显性（肌小节蛋白基因） | — |
| 杂音 | 无特征杂音 | 胸骨左缘 3-4 肋间收缩期喷射性 | 无特征杂音 |
| 杂音变化 | — | 减前负荷（Valsalva、站立）杂音增强；下蹲减弱 | — |
| 典型表现 | 心衰 | 劳力性呼吸困难、胸痛、晕厥猝死 | 酷似缩窄性心包炎 |
| 治疗 | 同 HFrEF 新四联＋ICD/CRT | β 阻滞剂（或维拉帕米）；切除/酒精消融；ICD | 对症；移植 |
| 禁忌 | — | 禁硝酸酯、强心药、利尿剂、血管扩张剂；禁硝苯地平 | — |
| 易错点 | — | 年轻人运动猝死要想到 HCM | 与缩窄性心包炎鉴别看心包钙化 |

### 病毒性心肌炎

| 维度 | 必背要点 |
|---|---|
| 病原 | 柯萨奇 B 组病毒最常见 |
| 病史 | 上感样症状后 1-3 周心悸气短 |
| 辅助 | cTn 升高、CK-MB 升高、ECG ST-T 改变与心律失常 |
| 治疗核心 | 休息（最根本）＋对症；重症可用激素/丙种球蛋白 |
| 注意 | 急性期忌剧烈运动（猝死风险） |
| 易错点 | 无特效抗病毒药，休息即治疗 |

## 九、心包疾病

| 项目 | 急性心包炎 | 心包积液/心脏压塞 | 缩窄性心包炎 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| NYHA vs Killip | NYHA 用于慢性心衰症状，Killip 专用于急性心梗 |
| UA vs NSTEMI | 同为 ACS，只差肌钙蛋白阴性/阳性；都不溶栓 |
| 心包炎 vs 心梗 ST 抬高 | 心包炎广泛凹面向上＋PR 压低；心梗局限弓背向上有演变 |
| 二狭 vs 主狭 | 二狭舒张期隆隆样心尖部；主狭收缩期喷射性向颈部传导 |
| HCM vs AS | 都有收缩期杂音；HCM 用 Valsalva 增强、减容量药禁忌，AS 症状即手术 |
| 缩窄性心包炎 vs 限制型心肌病 | 心包钙化、心包叩击音支持缩窄 |
| Osler 结节 vs Janeway 损害 | Osler 痛性（免疫现象），Janeway 无痛（血管现象） |
| 电复律 vs 除颤 | 同步（有脉的快速心律失常），非同步（无脉室速/室颤） |
