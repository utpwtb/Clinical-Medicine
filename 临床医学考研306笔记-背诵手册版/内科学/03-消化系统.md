# 内科学·背诵手册版——03 消化系统

> 冲刺背诵版：全表格短句、每行一个信息点、右栏遮盖自测。
> 覆盖：GERD、胃炎、溃疡、胃癌、IBD、肠结核、肝硬化、肝性脑病、肝癌、胰腺炎、上消化道出血。

---

## 一、胃食管反流病（GERD）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 一过性下食管括约肌松弛（TLESR）最重要 |
| 典型症状 | 烧心、反流；食管外表现哮喘、慢性咳嗽 |
| 分型 | 内镜阴性=NERD；有食管炎=RE；Barrett 食管 |
| Barrett 食管 | 食管鳞状上皮被柱状上皮取代——癌前病变（腺癌风险） |
| 首选治疗 | PPI（抑酸效果强于 H2RA）；试验性治疗有效支持诊断 |
| 生活方式 | 抬高床头、睡前 3 h 不进食、减重、忌酒咖啡高脂 |
| 易错点 | Barrett 需内镜定期监测，不是 PPI 能逆转 |

## 二、慢性胃炎

| 维度 | A 型（自身免疫性） | B 型（HP 相关性） |
|---|---|---|
| 部位 | 胃体 | 胃窦 |
| 机制 | 自身免疫（抗壁细胞/内因子抗体） | HP 感染为主 |
| 后果 | 内因子缺乏→恶性贫血（B12 吸收障碍） | 萎缩→肠化→异型增生→胃癌 |
| 抗体 | 抗壁细胞抗体、抗内因子抗体（+） | HP 抗体 |
| 诊断 | 胃镜＋活检为金标准 | 同左 |
| HP 检测首选 | 尿素呼气试验（非侵入）；快速尿素酶试验（内镜时） | — |
| 检测前停药 | PPI ≥2 周；抗生素、铋剂 ≥4 周 | — |
| 癌前链条 | 慢性胃炎→萎缩→肠化→异型增生→胃癌 | — |
| 易错点 | A 型贫血 B 型癌；查 HP 前先停 PPI | — |

## 三、消化性溃疡（PU）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 胃酸/胃蛋白酶攻击与黏膜防御失衡；HP 感染为最常见病因，NSAIDs 次之 |
| 胃溃疡节律 | 餐后 1 h 痛→下次餐前缓解（进食-疼痛-缓解） |
| 十二指肠溃疡节律 | 空腹痛、夜间痛→进食缓解（疼痛-进食-缓解） |
| 诊断金标准 | 胃镜＋活检 |
| 胃溃疡必须活检 | 排除恶性（恶性：边缘隆起、底污秽、皱襞中断） |
| 并发症顺位 | 出血最常见→穿孔→幽门梗阻→癌变（GU） |
| HP 根除方案 | 四联 10-14 天：PPI＋铋剂＋2 种抗生素（阿莫西林＋克拉霉素等） |
| 根除后复查 | 停药 ≥4 周行尿素呼气试验 |
| PPI 疗程 | DU 4-6 周；GU 6-8 周 |
| NSAIDs 溃疡 | PPI 防治；能停则停 NSAIDs |
| 易错点 | GU 疼餐后、DU 疼夜间；胃溃疡一律活检 |

## 四、胃癌

| 维度 | 必背要点 |
|---|---|
| 早期胃癌定义 | 局限于黏膜或黏膜下层，不论有无淋巴结转移 |
| 诊断金标准 | 胃镜＋活检 |
| 转移途径 | 淋巴转移为主（左锁骨上淋巴结——Virchow） |
| 种植转移 | 女性卵巢——Krukenberg 瘤 |
| 癌前状态 | 萎缩、肠化、异型增生、胃溃疡、残胃 |
| 治疗 | 手术为主；早癌内镜下切除（ESD） |
| 易错点 | 早期胃癌可已有淋巴转移，定语是浸润深度不是转移 |

## 五、炎症性肠病：UC vs Crohn（必考对比）

| 项目 | 溃疡性结肠炎（UC） | 克罗恩病（CD） |
|---|---|---|
| 好发部位 | 直肠起病、连续逆行蔓延 | 回肠末端＋右半结肠多见 |
| 病变范围 | 黏膜与黏膜下层 | 全壁层炎 |
| 分布 | 连续性 | 节段性/跳跃性 |
| 标志症状 | 黏液脓血便 | 腹痛（右下腹）、腹泻多无脓血 |
| 内镜特征 | 弥漫充血颗粒感、浅溃疡、假性息肉 | 纵行溃疡、鹅卵石样改变 |
| 病理 | 隐窝脓肿 | 非干酪性肉芽肿 |
| X 线 | 铅管征 | 线样征、跳跃 |
| 特有并发症 | 中毒性巨结肠、癌变 | 瘘管、肛周病变、肠梗阻 |
| 中毒性巨结肠诱因 | 低钾、抗胆碱药；钡灌肠禁忌 | — |
| UC 一线治疗 | 氨基水杨酸（美沙拉嗪） | 激素诱导（回肠型可用布地奈德） |
| 重度 UC | 静脉激素，48-72 h 无效→环孢素/手术 | 硫唑嘌呤/甲氨蝶呤维持 |
| 生物制剂 | 英夫利西单抗等 | 同类；儿童 CD 可用全肠内营养首选 |
| 手术 | UC 切结肠可治愈 | CD 手术仅针对并发症（易复发） |
| 癌变监测 | 全结肠型病史 >8-10 年定期结肠镜 | — |
| 易错点 | UC 脓血便连续、CD 无脓血跳跃有瘘管 | — |

## 六、肠结核

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 人型结核菌经口感染；好发回盲部（淋巴组织丰富＋滞留） |
| 分型 | 溃疡型（环形溃疡、干酪样坏死）、增生型（肉芽增生、包块） |
| 典型表现 | 右下腹痛＋腹泻或腹泻便秘交替＋低热盗汗 |
| 辅助 | PPD 强阳性、血沉快；结肠镜＋活检干酪性肉芽肿确诊 |
| 与 CD 鉴别关键 | 干酪样坏死只见于肠结核 |
| 与克罗恩共有 | 回盲部、肉芽肿、跳跃倾向 |
| 治疗 | 抗结核（同肺结核方案） |
| 易错点 | 干酪性坏死是肠结核的法宝，CD 是非干酪性 |

## 七、肝硬化

| 维度 | 必背要点 |
|---|---|
| 我国最常见病因 | 乙型病毒性肝炎 |
| 失代偿四表现 | 腹水、食管胃底曲张出血、肝性脑病、黄疸 |
| Child-Pugh 五项 | 胆红素、白蛋白、PT 延长、腹水、肝性脑病 |
| Child 分级 | A 级 5-6 分、B 级 7-9 分、C 级 10-15 分 |
| 腹水性质 | 漏出液为主；SBP 时可中性粒细胞升高 |
| SBP 诊断 | 腹水 PMN ≥250×10^6/L 即可诊断（不需培养阳性） |
| SBP 病原 | 大肠杆菌等 G- 杆菌为主 |
| SBP 治疗 | 三代头孢（头孢噻肟） |
| 腹水治疗 | 限钠＋螺内酯：呋塞米（100 mg:40 mg 比例） |
| 顽固性腹水 | 大量放腹水＋白蛋白（放 >5 L 需按每升 6-8 g 补）；TIPS |
| 曲张出血药物 | 生长抑素/奥曲肽、特利加压素＋三代头孢 |
| 曲张出血内镜 | 套扎（EVL）或硬化剂 |
| 二级预防 | 非选择性 β 阻滞剂（普萘洛尔）降门脉压 |
| 垂体后叶素 | 冠心病慎用（收缩冠脉） |
| 肝肾综合征 | 低尿钠＋Cr 升高、肾脏无器质损害；特利加压素＋白蛋白 |
| 易错点 | SBP 看 PMN 不等培养；放腹水必须配白蛋白 |

## 八、肝性脑病（HE）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 氨中毒学说为核心（假性神经递质、氨基酸失衡等参与） |
| 最常见诱因 | 消化道出血；高蛋白、感染、便秘、低钾碱中毒、镇静药 |
| 低钾促发机制 | 碱中毒使 NH4+ 转为 NH3 透过血脑屏障 |
| 分期 I 期（前驱） | 性格行为改变、睡眠倒错 |
| 分期 II 期（昏迷前期） | 嗜睡、扑翼样震颤（+）、肌张力升高 |
| 分期 III 期（昏睡） | 昏睡但可唤醒 |
| 分期 IV 期（昏迷） | 昏迷，扑翼样震颤无法引出 |
| 治疗根本 | 去除诱因 |
| 首选药物 | 乳果糖（酸化肠道＋渗透性腹泻减少氨吸收）；利福昔明 |
| 降氨药 | 门冬氨酸鸟氨酸；支链氨基酸 |
| 蛋白摄入 | 不严格限蛋白（1.2-1.5 g/kg/d，植物蛋白/乳制品优先） |
| 镇静相关昏迷 | 可试用氟马西尼 |
| 易错点 | 现在不再严格禁蛋白；IV 期扑翼样震颤引不出 |

## 九、原发性肝癌

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 乙肝/丙肝—肝硬化—肝癌三部曲 |
| 最常见病因 | 慢性病毒性肝炎（乙肝） |
| 肿瘤标志 | AFP：≥400 μg/L 持续 4 周（排除妊娠、活动性肝病、生殖腺肿瘤） |
| 筛查方案 | 高危人群每 6 个月：肝脏超声＋AFP |
| 确诊影像 | 增强 CT/MRI（快进快出强化） |
| 治疗 | 手术切除首选（可切者）；介入 TACE（不可切）；消融小肝癌 |
| 易错点 | AFP 升高先排除妊娠与活动性肝病再谈肝癌 |

## 十、急性胰腺炎（AP）

| 维度 | 必背要点 |
|---|---|
| 核心机制 | 胰酶提前激活→胰腺自身消化→全身炎症 |
| 我国最常见病因 | 胆石症（胆源性）；西方酒精多 |
| 诊断三标准（满足 2 条） | ①典型上腹痛（向腰背放射）；②血淀粉酶/脂肪酶 ≥3 倍正常；③影像学 |
| 脂肪酶 | 特异性高于淀粉酶 |
| 确诊影像 | 增强 CT（72 h 后更能判坏死） |
| 严重度（Atlanta） | 轻症→中度→重症 SAP（持续 >48 h 器官衰竭） |
| 重症预警 | CRP >150 mg/L 提示重症 |
| 局部并发症 | 假性囊肿（>4 周、有囊壁、无上皮衬里）、包裹性坏死 |
| 全身并发症 | ARDS、急性肾损伤、胰性脑病 |
| 治疗基础 | 禁食胃肠减压＋液体复苏（早期目标导向） |
| 抑制分泌 | 生长抑素/奥曲肽＋PPI |
| 镇痛 | 首选哌替啶（传统观点慎用吗啡） |
| 抗感染 | 不预防性使用；感染性坏死才用（三代头孢＋甲硝唑、碳青霉烯） |
| 营养 | 重症 24-48 h 内启动肠内营养优于肠外 |
| 胆源性处理 | 合并胆管炎/梗阻 24 h 内 ERCP；恢复后胆囊切除 |
| 易错点 | 淀粉酶高低与病情不平行；假性囊肿满 4 周才定名 |

## 十一、上消化道出血

| 维度 | 必背要点 |
|---|---|
| 最常见病因 | 消化性溃疡 |
| 其他病因 | 曲张破裂、糜烂出血性胃炎、胃癌、Mallory-Weiss 撕裂 |
| 出血量 5-10 ml | 粪便隐血阳性 |
| 出血量 50-100 ml | 黑便 |
| 出血量 250-300 ml | 呕血 |
| 出血量 >400 ml | 头晕、心悸 |
| 出血量 >1000 ml | 周围循环衰竭（休克） |
| 第一步 | 复苏：双通道扩容；Hb <70 g/L 输血 |
| 门脉高压输血 | 目标 Hb 80 g/L；避免过量扩容诱发再出血 |
| 抑酸 | 大剂量 PPI（如艾司奥美拉唑 80 mg 静推后 8 mg/h） |
| 曲张出血加用 | 生长抑素/奥曲肽/特利加压素＋三代头孢（降感染与病死率） |
| 内镜时机 | 24 h 内急诊内镜止血（夹/热凝/套扎） |
| 失败手段 | 三腔二囊管压迫（过渡）、TIPS、手术 |
| 易错点 | 曲张出血要抗生素＋限制性输血；先复苏再内镜 |

## 【易混对照】

| 组 | 一句话辨析 |
|---|---|
| 胃溃疡 vs 十二指肠溃疡 | GU 餐后痛→餐前缓，DU 夜间痛→进食缓 |
| 良性 vs 恶性溃疡 | 恶性：边缘隆起结节、底污秽苔、皱襞中断 |
| UC vs CD | UC 连续、黏膜层、脓血便；CD 跳跃、全层、瘘管肉芽肿 |
| 肠结核 vs 克罗恩 | 干酪样坏死只在肠结核 |
| 漏出液 vs SBP 腹水 | 肝硬化腹水漏出为主；PMN≥250 即 SBP |
| 肝性脑病 II vs IV 期 | II 期扑翼样震颤可引出，IV 期引不出 |
| 淀粉酶 vs 脂肪酶 | 脂肪酶特异性更高；酶值高低不等于病情轻重 |
| 曲张 vs 非曲张出血 | 曲张加生长抑素＋抗生素；都需大剂量 PPI（非曲张为主） |
