# 临床医学考研 306 笔记 · 讲义精讲版

> **定位**：一轮/二轮**精读用的完整讲义**。特征：知识点全面铺开（含次要病种要点）、机制讲透（解释"为什么"）、大型鉴别对比表。
> **编写基准**：人卫第 10 版教材体系与现行主流指南共识；内容为按考点重新组织编写，非教材原文摘抄；版本敏感处标注"（以最新指南/教材为准）"或"⚠ 需核对"。
> **标记约定**：★ 高频考点 ｜ ⚠ 易错点 ｜ 每病末尾附【高频考点提示】。

## 三套版本怎么配合用

| 阶段 | 用哪套 | 怎么用 |
|---|---|---|
| 一轮（2026.9–2027.3） | **讲义精讲版** + 教材 | 逐病精读，抄写每张对比表，建立框架 |
| 二轮（2027.4–2027.8） | **真题导向版** + 真题 | 做完成套真题后按考点回看，重点看"陷阱与干扰项" |
| 三轮冲刺（2027.9–11） | **背诵手册版** | 每天按系统过速记总表与口诀 |
| 考前（2027.12） | 第一版速记 + 背诵手册版【速记总表】 | 只背加粗条目与数值 |

## Obsidian 使用说明（本库已做图谱化增强）

- **思维导图（笔记内，无需插件）**：每个内容文件开头有一张全局导图（Mermaid mindmap 代码块），机制复杂、大表集中的重点章节开头另有小图，Obsidian 原生渲染（阅读视图/实时预览均生效，源码模式下显示为可读大纲）。注意：在源码模式或光标停在代码块内时不会渲染。
- **思维导图（交互画布版，需 MindCanvas 插件）**：每科 `思维导图/` 子目录下有与各文件同名的 `.naotu` 文件，点击即打开可拖拽、缩放、折叠的交互导图；章节点可直接跳回笔记对应标题。也可对任意 md 文件使用 MindCanvas 命令"从当前 Markdown 标题创建脑图"或"从当前文件创建本地知识图谱"（后者会利用文末的相关知识点内链）。
- **知识图谱**：每个病种/章节末尾附"相关知识点"链接行，点击直达对应章节；按 `Ctrl+G` 打开图谱可查看全库联系。各科的 `90-*地图.md` 是本科全部章节的入口（MOC），在图谱中是枢纽节点，建议作为浏览起点。
- **属性标签**：每个文件带 tags / 科目 / 系统 / 内容 frontmatter 属性，可用标签面板按 `#考研306/科目/系统` 层级筛选。
- **维护提醒**：所有内链基于 `文件名#标题` 锚点，请勿改动各文件中的标题文字（含 ★ 标记与全角括号），否则对应链接会失效；文件基名（如 01-呼吸系统）在全库唯一，重命名文件会导致链接断开。
