## 第一章 细胞和组织的适应与损伤 ★★

### 1.1 适应性改变

【定义/概述】
- 适应 = 细胞/组织对内外环境持续性刺激的非损伤性应答：萎缩、肥大、增生、化生。

【对比表】四种适应对比（必背大表）

| | 定义 | 机制 | 典型例子 | 易错点 |
|---|---|---|---|---|
| ★萎缩 | 发育正常的细胞/组织/器官**体积缩小**（可伴数量减少） | 蛋白分解↑合成↓、细胞器减少 | 营养不良性（恶病质）、压迫性（脑积水）、失用性（久卧）、去神经性（脊髓灰质炎）、内分泌性、老年性 | ⚠发育不良≠萎缩（萎缩指已发育正常者缩小） |
| ★肥大 | 细胞**体积增大** | 合成代谢↑、细胞器增多 | 高血压左心室肥大、运动员骨骼肌、妊娠子宫（肥大+增生并存） | ⚠心肌、骨骼肌只有肥大无增生（永久细胞） |
| ★增生 | 细胞**数量增多** | 有丝分裂增强 | 子宫内膜增生（雌激素↑）、肝切除后再生性增生、前列腺增生 | ⚠前列腺增生属增生；子宫内膜增生过长是癌前背景 |
| ★化生 | 一种**分化成熟**细胞被另一种分化成熟细胞取代 | 可逆；同源细胞间（上皮↔上皮、间叶↔间叶） | 支气管假复层纤毛柱状上皮→鳞化（吸烟）；慢性萎缩性胃炎→肠化生；结缔组织→骨（骨化性肌炎） | ⚠化生是保护适应但失分化保护功能→癌变温床（肠化→胃癌；鳞化→鳞癌） |

【机制与原理】化生为什么既适应又危险？
- 化生经干细胞分化方向重编程实现，使脆弱上皮获得更强的屏障（如支气管鳞化对抗烟尘）。但新细胞失去原有功能（纤毛清除），且其增殖基因重编程后更易受致癌因素攻击——化生→异型增生→癌是常见通路。

【对比表】化生类型与癌变风险配对

| 化生类型 | 场景 | 潜在风险 |
|---|---|---|
| ★鳞状上皮化生 | 支气管（吸烟）、宫颈移行带、膀胱移行上皮 | 鳞癌 |
| ★肠上皮化生 | 慢性萎缩性胃炎 | 胃腺癌（癌前） |
| 假幽门腺化生 | 胃体黏膜萎缩 | 胃腺癌 |
| 骨/软骨化生 | 结缔组织（骨化性肌炎） | — |

- 萎缩机制总览：蛋白降解↑（泛素-蛋白酶体）+合成↓、细胞器减少（自噬增强）；萎缩可复，持续过久则细胞死亡。
- 【对比表】病理性萎缩的分类

| 类型 | 机制 | 例 |
|---|---|---|
| ★营养不良性 | 全身/局部营养缺乏 | 恶病质、压迫性（肿瘤压迫） |
| ★压迫性 | 局部受压+缺血 | 脑积水脑皮质萎缩、肾结石肾实质萎缩 |
| ★失用性 | 活动减少、代谢↓ | 久卧/石膏固定后肌肉萎缩 |
| ★去神经性 | 神经营养丧失 | 脊髓灰质炎肢体细小 |
| ★内分泌性 | 激素靶效应丧失 | Simmonds 综合征靶器官萎缩 |
| 老化性 | 细胞老化 | 老年性子宫/脑萎缩 |
- 老化：端粒缩短学说、氧化损伤累积学说、干细胞耗竭；★脂褐素沉积是老化的形态标志之一。

### 1.2 细胞损伤的原因与机制 ★

【要点展开】常见损伤原因
- 缺氧（最常见）、化学因素（CCl₄→肝脂变；药物）、物理因素（机械、高温、电离辐射）、生物因素（病毒、细菌）、免疫反应（超敏、自身免疫）、遗传变异、营养失衡、社会心理因素。

【机制与原理】缺血缺氧损伤的逻辑链（必会）
- ATP↓ → **Na⁺-K⁺ 泵障碍** → 细胞水肿；ATP↓ → 无氧酵解 → pH↓；持续 → **溶酶体膜损伤**释放酶 → 自溶坏死。缺血-再灌注时 ROS 大量产生+Ca²⁺超载 → 加速膜脂过氧化（再灌注损伤的核心机制）。
- ★ 可逆→不可逆的分水岭：**线粒体不可逆损伤与细胞膜完整性丧失**（形态上以酶漏出、超微结构破坏为界）。

### 1.2 可逆性损伤（变性）★

【对比表】主要变性类型大表（必背大表之一）

| 变性 | 病变本质 | 好发/特征 | 临床联系 |
|---|---|---|---|
| ★细胞水肿（水变性） | 线粒体损伤→ATP↓→Na⁺-K⁺ 泵障碍→水钠潴留 | 肝、心、肾；胞质疏松红染；★病毒性肝炎**气球样变** | 缺氧、感染最常见可逆损伤 |
| ★脂肪变 | 甘油三酯蓄积于**非脂肪细胞**胞质 | **肝最常见**（肥胖、酒精、CCl₄、糖尿病、缺氧）；心肌**虎斑心**（与心外膜脂肪浸润区别）；石蜡切片呈空泡，冰冻切片苏丹Ⅲ/Ⅳ、锇酸阳性 | 脂肪肝可逆；慢性肝损伤→纤维化 |
| ★玻璃样变（透明变性） | 蛋白质在细胞内/间质/血管壁蓄积，HE 红染均质 | ①血管壁：**细动脉硬化（高血压、糖尿病）**；②结缔组织：瘢痕；③细胞内：**Mallory 小体（酒精性肝病，前角蛋白）**、**Russell 小体（浆细胞，免疫球蛋白）** | 高血压细动脉玻璃样变=特征性病变 |
| ★淀粉样变 | 淀粉样物质（β 折叠原纤维）细胞外沉积 | ★刚果红染色**砖红色**、偏振光苹果绿；AL 型（多发性骨髓瘤）、AA 型（结核、RA）；阿尔茨海默 | 器官功能渐损 |
| 黏液样变 | 黏多糖与蛋白蓄积 | 间叶组织肿瘤、风湿病、甲减黏液性水肿 | — |
| ★病理性色素沉着 | 色素异常蓄积 | **含铁血黄素（★心衰细胞——左心衰肺淤血）、脂褐素（老年/萎缩）、黑色素、胆红素** | 心衰细胞=含铁血黄素的肺泡巨噬细胞 |

【机制与原理】肝脂肪变的四条机制（考试常问"哪项不是"）
- ①脂肪酸摄取/合成↑或氧化↓；②**脂蛋白合成障碍**（载脂蛋白/磷脂/胆碱缺乏——CCl₄ 破坏粗面内质网）；③甘油三酯合成↑；④脂肪酸运出障碍。四条中任何一条失衡即发生脂肪变——肥胖（供过多）与酒精/CCl₄（出路受阻）各占一端。

【对比表】营养不良性钙化 vs 转移性钙化（必背）

| | 营养不良性钙化 | 转移性钙化 |
|---|---|---|
| 血钙 | **正常** | **升高** |
| 部位 | 变性坏死组织、异物（★结核干酪坏死、AS 斑块、死亡寄生虫） | 正常组织，好发**排酸部位**：肾小管、肺泡壁、胃黏膜 |
| 全身钙磷代谢 | 无异常 | 有异常（甲旁亢、骨破坏、VitD 过多） |
| 频率 | 最常见 | 较少见 |

### 1.3 细胞死亡：坏死 ★★

【机制与原理】坏死的形态如何产生？
- 致损伤因素使膜系统（细胞膜、溶酶体膜）破坏 → 酶性消化 + 蛋白变性 → 形态学"三步"：★**核固缩→核碎裂→核溶解**，胞质嗜酸增强、间质胶原肿胀崩解。坏死是不可逆的，必然引发炎症反应（与凋亡的本质区别）。

【对比表】五种坏死类型（必背大表之二）

| 类型 | 机制 | 好发部位/疾病 | 大体/镜下特征 |
|---|---|---|---|
| ★凝固性坏死 | 蛋白质变性凝固占优（溶酶体酶作用弱） | 心、肝、肾、脾（★心肌梗死、肾梗死） | 灰白干燥、**原组织轮廓残影保存** |
| ★干酪样坏死 | 结核感染；彻底凝固+脂质丰富 | ★结核病特征性 | 灰黄细腻如干酪、**不见组织轮廓** |
| ★液化性坏死 | 含脂质/水分多、蛋白少或酶性强 | ★脑（含磷脂多）、脊髓、脓肿（中性粒细胞酶）、阿米巴肝脓肿 | 液化呈囊腔 |
| ★脂肪坏死 | 酶解性（胰酶外溢）/外伤性 | ★**急性胰腺炎**（脂肪细胞坏死+钙皂）、乳房外伤 | 白色钙皂斑点 |
| ★纤维素样坏死 | 免疫复合物+纤维蛋白沉积、胶原纤维破坏 | ★结缔组织与小血管壁——**风湿病、SLE、结节性多动脉炎、恶性高血压细动脉、急进性肾炎** | HE 红染纤维素样物质 |

【要点展开】坏疽（坏死+腐败菌感染）

| | 干性坏疽 | 湿性坏疽 | 气性坏疽 |
|---|---|---|---|
| 部位 | 四肢末端 | 与外界相通内脏（肺、肠、子宫）+四肢动静脉均阻 | 深部肌肉开放性创伤 |
| 感染/气体 | 较轻 | 重、恶臭 | ★**产气荚膜梭菌**、捻发感 |
| 分界 | **清楚** | 不清 | 不清 |
| 全身中毒 | 轻 | 重 | **极重、进展极快** |

- 坏死结局：溶解吸收 → 分离排出（**糜烂浅表/溃疡达肌层/窦道-瘘管/空洞**——肺、肾坏死物经支气管、输尿管排出）→ 机化与包裹（★机化=肉芽组织取代坏死组织）→ 钙化。
- ⚠ 定义辨析：**窦道**=深部组织通向体表的病理性盲管；**瘘管**=连接两个空腔器官或器官与体表的管道（肛瘘）；**空洞**=肺/肾等坏死物经自然管道排出后残留的腔隙。

### 1.4 细胞死亡：凋亡 ★

【机制与原理】凋亡为什么"不引起炎症"？
- 凋亡是基因（caspases 家族执行）调控的主动死亡：细胞皱缩、核染色质边集、**膜内陷包裹成分形成凋亡小体**被邻近细胞/巨噬细胞**完整吞噬**——膜始终完整、内容物不外漏，故无炎症。坏死则膜破裂、酶外漏 → 炎症。

【对比表】凋亡 vs 坏死（必考大表）

| | 凋亡 | 坏死 |
|---|---|---|
| 性质 | 程序性、主动 | 被动、损伤性 |
| 范围 | **单个细胞** | 成群细胞 |
| 膜完整性 | 完整至末 | 早期即破坏 |
| 形态 | 细胞皱缩、**凋亡小体** | 肿胀、核固缩碎裂溶解、细胞自溶 |
| 炎症反应 | **无** | **有** |
| 能量 | 依赖 ATP | 不依赖 |
| 生理/病理 | 生理（胚胎、老化）+病理（★病毒性肝炎嗜酸性小体） | 病理为主 |
| 执行者 | ★caspases | 溶酶体酶外漏 |

- 凋亡信号通路：①★死亡受体途径（Fas/FasL、TNF → caspase 8）；②★线粒体途径（Bcl-2 家族调控、细胞色素 c 释放 → 凋亡小体 → caspase 9 → caspase 3 执行）；③内质网途径。★Bcl-2 抑制凋亡——t(14;18) 滤泡性淋巴瘤的机制闭环（与生化癌基因章联动）。
- 自噬、坏死性凋亡、焦亡、铁死亡（调节性细胞死亡新概念，了解）。

【高频考点提示】
- ★ 损伤"可逆/不可逆"分水岭=线粒体不可逆损伤与膜完整性丧失；缺氧是最常见原因。
- ★ 化生三例+癌变关联；心肌只肥大不增生。
- ★ Mallory 小体（前角蛋白）/Russell 小体（Ig）/刚果红苹果绿=三大"小体-染色"配对。
- ★ 五种坏死+三种坏疽大表；脑=液化、心肌梗死=凝固、结核=干酪、胰腺炎=脂肪坏死。
- ★ 凋亡核心：凋亡小体、无炎症、caspases；两条启动通路（死亡受体/线粒体）。
- 调亡检测线索（病理题干信号）："嗜酸性小体"（病毒性肝炎）、"凋亡小体"、单个细胞嗜酸深染核浓缩——答题时优先判"凋亡"而非坏死。

## 第二章 损伤的修复 ★

### 2.1 再生

【机制与原理】细胞按再生能力分三类的依据是什么？
- 取决于细胞周期进入能力与分化程度：不稳定细胞持续分裂（覆盖/衬覆功能，损耗大）→ 表皮、呼吸道消化道被覆上皮、生殖细胞、淋巴造血细胞；稳定细胞处于 G0 期、损伤后可重返周期 → 肝细胞、腺体（胰腺、甲状腺、涎腺）、肾小管上皮、平滑肌；**永久细胞**（神经元、骨骼肌、心肌）失去分裂能力 → 只能瘢痕修复。★⚠ 神经**纤维（轴突）可再生而神经元不可再生**。

### 2.2 肉芽组织 ★★

【定义/概述】
- 肉芽组织 = **新生毛细血管 + 成纤维细胞 + 炎细胞（巨噬细胞为主）**；鲜红颗粒状、湿润、触之易出血、无痛觉。

【机制与原理】肉芽组织为什么是修复的"万能脚手架"？
- 巨噬细胞清除坏死与病原并释放生长因子；新生毛细血管供氧供营养；成纤维细胞增生并分泌胶原逐步"固化"缺损 → 最终演变为瘢痕组织（胶原多、血管少、灰白坚韧）。故其三大功能：★抗感染保护创面、填补伤口缺损、**机化**坏死组织/血栓/异物。

### 2.3 创伤愈合 ★

【对比表】一期愈合 vs 二期愈合

| | 一期愈合 | 二期愈合 |
|---|---|---|
| 条件 | 创缘整齐、无感染、对合好（手术切口） | 缺损大、有感染、无法对合 |
| 过程 | 少量肉芽组织、表皮快速覆盖 | 大量肉芽组织填充+创缘收缩+上皮覆盖 |
| 结果 | 瘢痕小、线状 | 瘢痕大、时间长 |

- 骨折愈合：血肿形成 → 纤维性骨痂 → 骨性骨痂（编织骨）→ 骨痂改建（板层骨、恢复髓腔）。
- 皮肤愈合时序（理解用）：12–24 h 炎细胞浸润→24–72 h 表皮增生迁移→3 天肉芽长满→5–6 天胶原出现→数月瘢痕成熟重塑。

【对比表】影响骨折愈合的因素

| 有利 | 不利 |
|---|---|
| 年龄轻、血供好、复位对合好、固定牢靠 | ★骨折断端嵌夹软组织、骨缺损大 |
| 营养充分、功能锻炼适时 | 感染、反复活动 |
| — | ★维 C 缺乏（胶原羟化障碍）、糖皮质激素、吸烟、电离辐射 |

- 影响愈合因素：年龄、营养（★维 C 缺乏→胶原羟化障碍；蛋白质缺乏）、感染与异物、局部血供、神经支配、电离辐射、糖皮质激素（抑制愈合）。
- ⚠ 瘢痕收缩可致挛缩畸形；瘢痕疙瘩=胶原过度增生。
- 【要点展开】瘢痕组织的利与弊
  - 利：填补缺损、保持组织器官完整性、有一定抗张强度。
  - 弊：①收缩——挛缩畸形（烧伤瘢痕）、幽门梗阻、十二指肠溃疡幽门狭窄；②过度增生——瘢痕疙瘩；③器官硬化——肺纤维化、肝硬化的本质都是反复损伤-纤维化的终局。

【对比表】肉芽组织 vs 肉芽肿（一字之差，年年设坑）

| | 肉芽组织（granulation tissue） | 肉芽肿（granuloma） |
|---|---|---|
| 本质 | **修复性结构** | **慢性炎症形态** |
| 构成 | 新生毛细血管+成纤维细胞+炎细胞 | 巨噬细胞及其衍生细胞（类上皮、巨细胞）+淋巴细胞 |
| 场景 | 创伤愈合、机化坏死/血栓/异物 | 结核、伤寒、梅毒、异物、结节病 |
| 结局 | →瘢痕组织 | →纤维化/钙化 |

【对比表】与修复相关的重要生长因子（必背）

| 生长因子 | 主要作用 |
|---|---|
| PDGF | 促成纤维细胞、平滑肌、单核细胞增殖迁移 |
| EGF | 促上皮细胞增殖 |
| ★VEGF | **促血管新生**（肉芽组织毛细血管的主要动力） |
| FGF | 促血管生成与成纤维细胞增殖 |
| ★TGF-β | 促胶原合成与纤维化（瘢痕关键），抑制多数上皮增殖 |

- ★ 细胞外基质（ECM）：胶原、弹力蛋白、纤连蛋白/层粘连蛋白、蛋白聚糖——提供支架并传递信号；维 C 缺乏→胶原羟化障碍→伤口不愈（机制闭环）。
- 【要点展开】再生的过程要点
  - 上皮再生：边缘基底细胞增生迁移→覆盖缺损→分化成熟（一期愈合的基础）。
  - 血管再生：毛细血管以"出芽"方式新生（VEGF 驱动）→管腔相通→改建；大血管断裂需吻合（手术）。
  - 纤维性修复：成纤维细胞增殖→合成胶原（原胶原蛋白分子交联→张力渐增）→肉芽组织成熟为瘢痕。
  - ⚠ 神经纤维再生：断离后近端轴突以约 1 mm/天生长，须有施万细胞鞘引导；两断端对合不良→创伤性神经瘤。

【高频考点提示】
- ★ 永久细胞三兄弟（神经元、骨骼肌、心肌）；肉芽组织三成分与三功能。
- ★ 维 C 缺乏影响胶原合成→愈合延迟。

## 第三章 局部血液循环障碍 ★★

### 3.1 充血与淤血

- 动脉性充血（主动）：生理性（运动后肌肉、进食后胃肠）与病理性（炎症性、减压后充血）——局部红、热、肿。
- 静脉性充血（淤血，被动、更重要）：静脉受压、腔内阻塞、心衰——全身性（右心衰）或局部性（静脉血栓）。

【对比表】肺淤血 vs 肝淤血（必背）

| | 肺淤血（左心衰） | 肝淤血（右心衰） |
|---|---|---|
| 急性 | 肺泡壁毛细血管扩张+**心衰细胞**+水肿（粉红泡沫痰） | 肝小叶中央静脉周围淤血 |
| 慢性 | ★**肺褐色硬化**（含铁血黄素+纤维化） | ★**槟榔肝**（红[中央淤血区]黄[脂肪变区]相间）→淤血性（心源性）肝硬化——**纤维间隔不完整分割、假小叶不典型** |

### 3.2 血栓形成 ★★

【机制与原理】血栓形成三条件（Virchow 三要素）如何配合？
- ★①心血管**内膜损伤**（最重要——胶原暴露+TF 释放，启动内/外源凝血与血小板黏附）；②血流状态改变（缓慢/涡流——静脉血栓多于动脉的原因：静脉瓣窝易成涡流且流速慢）；③血液凝固性↑（高凝状态：恶性肿瘤释放 TF、妊娠/口服避孕药、DIC）。

【对比表】四种血栓类型（必背大表之三）

| 类型 | 成分 | 部位 | 特征 |
|---|---|---|---|
| ★白色血栓 | 血小板+纤维蛋白 | **血流快处**：动脉、心瓣膜；静脉血栓**头部** | 灰白、坚实 |
| ★混合血栓 | 血小板小梁（珊瑚状）+红细胞层状交替 | 静脉延续性血栓**体部** | 灰白与暗红层状 |
| ★红色血栓 | 纤维蛋白网罗大量红细胞 | 静脉血栓**尾部**（管腔全堵后血流停滞） | 暗红、**易脱落→栓塞** |
| ★透明血栓（微血栓） | 纤维蛋白 | **DIC 的微循环内** | 只有镜下可见 |

- 血栓结局：软化溶解吸收、机化与**再通**、钙化（静脉石）。
- ⚠ 风湿性心内膜炎疣状赘生物（白色血栓）不易脱落；感染性心内膜炎赘生物易脱落→栓塞。
- 血栓对机体影响两面性：利——血管破裂时封堵止血；弊——①阻塞血管（动脉→梗死、静脉→淤血水肿）；②脱落栓塞；③心瓣膜赘生物机化→瓣膜变形（瓣膜病）；④**DIC 广泛微血栓**→消耗性凝血障碍→出血+休克。
- 【要点展开】出血类型：**破裂性**（血管壁结构破坏——外伤、动脉瘤、溃疡/结核侵蚀血管壁）与**漏出性**（通透性↑——缺氧、感染中毒、维 C 缺乏、DIC）。

### 3.3 栓塞 ★

【对比表】栓塞类型大表（必背）

| 类型 | 栓子来源 | 部位/后果 | 要点 |
|---|---|---|---|
| ★血栓栓塞（占 99%） | 下肢深静脉（髂/股静脉） | **肺动脉栓塞**；左心/动脉粥样斑块→体循环（脑、脾、肾、下肢） | 脱落的血栓随血流运行 |
| ★脂肪栓塞 | 长骨骨折、脂肪组织挫伤、脂肪肝挤压 | 肺（呼吸困难）→循环到达脑（神经症状、瘀点） | 机制：机械阻塞+脂质毒性 |
| ★气体栓塞 | 静脉破裂进空气；★**减压病（沉箱病）——氮气气泡** | 空气量>100 ml 可致命 | 溶解气体析出 |
| ★羊水栓塞 | 分娩中羊水入血 | ★**肺小动脉内羊水成分（角化上皮、胎毛、胎脂、黏液）** → DIC、休克、猝死 | 产科最凶险并发症 |
| 其他 | 肿瘤细胞（转移）、寄生虫、细菌菌落 | — | — |

【要点展开】栓子运行途径（与解剖对位记忆，必会）
- 体静脉系统/右心栓子 → **肺动脉**（肺栓塞）；
- 左心/动脉系统栓子 → 全身脏器（脑、脾、肾、下肢）；
- 门静脉系统栓子 → **肝**（门静脉癌栓→肝癌肝内转移最早的病理基础）；
- ★**交叉性栓塞**：先天性房间隔/室间隔缺损时，体循环栓子可入肺循环、反之亦然；**逆行性栓塞**：下腔静脉内栓子在腹压骤升时逆向运行。

### 3.4 梗死 ★

【机制与原理】梗死为什么有"白"与"红"之分？
- 取决于器官组织结构（致密/疏松）与血供（侧支/双重）：实质器官致密且侧支少 → 梗死区蛋白渗出少、出血不流入 → **贫血性（白色）梗死**；肺（支气管动脉+肺动脉双重供血）、肠（系膜血管吻合弓丰富+疏松组织）在淤血基础上梗死 → 血液自吻合支灌入坏死区 → **出血性（红色）梗死**。

【对比表】贫血性梗死 vs 出血性梗死（必考大表）

| | 贫血性（白色）梗死 | 出血性（红色）梗死 |
|---|---|---|
| 条件 | **实质器官、组织致密、侧支循环少** | **双重血供或组织疏松+淤血** |
| 器官 | ★心、脾、肾、脑 | ★肺、肠 |
| 形态 | 灰白、锥形（脾肾，尖朝门部）、心肌地图形 | 暗红、肿大 |
| 坏死类型 | 凝固性为主（脑为液化性） | 凝固性+出血 |

- 败血性梗死：含菌栓子→梗死区继发脓肿。
- 梗死对机体的影响取决于部位与范围：肾/脾梗死影响小（代偿良好、机化为瘢痕凹陷）；心肌梗死→心衰/心律失常/猝死；脑梗死→偏瘫失语；肠梗死→坏疽穿孔腹膜炎。
- 肠梗死：肠套叠/肠扭转/肠系膜动脉栓塞→湿性坏疽。
- 梗死结局与影响：取决于器官、部位与有无感染——肾脾梗死功能影响小（代偿），心脑梗死后果重；陈旧梗死机化形成瘢痕凹陷。

【对比表】血栓形成 vs 栓塞 vs 梗死（概念链辨析，必考）

| | 血栓形成 | 栓塞 | 梗死 |
|---|---|---|---|
| 定义 | 活体心血管内血液**原位**凝固 | 随血流运行的**异物**阻塞血管 | 器官组织**缺血坏死** |
| 关系 | 血栓脱落→成为栓子→引起栓塞 | 栓塞的后果之一（侧支不足时）→梗死 | 是结局；梗死灶内可有血栓 |
| 关键词 | 原位、Virchow 三要素 | 运行、脱落 | 缺血、坏死、侧支循环 |

【高频考点提示】
- ★ 血栓三条件以"内膜损伤最重要"；四种血栓-部位配对；DIC=透明血栓。
- ★ 羊水栓塞四成分+DIC；减压病=氮气气泡。
- ★ 白色梗死（心脾肾脑）vs 红色梗死（肺肠）及其原因。

## 第四章 炎症 ★★

### 4.1 炎症概述

【定义/概述】
- 炎症 = 活体组织对损伤的**防御性血管反应**；基本病变：★**变质、渗出、增生**——渗出最具特征（也是防御的核心：稀释、吞噬、运载免疫成分）。

【要点展开】
- 急性炎症血流动力学变化：细动脉短暂收缩 → 血管扩张血流加速 → 血流缓慢淤血 → 通透性↑液体渗出 → 白细胞边集附壁游出。

【机制与原理】白细胞如何"找到并吞掉"敌人？
- 边集滚动（**选择素**介导）→ 紧密黏附（**整合素**-ICAM）→ ★**游出**（穿内皮主动移出）→ 趋化（C5a、LTB4、IL-8、细菌产物梯度导航）→ 识别附着（★调理素：IgG Fc 段、C3b——增强吞噬）→ 吞入成吞噬体 → 溶酶体融合 → **H₂O₂-MPO-卤素系统**杀伤（氧依赖）；溶菌酶、防御素（氧不依赖）。
- ⚠ 游出是白细胞的**主动**过程；**红细胞漏出是被动**的（通透性极高时），称"红细胞外溢"。
- 炎症的意义：稀释毒素、运载抗体补体、局限感染、为修复铺垫——防御为主；代价为过度炎症（细胞因子风暴）与慢性化（纤维化瘢痕）。
- ⚠ 渗出液 vs 漏出液（与诊断学联动）：渗出液蛋白高、细胞多、比重>1.018、能自凝（炎症性）；漏出液相反（静水压/胶体压失衡）。

【对比表】急性炎症各期血管-细胞事件

| 阶段 | 血管事件 | 细胞事件 | 主要介质 |
|---|---|---|---|
| 速发短暂收缩 | 细动脉收缩 | — | 神经反射 |
| 充血 | 细动脉/毛细血管扩张、血流加速 | — | 组胺、NO、PG |
| 淤血渗出 | 通透性↑、血流缓慢、液体渗出 | 白细胞边集滚动 | 组胺、缓激肽、LT |
| 游出吞噬 | — | 黏附→游出→趋化→调理吞噬 | C5a、IL-8、LTB4 |

- 答题定位法：题干出现"脓""中性粒细胞"→化脓性炎；"假膜"→纤维素性炎（白喉/菌痢）；"水疱/积液清亮"→浆液性炎；"瘀点瘀斑"→出血性炎。
- ★ 通透性升高机制：内皮细胞收缩（组胺、缓激肽——速发短暂）、穿胞作用、内皮直接损伤、白细胞介导损伤、新生内皮细胞间隙。
- 炎症介质速记：扩血管=组胺、缓激肽、PG、NO；通透性↑=组胺、缓激肽、C3a/C5a、白三烯 C4D4E4；趋化=C5a、白三烯 B4、细菌产物、IL-8；发热=IL-1、IL-6、TNF、PGE₂；疼痛=缓激肽、PG；★**糖皮质激素抗炎=抑制磷脂酶 A₂（抑制花生四烯酸级联）**。
- 【对比表】炎症介质两大来源

| 来源 | 代表介质 | 特点 |
|---|---|---|
| 细胞释放 | 组胺（肥大细胞）、5-HT、PG/LT、细胞因子（IL-1/IL-6/TNF）、NO、溶酶体酶 | 多数贮存在颗粒或即时合成 |
| ★体液（血浆）级联 | **补体系统**（C3a/C5a）、**激肽系统**（缓激肽）、**凝血/纤溶系统**（纤维蛋白肽） | 依次级联激活、相互交织 |

### 4.2 炎细胞 ★

| 巨细胞 | 肉芽肿 | ★朗汉斯巨细胞（结核）、异物巨细胞、Touton 细胞 |

### 4.3 急性炎症类型 ★★

【对比表】急性炎症四大类型（必背大表之四）

| 类型 | 特征 | 部位 | 典型疾病 |

| ★纤维素性炎 | 纤维蛋白原渗出→纤维素 | ★**黏膜、浆膜、肺** | 白喉（**假膜性炎**——咽白喉、气管）、菌痢（假膜性肠炎）、★大叶性肺炎（肺泡腔纤维素）、**绒毛心**（心包纤维素性炎→缩窄性心包炎） |

| 出血性炎 | 血管损伤严重、红细胞大量漏出 | — | ★炭疽、鼠疫、钩端螺旋体病、流行性出血热 |

【对比表】蜂窝织炎 vs 脓肿（化脓性炎两型，必考）

| | 蜂窝织炎 | 脓肿 |
|---|---|---|
| 病原 | ★**溶血性链球菌**（透明质酸酶+链激酶——"开路"） | ★**金黄色葡萄球菌**（血浆凝固酶——"筑墙"） |
| 形态 | 弥漫、不局限、范围大 | 局限、脓腔形成 |

- 表面化脓与积脓：黏膜/浆膜表面化脓（化脓性支气管炎、输卵管积脓、化脓性脑膜炎——蛛网膜下腔积脓）。
- 卡他性炎：黏膜浆液性渗出为主、稀薄（感冒初期鼻炎）；后期可转为黏液化脓性。

### 4.4 慢性炎症与肉芽肿性炎 ★★

【对比表】肉芽肿性炎配对（必背大表之五）

| 肉芽肿 | 构成 | 特征/鉴别 |
|---|---|---|
| ★结核结节 | 干酪样坏死+类上皮细胞+★朗汉斯巨细胞+淋巴细胞+成纤维细胞 | 抗酸染色阳性；中央坏死典型 |
| 伤寒小结 | 伤寒细胞（吞噬红细胞/淋巴细胞/细胞碎片的巨噬细胞） | 无干酪样坏死 |
| ★梅毒树胶肿 | 似结核结节但**坏死不彻底**（残留血管轮廓）、钙化少、浆细胞浸润恒定 | 三期梅毒 |
| 异物肉芽肿 | 异物巨细胞 | 缝线、石棉（石棉小体）、滑石粉 |
| 原因不明 | — | 结节病（非干酪、星形小体）、Crohn 病（非干酪性）、Wegener 肉芽肿 |

【机制与原理】结核结节为什么有朗汉斯巨细胞？
- 结核分枝杆菌被巨噬细胞吞噬后不易杀灭，巨噬细胞在 Th1 细胞因子（IFN-γ）作用下持续激活并**融合或核分裂而胞质不分裂**形成多核的朗汉斯巨细胞（核呈马蹄形/花环状排列于胞质周边），同时巨噬细胞演变为**类上皮细胞**——这是"细胞免疫介导的围困战略"：以结节隔离病原，代价是中心缺血 → **干酪样坏死**。
- ⚠ 与异物巨细胞鉴别：朗汉斯巨细胞核排列成**花环/马蹄状**（周边规则），异物巨细胞核**杂乱聚集于中央**。
- 肉芽肿的通用判读：见到"类上皮细胞+多核巨细胞+结节状"→先想肉芽肿性炎；再看有无干酪样坏死（有→结核；无→结节病/Crohn/异物/梅毒/伤寒）。

### 4.5 炎症的经过与结局

- 痊愈（完全/不完全——纤维化）；迁延为慢性；蔓延扩散：局部蔓延、淋巴道（淋巴管炎、淋巴结炎）、血道——★**菌血症（血中有菌无中毒症状）→ 毒血症（毒素入血）→ 败血症（细菌入血繁殖+中毒+皮肤黏膜瘀点、脾大）→ 脓毒败血症（化脓菌+多发脓肿）**。
- ⚠ 菌血症与败血症的分界在"是否繁殖并引起中毒表现"；脓毒败血症=败血症+多发性脓肿（金葡菌最常见）。
- 慢性炎症特殊形态：**炎性息肉**（黏膜慢性炎+局部黏膜增生）、**炎性假瘤**（组织炎性增生形成边界清楚肿块，形似肿瘤）。
- 一般慢性炎症特征：单核/淋巴/浆细胞浸润、组织破坏与修复并存（纤维化）、血管新生；病因常为病原持续存在（结核）、反复损伤或自身免疫。

【高频考点提示】
- ★ 纤维素性炎三部位（黏膜-假膜、浆膜-绒毛心、肺-大叶性肺炎）。
- ★ 链球菌=蜂窝织炎（酶扩散）；金葡菌=脓肿（凝固酶局限）。
- ★ 结核结节构成五件套与朗汉斯巨细胞；菌血症/毒血症/败血症/脓毒败血症递进定义。
- ★ 判断题信号词："大量中性粒细胞"→化脓性；"纤维素+中性粒细胞覆盖黏膜"→假膜性炎；"嗜酸性粒细胞"→寄生虫/过敏；"多核巨细胞+类上皮"→肉芽肿性炎。

## 第五章 肿瘤 ★★★

### 5.1 肿瘤的概念与异型性

【定义/概述】
- 肿瘤性增生 = 局部细胞在基因水平失去正常调控后的**克隆性、自主性**增生：与机体需要不协调、失去接触抑制、不同程度失去分化成熟的能力、病因去除后仍持续生长（与非肿瘤性增生的根本区别）。
- 【要点展开】大体形态线索（颜色/质地提示来源）
  - 脂肪瘤：淡黄、油腻感；血管瘤：暗红、海绵状；黑色素瘤：黑褐色；黏液变性：灰白半透明胶冻状。
  - 质地硬→纤维/骨/软骨成分或癌（间质多）；鱼肉状→肉瘤；囊性→腺体来源伴囊腔（囊腺瘤）。

【机制与原理】异型性为什么是诊断良恶性的核心依据？
- 肿瘤的本质是基因组异常驱动的"去分化+增殖失控"：分化越差、越偏离起源组织的正常形态 = **异型性越大**，行为越恶。形态学上集中表现为：细胞核的异型（★**核大、核浆比↑、核深染、核仁明显、病理性核分裂象**——不对称/多极）与组织结构异型（排列紊乱、极性丧失）。"间变"=高度异型、近乎未分化。

【要点展开】
- 良恶性肿瘤大表见下；肿瘤分化指与正常组织的相似程度；"未分化癌"恶性度最高。
- 肿瘤生长：膨胀性（良性）、外生性（良性/恶性均可——恶性者基底同时浸润）、浸润性（恶性特征）。

【对比表】良恶性肿瘤鉴别大表（必背大表之六）

| 特征 | 良性 | 恶性 |
|---|---|---|
| 分化/异型性 | 分化好、异型性小 | 分化差、异型性大 |
| 核分裂 | 少、无病理性核分裂 | 多、**病理性核分裂** |
| 生长速度 | 缓慢 | 较快 |
| 生长方式 | **膨胀性/外生性、有包膜、界限清、可推动** | **浸润性、无包膜、界限不清、常固定** |
| 转移 | **不转移** | 可转移 |
| 复发 | 少 | 常复发 |
| 继发改变 | 少见 | 常见出血、坏死、溃疡 |
| 对机体影响 | 局部压迫阻塞为主 | 破坏组织器官、恶病质、转移 |
| 核酸代谢/DNA | 与正常接近 | 核酸代谢旺盛、异倍体多见 |

### 5.2 肿瘤的扩散 ★★

【要点展开】
- 直接蔓延。
- ★ 淋巴道转移：**癌最常见**的转移途径，先入区域淋巴结（边缘窦）→ 可继发血道。
- 【要点展开】转移的细节
  - 肿瘤生长动力学：含增殖池与 **G0 期（非增殖）细胞**——化疗主要打击增殖细胞，G0 细胞是复发根源；生长分数与血管生成共同决定生长速度。
  - ⚠ 淋巴结转移偶可**逆行**（淋巴管阻塞时）或"跳跃"至非邻站淋巴结。
  - 血道定位规律：体循环静脉→右心→**肺**；腹腔器官（胃肠）→门静脉→**肝**；脊椎静脉丛（Batson 丛，无瓣膜）→★前列腺癌易转移至腰椎。
- ★ 血道转移：**肉瘤最常见**、癌晚期；入侵静脉→**肺**（体循环静脉系）与**肝**（门静脉系）为最常见靶器官；★**绒毛膜癌最早、最易经血道转移**。
- ★ 种植性转移：体腔内脱落种植——**胃癌种植卵巢=Krukenberg 瘤**（多为印戒细胞癌）；胸腹膜播散→癌性积液（血性、可查到瘤细胞）。
- ⚠ 良性肿瘤不转移；转移是诊断恶性的**最可靠**依据。

### 5.3 肿瘤的命名与分类

【对比表】癌 vs 肉瘤（必考大表）

| | 癌 | 肉瘤 |
|---|---|---|
| 组织来源 | **上皮组织** | **间叶组织** |
| 发病率 | 高（40 岁以上多见） | 低（青少年多见） |
| 大体 | 质硬、灰白、干燥 | 质软、**鱼肉状**、细腻 |
| 镜下 | ★**癌巢**、实质与间质分界清楚、间质纤维多 | ★肉瘤细胞**弥漫分布**、实质间质分界不清、间质血管丰富 |
| 网状纤维染色 | 癌巢周围（巢外） | 肉瘤细胞间 |

| ★转移 | **淋巴道早** | **血道早** |

- 特殊命名陷阱："瘤"实为恶性：★视网膜母细胞瘤、白血病、精原细胞瘤、霍奇金淋巴瘤、黑色素瘤、骨髓瘤；"母细胞瘤"可良可恶（骨软骨瘤良性 vs 神经母细胞瘤恶性）。

### 5.4 癌前病变、异型增生与原位癌 ★★

【机制与原理】从癌前病变到浸润癌的阶梯
- 正常 → 癌前病变（有癌变潜能的良性病变）→ **异型增生（非典型增生）**（细胞异型但未达全层）→ **原位癌**（异型细胞累及上皮**全层但未突破基底膜**）→ **浸润癌**（突破基底膜、获得浸润与转移能力）。突破基底膜是"原位"与"浸润"的分水岭——因为基底膜是浸润与转移的第一道屏障。

【对比表】演进阶梯要点

| 阶段 | 定义 | 处理意义 |
|---|---|---|
| ★癌前病变（疾病） | 黏膜白斑、慢性宫颈炎伴糜烂、乳腺纤维囊性病、**家族性腺瘤性息肉病（APC）**、慢性萎缩性胃炎伴肠化、溃疡性结肠炎、皮肤慢性溃疡、肝硬化、Barrett 食管、慢性乙肝 | 积极干预、随访 |
| ★异型增生 | 轻/中/重三级；累积范围递增 | 可逆性递减 |
| ★原位癌 | 累及全层、**未突破基底膜**、无转移 | 局部切除可治愈 |
| 上皮内瘤变（IN/CIN） | 异型增生+原位癌的统称；**CIN Ⅲ=重度异型+原位癌** | 宫颈筛查分级管理 |
| 浸润癌 | 突破基底膜 | 需按恶性肿瘤处理 |

【机制与原理】肿瘤是多基因、多步骤的克隆进化
- ★原癌基因**显性激活**（ras 点突变、myc 重排/扩增、HER2 扩增）+ ★抑癌基因**隐性失活**（p53——守卫基因、Rb——二次打击）+ 调亡基因异常（**BCL-2——滤泡性淋巴瘤 t(14;18)**）+ DNA 修复基因缺陷（MMR 缺陷→Lynch 综合征、微卫星不稳定）→ 克隆优势扩增。★结肠癌经典模型：**APC→KRAS→SMAD→p53** 累积。肿瘤血管生成（VEGF）、端粒酶活化、免疫逃逸是恶性表型的"配套工程"。
- ★**肿瘤异质性**：单克隆起源后随突变累积分化出不同亚克隆，侵袭性与耐药亚群被治疗"筛选"放大——复发耐药的理论基础。
- ★**Warburg 效应**：肿瘤在氧充足时仍以糖酵解为主——快速增殖对合成原料的需求超过对 ATP 效率的需求；¹⁸F-FDG PET-CT 显像的病理基础。

| 意义 | 预测恶性程度 | 指导治疗与预后（与分级互补） |

【要点展开】命名规则
- 良性：组织来源+"瘤"（腺瘤、脂肪瘤）；恶性上皮=**癌**（鳞癌/腺癌/移行细胞癌）；恶性间叶=**肉瘤**；特殊命名：母细胞瘤、白血病、精原细胞瘤、黑色素瘤、淋巴瘤、骨髓瘤（称"瘤"实为恶性）；"瘤病"=多发（神经纤维瘤病）。
- ★交界性肿瘤：形态与行为介于良恶之间（卵巢交界性浆液/黏液性肿瘤）——低度恶性潜能，可复发但多不转移。
- 肿瘤的特殊形态线索：异位激素分泌（内分泌样肿瘤）、自分泌环（肿瘤细胞自己产生生长因子并表达其受体）——解释部分肿瘤"自主生长"的分子基础。
- 【对比表】生长方式小结：膨胀性=良性（有包膜推挤周围）；浸润性=恶性（蟹足样破坏）；外生性=体表/腔面肿瘤的表面形式，良恶性均可、恶者基底浸润。

【要点展开】肿瘤对机体的影响
- 局部：压迫阻塞（胆管癌→黄疸、食管癌→吞咽困难）、破坏器官结构、出血与感染（癌性溃疡）、疼痛（浸润神经）、穿孔。
- 全身：★**恶病质**（TNF-α、IL-1、IL-6 介导食欲抑制与肌肉脂肪消耗）；发热；副肿瘤综合征。
- ⚠ 恶病质机制高频：细胞因子（TNF-α 又称"恶病质素"）抑制脂蛋白脂肪酶与食欲中枢——"消瘦不是因为吃，而是因为因子"。
- ★异位内分泌综合征（副肿瘤综合征）：非内分泌腺肿瘤分泌激素/激素样物质——★小细胞肺癌→ACTH、ADH；类癌→5-HT；肾癌→EPO 样物质；另有免疫交叉反应性神经肌肉病变（Lambert-Eaton）。

【对比表】常用免疫组化标记（各论通用的"身份卡"，必背）

| 标记 | 提示来源 |
|---|---|
| ★CK（细胞角蛋白） | 上皮（癌） |
| ★Vimentin | 间叶（肉瘤） |
| ★AFP | 肝细胞癌、卵黄囊瘤 |
| CEA | 腺癌（胃肠） |
| ★PSA | 前列腺 |
| CD15/CD30 | 霍奇金 R-S 细胞 |

【机制与原理】转移的分子步骤（为何如此"挑剔"）
- 离开原发灶（E-钙粘蛋白下调）→ 降解基底膜（Ⅳ型胶原酶/MMP）→ 侵入脉管 → 循环中存活（抵抗失巢凋亡）→ 远处毛细血管床滞留 → 穿出血管 → 定植生长（需血管生成因子）。"种子-土壤"学说解释器官偏好：前列腺/乳腺/肺癌偏好骨转移（成骨/溶骨差异）。

【要点展开】肿瘤的实验室与辅助检查
- 大体与镜下：**活体组织检查（活检）=确诊依据**（内镜/穿刺/术中冰冻）；脱落细胞学（宫颈刮片、痰、胸腹水）——筛查与辅助。
- 免疫组化（见上表）、电镜（特殊颗粒——神经内分泌颗粒）、流式细胞术（DNA 倍体）、基因检测（HER2 扩增、EGFR 突变、BCR-ABL）。
- 肿瘤标志物：★AFP（肝细胞癌、卵黄囊瘤）、CEA（胃肠腺癌）、CA19-9（胰腺）、CA125（卵巢上皮）、PSA（前列腺）、hCG（滋养层疾病）——用于辅助诊断与**随访监测**，不作为确诊手段。
- ★ 肿瘤免疫：肿瘤抗原（突变抗原、胚胎抗原如 AFP/CEA——"癌胚性重现"）；免疫监视（NK、CTL）；逃逸机制（抗原调变、MHC-Ⅰ 下调、Tregs、PD-L1）——免疫检查点抑制剂的理论基础。
- ⚠ 答题纪律：确诊靠病理形态（活检）；标志物升高≠患癌，正常≠排除——以"辅助/监测"定位。

【高频考点提示】
- ★ 病理性核分裂象=恶性形态学铁证；转移=恶性最可靠证据。
- ★ 癌巢/鱼肉状/淋巴道 vs 血道——癌与肉瘤大表每年必考其一。
- ★ 原位癌未突破基底膜；CIN Ⅲ 含原位癌。
- ★ 致癌配对：黄曲霉 B₁-肝癌、EBV-鼻咽癌+Burkitt、HPV16/18-宫颈癌、H. pylori-胃癌+MALT。
