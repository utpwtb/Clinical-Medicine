## 第一篇 生物大分子的结构与功能

## 第一章 蛋白质的结构与功能 ★★

### 1.1 蛋白质的分子组成

【定义/概述】
- 20 种标准氨基酸均为 **L-α-氨基酸**（甘氨酸无手性碳除外）；按侧链性质分类记忆酸碱与含硫。

【要点展开】
- ★ 必需氨基酸 8 种：**甲硫（蛋）氨酸、缬氨酸、赖氨酸、异亮氨酸、苯丙氨酸、亮氨酸、色氨酸、苏氨酸**。【口诀：甲携来一本亮色书】；婴儿还需组氨酸（精氨酸为半必需）。
- 酸性氨基酸：天冬氨酸、谷氨酸；碱性氨基酸：赖、精、组；含硫：Met、Cys。
- ★ 肽键是连接氨基酸的主键；**二硫键不属次级键，习惯上归入一级结构**。

### 1.2 蛋白质的分子结构（四级层次必背）

【机制与原理】为什么一级结构决定高级结构与功能？
- 一级结构（氨基酸序列）决定肽链如何折叠：疏水侧链向内、亲水向外的自组装倾向使空间构象主要由序列"编码"；因此一级结构相似 → 功能相似（不同种属的细胞色素 c），一级结构关键位点的改变 → 空间结构改变 → **分子病**（★镰状细胞贫血：Hb β 链第 6 位谷氨酸→缬氨酸，表面疏水性改变 → 红细胞镰变）。

【对比表】蛋白质四级结构层次（必背）

| 层次 | 定义 | 维系键 | 典型例证 |
|---|---|---|---|
| 一级结构 | 氨基酸排列顺序 | **肽键（+二硫键）** | 胰岛素序列；镰变 Hb |
| 二级结构 | 主链局部空间构象（不涉及侧链） | **氢键** | ★α-螺旋（右手、3.6 残基/圈）、β-折叠、β-转角、无规卷曲 |
| 三级结构 | 整条肽链全部原子的空间排布 | **疏水作用为主**+离子键、氢键、vanderWaals | 肌红蛋白；**结构域**为功能单位 |
| 四级结构 | 亚基间空间排布与相互作用 | 疏水作用等非共价键 | ★Hb 为 α₂β₂ 四聚体 |

- 模体（motif）：几种二级结构元件的组合特征——★**锌指结构**（DNA 结合蛋白）；**分子伴侣**辅助折叠。

### 1.3 蛋白质结构与功能的关系

【机制与原理】Hb 为什么是 S 形曲线而 Mb 不是？
- Mb 单亚基无协同效应，与 O₂ 呈直角双曲线；Hb 四聚体存在 T（紧张，低亲和）↔R（松弛，高亲和）构象互变，第一个 O₂ 结合促进后续结合（**别构/协同效应**）→ S 形曲线，便于肺内载氧、组织内释氧。

### 1.4 蛋白质的理化性质

【机制与原理】变性与沉淀的区别
- 变性：**次级键断裂 → 空间结构破坏，一级结构不变**；表现为溶解度↓、黏度↑、易酶解、**生物学活性丧失**；若去除变性因素且一级结构完好可**复性**（核糖核酸酶复性实验）。凝固 = 变性后紧密缠绕聚集，**不可逆**。
- 沉淀不一定变性（盐析——分段盐析可分离蛋白，不变性）。

### 1.5 其他理化性质与氨基酸衍生物

【要点展开】
- ★ 紫外吸收：蛋白质中**色氨酸、酪氨酸**残基在 **280 nm** 有特征吸收峰（含量测定用）；对照：核酸在 **260 nm**。
- 呈色反应：**双缩脲反应**（紫红色，检测**肽键**，需≥2 个肽键）；**茚三酮反应**（蓝紫色，检测氨基酸）。
- 等电点 pI：蛋白质净电荷为零时的 pH；血浆蛋白 pI 偏酸性，生理 pH 下带负电荷——电泳分离（白蛋白泳动最快）的基础。
- 氨基酸衍生物：★**谷胱甘肽（GSH）**——谷、半胱、甘三肽，半胱氨酸巯基提供还原力（保护红细胞膜，与 G6PD 缺乏联动）；牛磺酸（半胱氨酸衍生，结合胆汁酸）。
- 蛋白质分类：按组成——单纯蛋白/结合蛋白（含辅基：糖蛋白、脂蛋白、核蛋白等）；按形状——纤维状蛋白（胶原、角蛋白，起结构作用）与球状蛋白（酶、血红蛋白，功能多样）。

【高频考点提示】
- ★ 四级结构维系键与三级结构主要维系力（疏水作用）。
- ★ 一级结构不变、空间结构破坏=变性；镰变 Hb 的氨基酸替换位点。
- ★ α-螺旋：右手、3.6 个残基/圈、氢键维系。

## 第二章 核酸的结构与功能 ★★

### 2.1 核酸的化学组成

- 核苷酸 = 碱基 + 戊糖 + 磷酸；★DNA 含脱氧核糖与 **T**；RNA 含核糖与 **U**。
- ★ Chargaff 规律：A=T、G=C、A+G=T+C（嘌呤总量=嘧啶总量）；（A+T)/(G+C) 比值有种属特异性。

### 2.2 DNA 的结构与功能

【机制与原理】B 型双螺旋的结构要点如何支持复制与转录？
- 两链**反向平行**、骨架（脱氧核糖-磷酸）在外、碱基在内；A-T（2 氢键）、G-C（3 氢键）→ 互补性提供**半保留复制的模板基础**；氢键弱而众多 → 局部解链所需能量小，便于复制/转录的"拉链式"操作。

【要点展开】
- ★ B-DNA 参数：直径 **2 nm**、螺距 **3.4 nm**、每圈 **10 bp**、右手螺旋。
- 原核 DNA 为超螺旋环状；真核 DNA 与组蛋白构成**核小体**（染色质基本单位）→ 螺线管 → 染色单体。

### 2.3 RNA 的结构与功能（三种 RNA 必背）

【对比表】mRNA/tRNA/rRNA 三者对比（必背大表）

| | mRNA | tRNA | rRNA |
|---|---|---|---|
| 含量 | **最少**（约 5% 以下） | 较少（10%–15%） | **最多（80% 以上）** |
| 半衰期 | **最短** | — | 长 |
| 功能 | 蛋白质合成的**模板** | **适配器**（搬运氨基酸、读码） | 与蛋白构成**核糖体**（合成场所） |
| 结构特征 | 真核 5′ **帽子 m⁷GpppN**、3′ **polyA 尾**；含密码子 | ★分子最小；**三叶草形二级/倒 L 形三级**；稀有碱基多（DHU、ψ）；**3′ 末端 CCA-OH（氨基酸臂）**；反密码环 | 与蛋白组成大小亚基 |

- hnRNA（mRNA 前体）→ 加工为成熟 mRNA（详见下册转录后加工）。

【要点展开】DNA 的高级结构与基因
- ★ DNA 三级结构：原核——**超螺旋**；真核——**核小体**（组蛋白八聚体核心+约 146 bp DNA 缠绕）→螺线管→环状结构域→染色体（总压缩约 8000–10000 倍）。
- 基因=可编码一种 RNA 或一条多肽的 DNA 片段；基因组=一个细胞/生物体的全部 DNA。
- 其他小 RNA：snRNA（参与 mRNA 剪接）、5S-rRNA（pol Ⅲ 转录）；线粒体 DNA——母系遗传、半自主复制。

### 2.4 核酸的理化性质

【机制与原理】Tm 为什么与 G-C 含量正相关？
- 变性 = **氢键断裂、双链解开**（一级结构不变），伴随**增色效应**（A260↑）。G-C 有 3 个氢键且在双螺旋中堆积更紧密，解开所需能量大 → G-C 含量越高，**Tm（解链 50% 时的温度）越高**。
- 复性（退火）：缓慢降温后互补链重新配对；不同来源互补单链杂交 = **核酸分子杂交**（Southern-DNA、Northern-RNA 的原理基础）。影响复性的因素：简单序列（重复序列多）复性快、片段小复性快、浓度高复性快（Cot 曲线思想）。
- 核酶：具有催化功能的 RNA。

【高频考点提示】
- ★ Tm 与 G-C 含量；增色效应=变性。
- ★ tRNA：三叶草/倒 L、CCA-OH、反密码环——三处结构常合并出题。
- ★ 含量最多=rRNA；半衰期最短=mRNA。

## 第三章 酶与维生素 ★★

### 3.1 酶的分子结构与催化机制

【定义/概述】
- 酶=生物催化剂：高效性、**高度特异性**（绝对/相对/立体异构）、可调节性、不稳定性。
- 结合酶 = **酶蛋白（决定特异性）+ 辅助因子（决定反应类型与电子/基团传递）**；辅酶（松弛结合、可透析）与辅基（紧密结合）。

【要点展开】
- 必需基团集中于**活性中心**（结合基团+催化基团）。
- ★ 同工酶：催化同一反应而分子结构/理化性质不同的酶——**CK 同工酶 CK-MB（心肌损伤）、LDH 五种同工酶**。

### 3.2 米氏方程与抑制剂 ★★

【机制与原理】Km 为什么能代表亲和力？
- V = Vmax[S]/(Km+[S])；当 [S] = Km 时 V = Vmax/2。Km 越小，达到半速所需底物越少 → 酶-底物结合越牢 → **Km 近似反映亲和力（越小亲和力越大）**。Km 是酶的特征性常数：与酶浓度无关、与 [S] 无关，受 pH、温度、抑制剂影响。

【对比表】三类可逆抑制动力学对比（必考大表）

| | 竞争性 | 非竞争性 | 反竞争性 |
|---|---|---|---|
| 结合对象 | 游离酶活性中心（与底物**竞争**） | 酶与 ES 均可结合（活性中心外） | **仅 ES** |
| Km | **↑** | **不变** | **↓** |
| Vmax | 不变 | **↓** | **↓** |
| 增大底物浓度能否解除 | **能** | 不能 | 不能 |
| 典型例 | ★丙二酸抑制琥珀酸脱氢酶；**磺胺（拟对氨基苯甲酸）** | — | — |

### 3.3 酶的调节

【对比表】别构调节 vs 化学修饰调节

| | 别构（变构）调节 | 化学修饰调节 |
|---|---|---|
| 机制 | 效应剂与**调节亚基**非共价结合改变构象 | 其他酶催化共价修饰（★磷酸化/去磷酸化最常见） |
| 动力学曲线 | S 形 | 级联放大、快 |
| 代表 | PFK-1 受 F-2,6-BP、ATP 调节 | 糖原磷酸化酶磷酸化激活 |

- 酶原激活：消化酶、凝血酶原等——避免自身消化；属不可逆"开闸"。

【对比表】影响酶促反应的因素

| 因素 | 规律 | 要点 |
|---|---|---|
| 底物浓度 | 矩形双曲线 | 米氏方程的来源；高 [S] 时近 Vmax |
| 酶浓度 | 正比 | [S] 足量时 V ∝ [E] |
| 温度 | 双重效应 | 升温促反应+变性失活；人体酶最适约 37 ℃ |
| pH | 钟形曲线 | 最适 pH **不是**酶的特征性常数（可受缓冲液影响） |
| 激活剂 | 必需/非必需 | Cl⁻ 为唾液淀粉酶激活剂 |

- ★ 同工酶临床应用：LDH 5 种同工酶（**LDH1 心肌最高——心肌损伤时 LDH1>LDH2；肝以 LDH5 为主**）；CK-MB 为心肌损伤早期指标；ALP 同工酶分辨骨/肝/肠来源。

【要点展开】酶学与临床
- 血清酶诊断原理：组织损伤→细胞内酶释放入血——酶活性升高幅度与分布谱提示损伤部位（ALT/AST-肝心、CK-MB-心肌、AMY-胰腺、ALP-骨/胆道）。
- 工具酶：限制酶、Taq 酶等（下册）；药物靶酶：HMG-CoA 还原酶（他汀）、ACE（普利类）、二氢叶酸还原酶（MTX）——"靶酶思维"把生化与药理联动。

【高频考点提示】
- ★ Km 三句话：半速浓度、亲和力反指标、特征性常数。
- ★ 竞争性 Km↑Vmax 不变（磺胺抑菌、丙二酸）。
- ★ 辅酶-维生素配对与"酶蛋白决定特异性、辅酶决定反应类型"。

## 第四章 生物氧化

### 4.1 概述与呼吸链组成

【机制与原理】生物氧化与体外燃烧的差别
- 体内：温和条件（体温、近中性 pH）下酶促、逐步脱氢脱电子，能量**分次释放**并被 ADP 磷酸化捕获为 ATP——这正是"氧化磷酸化"得以实现的前提；CO₂ 来自脱羧，H₂O 来自呼吸链末端 O₂ 接受电子。

【要点展开】
- 呼吸链位于**线粒体内膜**，四个复合体：Ⅰ（NADH-泛醌还原酶，FMN/Fe-S）、Ⅱ（琥珀酸-泛醌还原酶，FAD/Fe-S）、Ⅲ（泛醌-Cyt c 还原酶，Cyt b/c₁）、Ⅳ（Cyt c 氧化酶，Cyt a/a₃——**O₂ 为最终电子受体**）；CoQ 与 Cyt c 为可移动递体。

### 4.2 两条呼吸链与氧化磷酸化 ★★

【对比表】NADH 氧化呼吸链 vs FADH₂（琥珀酸）氧化呼吸链（必背大表）

| | NADH 呼吸链 | FADH₂ 呼吸链 |
|---|---|---|
| 入口 | NADH → **复合体 Ⅰ** | 琥珀酸 → **复合体 Ⅱ** |
| 路径 | Ⅰ → CoQ → Ⅲ → Cyt c → Ⅳ → O₂ | Ⅱ → CoQ → Ⅲ → Cyt c → Ⅳ → O₂ |
| 偶联位点 | Ⅰ、Ⅲ、Ⅳ（3 处） | Ⅲ、Ⅳ（2 处，跳过 Ⅰ） |
| ★P/O | **≈2.5** | **≈1.5** |
| 产能 | 1 NADH ≈ 2.5 ATP | 1 FADH₂ ≈ 1.5 ATP |

【机制与原理】ATP 如何"偶联"产生？——化学渗透假说
- 递氢体将 H⁺ 泵至膜间隙 → 形成**跨膜 H⁺ 梯度（质子动力）** → H⁺ 经 **F₀ 通道回流**带动 F₁（头部）旋转合成 ATP。ATP 合酶（F₀F₁-ATP 合酶）即偶联机器；寡霉素阻断 F₀ 质子回流。

【对比表】氧化磷酸化抑制剂分类（必背）

| 类型 | 代表 | 作用点 | 后果 |
|---|---|---|---|
| 呼吸链抑制剂 | 鱼藤酮、阿米妥 | 复合体 Ⅰ | 全链电子流停 |
| | 抗霉素 A | 复合体 Ⅲ | 同上 |
| | ★**CN⁻、CO、N₃⁻** | 复合体 Ⅳ | 氰化物中毒 |
| ★解偶联剂 | **2,4-二硝基苯酚（DNP）** | 破坏 H⁺ 梯度 | **耗氧照常、不产 ATP（能量以热散失）**；褐色脂肪产热原理 |
| ATP 合酶抑制剂 | 寡霉素 | F₀ | 电子流也渐停（梯度顶满） |

- ADP 是氧化磷酸化最主要的**生理性调节**因素（[ATP]/[ADP] 比值）。
- 高能化合物：ATP 为通用货币；**磷酸肌酸**为肌肉储能；GTP/UTP/CTP 分别供蛋白/糖原/磷脂合成；线粒体 ATP-ADP 转位体输出 ATP。

【对比表】底物水平磷酸化 vs 氧化磷酸化（必考辨析）

| | 底物水平磷酸化 | 氧化磷酸化 |
|---|---|---|
| 部位 | 胞质/线粒体基质 | 线粒体内膜 |
| 能量来源 | 高能化合物**直接**转移给 ADP | 电子传递建立的 **H⁺ 梯度**驱动 ATP 合酶 |
| 需氧 | 否 | 是 |
| 位置 | 糖酵解 2 处（1,3-BPG、PEP）；TCA 1 处（琥珀酰 CoA） | 呼吸链（P/O：NADH 2.5、FADH₂ 1.5） |

- 其他氧化体系（了解）：微粒体细胞色素 **P450** 单加氧酶（肝生物转化、类固醇合成）；**ROS**（O₂⁻·、H₂O₂、·OH）由 SOD、过氧化氢酶、谷胱甘肽过氧化物酶清除。

【高频考点提示】
- ★ 两条呼吸链的路径与 P/O（2.5/1.5）；偶联部位 Ⅰ、Ⅲ、Ⅳ。
- ★ DNP 解偶联（耗氧不产 ATP）；CN⁻/CO 抑制 Ⅳ。

## 第五章 糖代谢 ★★★

### 5.1 糖的无氧氧化（糖酵解）

【定义/概述】
- 胞质中进行；缺氧时主要途径；**成熟红细胞（无线粒体）的唯一供能途径**。1 葡萄糖 → 2 乳酸，**净 2 ATP**（2 处底物水平磷酸化：1,3-BPG→3-PG、PEP→丙酮酸）。

【要点展开】
- ★ 三个不可逆关键酶：**己糖激酶（肝内为葡萄糖激酶，受 6-磷酸葡萄糖抑制）**、★**6-磷酸果糖激酶-1（PFK-1，最重要限速酶）**、★**丙酮酸激酶**。
- PFK-1 调节：激活剂 **AMP、ADP、2,6-双磷酸果糖（F-2,6-BP，最强激活剂）**；抑制剂 **ATP、柠檬酸**（有氧供能充足则关闭无氧通路——巴斯德效应的枢纽）。
- 2,3-BPG 支路：红细胞内 1,3-BPG → 2,3-BPG（调节 Hb 释氧）。

【对比表】糖酵解 10 步两段式（理解性记忆）

| 段 | 反应要点 | 能量 |
|---|---|---|
| 投资阶段（1–5 步） | 葡萄糖→6-磷酸葡萄糖（己糖激酶）→6-磷酸果糖→**1,6-双磷酸果糖（PFK-1，最重要的调控点）**→裂解为 2 个磷酸丙糖 | 耗 2 ATP |
| 收益阶段（6–10 步） | 磷酸丙糖→1,3-BPG（脱氢产 NADH）→**3-磷酸甘油酸（底物水平磷酸化①）**→PEP→**丙酮酸（底物水平磷酸化②）** | 净得 4 ATP + 2 NADH |
| 收尾 | 2 丙酮酸→2 乳酸（LDH，使 NADH 复氧化为 NAD⁺，保证酵解持续） | — |

- ★ 丙酮酸四条去路：有氧→乙酰 CoA；无氧→乳酸；转氨→丙氨酸；羧化→草酰乙酸（回补 TCA/糖异生起点）。
- 【要点展开】其他单糖代谢
  - 果糖：果糖激酶→1-磷酸果糖→**醛缩酶 B**→磷酸二羟丙酮+甘油醛；★果糖不耐受=醛缩酶 B 缺乏。
  - 半乳糖：半乳糖激酶→半乳糖-1-磷酸→**半乳糖-1-磷酸尿苷转移酶**（经典半乳糖血症的缺陷酶）。
  - 糖蛋白/蛋白聚糖：糖链参与细胞识别（ABO 血型抗原为糖链结构）；蛋白聚糖（糖胺聚糖+核心蛋白）构成细胞外基质。

### 5.2 糖的有氧氧化 ★★★

【机制与原理】三阶段如何衔接？
- 胞质：葡萄糖→丙酮酸；线粒体：丙酮酸经**丙酮酸脱氢酶复合体（PDH）**氧化脱羧→乙酰 CoA（PDH 辅酶五种：**TPP、硫辛酸、FAD、NAD⁺、CoA**——含 B₁、B₂、B₃、B₅；砷中毒抑制硫辛酸）；线粒体：乙酰 CoA 进入 TCA 彻底氧化。

【对比表】TCA 循环要点（必背）

| 项目 | 内容 |
|---|---|
| 一次循环产物 | **3 NADH + 1 FADH₂ + 1 GTP（底物水平磷酸化：琥珀酰 CoA→琥珀酸）+ 2 CO₂** |
| 关键酶（3 个不可逆） | ★**柠檬酸合酶、异柠檬酸脱氢酶（最重要限速酶）、α-酮戊二酸脱氢酶复合体** |
| 脱氢/脱羧次数 | 4 次脱氢、2 次脱羧 |
| 循环再生 | 草酰乙酸催化量循环再生（补充：丙酮酸羧化） |
| 意义 | 三大营养素彻底氧化共同通路、代谢联系枢纽 |

【机制与原理】1 分子葡萄糖为什么是 30 或 32 ATP？
- 有氧氧化净得：糖酵解阶段 2 ATP + 2 NADH（胞质）+ PDH 2 NADH + TCA 2×(3NADH+1FADH₂+1GTP)。胞质 NADH 入线粒体需穿梭：**苹果酸-天冬氨酸穿梭**（肝、心）→ 按 2.5 计 → **共 32**；**α-磷酸甘油穿梭**（肌肉、脑）→ 按 1.5 计 → **共 30**。差额只出在胞质 2 个 NADH 的"入关方式"。

【对比表】两种线粒体穿梭（必背）

| | 苹果酸-天冬氨酸穿梭 | α-磷酸甘油穿梭 |
|---|---|---|
| 主要组织 | ★肝、心 | ★肌肉、脑 |
| 胞质 NADH 折算 | **2.5 ATP** | **1.5 ATP** |
| 结果 | 1 葡萄糖=32 ATP | 1 葡萄糖=30 ATP |

- 巴斯德效应：有氧时氧化磷酸化使 ATP/柠檬酸↑ → 抑制 PFK-1 → 糖酵解↓（肌组织）；与之相对，酵母缺氧时酵解旺盛（酿酒原理，了解）。

### 5.3 磷酸戊糖途径 ★

- 部位：胞质；★关键酶 **6-磷酸葡萄糖脱氢酶（G6PD）**。
- 意义：①**NADPH**（脂肪酸/胆固醇合成的供氢体；维持 GSH 还原态保护膜脂；肝生物转化供氢）；②**5-磷酸核糖**（核苷酸合成原料）；不直接产 ATP。
- ★ G6PD 缺乏（蚕豆病）：NADPH↓→GSH↓→红细胞膜脂过氧化→进食蚕豆或氧化性药物（伯氨喹、磺胺）诱发**急性血管内溶血**（X 连锁，不完整红细胞）。

### 5.4 糖原的合成与分解 ★

【对比表】糖原合成 vs 分解

| | 糖原合成 | 糖原分解 |
|---|---|---|
| 关键酶 | ★**糖原合酶** | ★**糖原磷酸化酶**（产物 1-磷酸葡萄糖；脱支酶处理 α-1,6 键） |
| 活性供体/产物 | **UDPG** | 1-磷酸葡萄糖→6-磷酸葡萄糖 |
| 调节 | 胰岛素激活；磷酸化=失活 | 肾上腺素/胰高血糖素经 cAMP-PKA 磷酸化激活 |

- ★ **肝有 6-磷酸葡萄糖酶 → 肝糖原可直接补充血糖；肌肉缺此酶 → 肌糖原只能自身氧化，不能直接升血糖**（经典必考点）。
- 【要点展开】糖原累积症（Ⅰ 型对应"肝糖原不能有效升糖"的反例）

| 型 | 缺陷酶 | 要点 |
|---|---|---|
| ★Ⅰ 型（von Gierke 病） | **6-磷酸葡萄糖酶**（肝） | 低血糖、肝大、乳酸酸中毒 |
| Ⅱ 型（Pompe 病） | 溶酶体 α-葡萄糖苷酶 | 心肌糖原沉积（溶酶体病） |
| Ⅲ 型（Cori 病） | 脱支酶 | 极限糊精堆积 |
| Ⅴ 型（McArdle 病） | 肌磷酸化酶 | 运动不耐受、肌痛 |

### 5.5 糖异生 ★★

【机制与原理】为什么要 4 个关键酶？
- 糖酵解有 3 个不可逆反应构成"能障"，糖异生并非简单逆行，而需 4 个关键酶绕过：**丙酮酸羧化酶（线粒体，辅酶生物素；乙酰 CoA 变构激活）+ PEP 羧激酶**（绕过丙酮酸激酶）、**果糖二磷酸酶-1**（绕过 PFK-1）、**6-磷酸葡萄糖酶**（绕过己糖激酶，肝特有——再次解释肌糖原不能升糖）。

【要点展开】
- 部位：**肝为主、肾次之**；原料：乳酸、甘油、生糖氨基酸、丙酸。
- 意义：①空腹/饥饿维持血糖；②补充肝糖原；③**乳酸循环（Cori 循环）**：肌乳酸→血→肝异生成葡萄糖→血→肌（回收乳酸、防乳酸酸中毒，且肌肉与肝的酶互补）。

### 5.6 血糖及其调节 ★★

- 空腹血糖正常 **3.9–6.1 mmol/L**；肾糖阈 8.9–10 mmol/L（180 mg/dl）。
- 来源：食物吸收、肝糖原分解、糖异生；去路：氧化供能、合成糖原、转变脂肪/氨基酸。
- ★ 调节：**胰岛素唯一降糖**；升糖激素：**胰高血糖素（最主要）**、肾上腺素、糖皮质激素、GH。
- 低血糖 <2.8 mmol/L 出现交感兴奋+中枢神经缺糖症状。

【高频考点提示】
- ★ 糖酵解三关键酶与 TCA 三关键酶必须点名到位；F-2,6-BP 是 PFK-1 最强激活剂。
- ★ 30/32 ATP 的差别=胞质 NADH 穿梭方式；G6PD 缺乏=蚕豆病。
- ★ 肝糖原能升血糖、肌糖原不能（6-磷酸葡萄糖酶）——年年考。

## 第六章 脂质代谢 ★★★

### 6.1 脂肪动员与脂肪酸分解

【机制与原理】脂肪动员为什么由"激素敏感性脂肪酶"把关？
- 脂解激素（肾上腺素、胰高血糖素、ACTH、TSH）经 cAMP-PKA 磷酸化激活 **HSL（激素敏感性脂肪酶）** 与 ATGL → 甘油三酯水解为脂肪酸+甘油 → 脂肪酸入血与**白蛋白**结合运输。★**胰岛素是抗脂解激素**（去磷酸化失活 HSL）——应激/饥饿时脂解活跃、进食后关闭，方向由血糖状态决定。

【要点展开】脂肪动员分步（机制链）
1. 脂解激素（肾上腺素/胰高血糖素等）→ 脂肪细胞膜受体（GPCR）→ Gs → cAMP↑ → PKA；
2. PKA 磷酸化激活 ATGL/HSL → 甘油三酯逐级水解释放脂肪酸+甘油；
3. 脂肪酸与**血浆白蛋白**结合运输至肝、心、骨骼肌；
4. 肝内脂肪酸两个去向：酯化（合成 TG → VLDL 输出）或 β 氧化/生酮——"肝合成 TG 能力>输出能力"即脂肪肝的生化基础。

【对比表】甘油的去路 vs 脂肪酸的去路

| | 甘油 | 脂肪酸 |
|---|---|---|
| 代谢部位 | **肝为主**（甘油激酶） | 几乎所有组织（脑除外，成熟 RBC 除外） |
| 途径 | →α-磷酸甘油→磷酸二羟丙酮（与糖代谢交汇） | 活化为脂酰 CoA → **肉碱转运（CPT-Ⅰ 限速）** → β-氧化 |
| 结果 | 可异生成糖（少量） | 乙酰 CoA → TCA 或酮体；**不能净生成糖** |

【要点展开】β-氧化四步与产能
- 四步循环：**脱氢（FADH₂）→ 加水 → 再脱氢（NADH）→ 硫解**（缩短 2 个碳，生成 1 乙酰 CoA）。【口诀：脱加脱硫】
- ★ 1 分子**软脂酸（16C）**：7 轮 β-氧化 → 8 乙酰 CoA + 7 FADH₂ + 7 NADH → **共 106 ATP**（8×10+7×2.5+7×1.5=106；活化耗 2 个高能磷酸键，教材采用 106）。

### 6.2 酮体 ★★

【机制与原理】为什么"肝内生成、肝外利用"？
- 肝线粒体内脂肪酸 β-氧化旺盛产生大量乙酰 CoA，肝将其合成为酮体（乙酰乙酸、β-羟丁酸、丙酮；★限速酶 **HMG-CoA 合酶**）输出——肝内脂酰 CoA 不宜大量入 TCA（以输出方式利用脂肪）。而肝**缺乏琥珀酰 CoA 转硫酶（SCOT）**，不能活化乙酰乙酸 → 无法利用酮体；心、肾、脑、骨骼肌则可利用。这种"产-用分工"避免肝自耗并保证饥饿时脑的燃料（长期饥饿酮体供脑 50%–70% 能量）。
- ★ 饥饿、严重糖尿病 → 酮体↑ → 酮血症/酮尿症/**酮症酸中毒**（糖尿病急性并发症的生化基础）。

### 6.3 脂肪的合成

- 场所：肝（能力最强但不储存，以 VLDL 输出）、脂肪组织、小肠。
- 脂肪酸合成：胞质；原料乙酰 CoA（**柠檬酸-丙酮酸循环**出线粒体）、供氢体 **NADPH（主要来自磷酸戊糖途径）**；★关键酶 **乙酰 CoA 羧化酶**（生物素辅酶；产物丙二酰 CoA；柠檬酸激活、软脂酸抑制；丙二酰 CoA 抑制 CPT-Ⅰ——合成与氧化不同时进行）→ 脂肪酸合酶复合体 → 软脂酸。

### 6.4 胆固醇代谢 ★

- 合成：**肝为主（70%–80%）**；原料 **乙酰 CoA + NADPH**；★限速酶 **HMG-CoA 还原酶（他汀类靶点）**；胰岛素、甲状腺素促合成（⚠ 甲减时胆固醇↑——清除↓胜过合成↓）。
- ★ 转化去路：**胆汁酸（主要去路）**、类固醇激素、皮肤 7-脱氢胆固醇→VitD₃。
- 胆固醇不能被彻底氧化分解供能。

### 6.5 血浆脂蛋白 ★★

【对比表】四种脂蛋白（必考大表）

| 脂蛋白 | 密度 | 核心脂质 | 关键载脂蛋白 | 功能 | 临床指向 |
|---|---|---|---|---|---|
| **CM** | 最低 | 外源性 TG | **ApoB48** | 运输**外源性** TG（小肠合成） | 高 CM→高三酰甘油血症、乳糜血 |
| **VLDL** | 低 | 内源性 TG | **ApoB100** | 肝输出**内源性** TG | 升高→内源性高 TG |
| **LDL** | 中 | 胆固醇酯 | **ApoB100（LDL 受体配基）** | 转运胆固醇至肝外 | ★**致动脉粥样硬化** |
| **HDL** | 最高 | 磷脂、胆固醇 | **ApoAⅠ（激活 LCAT）** | ★**逆向转运胆固醇（肝外→肝）** | 抗动脉粥样硬化、保护因素 |

- 辅助记忆：ApoCⅡ激活 LPL（毛细血管内皮，分解 TG）；血浆胆固醇酯化依赖 **LCAT**。
- ⚠ CM/VLDL↑ = 高 TG 血症；LDL↑ = AS 危险因素；HDL↑ 为保护因素。

【要点展开】磷脂与多不饱和脂肪酸衍生物
- 甘油磷脂：原料为脂肪酸+甘油+磷酸+含氮碱（**CTP 参与活化**）；★磷脂酶 A₂ 水解磷脂释放**花生四烯酸**——炎症介质级联的起点。
- ★ 必需脂肪酸：亚油酸、α-亚麻酸（花生四烯酸可由亚油酸衍生）。
- 花生四烯酸三条代谢路：前列腺素（PG）、**血栓烷 A₂（TXA₂——促血小板聚集）**、白三烯（LT——过敏与炎症）；阿司匹林抑制 COX 同时阻断 TXA₂ 与 PGI₂ 合成（与生理学止血章联动）。

【高频考点提示】
- ★ HSL 限速脂肪动员、胰岛素抗脂解；CPT-Ⅰ 限速 β-氧化。
- ★ 软脂酸 106 ATP；酮体三成分+HMG-CoA 合酶+肝缺 SCOT。
- ★ HMG-CoA 还原酶=他汀靶点；胆固醇主要去路=胆汁酸。
- ★ 四种脂蛋白的功能与载脂蛋白配对（B48/B100/AⅠ）。

## 第七章 氨基酸代谢 ★★

### 7.1 蛋白质的营养作用

- 氮平衡：总氮平衡（正常成人）、★正氮平衡（生长、孕妇、恢复期）、负氮平衡（饥饿、消耗病）。
- 必需氨基酸 8 种（见第一章）；蛋白质营养价值取决于必需氨基酸的种类与比例（互补作用）；成人最低生理需要量约 20 g 优质蛋白/日（数量级了解）。

### 7.2 氨基酸的一般代谢

【机制与原理】联合脱氨基为什么是"主要方式"？
- 大多数氨基酸没有直接的强氧化脱氨酶；先经**转氨基**（转氨酶，辅酶 ★磷酸吡哆醛/B₆）把氨基交给 α-酮戊二酸生成谷氨酸，再由**L-谷氨酸脱氢酶**（线粒体，NAD⁺/NADP⁺）氧化脱氨释放 NH₃——两步联合覆盖几乎全部氨基酸。骨骼肌、心肌则经**嘌呤核苷酸循环**脱氨（谷氨酸脱氢酶活性低）。
- ★ ALT（GPT）主要在**肝**、AST（GOT）主要在**心**——临床酶学定位依据。

### 7.3 氨的代谢 ★★

【机制与原理】血氨从哪来、到哪去、路上怎么运？
- 来源：氨基酸脱氨基（主要）、肠道细菌腐败与尿素分解（**肝性脑病忌用肥皂水灌肠**——碱性环境促 NH₃ 吸收）、肾小管谷氨酰胺分解。
- 转运：**丙氨酸-葡萄糖循环**（肌→肝，肌肉向肝"空运"氨基+碳架）；★**谷氨酰胺**（脑→肝/肾——脑内解氨毒的主要形式，谷氨酰胺合成酶）。
- 去路：★**鸟氨酸循环（尿素循环，仅肝）**：NH₃+CO₂ → 氨基甲酰磷酸（**CPS-Ⅰ，线粒体，激活剂 N-乙酰谷氨酸 AGA**）→ 瓜氨酸 → 精氨酸代琥珀酸（★限速酶：**精氨酸代琥珀酸合成酶**）→ 精氨酸 → 尿素。★**1 分子尿素含 2 个氮：1 个来自游离 NH₃、1 个来自天冬氨酸**；耗 3 ATP（4 个高能磷酸键）。肝严重受损 → 尿素合成↓ → 血氨↑ → **肝性脑病（氨中毒学说）**。

## 第九章 物质代谢的联系与调节 ★★

### 9.1 三大代谢的交汇

【机制与原理】为什么"糖能变脂肪、脂肪不能大量变糖"？
- 三大交汇点：**6-磷酸葡萄糖、丙酮酸、乙酰 CoA**。糖→脂肪畅通（乙酰 CoA→脂肪酸+磷酸二羟丙酮→甘油）；但脂肪酸 β-氧化产物乙酰 CoA **不能净生成葡萄糖**（TCA 中两个碳以 CO₂ 流失，丙酮酸→乙酰 CoA 不可逆）；只有脂肪的**甘油部分**可经糖异生成糖。

【对比表】主要器官的代谢特点

| 器官 | 特点 | 记忆点 |
|---|---|---|
| 肝 | 物质代谢中枢 | ★唯一同时具备：6-磷酸葡萄糖酶、完整尿素循环、酮体生成 |
| 脑 | 正常只用葡萄糖；**长期饥饿改用酮体** | 耗能大、储能少 |
| 成熟红细胞 | **只能糖酵解**（无线粒体） | 2,3-BPG 支路 |
| 心肌 | 有氧氧化为主、燃料不挑（酮体、脂肪酸、乳酸皆可） | 供能连续稳定 |
| 骨骼肌 | 静息燃脂、剧烈运动酵解；支链氨基酸主要分解场所 | Cori 循环一端 |

【对比表】胰岛素 vs 胰高血糖素对三大代谢的作用（必背大表）

| 代谢 | 胰岛素（饱食状态） | 胰高血糖素（饥饿状态） |
|---|---|---|
| 糖酵解/糖原合成 | ↑ | ↓ |
| 糖原分解/糖异生 | ↓ | ↑ |
| 脂肪合成 | ↑ | ↓ |
| 脂肪动员/β 氧化 | ↓ | ↑ |
| 酮体生成 | ↓ | ↑ |
| 蛋白质合成 | ↑ | ↓（肌肉分解↑） |
| 受体/信号 | RTK（酪氨酸激酶） | GPCR→cAMP→PKA |

- 四大"器官间循环"：**乳酸循环（肌-肝）**、**葡萄糖-丙氨酸循环（肌向肝运送氨基与碳架）**、**酮体（肝生成-心脑利用）**、**谷氨酰胺（脑/肌-肝肾氨转运）**——考试中把"某物质在两个器官间的流动"题定位到这四个循环。

### 9.2 饥饿时的代谢变化 ★

【要点展开】
- 短期饥饿（1–3 天）：肝糖原耗竭 → 糖异生↑（肝）、脂肪动员↑、酮体开始生成、脑仍用葡萄糖。
- ★ 长期饥饿：**酮体成为脑的主要燃料**；肌肉蛋白分解**下降**（"保蛋白"——酮体抑制蛋白分解）；肾糖异生↑（谷氨酰胺）。
- 应激（创伤、感染）：血糖↑（肾上腺素、皮质醇）、脂肪动员与蛋白分解↑——与胰岛素作用方向相反。

【对比表】长期饥饿 vs 严重应激（易混辨析）

| | 长期饥饿 | 严重应激（创伤/感染） |
|---|---|---|
| 血糖 | 趋于降低 | **升高**（升糖激素主导） |
| 肌肉蛋白分解 | **下降**（保蛋白） | **上升**（氮丢失） |
| 酮体 | ↑↑（脑主要燃料） | 轻度↑ |
| 主导激素 | 胰高血糖素 | 肾上腺素+糖皮质激素 |

【高频考点提示】
- ★ 乙酰 CoA 是三大代谢总枢纽、但不能净生糖。
- ★ 长期饥饿三大变化：脑用酮体、保蛋白、肾糖异生↑。
- ★ 各器官"唯一"清单（肝的三个唯一、红细胞只能酵解）。
