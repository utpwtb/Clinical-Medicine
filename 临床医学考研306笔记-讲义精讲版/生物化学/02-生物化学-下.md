## 第十章 DNA 的生物合成（复制）

### 10.1 复制的基本规律

【机制与原理】为什么复制必须是"半保留、双向、半不连续"？
- **半保留复制**：双螺旋互补性使每条母链都能充当精确模板（Meselson-Stahl 实验证实）——最大限度保真传代。
- **双向复制**：从复制起点向两侧展开（复制叉），提高效率。
- **半不连续复制**：DNA 聚合酶只能沿 5′→3′ 延长，而双链反向平行 → 前导链可连续合成；后随链只能"倒退分段"合成 → **冈崎片段**，再由连接酶封口。这是酶的方向限制与模板方向矛盾的唯一解。

【要点展开】
- 原料：**dNTP**（dATP、dGTP、dCTP、dTTP）；方向：5′→3′；**需要引物**（原核 DnaG 引物酶合成 RNA 引物；真核 DNA-pol α）。
- 复制保真的三重保障：碱基互补配对 + 聚合酶 3′→5′ **校读（外切核酸酶活性）** + 修复系统。

### 10.2 参与复制的酶与蛋白

【对比表】原核 vs 真核复制体系（必背大表）

| | 原核（大肠杆菌） | 真核 |
|---|---|---|
| 主要复制酶 | ★**DNA-pol Ⅲ** | ★**pol δ（后随链）、pol ε（前导链）** |
| 切除引物/填补缺口/校读 | ★**DNA-pol Ⅰ**（5′→3′ 外切切除 RNA 引物） | pol δ、RNase H、FEN1 |
| 引发 | DnaG 引物酶 | pol α（引发酶复合体） |
| 解螺旋 | DnaB 解螺旋酶 | MCM 解旋酶 |
| 稳定单链 | **SSB** | RPA |
| 松弛超螺旋 | ★**拓扑异构酶（gyrase）——喹诺酮类作用靶点** | 拓扑异构酶 Ⅰ/Ⅱ（喜树碱靶点为 Ⅰ） |

|---|---|---|---|

### 10.3 复制全过程要点（原核主线）

【对比表】起始-延长-终止

| 阶段 | 关键事件 |
|---|---|
| 起始 | DnaA 识别复制起点 **oriC** → 解螺旋酶 DnaB（DnaC 助装）解链；**SSB** 稳定单链；拓扑异构酶（gyrase）松弛超螺旋；**引物酶 DnaG** 合成 RNA 引物 |
| 延长 | pol Ⅲ 全酶沿模板 5′→3′ 聚合：前导链连续、后随链分段（冈崎片段）；pol Ⅰ 切除片段间引物并填补 → **DNA 连接酶**封口 |
| 终止 | 到达 ter 区；拓扑异构酶解离连环子代 |

【要点展开】
- ★ Meselson-Stahl 实验（¹⁵N 标记→转¹⁴N 培养→密度梯度离心）证实半保留复制：一代后出现中等密度带。
- 原核单一起点；真核**多起点**（多点双向——补偿线性染色体的复制耗时）。
- 真核复制同时完成核小体装配：组蛋白解聚后随即包装到两条子链上。
- ⚠ 拓扑异构酶Ⅱ（gyrase）是喹诺酮类抗菌药靶点；真核拓扑异构酶Ⅰ是喜树碱靶点——药物-酶配对常出选择。

### 10.3 端粒与端粒酶 ★

【机制与原理】为什么线性 DNA 末端需要端粒酶？
- 后随链最末的 RNA 引物切除后无法填补 → 每次复制末端略有缩短。**端粒酶自带 RNA 模板**，以逆转录方式延伸端粒重复序列（TTAGGG）→ 解决"末端复制问题"。体细胞端粒酶活性低 → 端粒随分裂缩短 → 与**细胞衰老**相关；★**多数肿瘤端粒酶活性↑** → 永生化。

### 10.4 逆转录 ★

- 逆转录（反转录）：**RNA → DNA**。逆转录酶三活性：★**RNA 指导的 DNA 聚合酶 + RNase H（水解 RNA:DNA 杂交体中 RNA）+ DNA 指导的 DNA 聚合酶**。
- 逆转录病毒：**HIV（AIDS 病原）**——抗病毒药的核心靶点（核苷类逆转录酶抑制剂）。
- ★ 端粒酶也属逆转录酶（自带 RNA 模板）。
- ⚠ 逆转录酶无 3′→5′ 校读活性 → 逆转录病毒突变率高（耐药与疫苗难产的原因）。

### 10.5 DNA 损伤与修复 ★

【对比表】损伤类型与修复方式配对（必背大表）

| 损伤 | 诱因 | 修复方式 | 要点 |
|---|---|---|---|
| 嘧啶二聚体 | ★**紫外线** | ★**光修复**（光修复酶，直接修复） | 直接拆解二聚体 |
| 碱基错配/受损碱基 | 自发、化学 | ★**碱基切除修复** | 糖苷酶→AP 位点→填补 |
| 大块损伤（如嘧啶二聚体大加合物） | 紫外线、化学 | ★**核苷酸切除修复（NER）** | ★**着色性干皮病（XP）= NER 基因缺陷**→皮肤癌 |
| 双链断裂 | 电离辐射 | 重组修复（同源重组、NHEJ） | — |
| 复制期损伤 | SOS 应答 | SOS 修复 | **易错修复**（牺牲保真换取存活） |

- 突变类型：点突变（转换/颠换）、缺失/插入（**移码突变**）、重排；突变的意义：进化基础+致病（分子病）+多态性。
- 【对比表】常见致突变/损伤因素

| 类别 | 代表 | 作用方式 |
|---|---|---|
| 物理 | 紫外线、电离辐射 | 嘧啶二聚体/链断裂 |
| 化学 | 烷化剂、亚硝胺、黄曲霉毒素 B₁、苯并芘 | 碱基修饰、插入嵌入 |
| 生物 | 病毒（HBV、HPV、EBV） | 整合、干扰修复 |
| 自发 | 复制错误、脱氨基（C→U）、脱嘌呤 | 碱基错配/缺失 |

【高频考点提示】
- ★ 半保留/双向/半不连续三规律；冈崎片段=后随链。
- ★ 原核 pol Ⅲ（复制）与 pol Ⅰ（切引物填补）；真核 δ/ε/α/γ 分工。
- ★ 端粒酶=自带 RNA 模板的逆转录酶；肿瘤端粒酶↑。
- ★ 紫外线→嘧啶二聚体→光修复/NER；XP=核苷酸切除修复缺陷。
- ★ 复制保真三保障：碱基互补+聚合酶校读+修复系统；转录无校读——"保真程度：复制>翻译>转录"。

## 第十一章 RNA 的生物合成（转录）★

### 11.1 转录的基本特征

【机制与原理】转录为什么"不对称"？为什么不需要引物？
- 双链 DNA 中只有一条链被转录（**模板链/反义链**），另一条为**编码链（正义链，序列与 RNA 相同仅 T↔U）**——不同基因可选用不同链，故称不对称转录。
- RNA 聚合酶从头起始合成（无 3′ 端"对接"要求），故**不需引物**；这是转录与复制的关键差异之一（复制需 RNA 引物）。

### 11.2 RNA 聚合酶

【对比表】原核 vs 真核 RNA-pol（必背大表）

| | 原核 | 真核 |
|---|---|---|
| 组成 | ★全酶=α₂ββ′ω+**σ 因子**；核心酶（α₂ββ′）延长 | pol Ⅰ/Ⅱ/Ⅲ |
| 启动子识别 | ★**σ 因子辨认启动子**（−35/−10 区） | 各 pol 由转录因子（TFⅡD 识别 TATA 盒）定位 |
| 转录产物 | 一条多顺反子 mRNA | Ⅰ→**45S-rRNA**；Ⅱ→**mRNA（hnRNA）**；Ⅲ→**tRNA、5S-rRNA** |

【口诀：Ⅰ合 rRNA，Ⅱ合 mRNA，Ⅲ合 tRNA】

### 11.3 启动子与顺式作用元件

- 真核 pol Ⅱ 启动子核心序列：★**TATA 盒（约 −25）**、GC 盒、CAAT 盒。
- 顺式作用元件（启动子、**增强子**（远距离、无方向性）、沉默子）vs 反式作用因子（转录因子 TFⅠ/Ⅱ/Ⅲ 族）。

### 11.4 转录过程要点

【要点展开】原核转录起始-延长-终止
- 起始：σ 因子辨认启动子（−35 区 TTGACA、−10 区 **Pribnow 盒 TATAAT**）→ 闭合复合物 → 开放复合物 → 合成起始区段 → **σ 释放**、核心酶延长。
- 延长：转录泡（局部解链 12–17 bp）随 RNA-pol 前移，核苷酸经磷酸二酯键 5′→3′ 加入（NTP 焦磷酸水解供能）。
- 终止两种机制：①★**依赖 ρ 因子**（ρ 解旋酶沿 RNA 追赶聚合酶、解开 RNA-DNA 杂交体）；②★**不依赖 ρ**（GC 丰富回文序列→RNA 形成茎环结构+后续多聚 U——转录产物自发脱离）。

### 11.4 转录后加工（真核）★

【对比表】三种 RNA 前体加工（必背）

| 前体 | 加工步骤 | 要点 |
|---|---|---|
| ★hnRNA→mRNA | 5′ 端**加帽（m⁷GpppN）**、3′ 端**加 polyA 尾**、★**剪接（切除内含子、连接外显子）** | 帽子=翻译起始识别+稳定；尾=稳定+出核 |
| tRNA | 剪切、3′ 添加 **CCA-OH**、稀有碱基修饰 | — |
| rRNA | ★45S 前体→**28S、18S、5.8S** | 5S 由 pol Ⅲ 单独转录 |

- ★ 外显子=表达序列（保留于 mRNA）；内含子=剪除序列。断裂基因的真核普遍特征。
- RNA-pol **无校读功能** → 转录错误率高但转录产物寿命短，可接受。
- ★ **剪接体**：snRNA（U1、U2 等）+蛋白组成 snRNP；识别内含子 **5′-GT、3′-AG**（剪接供体/受体）→ 形成套索结构剪除内含子。
- RNA 编辑：转录后改变编码信息——★ApoB 基因在肠道经 C→U 编辑生成 **ApoB48**（肝内全长 ApoB100）——同一基因不同组织的产物差异。
- 加工时序：加帽（转录早期）→ 剪接（共转录进行）→ 加尾（转录终止时切断+polyA 聚合）；pol Ⅱ 羧基端结构域（CTD）磷酸化协调三步加工。
- 选择性剪接：同一 hnRNA 不同剪接方式→多个蛋白异构体——基因"数少功能多"的机制之一。

【高频考点提示】
- ★ 不对称转录、模板链/编码链定义。
- ★ 真核 pol Ⅰ/Ⅱ/Ⅲ 分工与 TATA 盒位置（−25）。
- ★ mRNA 三步加工（帽、尾、剪接）；45S→28S/18S/5.8S。

## 第十二章 蛋白质的生物合成（翻译）★

### 12.1 翻译体系

- 模板 mRNA；适配器 tRNA；场所核糖体（rRNA+蛋白）；原料 20 种氨基酸；供能 **ATP 与 GTP**；辅因子 Mg²⁺ 与各类蛋白因子。
- ★ 起始氨基酰-tRNA：原核 **fMet-tRNAᶠᵐᵉᵗ**、真核 **Met-tRNAᵢᵐᵉᵗ**。

### 12.2 遗传密码的特点 ★★

【要点展开】五特点必背
1. **方向性**：5′→3′；
2. **连续性**：无标点不重叠——插入/缺失→**移码突变**；
3. ★**简并性**：64 个密码子中 61 个编码氨基酸，一个氨基酸可有多个密码子，但**一种密码子只编码一种氨基酸**（简并≠歧义）——突变容错的基础；
4. **摆动性**：密码子第 3 位与反密码子第 1 位碱基配对可"摆动"（tRNA 种类少于 61 的原因）；
5. **通用性**：绝大多数生物通用（线粒体等例外）。
- ★ 起始密码 **AUG**（兼编码甲硫氨酸）；终止密码 **UAA、UAG、UGA**（不编码氨基酸）。

### 12.3 翻译三阶段 ★★

【对比表】起始-延长-终止要点

| 阶段 | 原核关键事件/因子 | 真核对应 | 耗能 |
|---|---|---|---|
| 起始 | ★**SD 序列**（与 16S-rRNA 3′ 端互补）定位；70S 起始复合物；fMet-tRNA 进 P 位 | 5′ 帽依赖扫描定位；80S 起始复合物 | GTP |
| ★延长 | **进位（EF-Tu）→ 成肽（转肽酶）→ 转位（EF-G）** | eEF1 / — / eEF2 | 每循环 2 GTP |
| 终止 | 释放因子 RF 识别终止密码 → 肽链释放 | eRF | — |

【口诀：进成转】

- 肽链合成方向 N→C 端；核糖体 A 位（受位）/P 位（供位）。

【要点展开】氨基酸的活化（翻译第一关）
- ★ 氨基酰-tRNA 合成酶（aaRS）：氨基酸+ATP+tRNA → 氨基酰-tRNA-AMP 中间体 → 转移到 tRNA 3′ 末端 CCA-OH，**共消耗 2 个高能磷酸键**；20 种氨基酸各有一种对应酶（同工 tRNA 由同一酶识别）；具**校对活性**——翻译保真的第一道关卡。
- 原核起始细节：IF1/IF2/IF3 参与；30S 小亚基经 **SD 序列**与 mRNA 对位 → fMet-tRNAᶠᵐᵉᵗ（IF2-GTP）进 P 位 → 50S 加入 → 70S 起始复合物。
- 真核起始：eIF 家族；**帽子依赖扫描模型**——40S 从 5′ 帽沿 mRNA 扫描至第一个 AUG；★磷酸化 eIF2 抑制起始（干扰素抗病毒机制之一）。

### 12.4 翻译后加工与靶向输送

- 加工：肽链折叠（**分子伴侣**）、切除 N 端 Met、水解修饰（**胰岛素原→胰岛素**）、二硫键形成、糖基化/磷酸化等修饰、亚基聚合（四级结构）。
- 信号肽分泌蛋白路径补充：核糖体（游离）→ 信号肽出笼 → SRP 结合并暂停翻译 → 引导至内质网膜 → 肽链入腔 → 信号肽切除 → 高尔基加工分选 → 分泌（结构上"边合成边转运"防止错误折叠）。
- 【对比表】翻译后靶向输送标记

| 目的地 | 标记/机制 |
|---|---|
| 分泌蛋白/膜蛋白 | ★N 端信号肽+SRP→内质网 |
| 溶酶体 | ★甘露糖-6-磷酸 |
| 细胞核 | ★核定位序列 NLS（核孔入核） |
| 线粒体 | N 端导肽 |
| 过氧化物酶体 | SKL 序列（C 端，了解） |
- 靶向输送标记：溶酶体蛋白=**甘露糖-6-磷酸**；核蛋白=**核定位序列 NLS**；线粒体蛋白=N 端导肽。

【对比表】翻译后加工分类

| 类型 | 内容/例 |
|---|---|
| N 端修饰 | 切除 fMet/Met |
| 水解修饰（酶原/激素前体） | ★胰岛素原→胰岛素（C 肽切除） |
| 二硫键形成 | 半胱氨酸氧化 |
| 化学修饰 | 糖基化、磷酸化、★羟基化（胶原 Pro/Lys 羟化——维 C 依赖）、脂酰化 |
| 辅基连接 | 血红素等 |
| 亚基聚合 | 四级结构（Hb α₂β₂） |
| 空间折叠 | ★分子伴侣（Hsp70 等） |

- ★ 泛素-蛋白酶体途径：E1/E2/E3 级联 → 多聚泛素化 → 26S 蛋白酶体降解（周期蛋白与 p53 的降解走此路——HPV E6 经 E6-AP 促进 p53 泛素化）；溶酶体途径处理长寿命蛋白与自噬。

### 12.5 干扰翻译的物质 ★

【对比表】抗生素与毒素作用点（必背大表）

| 物质 | 作用点 | 备注 |
|---|---|---|
| ★四环素 | 抑制**原核**氨基酰-tRNA 进位（30S） | — |
| ★氯霉素 | 结合**原核** 50S，抑制转肽酶 | 骨髓抑制副作用的基础 |
| ★链霉素 | 结合原核 30S，**致错读** | 耳肾毒性 |
| ★嘌呤霉素 | **氨基酰-tRNA 类似物**，提前释放肽链 | **原核、真核均抑制** |
| 放线菌酮 | 抑制真核延长 | — |
| ★白喉毒素 | 灭活 **eEF-2（真核转位因子）** | ADP-核糖基化 |
| 蓖麻蛋白 | 剪切 28S rRNA（灭活 60S） | — |
| ★干扰素 | 诱导 2′-5′A 合成酶（降解病毒 mRNA）+ 蛋白激酶（抑制起始） | 抗病毒 |

- ★ 干扰素双机制：①诱导 **2′-5′ 寡聚腺苷酸合成酶** → 激活核酸酶 RNase L 降解病毒 mRNA；②诱导 **蛋白激酶 PKR** → 磷酸化 eIF2 → 抑制翻译起始（双管齐下阻断病毒蛋白合成）。
- 抗生素作用点记忆法：按"30S（进位/错读）—50S（成肽）—延长因子"定位——四环素/链霉素打 30S，氯霉素打 50S，白喉毒素打转位因子 eEF-2。

【高频考点提示】
- ★ 密码子五特点+AUG/终止三联；简并性辨析（一密码一氨基酸）。
- ★ 延长三步"进成转"及因子；白喉毒素=eEF-2；嘌呤霉素原核真核均抑制。
- ★ SD 序列=原核核糖体结合位点。

## 第十三章 基因表达调控 ★

### 13.1 原核——乳糖操纵子 ★★

【机制与原理】正负调节如何协同实现"按需表达"？
- 结构：调节基因（lacI）+ 启动序列 + 操纵序列 + 三个结构基因（Z、Y、A）。
- **负调节（诱导）**：无乳糖时阻遏蛋白结合操纵序列 → 关闭转录；有乳糖（诱导剂异乳糖）与阻遏蛋白结合 → 解离 → 转录开启。
- **正调节（分解代谢物阻遏）**：葡萄糖存在 → cAMP↓ → **CAP（CRP）-cAMP 不能结合启动子上游** → 即使解除了阻遏，转录水平仍低——**葡萄糖优先利用**。两种机制叠加保证"有乳糖且无葡萄糖"时 lac 操纵子才高效表达。

【要点展开】
- 其他原核调控：色氨酸操纵子（阻遏+**衰减子**——转录衰减：色氨酸充足时先导序列形成终止茎环提前终止转录）；σ 因子切换（热休克应答）。
- ★ 原核基因调控的主要环节是**转录起始（操纵子水平）**；真核则以染色质活性和组合式转录调控为核心——"层次不同"是两类生物调控的对比主轴。

### 13.2 真核基因表达调控 ★

- 多层次：染色质水平（活性染色质对 **DNase Ⅰ 敏感**；组蛋白**乙酰化**→活化；★CpG 岛**甲基化→转录沉默**）、转录水平（顺式元件+反式因子组合调控）、转录后（mRNA 稳定性、miRNA）、翻译与翻译后水平。
- ★ 真核转录因子结构域：**DNA 结合域**（锌指、螺旋-转角-螺旋、亮氨酸拉链、螺旋-环-螺旋）+ 转录激活域——"锌指"是 DNA 结合蛋白的模体代表（与蛋白章呼应）。
- ★ miRNA 通路：pri-miRNA →（Drosha/DGCR8）→ pre-miRNA →（出核、**Dicer**）→ 成熟 miRNA → **RISC** 复合体 → 结合靶 mRNA 3′UTR →（不完全互补）翻译抑制/降解；siRNA（完全互补）直接切割靶 mRNA。
- mRNA 稳定性元件：3′UTR 的 AU 富集元件（ARE）、polyA 尾长度——转录后调控的重要层面。
- ★ 表观遗传：DNA 甲基化、组蛋白修饰、非编码 RNA——不改变序列而改变表达，可遗传。
- 非编码 RNA：**miRNA**（转录后抑制：降解 mRNA 或阻翻译）、siRNA（外源/人工双链 RNA 介导降解）、lncRNA。

【高频考点提示】
- ★ lac 操纵子双重控制：乳糖去阻遏（负调节解除）+葡萄糖经 cAMP-CAP 正调节。
- ★ 甲基化=沉默、乙酰化=活化。

## 第十四章 癌基因、抑癌基因与生长因子 ★★

### 14.1 癌基因

【机制与原理】原癌基因如何"变坏"？
- **原癌基因（c-onc）是正常细胞基因**，编码生长因子、生长因子受体、信号转导蛋白、转录因子、细胞周期蛋白等促增殖元件。激活 = 获得**功能**（显性）：★点突变（ras）、★基因扩增（HER2/neu——乳腺癌）、★染色体重排（CML——**BCR-ABL** 融合基因/Ph 染色体；Burkitt 淋巴瘤——c-myc 与免疫球蛋白基因邻接被强启动子驱动）。抑癌基因失活则需**两等位基因均失活**（隐性、二次打击）——方向相反是两者的本质区别。

【对比表】癌基因激活方式-疾病配对（必背大表）

| 激活方式 | 例 | 相关肿瘤 |
|---|---|---|
| 点突变 | ras（GTP 酶失活，持续信号） | 多种实体瘤 |
| 基因扩增 | ★HER2/neu | 乳腺癌（靶向：曲妥珠单抗） |
| ★染色体重排 | **t(9;22) BCR-ABL（Ph 染色体）** | ★**慢性髓系白血病 CML**（伊马替尼靶点） |
| 重排 | t(8;14) c-myc | ★Burkitt 淋巴瘤 |

### 14.2 抑癌基因

【对比表】抑癌基因-肿瘤配对（必背大表）

| 基因 | 功能 | 相关肿瘤/综合征 |
|---|---|---|
| ★**p53** | "基因组守卫者"：DNA 损伤→阻滞周期/诱导凋亡 | ★最常突变的抑癌基因；**Li-Fraumeni 综合征** |
| ★**Rb** | 结合 E2F 控制 G1/S | **视网膜母细胞瘤**（二次突变假说经典） |
| APC | 降解 β-catenin | **家族性腺瘤性息肉病（FAP）**→结肠癌 |
| BRCA1/2 | 双链断裂修复 | 遗传性乳腺癌/卵巢癌 |
| PTEN、NF1 | PI3K 负调、Ras 负调 | — |

【要点展开】抑癌基因的"岗位"分布
- 感受 DNA 损伤：p53（损伤→p21→阻滞 G1/S 或诱导凋亡）；
- 控制细胞周期：Rb（磷酸化释放 E2F 才进 S 期）；
- 负调促增殖信号：NF1（Ras-GAP）、PTEN（拮抗 PI3K）；
- 维护基因组稳定：BRCA1/2（同源重组修复）、MMR 家族（Lynch 综合征——与病理结肠癌章联动）。

- 生长因子：EGF、PDGF、TGF-β、VEGF、IGF；受体以 RTK、GPCR 为主——生长因子通路是原癌基因产物的"日常岗位"。

【对比表】原癌基因产物功能分类（必背）

| 功能类别 | 代表基因 | 激活后果 |
|---|---|---|
| 生长因子 | sis（PDGF-B 类似物） | 自分泌促增殖 |
| 受体类 | ★HER2/neu（扩增）、ret | 无配体依赖的持续信号 |
| 信号转导 | ★ras（GTP 酶活性丧失→持续激活） | MAPK 级联常开 |
| 转录因子 | ★myc、jun/fos（AP-1） | 增殖相关基因转录↑ |
| 周期/凋亡调控 | bcl-2、cyclin D1 | 逃逸凋亡、周期失控 |

【对比表】常见生长因子-受体-意义配对

| 生长因子 | 受体 | 意义 |
|---|---|---|
| EGF | EGFR（HER1，RTK） | 上皮增殖；肺癌靶向对象 |
| PDGF | PDGFR（RTK） | 间质/血管增殖 |
| TGF-β | Ser/Thr 激酶受体 | 多数上皮抑制增殖、间质促增殖；SMAD 通路 |
| ★VEGF | VEGFR | **血管生成**——实体瘤生长与抗 VEGF 治疗靶点 |
| IGF | IGF1R | 介导 GH 的促生长效应 |

【高频考点提示】
- ★癌基因显性激活（点突变/扩增/重排）vs 抑癌基因隐性失活（两次打击）。
- ★ ras=点突变、HER2=扩增、c-myc=重排、BCL-2=抗凋亡易位——产物分类表与激活方式表互为映照。
- ★ BCR-ABL=CML=伊马替尼；HER2 扩增=乳腺癌；c-myc=Burkitt；p53 最常突变。

## 第十五章 基因诊断与基因治疗

- **基因诊断**：利用分子生物学技术检测基因结构/表达异常——核酸分子杂交、★**PCR**、测序、基因芯片。优点：灵敏、特异、早期（症状前/产前）。
- 【要点展开】基因诊断应用场景
  - 遗传病：镰变 Hb、地中海贫血、PKU、Huntington 病；
  - 感染性疾病：病毒核酸定量（HIV 载量、HBV-DNA）；
  - 肿瘤：BCR-ABL 融合基因监测、HER2 扩增、微卫星不稳定；
  - 法医学与移植：STR 分型（亲子鉴定）、HLA 配型。
  - 原位杂交（FISH）：染色体易位与基因扩增的细胞水平检测。
- 【对比表】基因治疗常用载体

| 载体 | 优点 | 局限 |
|---|---|---|
| 逆转录病毒 | 稳定整合、长期表达 | 只感染分裂细胞；**插入突变**风险 |
| 慢病毒 | 可感染非分裂细胞 | 整合风险相对低 |
| 腺病毒 | 高滴度、不整合、感染力强 | 瞬时表达、免疫原性强 |
| ★AAV | 免疫原性低、长期表达（游离型） | 包装容量小（约 4.7 kb） |
| 质粒/脂质体 | 安全简便 | 转染效率低 |

- **基因治疗**：基因矫正、基因置换、★基因增补（最常用思路——只加不换）、基因沉默（反义核酸/RNAi/CRISPR 敲除）；方案分**体外法**（回输修饰的自体细胞——首例成功为 ADA-SCID）与体内法；伦理：以体细胞治疗为主，生殖细胞基因编辑被严格禁止。

## 第十六章 常用分子技术（306 高频小点）

【对比表】三大印迹与 PCR（必背大表）

| 技术 | 检测对象 | 探针/原理 | 记忆 |
|---|---|---|---|
| ★Southern blot | **DNA** | 标记核酸探针杂交 | "S—南—DNA" |
| ★Northern blot | **RNA** | 同上 | "N—北—RNA" |
| ★Western blot | **蛋白质** | 抗体（免疫印迹） | "W—西—蛋白" |

| qRT-PCR | mRNA 表达量 | 逆转录+实时荧光定量 | 测表达 |

- 基因工程要素：★限制性内切核酸酶（分子剪刀）、载体（质粒，含抗性基因/多克隆位点）、DNA 连接酶、转化/转染、筛选（抗性、蓝白斑）。
- 组学（了解）：基因组、转录组、蛋白质组、代谢组。

【对比表】基因工程（重组 DNA 技术）基本流程

| 步骤 | 内容 | 关键工具 |
|---|---|---|
| ①获取目的基因 | 化学合成、酶切回收、RT-PCR 扩增、基因组文库 | 限制酶、PCR |
| ②载体的选择与构建 | 质粒（含抗性基因、多克隆位点、ori） | ★限制酶+**DNA 连接酶** |

| ④筛选与鉴定 | 抗性筛选、蓝白斑、酶切/测序鉴定 | 标记基因 |

- 转基因动物（基因过度表达/导入）与基因敲除动物（定向失活）——研究基因功能的经典模型；CRISPR-Cas9 为新一代定点编辑工具（了解）。

【要点展开】PCR 与测序细节
- PCR 反应体系：模板、一对反向引物、dNTP、**Taq 酶**、Mg²⁺；产物特异性取决于**引物序列**；退火温度与引物 Tm 匹配。
- RT-PCR：RNA →（逆转录酶）→ cDNA → PCR——检测基因表达；qRT-PCR（实时荧光定量，SYBR Green/TaqMan 探针，Ct 值定量）。
- ★ Sanger 测序：**双脱氧核苷酸（ddNTP）链终止法**——第一代测序金标准；NGS 为高通量测序（了解）。
- ★基因芯片：固相寡核苷酸探针阵列+荧光标记样品——一次筛查大量序列/表达谱。
- PCR 应用纪律：扩增阳性≠有活病毒（核酸≠活性）；引物二聚体与非特异扩增是常见假阳性来源（了解）。

【对比表】三大印迹操作流程（必背大表）

| 步骤 | Southern（DNA） | Northern（RNA） | Western（蛋白） |
|---|---|---|---|
| 电泳 | 琼脂糖凝胶 | 变性凝胶 | SDS-PAGE |
| 转膜 | 硝酸纤维素/尼龙膜 | 同左 | PVDF 膜 |
| 探针 | 标记 DNA 探针 | 标记 DNA/RNA 探针 | ★**特异性抗体** |
| 检测 | 放射自显影/荧光 | 同左 | 化学发光（二抗） |

【高频考点提示】
- ★ blot 三兄弟与 PCR 三步循环——几乎每年必考其一。
- ★ PCR 需要 Taq 酶（耐热）；检测蛋白用 Western。

## 第十七章 复制、转录、翻译三大过程总对比 ★★★

【对比表】三大过程综合对比（基因信息传递的灵魂大表——必背）

| | 复制 | 转录 | 翻译 |
|---|---|---|---|
| 方向/产物 | DNA→DNA | DNA→RNA | mRNA→蛋白质 |
| 原料 | **dNTP** | **NTP** | 20 种氨基酸 |
| 核心机器 | DNA-pol（原核 Ⅲ；真核 δ/ε） | RNA-pol（原核全酶；真核 Ⅰ/Ⅱ/Ⅲ） | 核糖体（★转肽酶本质是 **rRNA**） |
| ★引物 | **需要**（RNA 引物） | **不需要** | 不需要（起始 tRNA 兼定位） |
| 合成方向 | 5′→3′ | 5′→3′ | N→C |
| 模板使用 | 双链均用（半保留、对称性复制） | 仅一条链（不对称转录） | 密码子读码（连续、简并、摆动） |
| 碱基配对 | A-T、G-C | A-U、G-C | 密码-反密码（可摆动） |
| ★校读 | 有（pol 3′→5′ 外切） | **无** | aaRS 校对+翻译监控 |
| 耗能 | dNTP 焦磷酸水解 | NTP 焦磷酸水解 | ATP（氨基酸活化）+GTP（起始/进位/转位） |
| 加工 | 一般无需 | 帽/尾/剪接（真核） | 折叠/修饰/靶向输送 |
| 经典抑制剂 | 喹诺酮（gyrase）、喜树碱（真核 topo Ⅰ） | **利福平**（原核 β 亚基）；★**α-鹅膏蕈碱**（真核 pol Ⅱ） | 四环素、氯霉素、白喉毒素、嘌呤霉素等 |
| 起始识别 | oriC/DnaA（原核） | σ 因子（原核）/TFⅡD-TATA（真核） | SD 序列（原核）/5′ 帽扫描（真核） |

- ⚠ 三大易混点集中默写：①只有复制需要引物；②只有 DNA-pol 有校读；③α-鹅膏蕈碱打真核 pol Ⅱ、利福平打原核 RNA-pol——两者千万不要交叉。

## 第十八章 易混概念辨析（考前清雷）

| 易混对 | 区分要点 |
|---|---|
| 复制起点（ori）vs 启动子 | 前者=DNA 复制开始的位置；后者=**转录**起始的信号序列 |
| 模板链 vs 编码链 | 被转录读到的为模板链；编码链序列与 RNA 相同（T↔U），**未被转录** |
| 癌基因 vs 抑癌基因 | 癌基因显性激活促增殖；抑癌基因隐性（两等位）失活——"油门踩死"vs"刹车失灵" |
| 病毒癌基因 v-onc vs 细胞癌基因 c-onc | v-onc 来自病毒基因组、有致瘤活性；c-onc=原癌基因，是正常细胞成分 |
| 端粒 vs 端粒酶 | 端粒=染色体末端的重复序列；端粒酶=延长端粒的逆转录酶 |
| 核酶 vs 酶（蛋白酶） | 核酶是 RNA，底物多为 RNA；化学本质不同 |
| miRNA vs siRNA | miRNA 内源性、不完全互补→翻译抑制为主；siRNA 双链、完全互补→切割降解 |
| 增强子 vs 启动子 | 增强子位置/方向不敏感、可远距离增强；启动子定位于转录起始位点附近 |
| 密码子 vs 反密码子 | 密码子在 mRNA；反密码子在 tRNA 反密码环 |
| 冈崎片段 vs 引物 | 冈崎片段=后随链上含引物的 DNA 片段；引物=其 5′ 端的短 RNA，最终被切除 |
| 半保留 vs 半不连续 | 半保留描述"模板分配"；半不连续描述"合成方式"，两者不冲突 |
| 转化 vs 转染 | 转化=外源 DNA 进入细菌；转染=进入真核细胞 |

【高频考点提示】
- ★ 基因信息传递篇的选择题 80% 落在"酶-过程配对"与"基因-疾病配对"两类，本章大表即为这两类的全集。
- ★ 转录后加工只发生在真核——原核 mRNA 直接翻译（多顺反子）。
- ★ 复制保真三保障、翻译保真首关（aaRS 校对）、转录无校读——三者保真机制对比常出组合题。
- ★ 概念链自查：基因→转录（hnRNA）→加工（mRNA）→翻译（肽链）→折叠修饰（功能蛋白）——用这条链串起下册全部章节。
