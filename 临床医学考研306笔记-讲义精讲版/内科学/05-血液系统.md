# 内科学·讲义精讲版——05 血液系统

> 覆盖：贫血总论、缺铁性贫血、巨幼贫、再生障碍性贫血、溶血性贫血各病、白细胞减少与粒缺、急性白血病与 APL、CML、CLL、淋巴瘤、多发性骨髓瘤、MDS、出血性疾病总论、ITP、TTP、血友病、DIC、抗栓药物、输血与输血反应。
> 用法：血液系统的考试逻辑是"实验室-病理-治疗"三角对应；缺铁 vs 海洋性贫血、血管内外溶血、血管/血小板/凝血三异常、DIC 治疗顺序四大块必须精确掌握。
> 血液学数值密集（治疗窗、界值、分型标准），建议结合速记要点多轮背诵。

## 一、贫血总论

### 1.1 诊断标准与形态学分类（必背）
- 海平面地区：**成人男性 Hb<120 g/L、女性（非妊娠）<110 g/L、孕妇 <100 g/L** 即贫血（妊娠中晚期阈值低）。
- **MCV 形态学分类（必背）**：

| 类型 | MCV | 代表疾病 |
|---|---|---|
| **小细胞低色素性** | <80 fl | **缺铁性贫血、海洋性（地中海）贫血、铁粒幼细胞贫血、慢性病贫血（部分）** |
| **正常细胞性** | 80–100 fl | **再生障碍性贫血、急性失血、多数溶血性贫血、慢性病贫血、肾性贫血** |
| **大细胞性** | >100 fl | **巨幼细胞贫血（叶酸/B₁₂缺乏）、MDS、肝病/甲减所致大细胞** |

- 其他基础指标：网织红细胞（Ret）——反映骨髓造血（溶血/失血↑，再生障碍↓）；外周血涂片（红细胞形态、幼稚细胞、破碎红细胞）。

## 二、缺铁性贫血（IDA）

### 2.1 病因与机制
- 铁代谢简图：食物 Fe²⁺ →（十二指肠/空场上段吸收，VitC 促吸收、茶/牛奶抑制）→ 转铁蛋白运输 → 骨髓利用 → **储存铁（铁蛋白、含铁血黄素）**。
- 病因三联（必背）：
  1. **需求增加/摄入不足**——婴幼儿、青少年、孕产妇；
  2. **吸收障碍**——胃大部切除、慢性萎缩性胃炎/长期腹泻；
  3. **丢失过多（成人最重要）——慢性失血**：月经过多、**消化道失血（男性和绝经后女性的 IDA 必须查胃肠道排除肿瘤/溃疡）**、痔疮。
- 机制链：储存铁耗尽（隐性缺铁）→ 铁缺乏性红细胞生成 → 小细胞低色素性贫血。

### 2.2 实验室（必背）
- 血象：MCV↓、MCH↓、MCHC↓；红细胞中央淡染区扩大；Ret 正常或轻度↑。
- **铁代谢指标四件套**：

| 指标 | 变化 | 备注 |
|---|---|---|
| **血清铁蛋白** | **↓（最早、最敏感）** | 急性炎症/肝病/肿瘤时假性正常/升高 |
| 血清铁 | ↓ | |
| **总铁结合力（TIBC）** | **↑**（转铁蛋白代偿↑） | 慢性病贫血时 ↓（鉴别点） |
| 转铁蛋白饱和度（TS） | ↓（<15%） | |
| **骨髓铁染色** | **细胞外铁消失/减少、铁粒幼细胞减少——诊断缺铁"最可靠"指标** | |

- ⚠ 与慢性病贫血鉴别：后者血清铁↓但**铁蛋白↑、TIBC↓**。
- ⚠ 与海洋性贫血鉴别（必背对比）：

| 项目 | 缺铁性贫血 | 海洋性贫血（β 轻型为例） |
|---|---|---|
| 铁蛋白/血清铁 | **↓** | **正常或↑** |
| TIBC | ↑ | 正常 |
| 形态 | 中央淡染扩大、异形轻 | **靶形红细胞、明显异形** |
| 家族史 | 无 | **有（遗传）** |
| 铁剂治疗 | 有效 | **无效且有害（铁过载）** |
| 确诊 | 铁代谢+骨髓铁 | **Hb 电泳（HbA₂↑、HbF↑）**、基因检测 |

### 2.3 治疗（必背）
- **口服铁剂为首选**：琥珀酸亚铁/硫酸亚铁/多糖铁复合物；**与维生素 C 同服促吸收；忌与浓茶、牛奶、抗酸剂同服**（影响吸收）；胃肠反应可餐后服（吸收略降）。
- **疗效观察（必背）**：**网织红细胞于服药后 3–4 天开始上升、5–10 天（约 1 周）达高峰（最早出现的疗效指标）**；2 周后 Hb 上升；**Hb 正常后仍需继续服药 3–6 个月补足储存铁**（铁蛋白恢复）。
- 注射铁剂指征：口服不耐受、吸收障碍（胃肠术后）、需快速纠正（妊娠晚期重度贫血）、持续失血者；蔗糖铁/右旋糖酐铁——⚠ 过敏（右旋糖酐铁）。
- **疗效不佳四大原因**：剂量不足/未规则服药；诊断错误（缺铁外还有其他病）；持续失血未去除；吸收障碍。

### 2.4 高频考点提示
- ★ 铁蛋白↓最早最敏感；骨髓铁染色最可靠；TIBC↑（慢性病贫血相反）。
- ★ 网织红 5–10 天达高峰=最早疗效指标；Hb 正常后继续 3–6 个月。
- ★ 男/绝经后女 IDA → 查消化道。

## 三、巨幼细胞贫血

### 3.1 病因与机制
- **叶酸或维生素 B₁₂ 缺乏 → DNA 合成障碍**（dTMP 合成受阻），RNA/蛋白质合成相对正常 → **"核幼浆老"的巨幼变**（细胞核发育落后于胞质）。
- 叶酸缺乏：摄入不足（偏食、酗酒、烹调过久）、需求↑（妊娠）、吸收障碍、**药物——甲氨蝶呤（叶酸拮抗剂）**、苯妥英钠/异烟肼（干扰）。
- B₁₂ 缺乏：**内因子缺乏（恶性贫血——抗内因子抗体）、全胃切除、回肠病变/切除、素食**；B₁₂ 参与甲基丙二酸-CoA 变位酶反应，缺乏 → 神经髓鞘合成障碍。

### 3.2 临床与实验室
- 贫血 + 消化道（**牛肉样舌/镜面舌、食欲差**）+ **B₁₂ 缺乏神经精神症状（必背）：对称性远端感觉异常→"亚急性联合变性"——脊髓后索（深感觉障碍、感觉性共济失调、Romberg 征+）与侧索（锥体束征、肌张力↑）变性**；
- 血象：MCV>100 fl、大卵圆形红细胞、**中性粒细胞分叶过多（≥5 叶）**；骨髓：巨幼红细胞（"核幼浆老"）、巨型杆状核粒细胞；
- 生化：**血清/红细胞叶酸、维生素 B₁₂↓；B₁₂ 缺乏者血清甲基丙二酸↑、同型半胱氨酸↑（叶酸缺乏者仅同型半胱氨酸↑——鉴别点）**；LDH、间接胆红素↑（原位溶血）。

### 3.3 治疗（必背）
- 叶酸缺乏：口服叶酸 5–15 mg/d（网织红 4–6 天上升）；
- B₁₂ 缺乏：肌注维生素 B₁₂（恶性贫血者终身维持）；
- **⚠ 核心考点：补叶酸前必须排除/同时补充 B₁₂**——单纯补叶酸可纠正贫血但**加速消耗 B₁₂，加重亚急性联合变性（神经损害不可逆）**；
- 补充后**低钾血症**（大量新生细胞摄取钾）需监测。

### 3.4 高频考点提示
- ★ "核幼浆老"；分叶过多；牛肉舌。
- ★ B₁₂ 缺乏 → 亚急性联合变性（后索+侧索）；先补 B₁₂ 或同时补。
- ★ 甲基丙二酸↑仅见于 B₁₂ 缺乏。

## 四、再生障碍性贫血（AA）

### 4.1 定义与病因
- 定义：**骨髓造血功能衰竭**（造血干/祖细胞数量与功能异常+免疫损伤）→ **全血细胞减少**的综合征。
- 病因：药物（**氯霉素、保泰松、磺胺**等）、化学毒物（苯）、电离辐射、病毒（**肝炎病毒（非甲非乙型相关再障）、微小病毒 B19、EBV、CMV**）、免疫异常；相当部分原因不明。
- ⚠ 与 PNH、MDS 鉴别（低增生 MDS、PNH 克隆检测）——三者在机制与治疗上相关。

### 4.2 临床与实验室
- 三系减少表现：贫血、出血（皮肤黏膜瘀点瘀斑，**颅内出血为主要死因之一**）、感染发热。
- **实验室要点（必背）**：全血细胞↓ + **网织红细胞绝对值↓（与溶血/失血的 Ret↑ 相反——鉴别核心）**；**骨髓象：增生减低或重度减低，粒/红/巨核三系造血细胞↓，非造血细胞（淋巴细胞、浆细胞、网状细胞、组织嗜碱细胞）比例↑，巨核细胞明显减少或缺如，无原始细胞增多、无病态造血**（区别于 MDS）；中性粒细胞碱性磷酸酶（NAP）活性↑。
- **分型（Camitta 标准，必背 2/3）**：

| 分型 | 标准 |
|---|---|
| **重型再障（SAA）** | **中性粒细胞 <0.5×10⁹/L、血小板 <20×10⁹/L、网织红细胞 <15×10⁹/L 中符合两项及以上**（伴骨髓增生重度减低） |
| 非重型（NSAA，旧称慢性） | 未达 SAA 标准；病程迁延 |

### 4.3 治疗（选择逻辑必背）
- **SAA：**
  - **年龄 <40 岁、有 HLA 相合同胞供者——首选异基因造血干细胞移植（allo-HSCT，可根治）**；
  - 无适合供者/年龄大——**IST（免疫抑制治疗）：ATG/ALG + 环孢素 A（±TPO 受体激动剂如艾曲泊帕等强化方案）**；
- **NSAA：环孢素 A ± 雄激素（司坦唑醇、达那唑、十一酸睾酮——刺激造血）**；疗效不佳者按 SAA 处理；
- 支持治疗：成分输血（血小板 <10×10⁹/L 或出血时输注；⚠ 反复输血 → 铁过载/致敏，移植前尽量避免家族成员血）、**防感染（保护性隔离、抗感染按粒细胞水平）**；
- ⚠ 诊断后应尽早治疗（SAA 半年生存率与干预时机强相关）；**禁忌致再障药物**（氯霉素等）。

### 4.4 高频考点提示
- ★ Ret 绝对值↓+骨髓"三少一多（非造血细胞）"+巨核缺如。
- ★ SAA 三条数值（<0.5、<20、<15×10⁹/L 任二）。
- ★ 年轻有供者→移植；否则 ATG+CsA；NSAA 用 CsA+雄激素。

## 五、溶血性贫血

### 5.1 总论与实验室证据（必背）
- 溶血证据链：Hb↓ + **间接胆红素↑、尿胆原↑** + **LDH↑** + **结合珠蛋白↓** + **Ret↑（≥5% 常见）** + 骨髓红系代偿增生。
- **血管内 vs 血管外溶血（必背大表）**：

| 项目 | 血管内溶血 | 血管外溶血 |
|---|---|---|
| 破坏场所 | 血管内（血循环） | **单核-巨噬细胞系统（脾、肝）** |
| 机制 | 补体、机械损伤、毒素 | 吞噬识别（IgG/CD47 改变等） |
| **血红蛋白尿** | **有（酱油色尿）** | 无 |
| **含铁血黄素尿（Rous 试验）** | **阳性（慢性血管内溶血）** | 阴性 |
| 游离血红蛋白↑、结合珠蛋白↓ | **明显** | 轻度 |
| 脾大 | 可不明显 | **常见** |
| 代表疾病 | 血型不合输血、**PNH**、G6PD 缺乏（蚕豆病）、机械瓣/微血管病 | **遗传性球形红细胞增多症、温抗体型 AIHA、海洋性贫血** |

- 病因筛查试验：**Coombs 试验（+）→ 免疫性（AIHA）**；**Ham 试验/蔗糖溶血/流式 CD55、CD59↓ → PNH**；**渗透脆性↑ → 遗传性球形红细胞增多症（脾切除有效）**；**Hb 电泳 → 海洋性贫血**；G6PD 酶活性 → 蚕豆病。

### 5.2 自身免疫性溶血性贫血（AIHA）
- 分类：**温抗体型（IgG，37 ℃ 反应，最常见——Coombs 直接试验阳性）**；**冷抗体型（IgM——冷凝集素综合征 CAS，遇冷加重；阵发性冷性血红蛋白尿为 Donath-Landsteiner IgG 双相抗体）**。
- 治疗：**糖皮质激素为温抗体型首选**（机制：抑制巨噬细胞吞噬与抗体生成）；无效/依赖——利妥昔单抗、脾切除、其他免疫抑制剂；**冷抗体型重在保暖**（激素效果差）；**继发性者治原发病**（SLE、淋巴瘤、药物）；**Evans 综合征 = AIHA + ITP 并存**。
- ⚠ 输血原则：尽量避免；必须输时选"最小不相容"血（无法配出完全相合血）。

### 5.3 阵发性睡眠性血红蛋白尿（PNH）
- 机制：**PIG-A 基因突变（获得性、造血干细胞水平）→ GPI 锚连蛋白缺失 → 补体调节蛋白 CD55、CD59 缺失 → 补体敏感 → 慢性血管内溶血（晨起酱油色尿为特征）**。
- 临床：溶血 + **全血细胞减少（可被误诊为再障——AA-PNH 综合征）** + **血栓倾向（肝静脉血栓/Budd-Chiari 为特征）**+ 平滑肌痉挛（腹痛、吞咽困难——游离 Hb 结合 NO 所致）。
- 确诊：**流式细胞术 CD55/CD59 表达缺失（金标准）；FLAER 检测更敏感**；Ham 试验（酸溶血）为经典试验。
- 治疗：**依库珠单抗（抗 C5 单抗——控制溶血与血栓）**；对症（叶酸、铁——溶血消耗）；AA 表现者 IST；**allo-HSCT 为唯一根治**；抗凝防血栓。

### 5.4 G6PD 缺乏症（蚕豆病）
- X 连锁不完全显性；诱因：**蚕豆、氧化性药物（伯氨喹、磺胺、呋喃类、萘）、感染**——急性血管内溶血（酱油色尿、黄疸、腰酸）。
- 诊断：急性期酶活性可能"假性正常"（新生红细胞酶活性高）——**溶血停止后复查 G6PD 活性**；Heinz 小体（变性珠蛋白）。
- 治疗：去除诱因、水化碱化防肾衰、输血（重度）；**预防：避免已知诱因（宣教核心）**。

### 5.5 海洋性贫血（地中海贫血）
- 常染色体隐性/共显性遗传性 **珠蛋白肽链合成障碍**（α 链不足 → β 链相对过剩形成包涵体；β 链不足 → α 链过剩）。
- **β 海洋性贫血**：轻型（杂合子——HbA₂↑（>3.5%）、轻度贫血、无需治疗）、中间型、**重型（Cooley 贫血）**——婴幼儿发病、**贫血+黄疸+肝脾大+地中海面容（颅骨改变）**、HbF 显著↑、靶形红细胞；依赖输血。
- **α 海洋性贫血**：静止型/标准型（携带）；**HbH 病（β₄ 四聚体——中等度溶血、脾大）**；**Hb Bart's 胎儿水肿综合征（γ₄——死胎/死产）**。
- 治疗：**定期输血 + 去铁治疗（去铁胺/地拉罗司——反复输血致铁过载）**；脾大亢进者脾切；**异基因造血干细胞移植为唯一根治**；基因治疗（进展中）。
- ⚠ **不是缺铁——禁用铁剂**；轻型无需治疗但需遗传咨询。

### 5.6 高频考点提示
- ★ 溶血证据四联：Ret↑、间接胆红素↑、结合珠蛋白↓、LDH↑。
- ★ 血管内=Hb 尿+含铁血黄素尿（Rous+）；血管外=脾大。
- ★ Coombs+→AIHA（温抗体激素首选）；CD55/CD59↓→PNH；脆性↑→球形红增（脾切）；Hb 电泳→海洋性。
- ★ 蚕豆病急性期酶活性可假阴性，需复查。

## 六、白细胞减少与粒细胞缺乏症

- 定义：白细胞 <4×10⁹/L 为白细胞减少；**中性粒细胞 <0.5×10⁹/L 为粒细胞缺乏（粒缺）**——感染风险极高。
- 病因：①生成减少——**细胞毒药物/化疗、抗甲状腺药（甲巯咪唑）、氯霉素、再障、MDS、白血病、叶酸/B₁₂ 缺乏**；②破坏/消耗过多——药物免疫性、自身免疫、脾亢（Felty 综合征=RA+脾大+粒减）、严重感染消耗；③分布异常（边缘池↑）。
- 临床：粒缺——**高热、口腔/咽部溃疡坏死、肛周感染、脓毒症**（可能无化脓灶——粒细胞缺乏所致）。
- 处理：**停用可疑药物**；**保护性隔离**；**G-CSF 升粒细胞**；广谱抗生素（发热即经验性覆盖 G⁻菌——碳青霉烯类/抗假单胞菌 β 内酰胺类）；输注粒细胞一般不用。
- 高频考点：抗甲状腺药物最严重副作用=粒细胞缺乏——**发热咽痛立即查血常规**。

## 七、急性白血病

### 7.1 分型（FAB 与 MICM）
- **FAB 分型**：AML——**M0（急髓微分化）–M7（急性巨核细胞白血病）**（M1 急粒未分化型、M2 急粒部分分化型、M3 急性早幼粒细胞白血病、M4 急粒-单、M5 急单、M6 红白血病、M7 巨核）；ALL——L1、L2、L3（Burkitt 样）。
- **MICM 分型 = 形态学 + 免疫学 + 细胞遗传学 + 分子生物学**——现代诊断标准。
- 免疫标志（必背）：**AML：MPO（+，最特异）、CD13、CD33、CD117**；**B-ALL：CD10、CD19、CD20、TdT（+）、cyCD79a**；**T-ALL：cyCD3、CD7**。
- 遗传/分子标志（必背）：**M3——t(15;17)（PML-RARα）**；M2——t(8;21)；M4eo——inv(16)；ALL——t(9;22)（Ph+ ALL，预后差）；Burkitt——t(8;14)（c-MYC）。

### 7.2 临床表现（四大表现：贫血、出血、感染、浸润）
- 贫血（进行性）、出血（血小板↓+DIC——M3 严重）、发热感染；
- **浸润（必背）**：**肝脾淋巴结肿大（ALL 最显著）**、**胸骨下段压痛（骨痛——特征性）**、**牙龈增生肿胀（M4/M5——单核细胞）**、**绿色瘤/粒细胞肉瘤（AML，眼眶——突眼）**、CNS 浸润。

### 7.3 实验室与诊断
- 血象：WBC 可↑（高白细胞性 >100×10⁹/L）、正常或↓（低增生性）；**外周血见原始/幼稚细胞**；贫血与血小板↓。
- **骨髓象：原始细胞 ≥20%（WHO 标准）即可诊断急性白血病**（FAB 原标准 ≥30%，⚠ 按现行 WHO）；**Auer 小体——仅见于 AML（M3 呈柴捆状）**，ALL 阴性（重要鉴别）。
- 细胞化学：POX/MPO（AML+）、PAS（ALL 块状+）、NSE（单核+，可被氟化钠抑制）。

### 7.4 APL（M3）专段（必考）
- **t(15;17) → PML-RARα 融合基因**；异常早幼粒细胞颗粒富含组织因子与纤溶酶原激活物 → **DIC 是 APL 最重要的早期并发症与死因**（出血严重）。
- **治疗革命：全反式维 A 酸（ATRA）+ 砷剂（三氧化二砷）诱导分化与凋亡——治愈率高（90% 左右）**，避免传统强烈化疗的早期死亡；化疗（蒽环类）在高危者联合。
- ⚠ **ATRA/砷剂相关分化综合征（维 A 酸综合征）**：发热、呼吸窘迫、肺浸润、体重增加——**立即停药/加用地塞米松**；防治 DIC：替代+监测。
- 诊断线索：中青年、严重出血（DIC）+ 全身衰竭、t(15;17)。

### 7.5 中枢神经系统白血病（CNSL，必背）
- **最常见于 ALL（尤其高危、高白细胞、L3 型），也可发生 AML（M4/M5）**；多发生在缓解期（"庇护所"）。
- 表现：头痛、呕吐、视盘水肿（颅压高）+ 脑神经麻痹（面神经多见）；**脑脊液找到白血病细胞可确诊**（压力↑、蛋白↑、糖↓）。
- 处理：**预防为主——ALL 常规鞘内注射 MTX±Ara-C±地塞米松**（或大剂量 MTX 全身化疗）；治疗——鞘注联合头颅放疗（视情况）。

### 7.6 治疗
- 诱导缓解：**AML——"3+7"（柔红霉素/去甲氧柔红霉素 + 阿糖胞苷）±靶向（FLT3 抑制剂等）**；**ALL——VDLP（长春新碱+柔红霉素+左旋门冬酰胺酶+泼尼松）**。
- **完全缓解（CR）标准（必背）**：**骨髓原始细胞 <5%，ANC ≥1.0×10⁹/L、PLT ≥100×10⁹/L，髓外白血病消失，无相关症状体征**。
- 缓解后治疗：巩固强化（AML：HiDAC 等）→ 维持（**ALL 需 2–3 年维持**——6-MP+MTX）；**高危/复发/难治——异基因造血干细胞移植**。
- 支持治疗（必背）：**防治感染（保护性隔离、发热即经验性抗生素）**、成分输血、**肿瘤溶解综合征（TLS）——高尿酸（别嘌醇/拉布立酶）、高钾、高磷、低钙——大量水化碱化**（高白细胞性/高增殖肿瘤预防性应用）；M3 防 DIC。

### 7.7 高频考点提示
- ★ 原始细胞 ≥20%（WHO）；Auer 小体仅 AML；胸骨压痛。
- ★ M3：t(15;17)、ATRA+砷剂、DIC、分化综合征用激素。
- ★ CNSL：ALL 最常见、缓解期发病、鞘内 MTX。
- ★ TLS：高钾高磷低钙高尿酸——水化碱化+别嘌醇。

## 八、慢性髓系白血病（CML）

- 定义：**Ph 染色体 [t(9;22) → BCR-ABL 融合基因（p210）] 阳性的骨髓增殖性肿瘤**；酪氨酸激酶持续激活是发病核心。
- 临床（慢性期）：中老年多；**脾大（巨脾——最常见体征）、乏力、消瘦、低热**；白细胞极度增高（常 >100×10⁹/L，以中晚幼粒与成熟粒细胞为主）、**嗜碱性粒细胞增多**、血小板早期↑；**中性粒细胞碱性磷酸酶（NAP）积分显著降低或缺如（与类白血病反应鉴别——类白 NAP↑）**。
- 分期：慢性期（1–4 年）→ 加速期（治疗无效、原始细胞增多、嗜碱>20% 等）→ **急变期（AML 或 ALL 表型——预后极差，"终末期"）**。
- 诊断：Ph 染色体/BCR-ABL 检测（FISH/PCR）确诊；类白血病反应无 Ph+ 且有原发病。
- **治疗（必背）**：**酪氨酸激酶抑制剂（TKI）——伊马替尼为一线首选**（BCR-ABL 酪氨酸激酶选择性抑制）；二代 TKI（达沙替尼、尼洛替尼）用于不耐受/耐药/进展者；**allo-HSCT 用于 TKI 耐药/T315I 突变/急变期**（⚠ T315I 对多数 TKI 耐药——普纳替尼等三代药物，了解）；羟基脲为控制高白细胞的过渡手段；脾区放疗少用。
- 慢淋（CLL）速览：老年；**成熟小淋巴细胞克隆性增殖（B-CLL：CD5⁺、CD19⁺、CD23⁺、CD20 弱、smIg 弱、CD10⁻）**；淋巴细胞持续 ≥5×10⁹/L；肝脾淋巴结肿大；Rai/Binet 分期；**治疗指征（不主张早治）：进行性血细胞减少（贫血/Hb 或 PLT 明显下降）、巨脾/进行性淋巴结大、B 症状、自身免疫性血细胞减少**——化疗免疫（FCR/BR）与 BTK 抑制剂（伊布替尼）等新药；Richter 转化（转 DLBCL）。

### 高频考点提示
- ★ Ph（9;22）BCR-ABL + NAP↓ + 嗜碱↑ + 巨脾。
- ★ TKI（伊马替尼）为一线；类白血病反应 NAP↑ 无 Ph。
- ★ CLL：CD5⁺ 成熟 B 细胞；有治疗指征才治。

## 九、淋巴瘤

### 9.1 霍奇金淋巴瘤（HL）
- 特征：**R-S 细胞（镜影细胞）**——诊断必需（但非特异）；**沿淋巴结区连续性播散**；青年双峰；常从颈/锁骨上起病。
- **组织学亚型（必背）**：
  - 结节性淋巴细胞为主型（NLPHL，"爆米花"细胞，预后最好）；
  - **经典型 4 类**：**结节硬化型（最常见，年轻女性、纵隔受累）**、混合细胞型（我国多见、EBV 相关）、淋巴细胞为主型（预后好）、淋巴细胞消减型（最少、预后最差）。
- **Ann Arbor 分期 + B 症状（必背）**：Ⅰ 期——单一淋巴结区（或单一结外器官）；Ⅱ 期——**横膈同侧**≥2 个淋巴结区；Ⅲ 期——横膈两侧；Ⅳ 期——**弥漫/多发结外器官（肝、骨髓等）**；**B 症状 = 发热 >38 ℃ 连续 3 天、盗汗、6 个月内体重下降 >10%**（有=B，无=A）。
- 治疗：**Ⅰ–Ⅱ 期——ABVD 化疗 ± 受累野放疗**；Ⅲ–Ⅳ 期——**ABVD 方案为主**（多柔比星+博来霉素+长春碱+达卡巴嗪），进展期可选强化方案；复发难治——自体移植±新药。
- 预后良好（现代治愈率高）。

### 9.2 非霍奇金淋巴瘤（NHL）
- 特征：**跳跃性播散、结外侵犯多见、易骨髓受累**；类型多样（B 细胞为主）。
- 常见类型（必背）：

| 类型 | 特征 | 治疗要点 |
|---|---|---|
| **弥漫大 B 细胞淋巴瘤（DLBCL）** | **成人 NHL 最常见**，侵袭性 | **R-CHOP（利妥昔单抗+环磷酰胺+多柔比星+长春新碱+泼尼松）×6±放疗** |
| 滤泡性淋巴瘤 | 惰性；t(14;18)（BCL-2） | 治疗指征才治（观察等待策略）；R-化学免疫 |
| MALT 淋巴瘤（边缘区） | **胃 MALT——HP 相关** | **早期首先根除 HP** |
| Burkitt 淋巴瘤 | t(8;14)（c-MYC）；儿童下颌/腹部；高增殖（Ki-67≈100%） | **短程、高强度**方案（联合中枢预防） |
| 套细胞淋巴瘤 | t(11;14)（cyclin D1）；老年男性、侵袭性与惰性表现并存 | 联合化疗±移植、BTK 抑制剂 |
| 淋巴母细胞淋巴瘤/T-NHL | 侵袭性、纵隔 | 类 ALL 方案 |

- 分期与治疗：同 Ann Arbor（Lugano 修订）；惰性——指征治疗；侵袭性——立即治疗；中枢高危者鞘注预防。

### 9.3 高频考点提示
- ★ HL=连续播散+R-S 细胞+ABVD；NHL=跳跃+结外+R-CHOP（DLBCL）。
- ★ Ann Arbor Ⅱ/Ⅲ/Ⅳ 期界定 + B 症状三联。
- ★ 胃 MALT 先根除 HP；Burkitt=t(8;14)。

## 十、多发性骨髓瘤（MM）

- 定义：浆细胞克隆性恶性增殖，分泌**单克隆免疫球蛋白（M 蛋白）**并致靶器官损害；中老年。
- **CRAB（必背）**：
  - **C 高钙血症**（骨破坏释钙；嗜睡、多尿、便秘）；
  - **R 肾损害**——轻链（本周蛋白）沉积→**管型肾病**（⚠ 与轻链沉积病、淀粉样变不同机制）；避免肾毒性药与造影剂；
  - **A 贫血**（骨髓浸润+肾性 EPO↓）；
  - **B 骨病——溶骨性破坏（X线"穿凿样"改变，颅骨/脊柱多见）**——骨痛（最常见首发症状）、病理性骨折。
- 实验室：M 蛋白（血清蛋白电泳 M 带；**IgG 型最常见**）；**尿本周蛋白（游离轻链）**；血清游离轻链比值异常；骨髓浆细胞 **≥10%**（正常 <3%?——正常骨髓浆细胞比例低，诊断标准为克隆性浆细胞 ≥10% 或活检证实浆细胞瘤）。
- 诊断：克隆性浆细胞证据 + M 蛋白 + **CRAB 或生物标志物**（骨髓浆细胞 ≥60%、FLC 比值 ≥100、MRI 多发局灶损害——SLiM 标准）。
- 治疗：**VRd 方案（硼替佐米——蛋白酶体抑制剂 + 来那度胺——免疫调节剂 + 地塞米松）±自体造血干细胞移植**（适龄者）；复发——卡非佐米/泊马度胺、抗 BCMA CAR-T 等（了解）；**双膦酸盐（唑来膦酸）减少骨事件**（⚠ 监测下颌骨坏死）；高钙危象——水化+双膦酸盐±激素±降钙素；放疗局部骨痛。
- 高频考点：★ CRAB+穿凿样骨破坏+本周蛋白；硼替佐米+来那度胺；高钙处理。

## 十一、骨髓增生异常综合征（MDS）

- 定义：造血干细胞克隆性疾病——**无效造血（病态造血）+ 外周血细胞减少 + 原始细胞增多倾向 + 向急性白血病转化风险**；老年多见。
- 诊断要点：≥1 系血细胞减少 + 病态造血（≥1 系 10% 以上细胞）±原始细胞比例分级（WHO：<5%、5%–9%、10%–19% 等）+ 典型细胞遗传学异常（**-5/5q-、-7/7q-、+8 等**；**5q- 综合征——老年女性、难治性贫血、血小板正常/↑、来那度胺特效**）；基因突变（SF3B1 等）辅助。
- ⚠ 与再障鉴别：MDS 有**病态造血与原始细胞**，骨髓可增生活跃；与巨幼贫鉴别（B₁₂/叶酸水平、试验治疗）。
- 风险分层：IPSS-R（细胞遗传学、骨髓原始细胞、血细胞减少系数）——决定治疗。
- 治疗：**低危——支持（输血、去铁）、EPO、来那度胺（5q-）；高危——去甲基化药物（阿扎胞苷）**、强化化疗；**allo-HSCT 为唯一可能治愈手段（高危年轻者）**。
- 高频考点：★ 病态造血+原始细胞=与再障的鉴别核心；5q- 用来那度胺；高危阿扎胞苷/移植。

## 十二、出血性疾病总论

### 12.1 三大异常鉴别（必背大表）

| 项目 | 血管壁异常 | 血小板异常 | 凝血功能异常 |
|---|---|---|---|
| 性别/遗传 | 少见家族史 | 可有家族史 | **多见（X 连锁——血友病）** |
| **出血特点** | 皮肤瘀点瘀斑、鼻衄 | **皮肤黏膜瘀点瘀斑、牙龈鼻出血、月经过多——浅表、即时出血** | **深部组织血肿、关节积血、内脏/术后延迟出血——深部、迟发出血** |
| 血小板计数 | 正常 | **↓（或功能异常时正常）** | 正常 |
| 出血时间（BT） | 正常或延 | **延长** | 正常 |
| **PT/APTT** | 正常 | 正常 | **异常（PT——外源/共同；APTT——内源）** |
| 代表病 | 过敏性（IgA 血管炎）、遗传性出血性毛细血管扩张症 | **ITP、TTP、DIC、血小板无力症** | **血友病、肝病、维生素 K 缺乏、DIC、抗凝药过量** |

- 筛查逻辑：**APTT 延长+PT 正常 → 内源途径（Ⅷ、Ⅸ、Ⅺ、Ⅻ）——血友病**；PT 延长±APTT → 外源/共同（Ⅶ、Ⅹ、Ⅴ、Ⅱ、Ⅰ）——肝病、VitK 缺乏、华法林；两者都延 → 共同途径/DIC/严重肝病；只有 BT 延 → 血管/血小板。

### 12.2 ITP（原发免疫性血小板减少症）
- 机制：抗血小板自身抗体（gpⅡb/Ⅲa 等）→ **脾脏破坏 + 巨核细胞成熟障碍**。
- 临床：**皮肤黏膜瘀点瘀斑、鼻衄、牙龈出血、月经过多；一般无脾大**（有脾大需另寻原因）；内脏/颅内出血少见但致命（PLT 极低时）。
- 实验室：**PLT↓（重症 <20×10⁹/L）、MPV↑（代偿）、骨髓巨核细胞数量正常或↑但成熟障碍（颗粒型多、产板型↓）、血小板相关抗体（PAIg）↑**；余凝血正常。
- 治疗（必背）：
  - **观察阈值：PLT>30×10⁹/L 且无出血——一般不需治疗**；
  - **一线：糖皮质激素**（泼尼松 1 mg/kg；IVIG 用于重症出血/术前/分娩前——封闭 Fc 受体快速升板）；
  - **二线：TPO 受体激动剂（艾曲泊帕、罗米司亭）、利妥昔单抗、脾切除**（慢性难治者，有效率较高）；
  - ⚠ **禁用阿司匹林等抗血小板药**；输血小板仅用于致命出血（很快被抗体破坏）。

### 12.3 TTP（血栓性血小板减少性紫癜，必考）
- 机制：**ADAMTS13 活性严重缺乏（<10%，自身抗体抑制为主）→ 超大 vWF 多聚体不能降解 → 微血管血小板血栓 → 微血管病性溶血**。
- **五联征（必背）**：①**微血管病性溶血性贫血（外周血破碎红细胞 >1%——关键）**；②**血小板减少**；③**神经精神症状（头痛、意识障碍、抽搐——波动性）**；④肾损害（血尿、肌酐↑）；⑤发热。
- **治疗：血浆置换为救命性首选治疗（确诊当日启动）**；糖皮质激素；**⚠ 禁输血小板（加重微血栓）——除非致命出血**；ADAMTS13 抗体检测；caplacizumab（抗 vWF 药，了解）。
- 鉴别：与 DIC、Evans、溶血尿毒综合征（HUS——儿童、志贺毒素相关）。

### 12.4 血友病
- 遗传：**X 连锁隐性**——男性发病、女性携带；**A 型（FⅧ 缺乏，约占 80%–85%）、B 型（FⅨ 缺乏）**；FⅪ 缺乏（罕见）。
- 出血特征：**自幼、轻微外伤后深部血肿、关节腔积血（负重关节——膝、踝、肘，反复致血友病性关节病）**、术后延迟渗血不止；皮肤瘀点少见（区别于血小板病）。
- 实验室（必背）：**APTT 延长、PT 正常、TT 正常、BT 正常、PLT 正常**；纠正试验（加正常血浆可纠正→因子缺乏）；**FⅧ/FⅨ 活性测定确诊并分度：重型 <1%、中型 1%–5%、轻型 5%–40%**（⚠ 各教材分度上限略有差异，需核对，常用 <1/1–5/5–25% 口径）。
- 治疗：**替代治疗（核心）——FⅧ 浓缩物/重组 FⅧ（A 型）、FⅨ 浓缩物/凝血酶原复合物（B 型）**；**轻中型 A 型可用 DDAVP（去氨加压素——释放内皮 vWF/FⅧ）**；**冷沉淀/新鲜冰冻血浆**在无浓缩物时可用；辅助——抗纤溶药（氨甲环酸，血尿慎用防输尿管堵塞）；A 型产生抑制物（抗体）者——旁路途径药物（rFⅦa、活化凝血酶原复合物）。
- ⚠ **护理禁忌：禁肌内注射、禁用阿司匹林等影响血小板的药物；避免关节穿刺于非替代治疗下进行**。
- 高频考点：★ APTT↑+PT 正常+男性家族史+关节血肿；FⅧ 替代+DDAVP（轻型 A）。

## 十三、DIC（弥散性血管内凝血）

### 13.1 病因与机制
- 病因（必背排序）：**感染（脓毒症——最常见）**、恶性肿瘤（**APL 最典型**）、病理产科（**羊水栓塞、胎盘早剥、死胎**——组织因子入血）、严重创伤/手术、血管内溶血、蛇毒、肝病。
- 机制链：组织因子/促凝物质入血 → **广泛微血栓形成 → 凝血因子与血小板消耗（消耗性凝血病）→ 继发纤溶亢进 → 出血 + 休克 + 微血管病性溶血 + 多器官功能障碍**。

### 13.2 实验室（必背）
- **PLT↓（<100×10⁹/L 或进行性↓）**；
- **纤维蛋白原（FIB）↓（<1.5 g/L 或进行性↓）**；
- **PT、APTT 延长**；
- **D-二聚体↑↑、FDP↑（纤溶证据）**；
- **3P 试验（鱼精蛋白副凝，早期 SFMC 阳性）**、外周血破碎红细胞。
- 诊断：原发病 + 出血/微血栓/休克表现 + 上述多指标异常（ISTH 评分可用于分级）。

### 13.3 治疗顺序（必背）
1. **去除病因（根本）**——控制感染、清创、终止妊娠、治疗肿瘤；
2. **替代治疗（出血为主时基础）**：新鲜冰冻血浆、**PLT<20–50×10⁹/L 或活动性出血时输血小板**、**FIB<1–1.5 g/L 时输冷沉淀/纤维蛋白原**；
3. **抗凝（肝素）——指征：高凝期/以血栓栓塞为主者（慢性 DIC、脓毒症早期）；⚠ 禁忌/慎用：以出血为主、术后创面、FIB 极低（<1 g/L 时先补充再考虑）**；普通肝素 APTT 监测，低分子肝素常用；
4. **抗纤溶（氨甲环酸/氨基己酸）——仅用于纤溶亢进为主、出血严重者；⚠ 微血栓期禁用（加重栓塞）**；
5. 支持器官功能。
- 记忆主线：**"治本 → 补（凝因子/血小板/纤维蛋白原）→ 抗凝（选择性）→ 抗纤溶（选择性）"**。

### 13.4 高频考点提示
- ★ 实验室五项：PLT↓、FIB↓、PT/APTT↑、D-二聚体/FDP↑、3P（+）。
- ★ 肝素只给"血栓为主/FIB 不太低"；先补 FIB 再抗凝；抗纤溶药微血栓期禁用。

## 十四、抗凝与抗血小板药物概览

| 药物 | 机制 | 监测 | 拮抗剂 |
|---|---|---|---|
| **华法林** | **抑制维生素 K 环氧化物还原酶→Ⅱ、Ⅶ、Ⅸ、Ⅹ 合成↓**（起效慢，需肝素桥接） | **INR 2–3** | **维生素 K₁**（+凝血酶原复合物/FFP 紧急） |
| **普通肝素（UFH）** | 与抗凝血酶Ⅲ结合，灭活 Ⅱa、Ⅹa | **APTT 1.5–2.5 倍** | **鱼精蛋白（完全拮抗）** |
| **低分子肝素（LMWH）** | 以抗 Ⅹa 为主 | 常规不监测（抗 Ⅹa 必要时） | 鱼精蛋白（部分） |
| **磺达肝癸钠** | 选择性 Ⅹa 抑制剂（不引起 HIT） | 不监测 | 无特异 |
| **达比加群** | 直接凝血酶（Ⅱa）抑制剂 | APTT 部分反映 | **依达赛珠单抗**（特异性拮抗剂）；80% 肾排——可透析 |
| **利伐沙班/阿哌沙班/依度沙班** | 直接 Ⅹa 抑制剂 | 影响 PT/APTT 不规则 | 特异性拮抗剂（了解）/凝血酶原复合物 |
| **阿司匹林** | **不可逆抑制 COX-1 → TXA₂↓**（血小板终身受抑） | 功能试验少用 | 无特效（去氨加压素/血小板输注——出血时） |
| **氯吡格雷** | **不可逆阻断 P2Y12 受体（ADP 途径）** | — | 无特效 |
| **替格瑞洛** | **可逆 P2Y12 抑制剂**（起效快、作用强） | — | 停药即渐恢复；副作用——呼吸困难、心动过缓 |
| **替罗非班等 GPIIb/Ⅲa 抑制剂** | 阻断血小板聚集终末共同通路 | PCI 中使用 | 停药即恢复 |
| **肝素诱导性血小板减少症（HIT）** | **PF4-肝素复合物抗体 → 血小板活化 → 血小板↓（>50%）+ 血栓（"低板高凝"）** | 用肝素后血小板监测 | **停一切肝素类（含 LMWH），改阿加曲班/磺达肝癸钠；禁输血小板** |

- 高频考点：★ INR 2–3、APTT 1.5–2.5 倍；华法林-VitK₁、肝素-鱼精蛋白；HIT=血小板↓+血栓→阿加曲班。

## 十五、输血与输血反应

### 15.1 输血基本要点
- **成分输血为原则**（缺什么补什么）：红细胞悬液（Hb<70 g/L 输注指征一般情形；心血管病者适当放宽 ⚠）、血小板（<10×10⁹/L 预防性输注；<20×10⁹/L 伴出血风险/发热感染；手术 <50）、新鲜冰冻血浆（凝血因子/血浆置换）、冷沉淀（纤维蛋白原、FⅧ、vWF——血友病 A、DIC）。
- 输血前流程：血型鉴定（ABO+RhD）+ 抗体筛查 + **交叉配血**；核对制度（双人核对）。
- Rh 阴性育龄女性尽量输 Rh 阴性血（防抗 D 抗体 → 新生儿溶血病）；免疫缺陷/骨髓移植者用辐照血（防 TA-GVHD）。

### 15.2 输血反应（必背）

| 反应 | 机制/特点 | 处理要点 |
|---|---|---|
| **溶血性输血反应（最严重）** | **ABO 血型不合**——立即血管内溶血：腰背痛、发热寒战、血红蛋白尿、休克、DIC、急性肾损伤 | **立即停止输血（保留静脉通路）**、抗休克、**水化碱化利尿**（保肾）、检查（血红蛋白尿、游离 Hb↑、结合珠蛋白↓）、重新配血鉴定原因 |
| **非溶血性发热反应（最常见）** | 受血者抗白细胞/细胞因子抗体 | 减速/停输、退热处理；去白细胞滤器预防 |
| 过敏反应 | 血浆蛋白过敏（IgA 缺乏者严重过敏） | 轻者抗组胺；重者停输+肾上腺素 |
| **TRALI（输血相关急性肺损伤）** | 供者抗体（多见于多次妊娠女性供者）攻击受者白细胞 → 非心源性肺水肿 | **立即停输、呼吸支持（与容量过负荷性肺水肿鉴别——TRALI 无颈静脉怒张）** |
| TA-GVHD | 活性淋巴细胞植入免疫低下受者 | 难治——**预防：辐照血** |
| 细菌污染 | 冷藏血 G⁻菌繁殖 | 高热休克——立即停输+抗感染 |
| 循环超负荷 | 老年/心衰快速大量输血 | 减速、利尿、坐位 |
| 大量输血并发症 | 枸橼酸中毒（低钙）、稀释性凝血病、低体温、高钾（保存血） | 补钙、成分纠正、加温输注 |

- 高频考点：★ 溶血反应=立即停输+水化碱化+抗休克；最常见反应=发热性；TRALI=非心源性肺水肿；TA-GVHD 用辐照血预防。

## 十六、造血干细胞移植概要（补充）

| 项目 | 自体移植（Auto-HSCT） | 异基因移植（Allo-HSCT） |
|---|---|---|
| 造血来源 | 自身缓解期采集的骨髓/外周血干细胞 | HLA 相合供者（同胞全相合、非血缘、**单倍体半相合**、脐血） |
| 适应证 | **淋巴瘤（HL/NHL）、多发性骨髓瘤**、部分实体瘤 | **急性白血病（高危/复发）、重型再障、MDS、CML 急变**、遗传性血液病 |
| 能否根治原病 | 不能（本质为大剂量化疗后的造血支持，复发风险仍在） | **可能根治——存在移植物抗白血病（GVL）效应** |
| 主要风险 | 无 GVHD；可能移植物中肿瘤污染 | **移植物抗宿主病（GVHD）**、植入失败、感染、肝窦阻塞综合征（SOS/VOD） |
| 前提 | 已达 CR 或疾病控制 | HLA 配型 + 预处理方案（清髓/减低强度） |

- **GVHD**：急性（移植后 100 天内——皮疹、黄疸、腹泻，靶器官皮肤/肝/肠）；慢性（硬皮样改变、干燥综合征样）；预防——CNI+MTX 等方案；治疗——激素、二线免疫抑制。
- 移植后监测：血象重建（植入证据）、嵌合率、微小残留病（MRD）、感染（CMV 等）与免疫重建。

### 继发性（慢性病）贫血（要点段落）

- 定义：慢性感染、炎症、恶性肿瘤、CKD 等所致贫血；机制——**炎症因子（IL-6→hepcidin↑）使铁滞留于巨噬细胞（铁代谢重排）+ EPO 生成受抑与红系抑制**。
- 实验室特征：**血清铁↓、TIBC↓、铁蛋白正常或升高、CRP/ESR↑**——与 IDA 的核心鉴别点是 **TIBC 与铁蛋白的方向相反**。
- 治疗：治疗基础病；CKD 与肿瘤相关者用重组 EPO（+铁剂维持铁储备）。
