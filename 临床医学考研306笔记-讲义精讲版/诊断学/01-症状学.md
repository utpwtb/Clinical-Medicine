## 第 1 节 发热

### 1.1 定义
- 发热：致热原作用于体温调节中枢，或体温中枢功能障碍，使**调定点上移**，产热增加、散热减少，体温升高超出正常范围。
- 正常体温：腋测法 36～37℃；口测法 36.3～37.2℃；肛测法 36.5～37.7℃。
- 体温升高 ≠ 发热：生理性升高（剧烈运动、进餐、月经前期、妊娠）与"过热"（中暑、甲亢危象、广泛皮肤病散热障碍）不经过调定点机制，不属于发热范畴。
- 病因两大类：
  1. **感染性发热**（最常见）：各种病原体——细菌、病毒、支原体、立克次体、螺旋体、真菌、寄生虫。
  2. **非感染性发热**：无菌性坏死物质吸收（心肌梗死、大手术后、烧伤）、抗原抗体反应（风湿热、SLE）、内分泌代谢障碍（甲亢、重度脱水）、皮肤散热减少、体温调节中枢功能障碍（中暑、脑出血）、自主神经功能紊乱（功能性低热）。

### 1.2 发生机制（必考逻辑链）
- 致热原性发热（绝大多数发热）：

  **外源性致热原**（病原体及其产物、内毒素、抗原抗体复合物、无菌坏死组织；分子量大，不能透过血脑屏障）→ 激活血中单核-巨噬细胞、内皮细胞等 → 释放**内源性致热原**（IL-1、TNF、IL-6、IFN 等）→ 作用于下丘脑体温调节中枢 → 合成释放 **PGE₂** → **体温调定点上移** → 产热增加、散热减少 → 体温升高。

- 由机制链推出的四个结论（命题点）：
  1. 外源性致热原**不直接**作用于体温调节中枢，必须通过内源性致热原介导。
  2. 解热镇痛药（抑制中枢 PGE₂ 合成）只对致热原性发热有效，对体温中枢直接破坏者基本无效。
  3. **非致热原性发热**：①体温调节中枢直接受损（颅脑外伤、脑出血、中暑）；②产热过多（甲亢、癫痫持续状态）；③散热障碍（广泛皮肤病、心力衰竭）——治疗以物理降温为主。
  4. 寒战提示调定点急速上移、散热骤减，常见于败血症、疟疾、急性胆道感染、输血反应。

### 1.3 发热分度（口温）
| 分度 | 体温 |
| --- | --- |
| 低热 | 37.3～38℃ |
| 中等度热 | 38.1～39℃ |
| 高热 | 39.1～41℃ |
| 超高热 | 41℃以上 |

### 1.4 六种热型与疾病配对（必背大表）
| 热型 | 体温特点 | 代表疾病 |
| --- | --- | --- |
| 稽留热 | 体温恒定维持于 39～40℃，24h 内波动 <1℃ | 大叶性肺炎、伤寒、斑疹伤寒高热期 |
| 弛张热（败血症热） | 常 >39℃，24h 波动 >2℃，最低点仍高于正常 | 败血症、风湿热、重症肺结核、化脓性感染 |
| 间歇热 | 体温骤升骤降，高热期与无热期反复交替 | 疟疾、急性肾盂肾炎 |
| 波状热 | 体温渐升至 39℃以上数日，又渐降至正常数日，反复呈波浪 | 布鲁菌病 |
| 回归热 | 骤升至 39℃以上持续数天后骤降至正常，高热期与无热期各持续数天、规律交替 | 回归热、霍奇金病（周期性发热，Pel-Ebstein 热） |
| 不规则热 | 发热曲线无规律 | 结核病、风湿热、支气管肺炎、渗出性胸膜炎；退热药/抗生素干扰后热型 |

- 提示：抗菌药、解热药、糖皮质激素可使典型热型变得不规则——先留取血培养再用药的意义所在。

### 1.5 发热与昏迷的先后关系（经典鉴别题）
| 先后关系 | 意义 | 代表疾病 |
| --- | --- | --- |
| 先发热后昏迷 | 发热为原发，提示全身性或颅内感染 | 乙型脑炎、流行性脑脊髓膜炎、伤寒、中毒型菌痢、重症肝炎、脑型疟疾 |
| 先昏迷后发热 | 昏迷为原发，发热继发（中枢性发热或合并感染） | 脑出血、蛛网膜下腔出血、巴比妥类药物中毒 |

### 1.6 伴随症状定位线索
| 伴随表现 | 提示疾病 |
| --- | --- |
| 寒战 | 败血症、疟疾、急性胆道感染、输血/输液反应 |
| 皮肤黏膜出血 | 流行性出血热（肾综合征出血热）、重症肝炎、败血症、急性白血病 |
| 口唇单纯疱疹 | 急性发热性疾病：大叶性肺炎、流行性脑脊髓膜炎、流感 |
| 淋巴结肿大 | 传染性单核细胞增多症、淋巴瘤、白血病、淋巴结结核 |
| 肝脾肿大 | 病毒性肝炎、传染性单核细胞增多症、疟疾、白血病、淋巴瘤 |
| 关节肿痛 | 败血症、风湿热、痛风、系统性红斑狼疮 |
| 皮疹 | 麻疹、猩红热、风疹、斑疹伤寒、药物疹 |
| 昏迷 | 见 1.5 先后关系表 |

### 1.7 高频考点提示
1. 机制链"外源致热原→内源性致热原（IL-1/TNF）→下丘脑 PGE₂→调定点上移"常以"下列哪项正确"形式出题。
2. 稽留热、弛张热、间歇热的"24 小时波动幅度"数值与代表疾病是高频配对。
3. "先昏迷后发热"四字可以直接排除大部分感染性疾病选项。

## 第 2 节 水肿

### 2.1 定义
- 水肿：组织间隙有过量液体积聚，使组织肿胀。显性水肿出现前体重常已增加（隐性水肿），短期体重明显增加是早期线索。
- 积液：液体积聚于体腔内（胸腔积液、腹腔积液、心包积液），为水肿的特殊形式。

### 2.2 发生机制（五条，必背）
1. **钠与水潴留**：肾小球滤过率下降或肾小管重吸收增加，继发性醛固酮增多（RAS 系统激活）——心、肝、肾性水肿的共同通路。
2. **毛细血管流体静压升高**：静脉回流受阻（右心衰竭、静脉血栓、肿瘤压迫）→ 组织液生成增加。
3. **血浆胶体渗透压降低**：低白蛋白血症（肾病综合征大量蛋白尿、肝硬化合成减少、营养不良摄入不足）→ 液体外渗。
4. **毛细血管通透性增高**：炎症、过敏、血管神经性水肿 → 局部红肿伴渗出。
5. **淋巴回流受阻**：丝虫病、淋巴结清扫或癌栓阻塞 → 蛋白与液体滞留于组织间隙（橡皮肿，非凹陷性）。

- 程度分级（凹陷性水肿）：轻度——踝部及胫前为主，指压后轻度凹陷；中度——全身疏松组织均可见，指压明显凹陷、平复缓慢；重度——全身严重水肿，可伴胸腔、腹腔、鞘膜腔积液。

### 2.3 全身性水肿五大病因鉴别（核心大表）
| 项目 | 心源性 | 肾源性 | 肝源性 | 营养不良性 | 黏液性（甲减） |
| --- | --- | --- | --- | --- | --- |
| 起始部位 | 下垂部位：立位自踝内侧、卧位自骶部 | 眼睑、颜面等组织疏松处 | 常以腹水为首发，后见下肢 | 足部开始，渐蔓延全身 | 颜面（眼睑、面部）及下肢 |
| 晨暮规律 | 晨轻暮重（受重力影响） | 晨起明显（夜里平卧，组织疏松处积液） | 随腹水与低蛋白程度进展 | 与营养状态相关 | 晨暮差异不明显 |
| 发展速度 | 较缓慢，逐渐上行 | 较快，可短期内全身 | 缓慢，伴腹水进行性加重 | 缓慢 | 缓慢 |
| 凹陷性 | 凹陷性 | 凹陷性 | 凹陷性 | 凹陷性 | **非凹陷性**（黏蛋白沉积） |
| 主要机制 | 毛细血管静水压↑、水钠潴留 | 胶体渗透压↓（蛋白尿）、水钠潴留 | 门脉高压＋白蛋白合成↓ | 低蛋白血症 | 淋巴回流障碍＋黏多糖沉积 |
| 主要伴随 | 颈静脉怒张、肝大、肝颈静脉回流征阳性 | 高血压、蛋白尿、血尿、管型尿 | 肝掌、蜘蛛痣、腹壁静脉曲张、脾大 | 消瘦、贫血、体重下降 | 怕冷、反应迟钝、心动过缓、便秘 |

### 2.4 局部性水肿
- 局部静脉回流受阻：血栓性静脉炎、上下腔静脉阻塞综合征。
- 淋巴回流受阻：丝虫病橡皮肿、癌性淋巴管阻塞、腋窝淋巴结清扫后。
- 炎症性水肿：局部红、肿、热、痛（蜂窝织炎、丹毒）。
- 血管神经性水肿：过敏所致，突发、可累及喉头（危险）。

### 2.5 高频考点提示
1. "为什么心源性水肿从下垂部位开始"——静水压升高叠加重力作用，低垂部位毛细血管流体静压最高。
2. "为什么肾源性水肿先见于眼睑"——平卧时组织疏松处静水压相对升高，且该处皮下组织最松软。
3. 凹陷性 vs 非凹陷性：黏液性水肿与淋巴性水肿（橡皮肿）为非凹陷性——记忆：两个"蛋白/黏液沉积"水肿不凹陷。
4. 心源性 vs 肾源性最常考鉴别点是**起始部位与晨暮规律**。

## 第 3 节 咯血与呕血

### 3.1 定义
- 咯血：喉及喉以下呼吸道任何部位出血，经口咯出。
- 呕血：上消化道疾病（Treitz 韧带以上：食管、胃、十二指肠、肝胆胰、胃空肠吻合术后）出血经口呕出。

### 3.2 咯血量分度
| 分度 | 24h 咯血量 |
| --- | --- |
| 小量 | <100ml |
| 中量 | 100～500ml |
| 大量（大咯血） | >500ml，或一次咯血 >100ml |

### 3.3 咯血 vs 呕血七维度大表（必考）
| 鉴别维度 | 咯血 | 呕血 |
| --- | --- | --- |
| 1. 病因 | 肺结核、支气管扩张、肺癌、肺炎、肺脓肿、二尖瓣狭窄、血液病 | 消化性溃疡、肝硬化食管胃底静脉曲张破裂、急性胃黏膜病变、胃癌、胆道出血 |
| 2. 出血前先兆 | 喉部痒感、胸闷、咳嗽 | 上腹部不适、恶心、呕吐 |
| 3. 出血方式 | 咯出 | 呕出，可为喷射状 |
| 4. 血的颜色 | 鲜红色 | 暗红色、棕黑色（咖啡渣样），出血快时亦可为鲜红 |
| 5. 血中混有物 | 痰、泡沫 | 食物残渣、胃液 |
| 6. 黑便 | 一般无（咽下血液时可有） | 常有，呈柏油样便，可持续数日 |
| 7. 酸碱反应（pH） | 碱性 | 酸性 |
| （补充）出血后痰的性状 | 常持续血痰数日 | 无痰 |

### 3.4 大咯血窒息（急症重点）
- 常见原因：血块阻塞大气道；体弱、咳嗽无力者更易发生。
- 窒息表现：咯血突然中止→烦躁、挣扎坐起→发绀、呼吸浅快→意识丧失、抽搐。
- 抢救体位：立即置患者于**头低足高 45°俯卧位**（或患侧卧位、头偏向一侧），轻拍背部促使血块排出，迅速清除口鼻腔血液血块；必要时气管插管吸引——窒息是大咯血的主要死因。
- 长期反复咯血者宜**患侧卧位**（保护健侧、防止血液流入健侧气道）。

### 3.5 咯血伴随症状配对
| 伴随表现 | 提示疾病 |
| --- | --- |
| 发热 | 肺结核、肺炎、肺脓肿、流行性出血热 |
| 大量脓痰 | 支气管扩张、肺脓肿 |
| 刺激性干咳 | 支气管肺癌 |
| 胸痛 | 大叶性肺炎、肺梗死、肺癌 |
| 皮肤黏膜出血 | 血液病、流行性出血热、钩端螺旋体病 |
| 黄疸 | 钩端螺旋体病、重症肝炎、肺梗死 |
| 心尖部舒张期隆隆样杂音 | 二尖瓣狭窄（肺静脉高压） |
| 反复咯血而无其他症状 | 支气管扩张 |

### 3.6 高频考点提示
1. 七维度鉴别表逐项记忆，最常考"颜色、混合物、黑便、pH"四项。
2. 大咯血窒息体位（头低足高位）几乎每年以 A1 或情境题形式出现。
3. 二尖瓣狭窄是心源性咯血的代表病因——瓣膜病可咯血，别只盯着呼吸系统。

## 第 4 节 呼吸困难

### 4.1 定义
- 呼吸困难：主观感到空气不足、呼吸费力；客观表现为呼吸运动用力，频率、深度、节律改变，重者鼻翼扇动、张口耸肩、辅助呼吸肌参与、发绀。

### 4.2 肺源性呼吸困难三型（核心表）
| 类型 | 机制 | 特点 | 代表疾病 |
| --- | --- | --- | --- |
| 吸气性 | 喉、气管、大支气管（大气道）狭窄梗阻 | 吸气费力、显著延长，**三凹征**（胸骨上窝、锁骨上窝、肋间隙吸气时凹陷），干咳及吸气性喉鸣 | 喉头水肿、气管异物、喉癌、气管肿瘤或外压性狭窄 |
| 呼气性 | 小支气管痉挛、狭窄，肺泡弹性减弱（小气道病变） | 呼气费力、呼气相延长，伴广泛哮鸣音 | 支气管哮喘、慢性阻塞性肺疾病 |
| 混合性 | 广泛肺实质/胸膜病变，呼吸面积减少 | 吸气呼气均费力，呼吸浅快 | 重症肺炎、大面积肺实变、大量胸腔积液、自发性气胸、间质性肺病 |

- 三凹征机制：大气道梗阻时吸气需克服更大阻力，胸腔负压显著增大，将胸壁软组织向内吸引。

### 4.3 心源性呼吸困难（左心衰竭为主）
- 渐进演变四阶段：**劳力性呼吸困难 → 夜间阵发性呼吸困难 → 端坐呼吸 → 急性肺水肿**。
- 夜间阵发性呼吸困难机制：平卧回心血量增加→夜间迷走神经张力增高→冠状动脉与外周小动脉收缩、肺血增多；熟睡中膈肌上抬、肺活量减少——患者憋醒、被迫坐起、重者咳粉红色泡沫痰。
- 急性左心衰（"心源性哮喘"）：端坐呼吸、大汗、咳粉红色泡沫痰、双肺满布湿啰音与哮鸣音、舒张期奔马律。
| 鉴别点 | 心源性哮喘 | 支气管哮喘 |
| --- | --- | --- |
| 病史 | 器质性心脏病（高血压、冠心病、瓣膜病） | 过敏史、幼年起反复发作 |
| 发作特点 | 夜间阵发、坐起可减 | 发作性呼气性呼吸困难，可自行或用药缓解 |
| 痰 | 粉红色泡沫痰 | 白色黏痰 |
| 体征 | 双肺底湿啰音为主＋哮鸣音、奔马律、心界大 | 双肺广泛哮鸣音、呼气延长 |
| 治疗反应 | 强心、利尿、扩血管有效 | 支气管扩张剂有效 |
| ⚠ | 无法鉴别时不宜贸然用吗啡或大量 β₂ 受体激动剂，需先明确心功能 | |

### 4.4 中毒性、血源性、神经精神性呼吸困难
- **Kussmaul 呼吸**（深大而规则、酸中毒大呼吸）：代谢性酸中毒时呼吸代偿排出 CO₂——糖尿病酮症酸中毒、尿毒症、肾小管酸中毒。
- 药物中毒：吗啡、巴比妥类——呼吸浅慢、节律异常（呼吸中枢抑制）。
- 血源性：重度贫血、高铁血红蛋白血症、CO 中毒——携氧能力下降，呼吸浅快。
- 神经精神性：
  - **潮式呼吸（Cheyne-Stokes 呼吸）**：呼吸由浅慢渐深快再浅慢、暂停数十秒周期出现——大脑（间脑）水平损伤、心力衰竭、尿毒症晚期（脑血流下降）。
  - **间停呼吸（Biot 呼吸）**：有规律呼吸几次后突然停止数秒又开始——脑桥/延髓水平损伤，较潮式呼吸更严重，预后差。
  - 叹气样呼吸：神经官能症。
  - 癔症性：浅快、过度通气→呼吸性碱中毒→手足搐搦（血钙离子降低）。
- 呼吸频率与节律变化小结（详见 02 体格检查第 4 节）：
| 变化 | 意义 |
| --- | --- |
| 呼吸过速（>20 次/分） | 发热、疼痛、贫血、甲亢、心衰 |
| 呼吸过缓（<12 次/分） | 麻醉药/镇静剂过量、颅内压增高 |
| 深大呼吸（Kussmaul） | 代谢性酸中毒（糖尿病酮症、尿毒症） |
| 潮式呼吸（Cheyne-Stokes） | 间脑/大脑水平损害、心力衰竭、尿毒症晚期 |
| 间停呼吸（Biot） | 脑桥/延髓损害，较潮式呼吸更危重 |

### 4.5 高频考点提示
1. 三凹征 = 吸气性 = 大气道；呼气性哮鸣 = 小气道——机制与部位配对是最高频考法。
2. Kussmaul 呼吸的疾病对应（酮症、尿毒症）与潮式/间停呼吸的中枢定位必背。
3. 心源性哮喘四阶段递进顺序常以排序题出现。

## 第 5 节 胸痛

### 5.1 概述
- 胸痛病因繁杂，危险度分层是核心：先识别**致命性胸痛**（ACS、主动脉夹层、肺栓塞、张力性气胸、食管破裂），再考虑一般病因。

### 5.2 五种危险胸痛（核心大表）
| 疾病 | 疼痛特点 | 部位与放射 | 伴随与关键线索 |
| --- | --- | --- | --- |
| 急性冠脉综合征（ACS） | 压榨样、紧缩感、濒死感，常 >10～20min 不缓解 | 胸骨后，向左肩、左臂内侧、颈部放射 | 大汗、恶心呕吐；含服硝酸甘油不能完全缓解（心梗）；ECG＋心肌标志物 |
| 主动脉夹层 | 突发撕裂样/刀割样剧痛，迅速达高峰 | 胸背部，可沿夹层走向向下放射迁移 | 血压可升高、双上肢血压差 >20mmHg、脉搏不对称；D-二聚体、CTA |
| 急性肺栓塞 | 呼吸相关胸膜性胸痛，可伴心绞痛样痛 | 患侧胸部 | **呼吸困难＋胸痛＋咯血"三联"**、低氧血症、D-二聚体、下肢深静脉血栓 |
| 张力性气胸 | 突发一侧针刺样或刀割样痛 | 患侧 | 进行性呼吸困难、皮下气肿、气管移向健侧、患侧呼吸音消失、叩诊鼓音 |
| 食管破裂（Boerhaave） | 剧烈呕吐后胸骨后/上腹剧痛 | 胸骨后、上腹 | 皮下气肿、纵隔气肿、液气胸；呕血后胸痛＋发热要警惕 |

### 5.3 常见非危险胸痛
| 疾病 | 疼痛特点 | 鉴别线索 |
| --- | --- | --- |
| 胸膜炎 | 尖锐刺痛，**与呼吸、咳嗽明显相关** | 患侧卧位可减轻；闻及胸膜摩擦音 |
| 带状疱疹 | 灼痛/刀割样，沿一侧肋间神经分布 | **不越过中线**；成簇疱疹可晚于疼痛出现 |
| 肋软骨炎 | 局部钝痛，有固定压痛 | 第 2～4 肋软骨处隆起压痛 |
| 反流性食管炎 | 烧灼痛，胸骨后 | 与体位（平卧、弯腰）、进食相关，抑酸有效 |
| 心脏神经官能症 | 部位不定、多变，短暂刺痛或持续隐痛 | 与情绪相关，长叹气后觉舒适 |

### 5.4 高频考点提示
1. 五种危险胸痛的"疼痛性质关键词"：压榨（ACS）、撕裂（夹层）、三联（肺栓塞）、皮下气肿（气胸/食管破裂）——关键词配对题。
2. 主动脉夹层的特征性体征是**双上肢血压不对称**。
3. 心包炎性胸痛与体位相关：前倾坐位减轻、平卧加重，与呼吸亦相关。

## 第 6 节 腹痛

### 6.1 腹痛发生机制三型（必考表）
| 机制 | 传入神经与感受器 | 疼痛特点 | 代表情形 |
| --- | --- | --- | --- |
| 内脏性腹痛 | 交感/副交感内脏神经传入；对牵拉、痉挛、缺血敏感，对切割、烧灼不敏感 | 部位模糊、近腹中线；钝痛、胀痛、痉挛性绞痛；伴恶心、呕吐、出汗等自主神经症状；不伴明确压痛 | 胃肠痉挛、空腔脏器扩张（早期阑尾炎脐周痛） |
| 躯体性腹痛 | 壁层腹膜及腹壁受刺激，经体神经（肋间神经、腰神经）传入 | 定位准确、疼痛剧烈而持续；锐痛；咳嗽、体位变动加重；有压痛、反跳痛等腹膜刺激征 | 溃疡穿孔波及腹膜、化脓性腹膜炎 |
| 牵涉痛 | 内脏痛觉冲动定位于相应脊髓节段支配的体表区域 | 疼痛剧烈、部位明确、局部无压痛 | 胆囊疾病→右肩背；胰腺炎→左腰背束带状；输尿管结石→会阴部；心梗→上腹痛 |

### 6.2 八大急腹症要点表（核心大表）
| 疾病 | 疼痛特点 | 体征 | 关键检查/线索 |
| --- | --- | --- | --- |
| 急性阑尾炎 | **转移性右下腹痛**：上腹/脐周数小时后定位于右下腹 | 麦氏点固定压痛、反跳痛，腰大肌试验、闭孔内肌试验阳性 | 血白细胞↑；机制：早期为内脏性痛，炎症波及壁层腹膜后转为躯体性定位痛 |
| 急性胰腺炎 | 持续性上腹剧痛，向腰背部**束带状**放射 | 弯腰屈膝位可减轻；重症者 Grey-Turner 征（腰胁瘀斑）、Cullen 征（脐周瘀斑） | 血/尿淀粉酶↑、脂肪酶↑；诱因：胆石、暴食、饮酒 |
| 急性胆囊炎/胆石症 | 右上腹绞痛，向右肩背放射，进食油腻诱发 | **Murphy 征阳性**；胆管炎时 Charcot 三联征（腹痛＋寒战高热＋黄疸） | 超声：胆囊壁增厚、结石 |
| 消化性溃疡穿孔 | 突发刀割样上腹痛，迅速波及全腹 | **板状腹**、显著压痛反跳痛、肝浊音界缩小或消失 | 立位腹部 X 线：**膈下游离气体** |
| 肠梗阻 | 阵发性绞痛 | **"痛、吐、胀、闭"四联征**；肠型、蠕动波；机械性者肠鸣音亢进、气过水声/金属音 | 立位 X 线：阶梯状气液平面 |
| 异位妊娠破裂 | 育龄女性，一侧下腹撕裂样痛 | 肛门坠胀、阴道不规则流血、休克；宫颈举痛、后穹窿饱满 | 停经史＋血/尿 hCG 阳性；阴道后穹窿穿刺抽出不凝血 |
| 输尿管结石 | 腰腹部阵发性绞痛，向会阴部、大腿内侧放射 | 肾区（肋脊角）叩击痛、输尿管走行区压痛 | 镜下血尿；超声/CT |
| ⚠ 急腹症镇痛原则 | **未明确诊断前禁用强效镇痛药（吗啡类）** | —— | 以免掩盖症状与体征延误诊断；诊断明确后可规范镇痛 |

### 6.3 伴随症状定位线索
| 伴随表现 | 提示疾病 |
| --- | --- |
| 发热、寒战 | 胆道感染、腹腔脓肿、门静脉炎 |
| 黄疸 | 肝胆胰疾病（胆总管结石、胰头癌、肝炎） |
| 休克 | 异位妊娠破裂、脏器穿孔、急性重症胰腺炎、大出血 |
| 呕吐隔夜宿食 | 幽门梗阻 |
| 血尿 | 泌尿系结石、肿瘤 |
| 腹泻 | 肠炎、肠结核、克罗恩病 |
| 反酸烧心、周期节律性上腹痛 | 消化性溃疡 |

### 6.4 高频考点提示
1. 内脏性/躯体性/牵涉痛三机制的"定位准不准、有无腹膜刺激征"对比是每年的基础送分点。
2. 转移性右下腹痛（阑尾炎）、束带状（胰腺炎）、板状腹＋膈下游离气体（穿孔）、痛吐胀闭（肠梗阻）四组关键词必须秒答。
3. 未确诊急腹症禁用强效镇痛药——常以"下列处理错误的是"形式考。

## 第 7 节 呕血与黑便

### 7.1 定义与机制
- 呕血：上消化道（Treitz 韧带以上）出血经口呕出；黑便：血红蛋白的铁经肠内硫化物作用形成**硫化铁**，使粪便呈黑色、附黏液而发亮（柏油样便）。
- 上消化道或高位小肠出血均可出现黑便；出血速度快、量大时可兼有呕血与暗红血便。

### 7.2 出血量与临床表现数值链（必背）
| 每日出血量 | 临床表现 |
| --- | --- |
| >5ml | 粪便隐血试验阳性 |
| >50ml | 出现黑便 |
| 胃内积血 250～300ml | 可引起呕血 |
| <400ml | 一般不出现全身症状（血容量可代偿） |
| >400ml | 头晕、心悸、乏力、出冷汗、脉快 |
| 短期内 >1000ml | 周围循环衰竭（休克）：脉搏细速 >120 次/分、血压下降、皮肤湿冷花斑、少尿、意识改变 |

### 7.3 病因与伴随配对
| 线索 | 提示疾病 |
| --- | --- |
| 慢性、周期性、节律性上腹痛 | 消化性溃疡（最常见病因之一） |
| 肝硬化征象（蜘蛛痣、肝掌、腹水、脾大） | 食管胃底静脉曲张破裂——量大、常呈鲜红、凶险 |
| 服药史（NSAID、糖皮质激素）或酗酒 | 急性胃黏膜病变 |
| 剧烈呕吐后呕血 | Mallory-Weiss 综合征（食管贲门黏膜撕裂） |
| 黄疸＋无痛性胆囊肿大 | 胰头癌/壶腹周围癌侵犯胆道、十二指肠 |
| 皮肤黏膜出血、发热、贫血 | 血液病、重症感染 |
| 40 岁以上、消瘦、粪便隐血持续阳性 | 胃癌 |

### 7.4 高频考点提示
1. 数值链 5→50→250-300→400→1000 ml 与对应表现必须逐级准确，是内科学+诊断学双重高频。
2. 黑便机制（硫化铁）与柏油样便的外观描述为名词解释级考点。
3. 判断出血是否继续：反复呕血/黑便变稀变暗红、肠鸣音亢进、血红蛋白继续下降、尿素氮持续升高等。

## 第 8 节 黄疸

### 8.1 定义与正常值
- 黄疸：血清总胆红素浓度升高使皮肤、黏膜、巩膜黄染。
- 正常血清总胆红素 1.7～17.1μmol/L（结合胆红素 0～6.8μmol/L，非结合胆红素 1.7～10.2μmol/L）。
- **隐性黄疸**：17.1～34.2μmol/L，肉眼难以察觉；>34.2μmol/L 为显性黄疸。

### 8.2 胆红素正常代谢（理解三型的钥匙）
1. 衰老红细胞在单核-巨噬系统破坏 → 释出血红素 → 转变为**非结合胆红素（UCB）**：不溶于水，与白蛋白结合运输，**不能经肾排出**，凡登白试验间接反应。
2. 肝细胞摄取 UCB → 经葡萄糖醛酸转移酶结合为**结合胆红素（CB）**：水溶性，**可经肾排出**，直接反应。
3. CB 随胆汁排入肠道 → 细菌还原为**尿胆原** → 氧化为尿胆素（粪便主要色素）；约 10%～20% 尿胆原被肠道重吸收 → 门静脉入肝（肠肝循环）→ 少量经尿排出。

### 8.3 三型黄疸鉴别大表（必背核心）
| 项目 | 溶血性黄疸 | 肝细胞性黄疸 | 胆汁淤积性黄疸（阻塞性） |
| --- | --- | --- | --- |
| 病因 | 红细胞大量破坏，UCB 生成过多，肝摄取处理能力相对不足 | 肝细胞损伤，摄取、结合、排泄均受损；血中 CB 与 UCB 均升高 | 胆道阻塞，毛细胆管内压升高破裂，CB 反流入血 |
| 升高的胆红素 | **UCB↑↑** | CB 与 UCB 均↑ | **CB↑↑** |
| 尿胆红素 | 阴性（UCB 不溶于水不能经肾排出） | 阳性 | 强阳性（胆红素尿，尿色深黄如浓茶） |
| 尿胆原 | 明显增加 | 轻度增加或正常 | 减少或缺如 |
| 粪便颜色 | 加深 | 正常或变浅 | 变浅或陶土色 |
| 皮肤瘙痒 | 无或轻 | 无或轻 | **明显**（胆盐刺激皮肤感觉神经末梢） |
| 皮肤色泽 | 浅柠檬色 | 浅黄至深黄 | 暗黄、黄绿或绿褐色 |
| 其他实验室 | 贫血、网织红细胞↑、骨髓红系增生 | ALT/AST↑↑、白蛋白↓ | AKP、GGT↑↑，胆固醇↑ |
| 代表疾病 | 蚕豆病、海洋性贫血、PNH、自身免疫性溶血 | 病毒性肝炎、肝硬化、中毒性肝损伤 | 胆总管结石、胰头癌、壶腹周围癌、药物性胆汁淤积 |

### 8.4 Courvoisier 征（库瓦济埃征）
- 胰头癌、壶腹周围癌压迫胆总管 → 进行性梗阻性黄疸＋**胆囊显著肿大但无压痛**。
- 鉴别意义：胆总管结石多伴慢性胆囊炎、胆囊壁纤维化收缩，虽亦梗阻但**胆囊常不肿大**——"结石性黄疸胆囊不大，癌性黄疸胆囊肿大"。

### 8.5 伴随症状配对
| 伴随表现 | 提示疾病 |
| --- | --- |
| 发热、寒战＋上腹剧痛＋黄疸 | Charcot 三联征——胆总管结石并急性胆管炎 |
| 腹水 | 重症肝炎、肝硬化失代偿、肝癌 |
| 无痛性进行性黄疸＋胆囊肿大＋消瘦 | 胰头癌、壶腹周围癌 |
| 明显瘙痒＋陶土色便 | 胆汁淤积（结石波动性、肿瘤进行性） |
| 贫血、脾大、血红蛋白尿 | 溶血性黄疸 |

### 8.6 先天性非溶血性黄疸（了解）
- Gilbert 综合征：肝摄取 UCB 障碍，UCB 升高；Dubin-Johnson 与 Rotor 综合征：CB 排泄障碍，CB 升高——常为良性、慢性间歇性。

### 8.7 高频考点提示
1. 三型黄疸表必须整表默写级掌握，尤其"尿胆红素、尿胆原"两项的组合（-/+、↑/↓）。
2. 溶血性黄疸尿胆红素阴性的机制（UCB 不溶于水不能经肾排出）与梗阻性黄疸瘙痒的机制（胆盐刺激）是机制题双热点。
3. 隐性黄疸 17.1～34.2μmol/L 数值边界常作为单选。

## 第 9 节 皮肤黏膜出血

### 9.1 概述与分类
- 病因三大类：**血管壁缺陷**、**血小板数量或功能异常**、**凝血功能障碍**；另有抗凝物质增多、纤溶亢进。
- 按直径分类：瘀点（<2mm）、紫癜（3～5mm）、瘀斑（>5mm）；片状出血伴皮肤显著隆起为**血肿**。

### 9.2 瘀点、紫癜 vs 充血性皮疹（必考点）
- 瘀点、紫癜：毛细血管或小血管破裂、血液外渗至皮下，**指压不褪色**，不高出皮面（过敏性紫癜可略隆起）。
- 充血性皮疹：小血管扩张充血所致，**指压褪色**、压迫后退色复又显现。

### 9.3 三类出血特点鉴别表
| 项目 | 血管壁/血管性异常 | 血小板异常 | 凝血功能异常 |
| --- | --- | --- | --- |
| 出血表现 | 瘀点、瘀斑为主 | 瘀点、紫癜、瘀斑，牙龈及鼻出血、月经过多 | 深部组织**血肿**、**关节腔出血**、大片瘀斑 |
| 出血方式 | 自发出血为主，创面压迫可止血 | 自发出血为主，创伤后即刻出血、渗血不止 | **延迟性出血**：外伤或术后出血不止 |
| 深部出血 | 罕见 | 较少（严重血小板减少可颅内出血） | 多见（肌肉、关节、内脏，血友病典型） |
| 代表疾病 | 过敏性紫癜（对称分布于下肢伸侧、成批出现，可伴腹痛、关节痛、肾损害）、单纯性紫癜 | ITP（血小板减少）、血小板无力症（功能异常）、再生障碍性贫血、白血病 | 血友病 A/B（Ⅷ/Ⅸ缺乏）、维生素 K 缺乏、严重肝病、DIC、抗凝药过量 |

### 9.4 伴随症状配对
| 伴随表现 | 提示疾病 |
| --- | --- |
| 对称性下肢紫癜＋腹痛＋关节痛＋血尿 | 过敏性紫癜（混合型/腹型/肾型） |
| 广泛出血＋发热＋贫血 | 急性白血病、再生障碍性贫血 |
| 出血＋黄疸、肝掌、蜘蛛痣 | 严重肝病凝血障碍 |
| 幼年起病、家族史、关节血肿 | 遗传性凝血病（血友病） |
| 出血＋微血管病性溶血、器官损害 | DIC、血栓性血小板减少性紫癜 |

### 9.5 高频考点提示
1. "压之褪色与否"是紫癜与充血性皮疹的唯一快速鉴别，题干必给。
2. 血小板异常=皮肤黏膜浅表出血；凝血异常=深部血肿＋关节腔出血——层次定位题。

## 第 10 节 意识障碍

### 10.1 定义与解剖基础
- 意识障碍：中枢神经系统对内外环境刺激的应答能力下降或丧失。
- 解剖基础：**觉醒**依赖脑干网状上行激动系统；**意识内容**（思维、记忆、定向、情感）依赖大脑皮质——两者任一受损均可致意识障碍。

### 10.2 意识障碍分级表（必背核心）
| 分级 | 意识状态 | 对刺激的反应 | 反射与生命体征 |
| --- | --- | --- | --- |
| 嗜睡（最轻） | 持续睡眠状态 | 可被唤醒，醒后能正确回答、配合查体；刺激停止后迅速入睡 | 生理反射存在，生命体征平稳 |
| 意识模糊 | 意识水平下降 | 能保持简单精神活动，但对时间、地点、人物的**定向力障碍**，思维语言不连贯 | 生理反射存在 |
| 昏睡 | 接近人事不省 | 强烈刺激（压眶、摇动）可唤醒，醒时答话含糊或答非所问，随即再入睡 | 角膜反射、瞳孔对光反射存在 |
| 浅昏迷 | 意识大部分丧失，无自主运动 | 对声光无反应；对疼痛刺激仍有痛苦表情或肢体退缩等防御反应 | 角膜反射、瞳孔对光反射、吞咽反射存在，生命体征平稳 |
| 中度昏迷 | 意识丧失 | 对强刺激的防御反射、角膜反射减弱，瞳孔对光反射迟钝，眼球无转动 | 反射减弱，生命体征轻度波动 |
| 深昏迷（最重） | 意识完全丧失 | 对各种刺激全无反应，全身肌肉松弛 | **深浅反射均消失**，生命体征异常（呼吸不规则、血压下降） |

### 10.3 谵妄
- 以**兴奋性增高**为主的急性高级神经中枢功能失调状态：意识模糊、定向力丧失、错觉与幻觉、躁动不安、言语杂乱。
- 特点：急性起病、症状昼夜波动（夜间加重）；常见于感染高热期、药物或酒精戒断、代谢性脑病、老年术后。
- 与昏迷的关系：可发展为昏迷；部分患者躁动与嗜睡交替。

### 10.4 特殊意识状态（了解）
- 去皮质（大脑）综合征：无意识睁眼闭眼、睡眠觉醒周期存在，上肢屈曲、下肢伸直——大脑皮质广泛损害而脑干功能保留。
- 无动性缄默：能注视周围但缄默不语、四肢不动——脑干网状上行激动系统受损。
- 闭锁综合征：意识清楚，仅能以眼球垂直运动和眨眼示意——脑桥基底部病变（"只睁眼睛不动弹"）。

### 10.5 常见病因分类（先分类再定位）
- 重症急性感染：脑炎、脑膜炎、败血症、中毒型菌痢、伤寒、脑型疟疾。
- 非感染性脑部病变：脑出血、脑梗死、脑肿瘤、脑外伤、癫痫持续状态。
- 内分泌与代谢性脑病：糖尿病酮症酸中毒/高渗昏迷、低血糖、尿毒症、肝性脑病、肺性脑病、严重水电解质紊乱。
- 外源性中毒：镇静催眠药、有机磷杀虫药、酒精、一氧化碳。
- 物理与缺氧性损害：中暑、触电、溺水、严重窒息。

### 10.6 意识障碍的定位组合（重要）
| 组合 | 提示疾病 |
| --- | --- |
| 意识障碍＋**脑膜刺激征**（颈强直、Kernig 征、Brudzinski 征） | 脑膜炎（流脑、结脑）、蛛网膜下腔出血 |
| 意识障碍＋局灶性神经体征（偏瘫、瞳孔不等大） | 脑出血、大面积脑梗死、脑疝 |
| 意识障碍＋瞳孔针尖样 | 脑桥出血、有机磷中毒、吗啡中毒 |
| 意识障碍＋呼吸形式改变（潮式/间停） | 中枢损害由大脑向脑干发展，提示病情恶化 |
| Glasgow 昏迷评分（睁眼 1～4＋语言 1～5＋运动 1～6，满分 15） | ≤8 分判定为昏迷（⚠ 各版本判读细则请核对教材） |

### 10.7 高频考点提示
1. 六级分层的"能否唤醒、答话质量、反射存否"三要素对比必须逐级区分，昏睡与浅昏迷最易混淆（昏睡强刺激**可**唤醒）。
2. 谵妄定义中的"兴奋性增高＋定向力丧失＋幻觉错觉"三要素。
3. 脑膜刺激征＋意识障碍的组合意义直接指向脑膜炎/SAH，是病例题的钥匙句。
