> 本册为 2028 届临床医学专硕 306 统考"讲义精讲版"诊断学部分第 2 册，供一轮精读与二轮背诵使用。

## 第 1 节 基本检查方法与叩诊音

### 1.1 视触叩听四法
- 视诊：观察全身与局部状态，光线与体位影响判断。
- 触诊：浅部触诊（约 1cm 深，体表与浅在病变）、深部触诊（2cm 以上，腹腔脏器与包块；含深部滑行、双手、深压、冲击触诊）。
- 叩诊：借叩击身体表浅部位产生的振动与声响判断脏器状态；分为直接叩诊与间接叩诊（指指叩诊，临床最常用）。
- 听诊：心肺听诊为主，听诊器膜面听高调音（呼吸音、瓣膜音）、钟面听低调音（二尖瓣狭窄舒张期隆隆样杂音、胎心音）。
- 嗅诊：烂苹果味——糖尿病酮症酸中毒；氨味——尿毒症；肝腥味——肝性脑病；大蒜味——有机磷中毒。

### 1.2 叩诊五音（必背配对）
| 叩诊音 | 声学特点 | 正常见于 | 病理见于 |
| --- | --- | --- | --- |
| 清音 | 音调低、音响强、历时较长 | 正常肺部 | —— |
| 鼓音 | 谐音，音调低、音响更强 | 胃泡区（Traube 鼓音区）、腹部 | 气胸、靠近胸壁的大空洞（肺结核空洞、肺脓肿） |
| 过清音 | 介于清音与鼓音之间 | 正常儿童肺（胸壁薄者） | **肺气肿**（含气量增多、弹性下降） |
| 浊音 | 音调高、音响较弱 | 心肝被肺缘覆盖的部分 | 肺实变（含气减少）、胸腔积液上方（被肺压缩） |
| 实音 | 音调更高、音响更弱 | 心脏、肝脏无肺遮盖区 | 大量胸腔积液、肺实变完全不含气 |

## 第 2 节 一般检查

### 2.1 生命体征与发育营养
- 体温、脉搏、呼吸、血压为四大体征；正常成人呼吸 16～20 次/分，脉搏 60～100 次/分。
- 体质指数（BMI）= 体重（kg）/ 身高²（m²）；18.5～23.9 为正常（⚠ 中国成人标准请核对）。
- 急性病容：面色潮红、兴奋不安、呼吸急促、痛苦呻吟——急性感染（大叶性肺炎、疟疾）。
- 慢性病容：面容憔悴、面色晦暗、目光暗淡——慢性消耗性疾病（肝硬化、结核、恶性肿瘤）。
- 甲亢面容：惊愕表情、眼裂增宽、眼球突出、目光炯炯、烦躁易怒。
- 黏液性水肿面容：面色苍黄、颜面浮肿、睑厚面宽、目光呆滞、反应迟钝、眉发稀疏——甲状腺功能减退。
- 满月面容：面圆如满月、皮肤发红、痤疮、向心性肥胖——库欣综合征、长期应用糖皮质激素。
- 肢端肥大症面容：头颅增大、面部变长、下颌前突、眉弓及两颧隆起、耳鼻增大。
- 肝病面容：面色晦暗、额部与鼻背双颊色素沉着——慢性肝病。
- 贫血面容：面色苍白、唇舌色淡、疲乏无力。
- 伤寒面容：表情淡漠、反应迟钝呈无欲貌——伤寒等高热衰竭患者。

### 2.2 体位
| 体位 | 意义 |
| --- | --- |
| 自主体位 | 正常或轻症 |
| 被动体位 | 患者不能自行调整——极度衰弱、意识丧失 |
| 强迫端坐位（端坐呼吸） | 心功能不全（急性左心衰）：坐位回心血量减少、膈肌下降增加肺活量 |
| 强迫蹲位 | 发绀型先天性心脏病（法洛四联症） |
| 辗转体位 | 胆绞痛、肾绞痛、胆道蛔虫 |
| 角弓反张位 | 破伤风、脑膜炎 |
| 强迫仰卧位 | 急性腹膜炎 |
| 强迫俯卧位 | 脊柱疾病 |

### 2.3 皮疹五型（必背）
| 类型 | 特点 | 代表疾病 |
| --- | --- | --- |
| 斑疹 | 只有局部颜色改变、不隆起皮面 | 斑疹伤寒、丹毒、风湿性多形红斑 |
| 丘疹 | 除颜色改变外、隆起皮面 | 药物疹、麻疹、猩红热、湿疹 |
| 斑丘疹 | 丘疹周围有皮肤发红的底盘 | 风疹、猩红热、药物疹 |
| 荨麻疹 | 稍隆起皮面的苍白色或红色局限性水肿，速起速退 | 各种过敏反应 |
| 疱疹 | 隆起、内含液体 | 水痘、带状疱疹、接触性皮炎 |

- **玫瑰疹**：伤寒的特征性皮疹——淡红色小斑丘疹，直径 2～4mm，压之褪色，多分布于胸腹部，分批出现，于病程第 7～13 天出现。
- 皮下出血：瘀点（<2mm）、紫癜（3～5mm）、瘀斑（>5mm）——压之**不褪色**，与充血性皮疹相鉴别（见 01 症状学）。

### 2.4 蜘蛛痣与肝掌
- 蜘蛛痣：皮肤小动脉末端分支扩张形成的血管痣，中心小动脉向四周辐射，压迫中心痣体可褪色消失、解除压迫复现。
- 分布区域：**上腔静脉引流区**——面、颈、手背、上臂、前胸、肩部。
- 机制：肝脏对**雌激素灭活能力减退**，体内雌激素水平相对升高（慢性肝炎、肝硬化；青春期与妊娠期少数正常人亦可出现）。
- 肝掌：手掌大小鱼际发红、加压褪色——机制同蜘蛛痣。
- 判读注意：慢性肝病患者蜘蛛痣的数量与大小可随肝功能波动；数量多、体积大者提示肝硬化可能。

### 2.5 浅表淋巴结
- 正常淋巴结：较小（直径多 0.2～0.5cm）、质软、光滑、无压痛、可推动，一般不易触及。
- 局部淋巴结肿大配对表：
| 性质 | 特点 | 代表疾病 |
| --- | --- | --- |
| 非特异性炎症 | 质软、有压痛、表面光滑、不粘连 | 所属引流区感染（口腔感染→颌下淋巴结） |
| 结核性 | 常颈部多枚、串珠状，质稍硬、互相粘连，破溃后形成瘘管 | 淋巴结结核 |
| 恶性肿瘤转移 | 质硬、无压痛、与周围组织粘连固定 | **Virchow 淋巴结**：左锁骨上淋巴结肿大——胃癌、食管癌转移的标志（胃、食管淋巴经胸导管汇入左静脉角） |
| 白血病/淋巴瘤 | 全身性、质韧或硬、无压痛、可融合 | 白血病、霍奇金/非霍奇金淋巴瘤 |
- 各区引流与病因推断：颌下——口腔、咽部感染；腋窝——上肢、乳腺；腹股沟——下肢、会阴、外生殖器；左锁骨上——Virchow 淋巴结（胃、食管癌经胸导管转移）；右锁骨上——多与肺、纵隔病变相关（⚠ 定位细节请核对教材）。
- 全身性淋巴结肿大：遍及全身、大小不等、无粘连——淋巴瘤、白血病、传染性单核细胞增多症、系统性红斑狼疮、艾滋病等。

## 第 3 节 头颈部检查

### 3.1 瞳孔（神经科窗口）
| 表现 | 机制/定位 | 代表疾病 |
| --- | --- | --- |
| 针尖样瞳孔 | 缩瞳中枢/交感受抑 | **有机磷中毒、吗啡中毒、脑桥出血** |
| 瞳孔散大 | 动眼神经麻痹、濒死 | 阿托品类药物中毒、视神经萎缩、濒死状态 |
| 双侧不等大＋对光反射消失 | 小脑幕切迹疝压迫一侧动眼神经 | 颅内高压、脑疝——危象 |
| 双侧不等大、变化不定 | 中脑病变 | 中脑损害 |
| Horner 征（同侧瞳孔缩小、上睑下垂、眼球内陷、面部无汗） | 颈交感神经节麻痹 | 肺上沟癌（Pancoast 瘤）、颈部外伤 |

### 3.2 颈部血管（右心与前负荷的窗口）
| 体征 | 判读 | 代表疾病 |
| --- | --- | --- |
| 颈静脉怒张 | 取 45°半卧位，颈静脉充盈超过正常水平（锁骨上缘至下颌角距离下 1/3 以内） | **右心衰竭、缩窄性心包炎、心包积液、上腔静脉阻塞综合征**——静脉回流受阻、静脉压升高 |
| 肝颈静脉回流征阳性 | 按压淤血肿大的肝脏 30～40s，颈静脉充盈更加明显 | 右心衰竭、缩窄性心包炎、心包积液——机制：按压肝脏使回心血量骤增，右心无法容纳而反充颈静脉；上腔静脉阻塞者此征**阴性**（鉴别点） |
| 颈动脉搏动明显（静息下可见） | 心搏量增加、脉压增大 | 主动脉瓣关闭不全、高血压、甲状腺功能亢进、严重贫血 |
| 颈静脉搏动 | 三尖瓣关闭不全（心室收缩血液反流至颈静脉） | 三尖瓣关闭不全——与颈动脉搏动的鉴别：颈静脉搏动柔和、弥漫、触诊无搏动感 |

### 3.3 甲状腺
- 视诊：观察大小与对称性，让患者做吞咽动作（甲状腺随吞咽上下移动——与颈前其他包块鉴别）。
- 触诊分度（必背）：
| 分度 | 标准 |
| --- | --- |
| Ⅰ度 | 不能看到但能触及 |
| Ⅱ度 | 能看到又能触及，但未超出胸锁乳突肌外缘 |
| Ⅲ度 | 超过胸锁乳突肌外缘 |
- 听诊：**Graves 病**——甲状腺血流增多，可闻及**连续性血管杂音**、触及震颤，是特征性体征。
- 注意：甲状腺癌质硬固定、表面不平，压迫喉返神经时伴声音嘶哑——颈部包块＋声嘶要警惕。
- 常见甲状腺疾病触感配对：Graves 病——弥漫性对称肿大、质软；桥本甲状腺炎——质韧如橡皮；结节性甲状腺肿/腺瘤——单发或多发结节；甲状腺癌——质硬、固定、表面不平。

### 3.4 气管移位方向表（必背）
| 病变 | 机制 | 气管移位方向 |
| --- | --- | --- |
| 大量胸腔积液、气胸、纵隔肿瘤 | 病侧胸内压增高，**推**挤纵隔 | 移向**健侧** |
| 肺不张、广泛肺纤维化、胸膜增厚粘连 | 病侧容积缩小，**拉**向病侧 | 移向**患侧** |
- 主动脉弓动脉瘤时，随心脏搏动可触及气管向下拽曳（Oliver 征，了解）。

## 第 4 节 胸部与肺检查

### 4.1 胸廓与胸壁
- 正常成人胸廓前后径与左右径之比约 1:1.5。
- **桶状胸**：前后径增大、与左右径几乎相等，肋间隙饱满增宽，呈圆桶状——严重肺气肿（哮喘慢支晚期）、老年人矮胖者生理性变圆。
- 佝偻病胸：鸡胸、漏斗胸、佝偻病串珠（沿肋骨与肋软骨交界处球形隆起）。
- 胸壁皮下气肿：按压有**捻发感/握雪感**，听诊有捻发音——气胸、纵隔气肿气体逸入皮下。

### 4.2 呼吸运动与频率
- 正常呼吸 16～20 次/分，呼吸过速 >20 次/分（发热时体温每升高 1℃，呼吸约增加 3～4 次/分）；过缓 <12 次/分（麻醉药、颅内压增高）。
- 胸式/腹式呼吸：肺炎、胸膜炎、肋骨骨折——胸式呼吸减弱；腹膜炎、大量腹水、肝脾极度肿大——腹式呼吸减弱。
- 吸气性呼吸困难三凹征见 01 症状学；一侧胸廓扩张度受限——大量胸腔积液、气胸、胸膜增厚、肺不张（病侧减弱）。
- 呼吸节律与深度异常（视诊速查表）：
| 异常 | 特点 | 意义 |
| --- | --- | --- |
| 潮式呼吸（Cheyne-Stokes） | 呼吸由浅慢渐深快、再浅慢，继以暂停数十秒，周期反复 | 中枢神经（大脑/间脑水平）受损、心力衰竭、尿毒症晚期 |
| 间停呼吸（Biot） | 规则呼吸数次后突然停止数秒，周而复始 | 脑桥/延髓水平损害，较潮式呼吸更危重 |
| 抑制性呼吸 | 吸气相因剧痛突然中断、浅而快 | 胸膜炎、肋骨骨折、气胸 |
| Kussmaul 呼吸 | 深而规则的大呼吸 | 代谢性酸中毒（糖尿病酮症、尿毒症） |
| 叹气样呼吸 | 自觉胸闷，间歇一次深大叹气后自觉舒适 | 神经官能症、精神紧张 |

### 4.3 语音震颤（触觉语颤）配对表（必背）
- 机制：声带振动产生的声波经气管、支气管、肺泡传至胸壁；**含气越少、传导介质越实，震颤越强**。
| 语颤变化 | 机制 | 疾病 |
| --- | --- | --- |
| 增强 | 肺泡内含气减少、传导良好 | **肺实变**（大叶性肺炎实变期、肺梗死）、靠近胸壁的大空洞（肺结核空洞、肺脓肿——声波在空洞内共鸣经实变区传导） |
| 减弱或消失 | 传导路径被气体、液体或增厚胸壁阻隔 | 肺气肿（含气过多）、支气管阻塞（阻塞性肺不张）、**大量胸腔积液、气胸**、胸膜高度增厚粘连、胸壁皮下气肿 |

### 4.4 胸部叩诊音-疾病配对（见 1.2 五音表在胸部的应用）
| 叩诊音 | 疾病 |
| --- | --- |
| 过清音 | 肺气肿 |
| 鼓音 | 气胸、靠近胸壁的肺大空洞 |
| 浊音 | 肺炎实变、肺梗死、胸腔积液上缘被压缩的肺组织 |
| 实音 | 大量胸腔积液、肺不张、巨大肿瘤 |
- 正常肺部叩诊为清音；左侧腋前线下方有 Traube 鼓音区（胃泡）。

### 4.5 肺下界与移动度
| 项目 | 数值/变化 | 意义 |
| --- | --- | --- |
| 肺下界（平静呼吸） | 锁骨中线第 6 肋间、腋中线第 8 肋间、肩胛线第 10 肋间 | 肥胖者可上移一肋间，瘦长者下移 |
| 肺下界降低 | 肺气肿、腹腔内脏下垂 | —— |
| 肺下界升高 | 肺不张、膈肌麻痹、大量腹水、肝脾大 | —— |
| 肺下界移动度 | 正常 **6～8cm** | 减弱或消失：肺气肿、胸腔积液、胸膜粘连、肺不张、膈神经麻痹 |

### 4.6 呼吸音
- 三种正常呼吸音分布表（必背）：
| 呼吸音 | 听诊特点 | 正常分布 |
| --- | --- | --- |
| 支气管呼吸音 | 呼气相较吸气相长，音调高、似"哈"音 | 喉部、胸骨上窝，背部第 6～8 颈椎及第 1～2 胸椎附近 |
| 支气管肺泡呼吸音 | 吸呼相近似，音调中等 | 胸骨两侧第 1、2 肋间隙，肩胛间区第 3、4 胸椎水平，肺尖前后部 |
| 肺泡呼吸音 | 吸气相较长、音响较强，似上齿咬下唇吸气的"夫"音 | 除上述区域外的大部分肺野（乳房下部、肩胛下部、腋窝下部最清楚） |
- 异常肺泡呼吸音：减弱或消失（气胸、胸腔积液、肺不张、肺气肿、膈麻痹）；增强（发热、运动、一侧减弱时健侧代偿）。
- **异常支气管呼吸音**（正常肺泡呼吸音区闻及支气管呼吸音）三情形（必背）：
| 情形 | 机制 | 疾病 |
| --- | --- | --- |
| 肺组织实变 | 实变组织传导支气管语音良好 | 大叶性肺炎实变期、肺梗死 |
| 肺内大空腔 | 空腔与支气管相通、共鸣增强 | 肺结核空洞、肺脓肿 |
| 压迫性肺不张 | 胸腔积液上方被压缩的肺组织致密、传导良好 | 大量胸腔积液区上方 |
- 异常支气管肺泡呼吸音：实变范围较小、与正常肺组织掺杂存在（支气管肺炎、肺结核早期、大叶性肺炎初期）。

### 4.7 啰音
| 分类 | 特点 | 疾病配对 |
| --- | --- | --- |
| 干啰音（哮鸣音、哨笛音、鼾音） | 呼吸道狭窄/痉挛，呼气相更明显，性质易变、部位可变 | 哮喘（广泛哮鸣音）、支气管炎、大气道分泌物（鼾音） |
| 湿啰音（水泡音） | 气道内稀薄液体被气流冲破的水泡破裂声，吸气末明显，部位恒定、性质较固定 | 见下 |
| **Velcro 啰音** | 吸气末高调、细碎爆裂音，似撕开尼龙扣 | **肺间质纤维化** |
| 局限性、固定性湿啰音 | 部位恒定、长期存在 | **支气管扩张** |
| 两肺底湿啰音 | 体位低垂部位肺淤血 | **左心衰竭** |
| 双肺满布湿啰音 | 急性肺水肿 | 急性左心衰、中毒性肺水肿 |

- 语音共振（听觉语音）：嘱患者用正常音调重复发"一、二、三"，听诊器听取——增强与减弱的意义同语音震颤；耳语音（改用耳语发音）在实变区可清晰闻及，是肺实变的佐证。

### 4.8 胸膜摩擦音 vs 心包摩擦音（屏气试验，必考）
| 项目 | 胸膜摩擦音 | 心包摩擦音 |
| --- | --- | --- |
| 部位 | 前下侧胸壁（腋中线第 5～7 肋间最易闻及） | 胸骨左缘第 3、4 肋间 |
| 性质 | 粗糙、搔抓样，与呼吸节律一致 | 粗糙搔抓样，**与心跳一致**，多为双相（收缩期＋舒张期） |
| **屏气试验** | 屏气后**消失** | 屏气后**仍存在** |
| 体位 | 吸气末呼气初明显 | 前倾坐位、呼气末更明显 |
| 意义 | 纤维素性胸膜炎、肺梗死、尿毒症、胸膜肿瘤 | 纤维素性心包炎（风湿性、结核性、病毒性）、尿毒症、急性心梗 |

## 第 5 节 心脏检查

### 5.1 视诊：心尖冲动
- 正常心尖冲动：第 5 肋间、左锁骨中线内 0.5～1.0cm，搏动范围直径 2.0～2.5cm。
| 疾病 | 心尖冲动移位方向 |
| --- | --- |
| 左心室增大 | **向左下移位** |
| 右心室增大 | **向左移位**（略向下甚至稍向上）——右室扩大使左室被推向左后 |
| 左、右心室均增大 | 向左下移位，范围扩大 |
| 右位心 | 移到右胸相应位置 |
| 大量胸腔积液、气胸 | 移向健侧 |
| 肺不张、胸膜粘连 | 移向患侧 |
| 大量腹水、腹腔巨大肿瘤、膈肌抬高 | 横位心，心尖冲动上移 |
- **负性心尖冲动**（收缩期心尖部反而内陷）：粘连性心包炎与周围组织广泛粘连、重度右室肥大（心脏顺钟向转位、左室转向后）。
- 心前区其他异常搏动：胸骨左缘第 3、4 肋间搏动——右室肥大；胸骨右缘第 2 肋间或胸骨上窝搏动——升主动脉瘤/主动脉弓动脉瘤；剑突下搏动——肺心病右室肥大（深吸气时增强者为右室搏动，减弱者为腹主动脉搏动——鉴别点）。

### 5.2 触诊：震颤（猫喘）
- 震颤是血流经狭窄瓣膜口/异常通道产生湍流，传至胸壁的细颗粒样振动——**器质性心血管病的特征性体征**（触及震颤必查心脏）。
| 部位 | 时期 | 疾病 |
| --- | --- | --- |
| 胸骨右缘第 2 肋间 | 收缩期 | 主动脉瓣狭窄 |
| 胸骨左缘第 2 肋间 | 收缩期 | 肺动脉瓣狭窄 |
| 胸骨左缘第 3、4 肋间 | 收缩期 | 室间隔缺损 |
| 胸骨左缘第 2 肋间 | **连续性** | 动脉导管未闭 |
| 心尖部 | **舒张期** | 二尖瓣狭窄 |

### 5.3 叩诊：三种心型（必背）
| 心型 | X 线/叩诊浊音界形态 | 机制 | 代表疾病 |
| --- | --- | --- | --- |
| **靴形心**（主动脉型） | 心左界向左下扩大、心腰加深凹陷 | 左室扩大＋主动脉增宽 | 主动脉瓣病变（狭窄/关闭不全）、高血压性心脏病、法洛四联症 |
| **梨形心**（二尖瓣型） | 心腰饱满/膨隆、左界下段扩大呈梨形 | 左房增大＋肺动脉段突出 | 二尖瓣狭窄 |
| **烧瓶形心** | 心界向两侧扩大、随体位改变（坐位三角烧瓶形、卧位心底部增宽） | 心包腔积液 | 心包积液（大量，>250～300ml 后出现） |

### 5.4 听诊：五个瓣膜听诊区（必背）
| 听诊区 | 体表位置 |
| --- | --- |
| 二尖瓣区 | 心尖部（第 5 肋间左锁骨中线内 0.5～1.0cm） |
| 肺动脉瓣区 | 胸骨左缘第 2 肋间 |
| 主动脉瓣区 | 胸骨右缘第 2 肋间 |
| 主动脉瓣第二听诊区（Erb 区） | 胸骨左缘第 3 肋间 |
| 三尖瓣区 | 胸骨下端左缘（第 4、5 肋间） |
- 听诊顺序：二尖瓣区→肺动脉瓣区→主动脉瓣区→主动脉瓣第二听诊区→三尖瓣区。内容：心率、心律、心音、额外心音、杂音、心包摩擦音。
- 心率：正常成人 60～100 次/分；<60 过缓，>100 过速。

### 5.5 S1 与 S2 鉴别表（必背）
| 鉴别点 | 第一心音 S1 | 第二心音 S2 |
| --- | --- | --- |
| 机制 | 房室瓣（二尖瓣、三尖瓣）关闭 | 半月瓣（主动脉瓣、肺动脉瓣）关闭 |
| 音调 | 较低 | 较高 |
| 时限 | 较长（约 0.1s） | 较短（约 0.08s） |
| 最响部位 | **心尖部** | **心底部**（胸骨右/左缘第 2 肋间） |
| 与心尖冲动/颈动脉搏动的关系 | **同步**（同时出现） | 不同步（稍后） |
| 与心动周期的关系 | S1 与下一 S1 的距离 < S1 与其后 S2 的距离……（S1-S2 短、S2-下一 S1 长） | —— |
- S2 分裂听诊要点：正常青少年肺动脉瓣区可闻 S2 生理性分裂（吸气时 P2 延迟）。

### 5.6 心音强度改变
| 改变 | 机制 | 疾病 |
| --- | --- | --- |
| S1 增强 | 舒张期充盈不足、瓣膜位置低垂；心肌收缩力强 | **二尖瓣狭窄**、高热、贫血、甲亢、**完全性房室传导阻滞（"大炮音"）** |
| S1 减弱 | 舒张期充盈过度、瓣膜损害、心肌收缩力下降 | 二尖瓣关闭不全、P-R 间期延长、心肌炎、心肌病、心衰 |
| S1 强弱不等 | 心律绝对不齐、充盈时相不定 | 心房颤动、完全性房室传导阻滞 |
| S2 增强 | 主/肺动脉压力增高 | 高血压（A2↑）、肺心病（P2↑） |
| S2 减弱 | 半月瓣狭窄、血压下降 | 主动脉瓣/肺动脉瓣狭窄、低血压 |
| S2 固定分裂 | 吸气时分裂不增宽也不缩小 | **房间隔缺损**（吸气右房压力↑反使左向右分流减少，右心容量恒定） |
| S2 反常分裂（逆分裂） | 主动脉瓣关闭延迟，A2 晚于 P2，呼气时明显 | **主动脉瓣狭窄、完全性左束支阻滞** |

### 5.7 额外心音与奔马律
| 额外心音 | 出现时相 | 意义 |
| --- | --- | --- |
| 奔马律（舒张早期奔马律，病理性 S3） | 舒张早期，与 S1、S2 构成"le-dè-dè"三音律 | **心力衰竭的可靠体征**：舒张期快速充盈冲击受损、顺应性下降的心室壁振动；提示严重器质性心脏病 |
| 开瓣音（二尖瓣开放拍击音） | 舒张早期 | 二尖瓣狭窄而**瓣膜弹性与活动度尚好**——介入或手术治疗适应证的重要参考 |
| 心包叩击音 | 舒张早期 | 缩窄性心包炎 |
| 收缩早期喷射音 | 收缩早期 | 主/肺动脉高压或瓣膜狭窄 |
| 收缩中晚期喀喇音 | 收缩中晚期 | 二尖瓣脱垂（可伴收缩晚期杂音） |

### 5.8 心房颤动的三特征（必背）
1. 心律**绝对不规则**；
2. **第一心音强弱不等**；
3. **脉搏短绌**（脉率<心率，弱的心搏射血量过少不能传至外周脉搏）。

### 5.9 杂音六要素与 Levine 分级
- 六要素：**部位、时期、性质、传导方向、强度、与体位/呼吸/运动的关系**。
- Levine 6 级分法（收缩期杂音）：
| 级别 | 特点 |
| --- | --- |
| 1/6 | 很轻，需仔细听诊才能察觉 |
| 2/6 | 较易听到，轻度杂音 |
| 3/6 | 明显的杂音，但**不伴震颤** |
| 4/6 | 响亮，**伴震颤** |
| 5/6 | 很响亮，听诊器边缘接触胸壁即可闻及 |
| 6/6 | 极响亮，听诊器**离开**胸壁仍可闻及 |
- 记录格式："2/6 收缩期吹风样杂音"。**3/6 及以上多为器质性**（2/6 以下需综合判断）。
- 分级法主要用于收缩期杂音的规范描述；舒张期杂音一般不分级，多以轻、中、重度描述。

### 5.10 功能性杂音 vs 器质性杂音（收缩期，必考）
| 项目 | 功能性（生理性）杂音 | 器质性杂音 |
| --- | --- | --- |
| 年龄 | 儿童、青少年多见 | 不定 |
| 部位 | 肺动脉瓣区/心尖部 | 相应瓣膜病变区 |
| 性质 | 柔和、吹风样 | 粗糙、吹风样或喷射样 |
| 强度 | ≤2/6 | ≥3/6 |
| 传导 | 局限、不传导 | 常沿血流方向传导 |
| 震颤 | 无 | 可有 |
| 心脏大小 | 正常 | 常有心房/心室增大 |
| 相对性杂音 | 高血压、贫血、甲亢等高动力循环致相对性瓣膜关闭不全 | —— |
- 注意：**舒张期杂音基本均为器质性**（Graham-Steell 杂音为肺动脉高压的相对性肺动脉瓣关闭不全，也属病理状态）。

### 5.11 各瓣膜区器质性杂音配对表（必背）
| 病变 | 部位 | 时期与性质 | 传导 | 关键伴随 |
| --- | --- | --- | --- | --- |
| 二尖瓣狭窄 | 心尖部 | 舒张中晚期**隆隆样**，左侧卧位、活动后增强 | 局限 | S1 亢进、开瓣音、舒张期震颤 |
| 二尖瓣关闭不全 | 心尖部 | 全收缩期粗糙**吹风样** | 向左腋下、左肩胛下区传导 | S1 减弱、心界向左下扩大 |
| 主动脉瓣狭窄 | 胸骨右缘第 2 肋间 | 收缩期**喷射样** | 向颈部传导 | 常伴收缩期震颤、A2 减弱 |
| 主动脉瓣关闭不全 | 胸骨左缘第 3 肋间 | 舒张期**叹气样** | 向心尖部、胸骨下端传导 | **前倾坐位、呼气末**更清楚；周围血管征（水冲脉、枪击音、Duroziez 征、毛细血管搏动征） |
| 肺动脉瓣关闭不全 | 胸骨左缘第 2 肋间 | 舒张期吹风样 | 局限 | 见于肺动脉高压——**Graham-Steell 杂音** |
| 室间隔缺损 | 胸骨左缘第 3、4 肋间 | 全收缩期粗糙 | 广泛 | 常伴收缩期震颤 |
| 动脉导管未闭 | 胸骨左缘第 2 肋间 | **连续性机器样**杂音，贯穿收缩与舒张期 | 向左锁骨下、颈部、背部传导 | 水冲脉等周围血管征 |
| 肺动脉瓣狭窄 | 胸骨左缘第 2 肋间 | 收缩期喷射样 | 局限 | 常伴收缩期震颤、P2 减弱 |

### 5.12 Austin-Flint 杂音 vs Graham-Steell 杂音（经典配对）
| 项目 | Austin-Flint 杂音 | Graham-Steell 杂音 |
| --- | --- | --- |
| 机制 | 主动脉瓣关闭不全→舒张期反流血冲击二尖瓣前叶→**相对性二尖瓣狭窄** | 二尖瓣狭窄→肺动脉高压→**相对性肺动脉瓣关闭不全** |
| 部位 | 心尖部舒张期隆隆样 | 胸骨左缘第 2 肋间舒张期吹风样 |
| 原发病 | 主动脉瓣关闭不全 | 二尖瓣狭窄（肺动脉高压） |
| 区别点 | 心尖部杂音但**无** S1 亢进与开瓣音 | 肺动脉瓣区杂音＋P2 亢进 |

### 5.13 心包摩擦音（见 4.8 表）要点补充
- 双相性（收缩期＋舒张期），与心跳一致、屏气不消失；前倾坐位呼气末最响；见于感染性（结核、病毒）与非感染性（尿毒症、急性心梗早期、结缔组织病）心包炎。

## 第 6 节 腹部检查

### 6.1 分区
- 四分法（十字形）：左上腹、右上腹、左下腹、右下腹。
- 九分法（两条水平线＋两条垂直线）：左/右上腹部、左/右侧腹部、左/右下腹部、上腹部、中腹部（脐部）、下腹部。
- 视诊顺序与项目：腹部外形、腹壁（静脉、皮疹、疝）、呼吸运动、胃肠型与蠕动波、脐部。
- 检查顺序技巧：全身体检总顺序为视、触、叩、听，但**腹部须先听诊（肠鸣音）再触叩**——触诊叩诊可刺激肠管改变肠鸣音结果。

### 6.2 腹壁静脉血流方向判读（必考）
- 判读方法（指压法）：挤压排空一段静脉后松开一侧手指，观察血流充盈方向。
| 病理状态 | 曲张静脉分布 | 血流方向 | 机制 |
| --- | --- | --- | --- |
| 门静脉高压 | 以**脐为中心**向四周辐射（"海蛇头"，可伴脐周静脉杂音） | 脐水平以上**向上**、脐水平以下**向下**（与正常一致） | 门静脉血经开放的脐旁静脉（附脐静脉）回流至上、下腔静脉 |
| 下腔静脉阻塞 | 腹壁两侧及下腹 | **自下而上** | 下腹壁静脉血不能经下腔静脉回流，改道向上经胸壁静脉入上腔静脉 |
| 上腔静脉阻塞 | 胸腹壁 | **自上而下** | 上半身血液经腹壁静脉向下腔静脉改道 |

### 6.3 视诊其他要点
| 体征 | 意义 |
| --- | --- |
| 全腹膨隆（蛙腹） | 大量腹水、肠麻痹；尖腹（妊娠） |
| 舟状腹 | 恶病质（结核、恶性肿瘤晚期、严重脱水） |
| 胃型、蠕动波（自左肋缘向右推进） | 幽门梗阻 |
| 肠型、梯形排列蠕动波 | 小肠梗阻 |
| 脐疝、腹壁疝 | 腹压增高 |
| 腹纹 | 白纹——妊娠、肥胖；紫纹——皮质醇增多症 |

### 6.4 触诊
| 体征 | 判读与意义 |
| --- | --- |
| 板状腹 | 急性弥漫性腹膜炎（胃肠穿孔）——腹肌高度紧张强直如木板 |
| 揉面感 | 结核性腹膜炎、癌性腹膜炎——腹壁柔韧似面团 |
| **腹膜刺激征三联** | 腹肌紧张＋压痛＋反跳痛——腹膜炎的标志 |
| **Murphy 征阳性** | 左手掌平放右肋缘、拇指按压胆囊点，嘱深吸气——发炎的胆囊下移碰触拇指，患者因剧痛而突然屏气——急性胆囊炎 |
| **Courvoisier 征阳性** | 无痛性胆囊肿大（黄疸但胆囊光滑无压痛）——胰头癌、壶腹周围癌压迫胆总管 |
| 肝脏大小 | 正常：肋下 <1cm、剑突下 <3cm；肝下移（肺气肿、内脏下垂）≠肝大 |
| 肝脏质地 | 质软如口唇——正常/急性肝炎；质韧如鼻尖——慢性肝炎、淤血肝；质硬如前额——肝硬化、肝癌（表面结节、边缘不整） |
| 脾肿大分度 | 轻度：深吸气脾缘 <肋下 2cm；中度：>2cm 但未过脐水平线；**巨脾**：超过脐水平线或前正中线——慢性粒细胞白血病、骨髓纤维化、慢性疟疾、黑热病、戈谢病 |
| 液波震颤 | **3000～4000ml 以上腹水**才可检出 |
| 振水音 | 清晨空腹或餐后 6～8h 以上仍闻及——幽门梗阻、胃扩张 |
| 肾脏触诊 | 正常一般不易触及；双手触诊深吸气时右肾下极偶可触及（瘦弱者）——触及且随呼吸上下移动多为肾下垂、游走肾 |
| 膀胱触诊 | 耻骨联合上方触及圆形包块、压之有尿意、排尿后消失——尿潴留（与卵巢囊肿、子宫等包块鉴别：导尿后消失） |
| 肋脊点、肋腰点压痛 | 肾盂肾炎、肾脓肿等上尿路感染的定位体征 |
| 输尿管走行区压痛 | 输尿管结石 |

### 6.5 叩诊与听诊
| 体征 | 数值/特点 | 意义 |
| --- | --- | --- |
| 移动性浊音 | 腹水 **>1000ml** 时阳性 | 体位改变时浊音界随之下移 |
| 肝浊音界缩小或消失 | —— | 急性胃肠穿孔（气体进入膈下）、重症肝炎 |
| 肝区叩击痛 | —— | 肝脓肿、肝炎、肝癌 |
| 肋脊角（肾区）叩击痛 | —— | 肾炎、肾盂肾炎、肾结石、肾结核、肾周围炎 |
| 肠鸣音正常 | 4～5 次/分 | —— |
| 肠鸣音活跃 | >10 次/分、音调不甚高 | 急性胃肠炎、服泻药后、消化道大出血 |
| 肠鸣音亢进＋金属音 | 次数多且响亮、高亢铿锵 | **机械性肠梗阻** |
| 肠鸣音减弱 | <1 次/分 | 老年便秘、腹膜炎、低钾血症 |
| 肠鸣音消失 | 3～5 分钟以上未闻及 | **急性腹膜炎、麻痹性肠梗阻** |
| 腹部血管杂音 | 腹中部收缩期杂音——腹主动脉瘤/狭窄；脐上两侧收缩期吹风样杂音——肾动脉狭窄 | —— |

## 第 7 节 脊柱、四肢与神经系统检查

### 7.0 脊柱与四肢检查要点
- 脊柱弯曲度：脊柱后凸（驼背）——佝偻病、脊柱结核（成角畸形）、强直性脊柱炎、老年骨质疏松；脊柱侧凸——姿势性或结构性。
- 脊柱活动度受限：颈椎病、腰椎间盘突出、强直性脊柱炎、脊柱结核、软组织损伤。
- 脊柱压痛与叩击痛：直接或间接叩击痛阳性——结核、骨折、椎间盘突出、椎旁脓肿。
- 四肢关节形态异常：梭形关节（类风湿关节炎）、爪形手（尺神经损伤）、腕垂症（桡神经损伤）、猿手（正中神经损伤）、膝内翻/膝外翻（佝偻病）。
- 浮髌试验阳性——膝关节腔中等量以上积液。
- 足内翻/足外翻畸形——先天畸形或脊髓灰质炎后遗症；双侧足背动脉搏动对比触诊——下肢动脉闭塞评估。

### 7.1 杵状指与匙状甲
| 体征 | 特点 | 疾病 |
| --- | --- | --- |
| 杵状指（趾） | 末端指节明显增宽增厚、甲根部弧形隆起如表蒙 | **慢性缺氧**与代谢障碍：支气管扩张、肺脓肿、慢性肺脓胸、支气管肺癌、发绀型先天性心脏病、感染性心内膜炎、炎症性肠病、肝硬化 |
| 匙状甲（反甲） | 指甲中部凹陷、边缘翘起、变薄粗糙 | **缺铁性贫血**、高原疾病 |

### 7.2 肌力分级（0～5 级，必背）
| 级别 | 标准 |
| --- | --- |
| 0 级 | 完全瘫痪，无肌肉收缩 |
| 1 级 | 可见肌肉收缩，但无肢体运动 |
| 2 级 | 肢体能在床面**水平移动**，但不能抬起 |
| 3 级 | 肢体能**抬离床面**，但不能对抗阻力 |
| 4 级 | 能对抗一定阻力，但较正常弱 |
| 5 级 | 正常肌力 |

### 7.3 肌张力与不自主运动
| 表现 | 类型 | 定位 |
| --- | --- | --- |
| 肌张力增高——**折刀样**（痉挛性） | 被动运动开始阻力大、终末突然减弱（如折刀） | **锥体束损害**（上运动神经元瘫痪） |
| 肌张力增高——**铅管样**（强直性） | 被动运动全程阻力均匀增高；伴震颤时呈"齿轮样" | **锥体外系损害**（帕金森病） |
| 肌张力降低 | —— | 下运动神经元损害、小脑病变、深昏迷 |
| 静止性震颤 | 静止时明显、运动时减轻 | 帕金森病 |
| 动作性（意向性）震颤 | 运动时出现、愈接近目标愈明显 | 小脑病变 |
| 舞蹈样运动、手足徐动 | 不自主、无规律的多动 | 锥体外系（纹状体）病变 |

### 7.4 生理反射与神经节段定位（必背）
| 反射 | 节段定位 | 临床意义 |
| --- | --- | --- |
| 角膜反射 | 三叉神经眼支传入、面神经传出 | 消失提示深昏迷或脑干受损 |
| 腹壁反射 | 上：胸髓 7～8；中：胸髓 9～10；下：胸髓 11～12 | 锥体束损害时消失；肥胖、老年可减弱 |
| 提睾反射 | 腰髓 1～2 | 同上 |
| 足底（跖）反射 | 骶髓 1～2 | —— |
| 肱二头肌反射 | 颈髓 5～6 | 深反射 |
| 肱三头肌反射 | 颈髓 6～8 | 深反射 |
| 膝反射 | **腰髓 2～4** | 深反射 |
| 跟腱（踝）反射 | **骶髓 1～2** | 深反射 |
- 深反射亢进＋阵挛（髌阵挛、踝阵挛）——上运动神经元损害；深反射减弱或消失——下运动神经元/周围神经/肌肉病变。

### 7.5 上运动神经元 vs 下运动神经元瘫痪鉴别（必背）
| 项目 | 上运动神经元瘫痪（中枢性/痉挛性） | 下运动神经元瘫痪（周围性/弛缓性） |
| --- | --- | --- |
| 损害部位 | 皮质运动区、锥体束 | 脊髓前角、前根、周围神经 |
| 肌张力 | 增高（折刀样） | 降低 |
| 腱反射 | 亢进 | 减弱或消失 |
| 病理反射 | **阳性（Babinski 征等）** | 阴性 |
| 肌萎缩 | 早期不明显（晚期废用性萎缩） | 早期即明显 |
| 肌束颤动 | 无 | 可有 |
| 代表疾病 | 脑梗死、脑出血、脊髓压迫症 | 脊髓灰质炎、吉兰-巴雷综合征、周围神经损伤 |

### 7.6 病理反射（锥体束损害的标志）
| 反射 | 检查方法与阳性表现 |
| --- | --- |
| **Babinski 征** | 划足底外侧缘自后向前至小趾根部转向内侧——拇趾背屈、其余四趾呈扇形分开 |
| Oppenheim 征 | 以拇指沿胫骨前缘自上而下用力下滑——同上表现 |
| Gordon 征 | 捏挤腓肠肌——同上表现 |
| Chaddock 征 | 划足背外侧缘——同上表现 |
- 1.5～2 岁以下婴幼儿锥体束尚未发育完善，Babinski 征可为生理性；成年人出现均为锥体束损害。

### 7.7 脑膜刺激征（三项，必背）
| 征象 | 检查与阳性表现 |
| --- | --- |
| 颈强直 | 被动屈颈阻力增强、下颌不能触及前胸（需排除颈椎病等） |
| Kernig 征 | 髋、膝关节屈曲 90°后被动伸膝受阻（<135°）并伴疼痛 |
| Brudzinski 征 | 被动屈颈时双侧髋、膝关节自动屈曲 |
- 意义：脑膜炎（化脓性、结核性、病毒性）、蛛网膜下腔出血、颅内压增高——与意识障碍组合的意义见 01 症状学第 10 节。

### 7.8 Lasegue 征（直腿抬高试验）
- 患者仰卧、双下肢伸直，抬高一侧下肢 <70° 时出现沿坐骨神经走行的放射性疼痛为阳性——腰椎间盘突出症、坐骨神经痛。

### 7.9 共济运动（了解）
- 指鼻试验、快速轮替动作、跟-膝-胫试验、Romberg 征（闭目难立）：睁眼闭眼均不稳——小脑性共济失调；闭眼时不稳、睁眼可代偿——感觉性共济失调（深感觉障碍、后索病变）。

### 7.10 感觉功能检查（速记）
- 浅感觉：痛觉（大头针轻刺）、触觉（棉絮轻触）、温度觉。
- 深感觉：运动觉、位置觉、振动觉——障碍提示后索病变（脊髓痨、亚急性联合变性）。
- 复合感觉（皮质感觉）：皮肤定位觉、两点辨别觉、实体觉——障碍提示大脑皮质感觉区病变。
