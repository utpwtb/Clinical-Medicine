## 第一章 绪论

### 1. 内环境与稳态
- 体液占体重约 60%：细胞内液 40%，细胞外液 20%（血浆 5% + 组织液 15%）。
- ★ 内环境 = 细胞外液；稳态 = 内环境理化性质（温度、pH、渗透压、各种离子浓度）保持相对恒定的动态平衡状态。
- 稳态是**动态平衡**而非固定不变；维持稳态主要靠**负反馈**调节。

### 2. 机体功能的调节
| 方式 | 特点 | 举例 |
|---|---|---|
| 神经调节 | **最快**、精确、短暂，**最主要**方式 | 减压反射、膝反射 |
| 体液调节 | 缓慢、广泛、持久 | 激素（胰岛素降糖） |
| 自身调节 | 不依赖神经/体液，范围小、幅度小 | 肾血流量的肌源性调节、心室功能曲线（Frank-Starling） |

### 3. 反馈控制系统
- ★ **负反馈**：维持稳态，使系统活动趋于稳定（减压反射、体温调节、血糖调节）。
- ★ **正反馈**：使生理过程不断加强、迅速完成直至结束（排尿、分娩、血液凝固、排便、射精、"排卵前 LH 峰"）。【口诀：分娩排尿又凝血，排便射精 LH 峰】
- ⚠ 病理状态下的"恶性循环"属于正反馈，但**不是**生理性调节。
- 前馈：干扰信号先于输出变化（条件反射、进餐引起胰岛素分泌先于血糖升高）。

## 第二章 细胞的基本功能

### 1. 跨膜物质转运 ★
| 方式 | 是否耗能 | 载体/通道 | 典型例子 |
|---|---|---|---|
| 单纯扩散 | 否（顺浓度） | — | O₂、CO₂、N₂、乙醇、尿素、类固醇激素 |
| 经通道易化扩散 | 否 | 通道蛋白（电压门控/化学门控/机械门控） | Na⁺/K⁺/Ca²⁺ 顺浓度差流动、动作电位去极化时 Na⁺ 内流 |
| 经载体易化扩散 | 否 | 载体蛋白 | ★葡萄糖、氨基酸进入一般细胞（GLUT），具有**饱和现象、竞争性抑制、结构特异性** |
| 原发性主动转运 | 是（直接耗 ATP） | 泵 | ★Na⁺-K⁺泵（3Na⁺出/2K⁺入，生电性）、Ca²⁺泵（肌浆网） |
| 继发性主动转运 | 是（间接，借助 Na⁺ 浓度差） | 同向/反向转运体 | ★同向：小肠/肾小管葡萄糖和氨基酸重吸收（SGLT）；★反向：Na⁺-Ca²⁺交换、Na⁺-H⁺交换 |
| 出胞/入胞 | 是 | — | 出胞：神经末梢递质释放、内分泌细胞分泌；入胞：吞噬、受体介导入胞（LDL） |

⚠ 大分子（蛋白质）入血吸收或肾小管重吸收 → 入胞/出胞；葡萄糖吸收/重吸收为**继发性主动转运**；葡萄糖入红细胞/一般组织细胞为**载体易化扩散**。

### 2. 静息电位与动作电位 ★★
- 静息电位（RP）：细胞安静时膜内为负。接近 K⁺ 平衡电位（Ek），形成机制：
  1. 安静时膜对 K⁺ 通透性大（K⁺ 漏通道开放），K⁺ 外流至接近平衡电位；
  2. 少量 Na⁺ 内流使 RP 略小于 Ek（绝对值略小）；
  3. Na⁺-K⁺泵维持浓度差（生电作用使 RP 增大一点点）。
- ★ 静息电位大小与膜外/膜内 K⁺ 浓度比成正比；**细胞外 K⁺↑（高钾）→ RP 绝对值↓（去极化）→ 兴奋性先升高后降低**。
- 动作电位（AP）分期（以神经/骨骼肌为例）：
  - **上升支（去极化）**：Na⁺ 通道大量开放，Na⁺ 内流（再生性 Na⁺ 内流），接近 Na⁺ 平衡电位（Ena ≈ +50~+60 mV）；
  - **下降支（复极化）**：Na⁺ 通道失活关闭 + K⁺ 外流增加；
  - **后电位**：负后电位（去极化方向，K⁺ 蓄积膜外）、正后电位（超极化方向，钠泵活动增强）。
- 全或无：刺激强度达到阈强度后，AP 幅度不再随刺激增强而增大；同一细胞 AP 幅度恒定，传导不衰减（衰减性传导的是局部电位/突触后电位）。
- ★ 兴奋性周期性变化（快反应细胞）：绝对不应期（Na⁺通道完全失活，无兴奋性）→ 局部反应期（Na⁺通道刚开始复活，阈上刺激只能产生局部反应）→ 相对不应期（兴奋性低于正常，阈上刺激可产生 AP）→ 超常期（兴奋性高于正常，负后电位前后）。**绝对不应期决定 AP 不可能发生融合（决定了最大频率）**。
- ★ 局部电位（局部兴奋）特点：等级性（幅度随刺激强度增大）、衰减性传导（电紧张性扩布）、**可以总和**（时间总和、空间总和）、没有不应期。终板电位、突触后电位（EPSP/IPSP）、感受器电位、发生器电位均属局部电位。

### 3. 神经-肌接头传递与骨骼肌收缩 ★
- 神经-肌接头（运动终板）传递过程：AP 到达 → Ca²⁺ 内流（接头前膜）→ 量子式释放 ACh → 与终板膜（接头后膜）**N₂ 型 ACh 受体（化学门控通道）**结合 → 终板电位（局部电位）→ 达阈电位产生肌膜 AP。
- ★ 特点：1:1 传递（一对一）、单向、有突触延搁（接头间隙）、易受药物影响（肉毒毒素抑制释放；筒箭毒阻断受体；有机磷抑制胆碱酯酶导致 ACh 蓄积）。
- ★ 兴奋-收缩耦联的关键结构：**横管（T管）**；耦联因子：**Ca²⁺**；关键蛋白：**L 型 Ca²⁺ 通道（DHPR）与肌浆网 ryanodine 受体（RYR1）的机械耦联（骨骼肌）**；心肌则经"钙诱导钙释放（CICR）"。
- 收缩机制：肌丝滑行——Ca²⁺ 与肌钙蛋白结合 → 原肌球蛋白移位 → 横桥与肌动蛋白结合 → 横桥周期（结合-摆动-解离-再结合，耗 ATP）。
- 前负荷（初长度）→ **最适初长度**时收缩张力最大（肌小节长度 2.0–2.2 μm，粗细肌丝最重叠）；后负荷↑ → 收缩速度↓、缩短程度↓、开始缩短时间延迟；等长收缩/等张收缩。
- 单收缩、不完全强直、完全强直（连续刺激，肌膜 AP 仍分开而收缩波融合）。

## 第三章 血液

### 1. 血液的组成与理化特性
- 血浆渗透压 ≈ 280–310 mOsm/(kg·H₂O)：
  - ★ **晶体渗透压**（主要由 Na⁺、Cl⁻ 形成）：维持**细胞内/外**水平衡；
  - ★ **胶体渗透压**（主要由**白蛋白**形成）：维持**血管内/外**（毛细血管内外）水平衡。
- 等渗溶液：0.85%（0.9%）NaCl、5% 葡萄糖；等张溶液：0.85% NaCl（葡萄糖不是等张，因可透入细胞被代谢）。
- 血浆 pH 7.35–7.45，主要缓冲对 NaHCO₃/H₂CO₃（比 20:1）。
- 红细胞比容：男性 40%–50%，女性 37%–48%。红细胞计数男（4.0–5.5）×10¹²/L，女（3.5–5.0）；Hb 男 120–160 g/L，女 110–150 g/L。

### 2. 红细胞 ★
- 特性：可塑变形性、悬浮稳定性（**血沉 ESR**——女性 0–20 mm/h 末、男性 0–15；血浆中**球蛋白、纤维蛋白原↑→血沉加快**；白蛋白↑血沉减慢）、渗透脆性。
- 生成原料：**铁 + 蛋白质**（血红蛋白合成）、**维生素 B₁₂ + 叶酸**（DNA 合成，红细胞成熟因子；B₁₂ 吸收需胃壁细胞分泌的内因子）。缺铁→小细胞低色素；缺 B₁₂/叶酸→巨幼细胞贫血。
- 调节：**EPO（促红细胞生成素，肾产生，作用于骨髓 BFU-E/CFU-E）**；雄激素促进造血；晚期红系祖细胞主要受 EPO 调节。
- 寿命约 120 天；破坏主要在肝、脾（脾破坏衰老变形的红细胞）。
- ⚠ 肾性贫血机制：EPO 生成减少。

### 3. 生理性止血与凝血 ★★
- 三步：血管收缩 → 血小板止血栓（黏附、释放、聚集：ADP、TXA₂ 促进聚集）→ 血液凝固。
- 血小板：寿命 7–14 天；生理性止血必需；**PGI₂（内皮产生）抑制聚集，TXA₂（血小板产生）促进聚集**。
- 凝血因子特点：IV 为 Ca²⁺；依赖维生素 K：Ⅱ、Ⅶ、Ⅸ、Ⅹ（肝合成）。【口诀：二七九十依赖维K】
- **内源性凝血**：由血管内膜损伤激活 → Ⅻ → Ⅺ → Ⅸ → Ⅷ + Ⅸa + PF3 + Ca²⁺ → 激活 Ⅹ；速度慢。
- **外源性凝血**：组织损伤释放**组织因子 TF（Ⅲ）→ Ⅶ** 复合物激活 Ⅹ；速度快，为主要启动途径。
- 共同途径：Ⅹ → 凝血酶原（Ⅱ）→ 凝血酶 → 纤维蛋白原（Ⅰ）→ 纤维蛋白（需 ⅩⅢ 使纤维蛋白交联稳固）。
- ⚠ 凝血过程中 Ca²⁺ 参与多个环节 → 枸橼酸盐、草酸盐抗凝原理（螯合 Ca²⁺）。
- 抗凝系统：**抗凝血酶Ⅲ（灭活凝血酶及 Ⅸa、Ⅹa、Ⅺa、Ⅻa，肝素增强其作用）**、**蛋白质 C 系统**、**组织因子途径抑制物（TFPI）**、肝素（肥大细胞/嗜碱性粒细胞产生）。
- 纤溶系统：纤溶酶原 → 纤溶酶 → 降解纤维蛋白（FDP、D-二聚体）；纤溶酶原激活物：**组织型 tPA、尿激酶型 uPA**；抑制物：PAI-1、α₂-抗纤溶酶。

### 4. 血型与输血 ★
- ABO 血型：
  - A 型（红细胞 A 抗原/抗 B 抗体）、B 型（B/抗 A）、AB 型（AB 抗原/无抗体，"万能受血者"）、O 型（无抗原/抗 A+抗 B 抗体，"万能供血者"但主张同型输血）。
  - ★ 抗体为天然 IgM（不能通过胎盘）；凝集原在红细胞上，凝集素在血清中。
  - 交叉配血：主侧（供者红细胞+受者血清）、次侧（受者红细胞+供者血清）；主侧凝集绝对禁止输血；两侧都不凝最理想。
- Rh 血型：**我国汉族 99% Rh 阳性**；Rh 抗体为 IgG（可通过胎盘）→ Rh 阴性母亲怀 Rh 阳性胎儿 → 新生儿溶血病（多发生在第二胎及以后）；Rh 阴性者首次输入 Rh 阳性血一般不发生输血反应，但可产生抗体。

## 第四章 血液循环 ★★★（西综最常考章节之一）

### 1. 心脏泵血
- ★ 心动周期：心率 75 次/分 → 周期 0.8 s（心房收缩 0.1 s，舒张 0.7 s；心室收缩 0.3 s，舒张 0.5 s）。心率加快 → 心动周期缩短，**舒张期缩短更明显**。
- 心室收缩期分期：
  - **等容收缩期**（室内压↑最快、瓣膜均关闭、心室容积不变）；
  - **快速射血期**（室内压最高，射血量占 2/3~3/4）；
  - 减慢射血期。
- 心室舒张期分期：
  - **等容舒张期**；
  - **快速充盈期**（充盈量最大，主要靠**心室舒张的抽吸**）；
  - 减慢充盈期；
  - **心房收缩期（0.1 s，贡献约 10%–30% 充盈量）**。
- ⚠ 主动脉压最低点出现在等容收缩期末；心室内压最高在快速射血期。
- ★ 心音：S1（心尖部、音调低、历时长，标志**心室收缩开始**，二尖瓣/三尖瓣关闭）；S2（胸骨旁第二肋间、音调高、历时短，标志**心室舒张开始**，主动脉瓣/肺动脉瓣关闭）。
- ★ 心输出量 = 每搏输出量 × 心率（成人约 5–6 L/min）；**心指数 = 心输出量/体表面积**（约 3.0–3.5 L/min·m²）；射血分数 = 每搏输出量/心室舒张末期容积（50%–60%）。
- ★ 影响心输出量的因素：
  - 前负荷（Starling 机制，心室功能曲线——异长自身调节，对**搏出量**进行精细的短期调节）；
  - 后负荷（动脉血压↑→搏出量↓）；
  - 心肌收缩能力（**等长自身调节**，儿茶酚胺 ↑ 收缩能力，心衰 ↓）；
  - 心率：70–180 次/分内加快心率可增加心输出量；**>180 次/分 → 心舒期过短、充盈不足 → 心输出量反而下降**。
- 心力贮备：最大心输出量/安静心输出量。

### 2. 心肌细胞电生理 ★★★
- 工作细胞（心房肌、心室肌）AP 分 5 期：
  - 0 期：**快 Na⁺ 通道**开放，Na⁺ 快速内流（去极化幅度大、速度快）；
  - 1 期：一过性外向 K⁺ 电流（Ito）；
  - **2 期（平台期）**：★心肌特有——**L 型 Ca²⁺ 内流与 K⁺ 外流平衡**，是心肌 AP 长的原因（不应期长，避免强直收缩）；
  - 3 期：K⁺ 外流；
  - 4 期：Na⁺-K⁺泵、Na⁺-Ca²⁺交换恢复离子分布。
- 窦房结 P 细胞 AP 特征：**0 期慢 Ca²⁺ 内流（慢反应细胞）**；无 1、2 期；3 期 K⁺ 外流；**4 期自动去极化**（IK 衰减、If（内向 Na⁺ 起搏电流）、T 型 Ca²⁺ 内流——递减性 IK 衰减 + 递增性 If 是主要机制）。
- ★ 快反应 vs 慢反应：0 期去极速度和幅度大→传导快；慢反应细胞传导慢。
- 有效不应期（ERP）：心室肌从 0 期至 3 期复极至 −55 mV 左右，**特别长（含整个收缩期+舒张早期）**→ 心肌不会发生完全强直收缩。
- ★ 期前收缩与代偿间歇：窦房结正常冲动落在期前兴奋的有效不应期内 → 脱落一次正常节律（代偿间歇）。
- 自动节律性：窦房结 100 次/分（正常起搏点）、房室结（交界区）50、浦肯野纤维 25；窦房结对潜在起搏点的控制——抢先占领 + 超速驱动压抑。
- 传导性：房室结处传导最慢（**房室延搁 0.1 s，保证房室顺序收缩**）；浦肯野纤维传导最快。
- ⚠ 影响因素：细胞外 K⁺ 高→兴奋性、传导性↓；Ca²⁺ 高→心肌收缩增强；迷走神经释放 ACh → K⁺ 外流↑、心率↓、传导↓（负性变时/变力/变传导）；交感神经 → 去甲肾上腺素，正性变时/变力/变传导。

### 4. 血管生理 ★★
- 动脉血压形成条件：足量血液充盈（前提）+ 心脏射血（动力）+ **外周阻力（小动脉、微动脉）** + 大动脉弹性贮器作用（缓冲收缩压、维持舒张压、降低脉压）。
- 正常值：收缩压 90–139 mmHg，舒张压 60–89 mmHg；脉压 30–40 mmHg；平均动脉压 ≈ 舒张压 + 1/3 脉压（约 100 mmHg）。
- ★ 影响因素：
  - **每搏输出量↑ → 收缩压↑明显（脉压↑）**；
  - **心率↑ → 舒张压↑明显（脉压↓）**；
  - **外周阻力↑ → 舒张压↑明显**（高血压主要机制）；
  - 大动脉弹性↓（老年人）→ 收缩压↑、舒张压↓、脉压↑；
  - 循环血量/血管系统容量比例↓（失血）→ 血压↓。
- 静脉血压：中心静脉压 CVP（4–12 cmH₂O，反映右心前负荷与输血输液指标）；重力对静脉压影响（直立位足部静脉压高）。
- 静脉回心血量影响因素：体循环平均充盈压、心脏收缩力（右心衰→颈静脉怒张、肝大）、体位改变、骨骼肌泵（肌肉泵+静脉瓣）、呼吸运动（吸气→胸内压更负→回心血量↑）。
- 微循环：三条通路——迂回通路（营养通路，物质交换）、直捷通路、动-静脉短路（调节体温）。
- ★ 组织液生成：有效滤过压 =（毛细血管血压 + 组织液胶体渗透压）−（血浆胶体渗透压 + 组织液静水压）；动脉端滤过、静脉端重吸收；淋巴回流是重要补充。**水肿机制**：毛细血管血压↑（右心衰）、血浆胶体渗透压↓（低蛋白血症）、淋巴回流受阻、毛细血管通透性↑。

### 5. 心血管活动的调节 ★★
- 神经调节：
  - 心交感神经（T1–T5）→ NE → β₁ 受体 → 正性变时、变力、变传导；
  - 心迷走神经（迷走神经背核、疑核）→ ACh → M 受体 → 负性变时、变力、变传导；
  - 交感缩血管纤维 → NE → α 受体 → 血管收缩（皮肤、内脏血管密，脑血管、冠脉少）。
- ★ 减压反射（颈动脉窦-主动脉弓压力感受性反射）：窦内压↑ → 窦神经（舌咽神经）→ 孤束核 → 心迷走↑、心交感↓、缩血管↓ → 血压↓。**生理意义：稳定血压（短期快速调节），对长期血压调节不重要**。特点：窦内压在 100 mmHg 附近最敏感；**是负反馈，不属正反馈**。
- ⚠ 颈动脉体/主动脉体化学感受器：感受 PaO₂↓、PaCO₂↑、H⁺↑ → 呼吸↑为主，血压可↑（只在低氧、窒息、失血时才有明显心血管效应）。
- ★ 心肺感受器（容量感受器）：牵张刺激 → 交感↓、迷走↑、ADH↓ → 血压↓、尿量↑。
- 体液调节：
  - ★ **RAAS**：肾球旁细胞（入球小动脉压力↓、交感兴奋、致密斑 Na⁺↓ → 肾素↑）→ AngⅠ → **ACE（肺血管内皮）** → **AngⅡ**（缩血管、促 ADH/醛固酮分泌、口渴、促心肌重构）→ 醛固酮（肾上腺皮质球状带：保 Na⁺ 保水排 K⁺）。
  - ★ 肾上腺素（Epinephrine）：与心脏 β₁ → 正性变力变时（强心药，临床"强心"）；低浓度时血管 β₂ 占优 → 总外周阻力可略降。
  - ★ 去甲肾上腺素（NE）：α 受体为主 → 血管强烈收缩、外周阻力↑ → **血压↑，但反射性心率↓**。⚠ 临床：NE 升压、Epi 强心（经典考点）。
  - 血管升压素（ADH，下丘脑视上核、室旁核）：大剂量缩血管；促水重吸收。
  - 血管内皮：NO（舒血管）、前列环素 PGI₂（舒）、内皮素 ET-1（缩）。
  - 激肽、组胺、5-HT：舒血管。
- 局部调节：代谢产物（CO₂、H⁺、K⁺、乳酸、腺苷）舒张血管；肌源性自身调节。
- 冠脉循环特点：灌注主要在**舒张期**（心肌收缩压迫冠脉）；冠脉血流调节最重要的因素是**心肌代谢水平（腺苷为主要舒血管物质）**；主动脉舒张压↑/心率↓ → 冠脉流量↑。
- 脑循环：血-脑屏障、对缺氧敏感（4–6 分钟不可逆损伤）、CO₂ 显著扩张脑血管。

## 第五章 呼吸

### 1. 肺通气 ★★
- 直接动力：肺内压与大气压之差；原动力：呼吸运动。
- ★ 肺内压变化：吸气末、呼气末 = 大气压；吸气时肺内压 < 大气压，呼气时 > 大气压。
- ★ 胸膜腔内压（胸内压）＝ 肺内压 − 肺回缩力，**始终低于大气压（平静呼吸时 −5～−10 cmH₂O 左右，呼气末约 −3～−5）**；形成机制：胸廓自然容积 > 肺自然容积 → 肺被牵拉回缩；生理意义：维持肺扩张、促进静脉血与淋巴回流。**气胸时胸内压 = 大气压 → 肺塌陷**。
- ★ 弹性阻力：
  - 肺弹性阻力 = 肺弹性纤维回缩力 + **肺泡表面张力（约占 2/3）**；
  - ★ **肺泡表面活性物质**：Ⅱ 型肺泡上皮细胞分泌（二棕榈酰卵磷脂 DPPC），降低表面张力：①防止肺泡塌陷；②防止肺水肿（减少组织液生成）；③稳定大小肺泡（小肺泡表面张力低不塌陷）。新生儿缺乏 → **新生儿呼吸窘迫综合征（NRDS）**；
  - 顺应性（C = ΔV/ΔP）：弹性阻力大 → 顺应性小；肺纤维化/表面活性物质缺乏 → 顺应性↓；肺气肿 → 顺应性↑。
- 非弹性阻力：气道阻力（主要来自大气道/鼻；主要受管径影响，呼气时气道阻力大 → **呼气费力**见于哮喘小气道痉挛；迷走→收缩，交感/儿茶酚胺→舒张）。
- ★ 肺通气量指标：
  - 潮气量 TV 400–600 ml；功能残气量 FRC = 残气量 + 补呼气量（缓冲气体分压变化）；
  - **肺活量 VC**：最大吸气后呼出的全部气量（男约 3.5 L）；
  - ★ **时间肺活量（FEV）**：第 1 秒 **FEV₁/FVC ≈ 80%**——评价通气功能最可靠、区分阻塞性/限制性通气障碍（阻塞→FEV₁/FVC↓；限制→FVC↓但比值正常或↑）；
  - **每分通气量 = TV × 呼吸频率**；**最大随意通气量**（评定通气贮备）；
  - ★ 肺泡通气量 =（潮气量 − 无效腔气量）× 呼吸频率（无效腔约 150 ml）→ **浅快呼吸效率低，深慢呼吸效率高**。
- 呼吸功：克服弹性阻力为主占 1/3、气道阻力 2/3。

### 2. 肺换气与组织换气 ★
- 驱动力：分压差；交换方式：单纯扩散。
- 影响因素：呼吸膜厚度（肺纤维化、肺水肿→扩散↓）、呼吸膜面积（肺气肿、肺不张→↓）、**通气/血流比值（V/Q）**：
  - ★ 正常 V/Q ≈ 0.84；V/Q↑（血流相对不足）→ 无效腔增大（生理无效腔↑）；V/Q↓（通气不足）→ 动-静脉短路（功能性分流）。
- 肺牵张反射（黑-伯反射）：肺扩张 → 抑制吸气（切断呼吸调整节律）；成年人在深吸气时才起作用。

### 3. 气体运输 ★★
- O₂：98.5% 以 HbO₂ 形式运输；血氧饱和度 = HbO₂/(HbO₂+HHb)；血氧容量、血氧含量、血氧饱和度概念。
- ★ **氧解离曲线**：S 形；上段（60–100 mmHg，平坦——高原/轻度呼吸功能不全时仍可维持较高 SaO₂，是安全缓冲区）；中段（40–60 mmHg，组织释 O₂）；下段（15–40 mmHg，代谢增强时进一步释 O₂——储备）。
- ★ **P₅₀**（SaO₂ 50% 时的 PO₂，正常约 26.5 mmHg）：P₅₀↑（右移）→ Hb 对 O₂ 亲和力↓，易释放 O₂；P₅₀↓（左移）→ 亲和力↑，不易释放。
- ★ 影响因素（右移因素——【口诀：酸碳热珠解离右，2,3-DPG 助释放】）：pH↓（波尔效应）、PCO₂↑、温度↑、**2,3-DPG↑（高原、贫血、糖酵解增强）**；CO 中毒：Hb 与 CO 亲和力比 O₂ 大约 250 倍，曲线左移。
- CO₂ 运输：物理溶解 5%、**碳酸氢盐 88%（主要）、氨基甲酰血红蛋白 7%**；氯离子转移（Cl⁻ shift）；何尔登效应（去氧 Hb 携带 CO₂ 能力↑）。

### 4. 呼吸运动的调节 ★
- 化学感受器：
  - **外周化学感受器**：颈动脉体、主动脉体，感受 **PaO₂↓、PaCO₂↑、H⁺↑**（缺氧刺激以颈动脉体为主）；
  - **中枢化学感受器**：延髓腹外侧，感受**脑脊液 H⁺**（CO₂ 透过血脑屏障 → H⁺↑）。
- ★ CO₂ 刺激呼吸作用最强：轻度升高时通过外周+中枢感受器，**中枢占主导**；但严重 CO₂ 潴留（COPD）→ 中枢麻痹，呼吸靠低 O₂ 刺激外周感受器维持（慢性高碳酸血症给氧需低流量，防呼吸抑制）。
- ★ 低 O₂ 对呼吸的刺激：完全通过**外周化学感受器**（反射性呼吸兴奋）；**严重缺氧直接抑制呼吸中枢**。
- H⁺：中枢+外周，但 H⁺ 难透过血脑屏障，以外周为主。

## 第六章 消化和吸收

### 1. 消化道平滑肌与胃肠神经
- 平滑肌电活动：慢波（基本电节律，纵行肌产生，胃约 3 次/分、十二指肠 12 次/分，起源于 Cajal 间质细胞）→ 达阈电位产生动作电位 → 收缩。
- 内在神经系统（肠神经系统）；副交感（迷走）促胃肠运动和分泌；交感抑制胃肠运动。

### 2. 胃肠激素 ★
| 激素 | 来源细胞 | 主要作用 |
|---|---|---|
| 促胃液素（胃泌素） | G 细胞（胃窦、十二指肠） | 促胃酸分泌（**最强**）、促胃运动、营养胃黏膜 |
| 促胰液素 | S 细胞（十二指肠） | **促胰液（水和 HCO₃⁻）分泌、抑制胃酸和胃运动** |
| 缩胆囊素（CCK） | I 细胞 | 促胰酶分泌、**胆囊收缩**、Oddi 括约肌松弛、抑制胃排空 |
| 抑胃肽（GIP）、促胃动素等 | — | GIP 促胰岛素分泌；胃动素促胃排空（MMC） |
【口诀：胃泌素促酸促运动，胰泌素促水促碱抑胃，CCK 促酶缩胆抑胃】

### 3. 胃液分泌 ★★
- 胃液成分：盐酸（**壁细胞**，H⁺-K⁺-ATP 酶即质子泵；作用：激活胃蛋白酶原、杀菌、促胰液素释放、促铁和钙吸收）、**胃蛋白酶原（主细胞，激活后最适 pH≈2，失活于 pH>6）**、黏液和碳酸氢盐（**黏液-碳酸氢盐屏障**，保护胃黏膜）、内因子（壁细胞分泌，促 B₁₂ 吸收——萎缩性胃炎→巨幼贫）。
- ★ 胃液分泌三相：
  - **头期**（迷走-迷走反射+胃泌素，量多酸高、酶多，占 30%）；
  - **胃期**（扩张刺激+氨基酸/肽促胃泌素释放，量最多占 60%）；
  - **肠期**（量少占 10%）。
- 抑制胃液分泌因素：盐酸（负反馈）、脂肪、高张溶液（肠抑胃素类）。
- ★ 胃排空：糖 > 蛋白 > 脂肪（混合食物完全排空 4–6 h）；胃排空受胃内压（促进）与十二指肠内因素（抑制——酸、脂肪、渗透压）双重控制；**间断排空**。

### 4. 胰液与胆汁 ★★
- ★ **胰液是最重要的消化液**（含三大营养素的消化酶）：胰淀粉酶、胰脂肪酶、胰蛋白酶原和糜蛋白酶原（肠激酶激活）等；**促胰液素→分泌大量水和 HCO₃⁻（碱性）**，**CCK→分泌胰酶**。
- 胆汁：肝细胞分泌（不含消化酶）；**胆盐**乳化脂肪、形成混合微胶粒促进脂肪吸收、乳化剂；胆盐的肠-肝循环；迷走+促胰液素促胆汁分泌。
- ★ 胆汁酸肠肝循环意义；胆汁中胆色素、胆固醇。

### 5. 吸收 ★
- 小肠是吸收的主要部位（面积大、绒毛、停留时间长）。
- ★ 铁的吸收：Fe²⁺ 形式（酸性环境促进，维生素C 促进）；主要在十二指肠、空肠上段；由转铁蛋白转运。
- ★ 钙的吸收：**活性维生素 D₃（1,25-(OH)₂D₃）** 促进、脂肪促进、需要钙结合蛋白；主要在十二指肠。
- ★ 维生素 B₁₂：回肠末端吸收，需内因子；胆盐、脂溶性维生素（A/D/E/K）需要胆汁。
- 糖：单糖（葡萄糖、半乳糖经 SGLT1 继发主动吸收，果糖经易化扩散）；蛋白质：氨基酸/寡肽；脂肪：混合微胶粒吸收，淋巴为主（乳糜）。

## 第七章 能量代谢与体温

### 1. 能量代谢
- 能量代谢测定的核心是氧热价（1 L O₂ 产热值）、呼吸商（RQ = CO₂ 产生量/O₂ 消耗量；混合食物 0.85）。
- ★ **基础代谢率（BMR）**：清醒、安静、空腹（餐后 12 h 以上）、环境 20–25 ℃、静卧状态下的能量代谢；**正常 ±15% 以内**；★ BMR 升高：**甲亢**（最显著）、发热；BMR 降低：甲减、Addison 病等。BMR 与**体表面积**成正比，与体重无关。
- 影响能量代谢：肌肉活动（最显著）、精神活动、食物特殊动力效应（**蛋白质最强，可达 30%**）、环境温度。

### 2. 体温 ★
- 正常腋窝 36.0–37.0 ℃、口腔 36.3–37.2 ℃、直肠 36.5–37.7 ℃；昼夜波动 <1 ℃（清晨最低、午后最高）。
- 产热：安静时以内脏（肝）为主，运动/寒战时以**骨骼肌**为主；褐色脂肪（新生儿）非寒战产热。
- 散热：**辐射、传导、对流、蒸发**；当环境温度 ≥ 皮肤温度时，**唯一方式是蒸发（发汗）**。
- 汗腺受交感胆碱能神经支配（发汗）；温热性出汗 vs 精神性出汗。
- ★ 体温调节中枢：**下丘脑（视前区-下丘脑前部 PO/AH）**；调定点学说：致热原 → 调定点上移 → 发热（产热↑散热↓）；体温调节的调定点正常约 37 ℃。

## 第八章 尿的生成和排出 ★★★

### 1. 肾的功能解剖与血流
- 肾小球滤过膜：毛细血管内皮（窗孔）+ 基膜（主要屏障）+ 足细胞裂隙膜（nephrin）；有效半径 < 2.0 nm 的物质自由滤过，> 4.2 nm 不能滤过。
- 皮质肾单位 vs 近髓肾单位（后者与尿浓缩稀释有关）。
- 肾血流量占心输出量 20%–25%；自身调节（80–180 mmHg 内 GFR 稳定——肌源性机制 + 管球反馈）。

### 2. 肾小球的滤过功能 ★★
- ★ GFR ≈ 125 ml/min；**滤过分数 FF = GFR/RPF ≈ 19%–20%**。
- ★ 有效滤过压 = 肾小球毛细血管血压 −（血浆胶体渗透压 + 肾小囊内压）=（60 − 32）mmHg ≈ 10 mmHg（入球端到出球端血浆胶体渗透压渐增，出球端达平衡——滤过平衡）。
- 影响肾小球滤过的因素：
  - 毛细血管血压（全身血压 80–180 mmHg 内自身调节不变）；
  - ★ **血浆胶体渗透压↓（大量输液、低蛋白血症）→ GFR↑**；
  - 囊内压↑（输尿管结石梗阻）→ GFR↓；
  - 肾血浆流量↑ → 滤过平衡延后 → GFR↑。

### 3. 肾小管和集合管的重吸收与分泌 ★★
- 近端小管：**重吸收全部葡萄糖、氨基酸、维生素，大部分（约 65%–70%）Na⁺、Cl⁻、K⁺ 和水，全部滤过的 HCO₃⁻ 约 80%–90% 在此重吸收**（碳酸酐酶）；H⁺ 分泌（Na⁺-H⁺交换）。
- ★ 葡萄糖重吸收：**肾糖阈**（血糖 > 180 mg/dl 时出现糖尿）；葡萄糖重吸收部位仅限近端小管；转运：SGLT2（与 Na⁺ 同向）。
- ★ 水重吸收：近端小管为**等渗、必然性重吸收（伴随溶质）**，不受 ADH 调节；**远曲小管和集合管为调节性重吸收（ADH 调节）**。
- 髓袢：**降支细段对水通透（逆流倍增）**；**升支粗段主动重吸收 Na⁺-K⁺-2Cl⁻（呋塞米作用位点）**，对水不通透——形成外髓高渗；尿素内髓再循环参与内髓高渗形成。
- 远曲小管+集合管：
  - ★ **ADH（血管升压素）**：集合管 V₂ 受体 → 水通道蛋白 AQP2 上膜 → 水重吸收↑（决定终尿量）；主控渗透压感受器（下丘脑渗透压感受器最敏感，阈值为 280 mOsm 左右）与容量感受器（心肺牵张，抑制 ADH）。
  - ★ **醛固酮**：肾上腺皮质球状带，远曲小管+集合管主细胞"**保 Na⁺、保水、排 K⁺**"（ENaC + Na⁺-K⁺泵），受 RAAS 和血 K⁺/Na⁺ 比值调节。
  - ★ K⁺ 的分泌：远曲小管+集合管主细胞分泌，K⁺ 平衡主要由此段"多进多排、少进少排、不进也排"调节。
- H⁺ 的分泌：近端小管 Na⁺-H⁺ 交换 + 远端闰细胞 H⁺ 泵；肾对酸碱平衡的调节：HCO₃⁻ 重吸收、H⁺ 排泌、NH₄⁺ 生成（谷氨酰胺）、可滴定酸（磷酸盐）。
- NH₃ 分泌：与 H⁺ 结合成 NH₄⁺ 排出。

### 4. 尿液的浓缩与稀释
- ★ 浓缩机制核心：肾髓质**高渗梯度**（外髓：NaCl 主动转运；内髓：尿素再循环 + NaCl）+ **ADH 决定集合管对水的通透性**。ADH↓ → 低比重尿/多尿（水利尿）；ADH↑ → 高渗尿。
- ⚠ 大量饮清水 → **水利尿**（血浆晶体渗透压↓→ADH↓）；大量出汗/失水 → ADH↑ → 少尿。

### 5. 清除率与排尿
- ★ 清除率 C =（尿中浓度 × 尿量）/血浆浓度；菊粉清除率 = GFR（标准值 125 ml/min）；**对氨基马尿酸 PAH 清除率 ≈ 肾血浆流量**。
- ★ 自由水清除率评价肾浓缩稀释功能。
- 排尿反射：正反馈；骶髓 2–4（S2–S4）为排尿初级中枢，高位截瘫 → 尿失禁（无意识排尿）；大脑皮层可抑制排尿。

## 第九章 感觉器官

### 1. 感受器一般特性
- 适宜刺激、换能作用、编码功能、适应现象（快适应：触觉、嗅觉；慢适应：肌梭、痛觉、压力感受器）。

### 2. 视觉 ★★

- ★ 近点与老视：近视眼（焦点落在视网膜前——凹透镜矫正）、远视眼（后——凸透镜）、散光（规则散光用柱镜）、老视（晶状体弹性↓，视近物调节能力↓——凸透镜，不属于"屈光不正"）。

- ★ 三种视锥色素（红绿蓝三原色觉）；色盲：红绿色盲为 X 连锁隐性遗传。
- 视网膜的信息处理：双极细胞、神经节细胞（感受野）；光照 → **感受器电位为超极化**（少数例外）。
- ★ 生理盲点：视盘（视神经乳头）处无视网膜感光细胞。

### 3. 听觉 ★

- 耳石器官（椭圆囊、球囊：感受直线变速运动/静态位置）、半规管（壶腹嵴：角加速度/旋转运动）。
- 听阈、听域（20–20000 Hz，最敏感 1000–3000 Hz）。

## 第十章 神经系统 ★★★

### 1. 突触传递
- 经典突触传递过程：AP 到突触前 → Ca²⁺ 内流 → 量子式释放递质 → 后膜受体 → 突触后电位。
- ★ **EPSP**：Na⁺ 内流为主的局部去极化，等级性、可总和；**IPSP**：Cl⁻ 内流/K⁺ 外流的超极化。
- 突触传递特征：单向传递、突触延搁（0.3–0.5 ms）、总和、兴奋节律改变、后发放、易疲劳性、对药物敏感。
- 神经胶质细胞、神经营养因子（了解）。
- 突触可塑性：习惯化、敏感化、长时程增强 LTP（学习记忆基础）。

### 2. 神经递质与受体 ★
- 外周：**胆碱能纤维**（全部交感/副交感节前纤维、副交感节后纤维、**少数交感节后纤维——支配汗腺和骨骼肌血管的舒血管纤维**）、运动神经；**肾上腺素能纤维**（多数交感节后）。
- ★ 受体与效应：
  - **N 受体**（烟碱）：N₁（神经节）、N₂（骨骼肌终板）；筒箭毒阻断；
  - **M 受体**（毒蕈碱）：心脏抑制、平滑肌收缩、腺体分泌、血管扩张；阿托品阻断；
  - **α 受体**（α₁ 血管收缩为主；α₂ 突触前抑制 NE 释放）；**β₁（心脏兴奋）、β₂（支气管、骨骼肌血管舒张）**。
- 中枢递质：谷氨酸（主要兴奋性）、GABA 与甘氨酸（抑制性）、多巴胺（黑质-纹状体——帕金森病）、5-HT、NE、乙酰胆碱。
- 突触前抑制（轴-轴突触）、突触后抑制（回返性抑制——Renshaw 细胞；传入侧支性抑制）。

### 3. 感觉分析功能 ★
- 特异性投射系统：点对点投射到皮层特定区域，引起**特定感觉**；非特异性投射系统：经脑干网状结构**弥散**投射，维持和改变大脑皮层兴奋状态（★ **上行激动系统**——受损则昏睡；对巴比妥类敏感）。
- 大脑皮层感觉代表区：中央后回（体表感觉，投射特点：左右交叉、倒置、代表区大小与感觉精细度成正比）。
- ★ **痛觉**：
  - 快痛（尖锐、Aδ 纤维）vs 慢痛（钝痛、C 纤维、弥散、伴情绪反应）；
  - ★ **牵涉痛**：内脏疾病引起特定体表部位疼痛（心→左肩臂、胆囊→右肩、胃胰→左上腹/肩胛间、肾输尿管→腰腹股沟、阑尾→上腹或脐周）；机制：会聚-投射学说。
- 丘脑核团：感觉接替核、联络核、髓板内核群（非特异投射）。

### 4. 对运动的调节 ★★
- 脊髓运动神经元：α（梭外肌）、γ（梭内肌，维持肌梭敏感性）、运动单位。
- ★ **牵张反射**：骨骼肌受牵拉时反射性收缩；**腱反射（位相性，快速牵拉，单突触）**与**肌紧张（紧张性，缓慢持续牵拉，多突触，维持姿势）**；感受器——肌梭（长度感受器）；腱器官（张力感受器，反牵张反射）。
- **去大脑僵直**：中脑上、下丘之间切断脑干 → 伸肌紧张性亢进（γ 僵直为主）；说明脑干网状结构抑制区/易化区失衡。
- 姿势反射：翻正反射等。
- 小脑：
  - 前庭小脑（绒球小结叶）：平衡（损伤→站立不稳）；
  - 脊髓小脑（蚓部、半球中间部）：调节进行中运动、**肌紧张调节**（损伤→**意向性震颤、共济失调、动作分解**——小脑性共济失调）；
  - 皮层小脑（半球外侧部）：运动计划（随意运动的发起与编程）。
- ★ 基底神经节：纹状体（尾状核+壳核）、苍白球、黑质、丘脑底核；通路：
  - **直接通路**：促进运动；**间接通路**：抑制运动；
  - ★ **帕金森病**：黑质多巴胺能神经元受损 → 直接通路活动↓、间接通路活动↑ → 运动过少（肌张力增高、静止性震颤、运动迟缓）；**亨廷顿病（舞蹈病）**：新纹状体 GABA 能神经元受损 → 间接通路活动↓ → 运动过多、肌张力↓。
- 大脑皮层运动区：中央前回（交叉、倒置、精细——拇指代表区最大）；锥体系（发起随意运动）vs 锥体外系（调节肌紧张、协调运动）。上运动神经元 vs 下运动神经元瘫（见诊断学/内科学）。

### 5. 自主神经系统 ★
- 交感神经：节前纤维短、节后长，分布广泛——**应急反应**（心跳加快、皮肤内脏血管收缩、血压升高、支气管扩张、瞳孔散大、血糖↑、抑制胃肠）。
- 副交感神经：节前长节后短、分布局限——**保护、休整、消化、储能**（心跳减慢、胃肠运动分泌增强、缩瞳、膀胱收缩排尿）。
- ⚠ 汗腺、肾上腺髓质受交感胆碱能支配；多数器官受双重支配，且常常是相互拮抗的（唾液腺分泌均为促进作用，但分泌成分不同）。
- 脊髓是排尿、排便、血管运动等初级中枢；**下丘脑是较高级的调节内脏活动的中枢**（体温、摄食、水平衡、内分泌、生物节律）；边缘系统与情绪、记忆（杏仁核——恐惧、海马——陈述性记忆）。

### 6. 脑电活动与觉醒睡眠
- ★ 脑电图（EEG）波形：**α 波**（清醒安静闭眼，枕叶，闭眼出现睁眼消失——α 阻断）；**β 波**（睁眼、活动时，额叶）；**θ 波**（困倦）；**δ 波**（深睡/婴儿/成人深度麻醉）。
- ★ 睡眠时相：
  - **慢波睡眠（NREM，N1–N3）**：生长激素分泌↑，利于生长发育与体力恢复；
  - **快眼动睡眠（REM）**：眼球快速运动、梦境、脑电似清醒（去同步化）、肌张力↓；**NE、5-HT 减少**；与学习记忆、精力恢复有关；REM 期易发生心肌缺血、哮喘发作。
  - 睡眠由下丘脑腹外侧视前区（VLPO）等控制；觉醒-睡眠与脑干网状上行激动系统、腺垂体（GH 慢波期分泌）、褪黑素（松果体）相关。

## 第十一章 内分泌 ★★★

### 1. 概述
- 激素分类（含氮类 vs 类固醇：**类固醇激素——皮质醇、醛固酮、性激素、1,25-(OH)₂D₃**；其余多为含氮激素）。
- 允许作用、协同、拮抗；下丘脑-垂体-靶腺轴（长反馈/短反馈/超短反馈）。

### 2. 下丘脑-垂体 ★
- ★ **生长激素 GH**：腺垂体嗜酸性细胞；作用——**促进生长**（骨骼、肌肉——通过**胰岛素样生长因子 IGF-1** 介导长骨生长），**升高血糖、促进脂肪分解、保留蛋白质**；GH 过多：幼年**巨人症**，成年**肢端肥大症**；分泌受 GHRH 促进、生长抑素抑制；慢波睡眠分泌↑、运动应激↑。
- ⚠ GH 促进生长但不直接促进脑发育；甲状腺激素为脑和骨发育所必需（幼年缺乏→**呆小症**）。
- ★ **催乳素 PRL**：促乳汁分泌；哺乳期高 PRL 抑制 GnRH（哺乳期闭经/不育）；受多巴胺（PIF）抑制。
- ★ **血管升压素 ADH**（下丘脑视上核为主）：抗利尿作用 V₂；大剂量缩血管 V₁。
- ★ **催产素 OXT**（室旁核为主）：子宫收缩、射乳（正反馈）。

### 3. 甲状腺激素 ★★
- 合成：聚碘（NIS 钠碘同向转运）、碘活化、酪氨酸碘化耦联（T3、T4）；储存于滤泡腔胶质中（T4 为 T3 的 10 倍量、活性 T3 强 3–5 倍）；T4→T3 在外周脱碘。
- ★ 作用：
  - **促进生长发育**（尤其**脑与骨**——幼年缺乏→**呆小症/克汀病**）；
  - **产热效应**（提高 BMR，↑Na⁺-K⁺-ATP 酶）；
  - 糖：升糖（促糖原分解与吸收）但促糖利用；脂肪：促分解为主（胆固醇↓）；蛋白质：生理量促合成，过量促分解；
  - 神经系统：提高兴奋性（甲亢→烦躁、失眠）；
  - 心血管：β 效应 → 心率↑、心输出量↑。
- 调节：**TSH（腺垂体）**受 TRH 促进；T3/T4 负反馈抑制 TSH（Graves 病时 TRAb 刺激甲状腺）；碘的 Wolff-Chaikoff 效应（过量碘暂时抑制）。

### 4. 钙磷调节 ★★（三大激素对比）
| 激素 | 来源 | 主要作用（对血钙） |
|---|---|---|
| **甲状旁腺激素 PTH** | 甲状旁腺主细胞 | **升血钙、降血磷**（促骨钙释放、促肾小管重吸收 Ca²⁺、激活 1α-羟化酶→活性 VitD₃↑、促尿磷排出）；最重要、慢性调节 |
| **降钙素 CT** | 甲状腺滤泡旁细胞（C 细胞） | **降血钙、降血磷**（抑制破骨）；急性、作用弱（成人意义有限） |
| **1,25-(OH)₂D₃** | 肾 1α-羟化（需 PTH） | **升血钙、升血磷**（促小肠吸收钙磷、骨重建） |
- 维生素 D 缺乏：儿童**佝偻病**、成人**骨软化症**；PTH 分泌异常 → 甲状旁腺功能亢进/减退。

### 5. 肾上腺 ★★
- **糖皮质激素（皮质醇）**：
  - 物质代谢：**升血糖**（糖异生↑）、促蛋白质分解（肌肉消瘦）、**促脂肪重新分布（向心性肥胖——满月脸、水牛背）**、保钠排钾（弱于醛固酮）；
  - 水盐：**允许作用**（允许儿茶酚胺发挥作用——维持血压所必需；★肾上腺皮质功能不全→低血压休克）；
  - 应激反应：ACTH-皮质醇轴是应激核心；**抗炎、抗过敏、抗免疫、抗休克（四抗）**；
  - 对血细胞：★ **红细胞↑、血小板↑、中性粒细胞↑、淋巴细胞↓、嗜酸性粒细胞↓**；
  - 分泌节律：**清晨 6–8 时最高，午夜最低**；
  - 调节：ACTH（应激↑；Addison 病时 ACTH↑→皮肤色素沉着）。
- **盐皮质激素（醛固酮）**：球状带；保钠保水排钾（远曲小管+集合管）；RAAS 调节 + 血 K⁺。
- **肾上腺髓质（儿茶酚胺：E > NE）**：交感节后神经元特化（受交感节前胆碱能支配）；应急反应 vs 应激反应（前者为交感-肾上腺髓质系统，后者为 ACTH-皮质醇轴）。
- ⚠ 切除肾上腺的动物不能耐受应激；糖皮质激素治疗突然停药 → 肾上腺危象（HPA 轴抑制）。

### 6. 胰岛内分泌 ★★
- ★ **胰岛素**（B 细胞，占 65%–80%）：
  - **促进合成代谢**：促糖摄取利用与糖原合成（唯一降糖激素）、促脂肪合成、促蛋白质合成；
  - 机制：受体为酪氨酸激酶型受体（RTK）；
  - 分泌调节：**血糖水平最重要**；氨基酸（精氨酸最强）、脂肪；激素——**抑胃肽 GIP 早期胰岛素分泌**、促胃液素/胰泌素/CCK 均促进；迷走神经（M）促进、交感（α₂）抑制；
  - 缺乏 → 糖尿病。
- ★ **胰高血糖素**（A 细胞）：升糖（糖原分解、糖异生）、促脂肪分解；受低血糖促进；CCK/促胃液素促进、促胰液素抑制。
- 生长抑素（D 细胞）抑制 A、B 细胞分泌；胰多肽（PP 细胞）。

### 7. 其他
- 松果体褪黑素：调节生物节律（昼夜节律）；促睡眠。
- 胸腺肽（T 细胞发育）。

## 第十二章 生殖

- 睾丸功能：生精 + 分泌**睾酮**（促进男性第二性征、维持生精、促蛋白质合成/骨骺闭合；FSH 作用于支持细胞产生雄激素结合蛋白 ABP，LH 作用于间质细胞）。
- ★ 卵巢功能与雌激素、孕激素：
  - **雌激素**（卵泡期颗粒细胞为主，主要雌二醇）：促女性第二性征、**增生期子宫内膜**、宫颈黏液稀薄拉丝长、对下丘脑正反馈（排卵前）；
  - **孕激素**（黄体）：**进一步增厚子宫内膜（分泌期）、降低子宫平滑肌兴奋性（安胎）、升高基础体温**。
- ★ **月经周期**：
  - 增生期（卵泡期）：FSH/LH↑ → 雌激素↑ → 子宫内膜增生；
  - 排卵：★ **LH 峰**（雌激素正反馈触发），约在下次月经前 14 天；
  - 分泌期（黄体期）：孕激素+雌激素 → 子宫内膜分泌期变化，基础体温升高约 0.3–0.5 ℃；
  - 月经期：未受孕 → 黄体萎缩 → 雌孕激素骤降 → 内膜脱落出血（负反馈解除）。
- 妊娠维持：HCG（合体滋养层，孕 8–10 周达峰；保黄体 → 孕激素维持；验孕指标）、hPL、雌孕激素由胎儿-胎盘单位合成。
- 乳房的射乳反射（OXT，正反馈）。
