# 医学人文笔记（306 西综 · 约占 6%，约 18 分）

> 考查形式：A 型题情境题为主（"医师应该怎么办"），涵盖医学职业素养、医患关系、临床伦理、卫生法律法规
> 特点：贴近临床情境、以"最佳选择"为原则——**病人利益第一、规范第一、沟通第一**

---

## 一、医学职业素养 ★

### 1. 医学职业精神的基本内容
- 医学的目的：**人的健康与生命，而非单纯治病**；
- 职业精神的三个支柱：**专业精神（精湛技术）、人文精神（尊重与关爱）、社会精神（公益与责任）**；
- 大医精诚（孙思邈）、希波克拉底誓言、《日内瓦宣言》《医师宣言》（职业化：**把患者利益放在首位**）。

### 2. 医师的基本职业素质
- **救死扶伤、防病治病**（《医师法》规定的宗旨）；
- 尊重患者：**人格尊严、知情同意权、隐私权**；
- 诚实守信、廉洁行医：**不得收受红包、回扣，不得索要财物**；
- ★ **依法执业**：在注册的执业地点、执业类别、执业范围内执业；
- 严谨求实：如实告知、如实书写病历（**病历不得涂改、伪造**）；
- 终身学习、团队协作、维护职业荣誉。

### 3. 医患关系
- **基本模式**（萨斯-荷伦德）：
  - **主动-被动型**：昏迷、休克、全麻、婴幼儿等**无自主能力**者；
  - **指导-合作型**：**急性病、一般患者**（最普遍）；
  - **共同参与型**：**慢性病、康复期、有自我管理能力者**（如糖尿病长期管理）。
- ★ 医患关系的性质：**以诚信为基础的、具有契约性质的信托关系**（不是单纯的商业买卖关系）；
- 医患沟通的基本原则：**尊重、真诚、有效、共情**；
- ★ **医患沟通中的"坏消息"告知**：告知病情应先与家属沟通策略→选择合适时机与环境→分次、逐步告知→给予支持与希望（SPIKES 模式）；**患者本人有知情权，家属意愿不能完全替代（法律上患者本人第一顺位）**。

## 二、临床伦理学 ★★

### 1. 医学伦理四原则（必背）
| 原则 | 含义 | 临床体现 |
|---|---|---|
| **尊重（自主）原则** | 尊重患者自主决定权、知情同意权、隐私保密权 | 手术/特殊检查前签署知情同意书；未经同意不得透露病情给他人 |
| **不伤害原则** | 避免使患者受到不应有的伤害 | 权衡利弊、选择伤害最小的方案；"两害相权取其轻" |
| **有利原则** | 把患者的健康利益置于首位 | 积极救治、最佳方案 |
| **公正原则** | 公平分配医疗资源，一视同仁 | 不因贫富、地位、种族、关系区别对待 |

### 2. 知情同意 ★★
- ★ **构成要素**：**信息的告知（充分）+ 信息的理解（有效）+ 自愿的同意 + 同意的能力**；
- ★ **内容**：病情、诊断、治疗方案、预期效果、风险、替代方案、费用；
- **知情同意的主体**：**患者本人为第一主体**；患者不能行使（昏迷、未成年、无民事行为能力）时由其**法定代理人/近亲属**行使；
- ★ **紧急情况（《医师法》第 25 条）**：因抢救生命垂危的患者等紧急情况，不能取得患者或其近亲属意见的，**经医疗机构负责人或者授权的负责人批准，可以立即实施相应的医疗措施**；
- ⚠ **不能以"签了字就免责"**：知情同意不能免除因**过错**造成的责任；
- ⚠ **代孕、器官买卖**：法律禁止。

### 3. 临终关怀与安乐死
- **临终关怀（安宁疗护）**：以**缓解症状、减轻痛苦、提高生存质量、维护尊严**为目标，不追求无意义延命（"有尊严地死亡"）；
- **安乐死**：我国**未合法化**——实施主动安乐死属违法行为；**终止无效的、患者明确拒绝的过度治疗（尊严死/放弃治疗）与安乐死不同**，在伦理上可接受；
- **脑死亡**（了解）：全脑（含脑干）功能不可逆丧失；我国现行以心肺死亡为标准，脑死亡尚未立法。

### 4. 器官移植伦理
- **原则**：自愿、无偿（**禁止任何形式买卖**）、知情同意、非商业化、公平分配；
- **活体器官**：仅限**配偶、直系血亲或三代以内旁系血亲，或有帮扶等形成亲情关系**的人；
- 死亡判定：由**独立于移植团队的专家**进行。

### 5. 临床研究伦理
- 《赫尔辛基宣言》；**受试者知情同意、伦理委员会审查、风险收益评估、随时退出权**；
- 特殊人群（儿童、孕产妇、认知障碍）的保护。

## 三、卫生法律法规 ★★（占人文分值最大）

### 1. 《中华人民共和国医师法》（2022 年施行，替代原执业医师法）★
- ★ **医师资格考试与注册**：医师资格考试分执业医师资格考试和执业助理医师资格考试；**类别：临床、中医、口腔、公共卫生**；经注册后方可执业；
- ★ **执业规则**：
  - 按注册的执业地点、类别、范围执业；**实施医疗、预防、保健措施，签署有关医学证明文件，必须亲自诊查、调查**；
  - **不得**对危急患者拒绝急救处置；**不得隐匿、伪造、篡改或者擅自销毁病历**；
  - **如实向患者或家属介绍病情，但应注意避免对患者产生不利后果**（保护性医疗）；
  - **不得利用职务之便索要、收受财物或不正当利益**；不得出具虚假医学证明文件；
  - ★ **紧急救治义务**：对急危患者应当采取紧急措施进行诊治，不得拒绝急救处置；
- ★ **法律责任**：违法执业的处罚——警告、暂停执业（6 个月以上 1 年以下）、吊销执业证书（**受吊销医师执业证书处罚的，自处罚决定之日起至重新申请注册之日止不满 2 年的不得注册**）；构成犯罪的追究刑事责任。

### 2. 《医疗机构管理条例》（要点）
- **医疗机构的执业必须登记、取得《医疗机构执业许可证》**，按核准登记的诊疗科目开展诊疗；
- **手术、特殊检查、特殊治疗**：必须征得患者同意并签字；无法取得患者意见时，应取得家属或关系人同意并签字；**无法取得患者意见又无家属/关系人在场，或遇到特殊情况——经治医师应提出处置方案，在取得医疗机构负责人或被授权负责人批准后实施**；
- 未经批准不得擅自开展人类辅助生殖技术等特殊技术。

### 3. 《医疗纠纷预防和处理条例》与医疗事故 ★★
- ★ **医疗事故的分级**（原《医疗事故处理条例》）：
  - **一级**：造成患者死亡、重度残疾；
  - **二级**：造成患者中度残疾、器官组织损伤导致严重功能障碍；
  - **三级**：造成患者轻度残疾、器官组织损伤导致一般功能障碍；
  - **四级**：造成患者明显人身损害的其他后果；
- ★ **医疗事故技术鉴定**：由**医学会**组织（医疗纠纷的鉴定也可委托司法鉴定机构）；
- ★ **医疗损害责任（民法典）**：适用**过错责任**原则——医疗机构及其医务人员有过错的，由医疗机构承担赔偿责任；**推定过错情形**：①违反法律、法规、规章及诊疗规范的规定；②**隐匿或拒绝提供与纠纷有关的病历资料**；③**遗失、伪造、篡改或违法销毁病历资料**；
- ★ **病历管理**：患者有权查阅、复制其病历资料（门诊病历、住院志、医嘱单、检验报告、手术及麻醉记录等）；发生纠纷时病历封存；
- **处理途径**：双方自愿协商、人民调解、行政调解、诉讼；**协商中不得接受"闹赔"原则——赔偿数额争议大时建议走鉴定**。

### 4. 《传染病防治法》★★（高频）
- ★ **法定传染病分类（40 种）**：
  - **甲类（2 种）**：**鼠疫、霍乱**——强制管理；
  - ★ **乙类（按甲类管理的病种）**：**传染性非典型肺炎（SARS）、炭疽中的肺炭疽**，以及 **新型冠状病毒感染（按乙类甲管阶段曾实施）**；其他乙类：传染性非典型肺炎、艾滋病、病毒性肝炎、脊髓灰质炎、人感染高致病性禽流感、麻疹、流行性出血热、狂犬病、流行性乙型脑炎、登革热、炭疽、细菌性和阿米巴性痢疾、肺结核、伤寒和副伤寒、流行性脑脊髓膜炎、百日咳、白喉、新生儿破伤风、猩红热、布鲁氏菌病、淋病、梅毒、钩端螺旋体病、血吸虫病、疟疾、人感染 H7N9 禽流感等；
  - **丙类**：流行性感冒、流行性腮腺炎、风疹、急性出血性结膜炎、麻风病、流行性和地方性斑疹伤寒、黑热病、包虫病、丝虫病、其他感染性腹泻病、手足口病等。
- ★ **报告时限**：
  - **甲类及按甲类管理的乙类传染病（2 小时内）**：责任报告单位/人发现甲类传染病和乙类中按甲类管理的传染病病人或疑似病人，应于 **2 小时内**将传染病报告卡通过网络报告；未实行网络直报的责任报告单位应于 2 小时内以最快方式（电话/传真）报告并寄出报告卡；
  - **其他乙类、丙类（24 小时内）**：应于 **24 小时内**网络报告；
- ★ **甲类传染病的强制措施**：对病人、病原携带者**予以隔离治疗**，隔离期限根据医学检查结果确定；拒绝隔离治疗或隔离期未满擅自脱离隔离治疗的，可由公安机关协助医疗机构采取强制隔离治疗措施；
  - **乙类中按甲类管理的**同样执行上述措施；
  - 医疗机构发现甲类传染病时：对病人/病原携带者隔离治疗；对疑似病人**确诊前在指定场所单独隔离治疗**；对密切接触者在指定场所进行医学观察和采取其他必要措施；
- ★ **医疗机构职责**：不得漏报、缓报、瞒报；违反者追责。

### 5. 《疫苗管理法》与预防接种（要点）
- 疫苗分类：**免疫规划疫苗（免费、应接种）与非免疫规划疫苗（自费、自愿）**；
- 接种单位资质与"三查七对一验证"；
- **预防接种异常反应**的补偿机制。

### 6. 《母婴保健法》（要点）
- **婚前保健**：婚前卫生指导、咨询、医学检查（指定传染病、严重遗传性疾病、有关精神病为检查重点）；
- **孕产期保健**：产前检查、产前诊断（**胎儿患严重遗传性疾病、严重缺陷，或患严重疾病继续妊娠可能危及孕妇生命——医师应向夫妻双方说明，并提出终止妊娠的医学意见——**经双方同意**）；
- 终止妊娠/结扎手术：**本人同意并签字**；无行为能力者应取得其监护人同意。

### 7. 《精神卫生法》（要点）
- **自愿住院为原则**，**非自愿住院（"严重精神障碍且有伤害自身/危害他人安全的危险"）为例外**——需按法定程序评估；
- 不得以精神健康为由非法限制人身自由（"被精神病"违法）。

### 8. 《献血法》（要点）
- **国家实行无偿献血制度**；**献血年龄 18–55 周岁**（既往无献血反应、符合健康检查要求的多次献血者可延至 60 周岁）；**一次献血量 200–400 ml，间隔不少于 6 个月**；
- **医疗机构不得将无偿献血的血液出售**；临床用血应当符合用血管理要求，**不得浪费和倒卖**。

### 9. 《药品管理法》与处方管理（要点）
- **处方书写**：每张处方限于**一名患者**；处方须有医师**签名/专用签章**；**麻醉药品和第一类精神药品处方**用**淡红色**（麻醉/精一），第二类精神药品处方**淡绿色（精二为白色？——精二处方为白色）**，普通处方**白色**，急诊处方**淡黄色**，儿科处方**淡绿色**；
  - ★ 麻醉药品与第一类精神药品：**不得在药店零售**；处方**限量**——注射剂一次常用量（**控缓释制剂不超过 7 日常用量，其他剂型不超过 3 日常用量**——门诊患者一般不超过 3 日常用量；**癌痛/慢性中重度疼痛患者：**注射剂不超过 3 日常用量、控缓释制剂不超过 15 日常用量、其他剂型不超过 7 日常用量**）；
  - **麻醉药品处方保存 3 年，精神药品处方保存 2 年，普通处方 1 年**；
- **药品不良反应报告**：严重不良反应 15 日内报告，死亡病例立即报告。

### 10. 《人体器官捐献和移植条例》（要点）
- 器官捐献须**本人书面同意（自愿、无偿）**；本人未表示反对、去世后由配偶、成年子女、父母共同书面同意；
- **禁止买卖器官**；医疗机构不得摘取未满 18 周岁公民的活体器官。

## 四、人文情境题解题思路 ★★

**答题三步法：**
1. **定性**——题目情境的核心矛盾是什么（知情同意？隐私？急救义务？廉洁？）；
2. **找法/找原则**——优先适用明确法律条文，其次伦理四原则；
3. **选最佳**——在选项中选"既合法、又符合病人利益、又体现沟通"的那一项。

**常见情境速判：**

| 情境 | 最佳做法 |
|---|---|
| 患者拒绝治疗，病情危重 | 反复沟通解释风险，记录在案；无自主能力者由家属/法定程序决定；**紧急情况下按规定报批后可施救** |
| 家属要求隐瞒癌症病情 | 患者有知情权——评估患者承受力，**选择适当方式、逐步告知本人**；同时与家属沟通 |
| 朋友/熟人托查他人病历 | 拒绝；**患者隐私未经同意不得泄露** |
| 家属问及他人（同事/邻居）病情 | 拒绝提供；仅在患者授权或法律要求时提供 |
| 患者送红包 | 婉言谢绝并说明规定；实在无法退回的上交医院按规定处理 |
| 医药代表许诺回扣 | 严词拒绝并按规定报告；**不得利用处方权谋私** |
| 危重患者无法联系家属 | **急救第一：报机构负责人批准后立即救治**，同时继续联系家属、记录 |
| 发现同行误诊/错误治疗 | 以患者利益为先，内部规范渠道提醒/纠正；避免当众羞辱；必要时报上级 |
| 确诊传染病（肺结核/肝炎等） | **按法定时限和类别上报**；同时注意保护患者隐私（只报告规定内容和渠道） |
| 传染病患者不配合隔离 | 说明法律义务；拒绝者由公安机关协助强制隔离（甲类） |
| 术中才发现新情况需扩大手术 | **重新取得知情同意**（能联系到本人/家属时）；不能联系且紧急——按规定报批 |
| 患者要求查看自己的病历 | 有权查阅、复制；按规定程序提供 |
| 媒体要求提供患者信息 | 未经患者同意不得提供 |
| 实习生单独操作/签处方 | **禁止**；实习生必须在带教老师指导下执业，不得单独出具医学文书 |

## 五、速记汇总（考前必背）

| 项目 | 要点 |
|---|---|
| 伦理四原则 | 尊重（自主）、不伤害、有利、公正 |
| 知情同意四要素 | 告知充分＋理解有效＋自愿＋有行为能力 |
| 知情同意第一主体 | 患者本人（家属不能完全替代） |
| 紧急救治 | 不能取得意见→医疗机构负责人或授权负责人批准后实施 |
| 医患关系三模式 | 主动-被动（昏迷）、指导-合作（急性）、共同参与（慢病） |
